# T-204.3 — Pinia store: voice-handy.ts

## Requirement

Create `apps/desktop/src/stores/voice-handy.ts`:

- Refs: `installed: boolean | null`, `running: boolean`, `enabled: boolean`, `path: string | null`
- `check()` action: calls `window.electronAPI.voiceCheck()`, updates refs
- `launch()` action: calls `window.electronAPI.voiceLaunch()`, re-checks after 2s delay
- 5-second `setInterval` poll while window has focus (`document.hasFocus()`)
- `enabled` persisted via localStorage using existing `readStorageValue`/`persistPreference` pattern
- Guard: if `window.electronAPI?.voiceCheck` is undefined, store is inert (web mode)

## Acceptance criteria

1. Store initializes on app mount and detects Handy status
2. Green running status updates within 5s of Handy launch/quit
3. Enabled toggle persists across app restart
4. No errors in web mode (graceful degradation)
