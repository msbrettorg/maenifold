# T-178.8d — Color token + shadow sweep (non-primitive components)

**Pipeline**: lightweight
**Pipeline Digest**: tbd

## Objective

Replace all non-tokenized rgba/hex color literals and non-Fluent shadows across application components (not shadcn primitives — those are T-178.8c).

## Grounding

Audit: `docs/DESIGN-AUDIT.md` findings #137–219 (color-token), #126–136 (shadow)
Design system: `apps/desktop/DESIGN.md`

## Scope — 65+ color violations + 24 shadow violations

### Color token fixes (by file)
Every `rgba(` and `#hex` literal in `.vue` and `.css` files outside `components/ui/` must be replaced with the appropriate CSS variable from DESIGN.md token table.

Key patterns:
- `rgba(173, 198, 255, ...)` → remove (Obsidian brand glow)
- `rgba(77, 142, 255, 0.4)` → `var(--color-brand)` focus ring
- `rgba(0, 0, 0, 0.6)` → `var(--color-bg-overlay)`
- `rgba(255, 255, 255, 0.1)` → `var(--color-border-card)` or `var(--color-bg-elevated)`
- `var(--blue)` → `var(--color-brand)`
- Hard-coded `#hex` values → map to nearest Fluent token

### Shadow fixes
- Remove all `box-shadow` with brand-tinted rgba (ambient glow)
- Replace with Fluent tokens: `var(--shadow-8)`, `var(--shadow-16)`, `var(--shadow-64)`

### Glass effect removal (3 instances)
- Delete all `backdrop-filter: blur(...)` — replace with solid Fluent surface + shadow

### Radius normalization (40+ instances)
- `2px` → `4px`
- `3px` → `4px`
- `6px` → `8px` (unless `999px` pill)
- Any value not in {4, 8, 12, 999} → nearest scale value

## Acceptance Criteria

1. Zero `rgba(` literals outside CSS variable definitions in `assets/tailwind.css`
2. Zero `var(--blue)` references
3. Zero `backdrop-filter: blur` usage
4. All `border-radius` values on the 4/8/12/999 scale
5. `npx vue-tsc --noEmit` passes
6. `npm run build` succeeds
