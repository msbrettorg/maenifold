# T-63.14 — Unified Input System + Focus Styles

**Requirement**: FR-7
**Test Cases**: TC-17, TC-18
**Repo**: pipeline-ui
**Component**: src/App.vue, src/components/AddNodeForm.vue, src/components/PipelineInspector.vue, src/components/PipelineRunner.vue

## Context

3 different input styles across components. Zero `:focus` styles on any input. Accessibility violation: users can't tell which field is focused.

## Acceptance Criteria

1. T-63.0 defines `.field-input`, `.field-select`, `.field-textarea` in App.vue. This spec MIGRATES all components to use them.
2. **AddNodeForm.vue**: Replace all inline input/select/textarea styles with `.field-input` / `.field-select` / `.field-textarea`
3. **PipelineInspector.vue**: Replace all inline input/select styles with `.field-input` / `.field-select`
4. **PipelineRunner.vue**: Replace prompt textarea styles with `.field-textarea`
5. Every `<input>`, `<select>`, and `<textarea>` element uses a shared `.field-*` class
6. Focus ring is visible: `:focus-visible` applies `outline: 2px solid var(--border-focus); outline-offset: 2px`
7. ZERO inline `background`, `border`, `border-radius`, `padding`, `font-size` on any form control
8. Typecheck passes: `npx vue-tsc --noEmit`

## SWE Remediation

PASS. Migrated AddNodeForm, PipelineInspector, and PipelineRunner form controls to shared .field-input/.field-select/.field-textarea classes, removed duplicated form-control CSS, and verified vue-tsc passes.
