## Problem

`apps/desktop/src/composables/__tests__/useMcpResources.test.ts` (multiple
timeouts) fail on `dev` HEAD before any other changes. Discovered while
verifying the auth-strip work (sprint 242.11 successor — code-level auth
removal). Failures are unrelated to that strip and pre-date it.

```bash
cd apps/desktop
npx vitest run src/composables/__tests__/mcpStateless.test.ts
# Test Files  1 failed (1)
# Tests       8 failed (8)
```

## Investigation Required

1. Determine when the failures were introduced (`git log --oneline apps/desktop/src/composables/__tests__/mcpStateless.test.ts`).
2. Diagnose whether the SDK's `StreamableHTTPClientTransport` behaviour drifted
   from what the tests assert, or whether the tests' fetch mocks no longer
   match the SDK's request shape.
3. Either fix the composables or update the tests to reflect the current
   contract — do not delete tests.
