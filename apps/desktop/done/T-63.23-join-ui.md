# T-63.23 — Join UI: Merge Pipelines

**Requirement**: FR-5
**Test Cases**: TC-13
**Repo**: pipeline-ui
**Component**: src/components/PipelineView.vue

## Context

Join merges another pipeline session into the current one by defining connecting edges. Advanced feature — the UI needs to let users specify which pipeline to merge and how to connect it.

## Acceptance Criteria

1. Add "Join Pipeline" button in `PipelineView.vue`, visible when a pipeline is loaded
2. Button opens a dialog with:
   - Source pipeline session ID input (text field)
   - Edge definition: list of source→target edge pairs, where source comes from the source pipeline and target from the current pipeline
   - Add/remove edge rows
3. On submit, calls `store.joinPipeline(currentSessionId, sourceSessionId, edges)`
4. After successful join, refreshes the pipeline view
5. Dialog uses `.field-input` classes and `.btn-primary` / `.btn-ghost` buttons
6. Include input validation: at least one edge required, no empty IDs
7. Typecheck passes: `npx vue-tsc --noEmit`

## Swe Notes

PASS. Added JoinPipelineDialog with source session + dynamic edge rows + validation, wired submit to store.joinPipeline(...) and refresh flow, and passed vue-tsc.
