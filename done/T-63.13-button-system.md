# T-63.13 — Unified Button System

**Requirement**: FR-6
**Test Cases**: TC-15
**Repo**: pipeline-ui
**Component**: src/App.vue, src/components/AddNodeForm.vue, src/components/PipelineRunner.vue, src/components/PipelineInspector.vue, src/components/PipelineSidebar.vue, src/components/PipelineComposer.vue

## Context

5 incompatible button systems across components. Each component defines its own button styles inline, with inconsistent padding, radius, colors, and state handling.

## Acceptance Criteria

1. T-63.0 defines `.btn` base + variants in App.vue. This spec MIGRATES all existing components to use them.
2. **AddNodeForm.vue**: Replace inline button styles with `.btn-primary` (submit), `.btn-ghost` (cancel)
3. **PipelineRunner.vue**: Replace inline styles with `.btn-success` (run), `.btn-pause` (pause), `.btn-primary` (resume), `.btn-danger` (cancel/delete)
4. **PipelineInspector.vue**: Replace inline styles with `.btn-primary` (restart), `.btn-danger` (abandon), `.btn-ghost` (complete)
5. **PipelineSidebar.vue**: Replace inline styles with `.btn-ghost` (sidebar items), `.btn-outline-danger` (delete)
6. **PipelineComposer.vue**: Replace toolbar button styles with `.btn-ghost` or `.btn-primary` as appropriate
7. ZERO inline `background`, `border`, `border-radius`, `padding` on any `<button>` element — all from `.btn` classes
8. All buttons have `:hover`, `:disabled`, `:focus-visible` states from the shared classes
9. Typecheck passes: `npx vue-tsc --noEmit`

## SWE Remediation

PASS. Migrated AddNodeForm, PipelineRunner, PipelineInspector, PipelineSidebar, and PipelineComposer buttons to shared .btn variants, removed local button chrome overrides, and verified vue-tsc + button-style grep checks.
