# T-67.6 — Border Elimination: Pipeline Components

**Requirement**: FR-28
**Phase**: 2

## Context
Pipeline-specific components (PipelineNodeCard, PipelineInspector, PipelineComposer, PipelineRunner, PipelineSidebar) have ~35 border declarations.

## Acceptance Criteria
1. All `1px solid` structural borders removed from pipeline component `<style>` blocks
2. Node card borders replaced with tonal layering (`--surface-container-highest` against `--surface-container`)
3. Inspector section dividers replaced with spacing or background shifts
4. Runner panel boundaries use tonal layering
5. Accent borders on node cards normalized to 4px (currently some use 3px)
6. `npx vue-tsc --noEmit` passes
