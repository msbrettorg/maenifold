# T-219.1 — Gate Done Tab Row Click Does Not Update Detail Panel

## Problem

Clicking a row in the Gate tab's Done sub-tab does not update the detail panel on the right. The detail panel remains frozen on the last Todo-tab selection. This means users cannot inspect completed task specs, history, or acceptance notes from the Done view.

## Reproduction

1. Open Gate tab
2. Click any Todo row — detail panel updates correctly
3. Switch to Done tab
4. Click any Done row — detail panel does NOT update, stays on previous Todo selection

## Evidence

CDP interactive testing in packaged Electron (2026-04-24):
- Clicked T-218.12 in Done tab → detail panel still shows T-218.5 (last Todo selection)
- Screenshot: `outputs/screenshots/sprint-219/gate-done-tab-detail-not-updating.png`

## Acceptance Criteria

- [ ] Clicking a Done tab row updates the detail panel to show that task's spec and history
- [ ] Clicking a Todo tab row continues to work as before
- [ ] Clicking an All tab row works for both todo and done tasks
- [ ] Switching between Todo/Done/All tabs preserves the last clicked row's detail (or clears it)
