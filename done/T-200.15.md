# T-200.15 — Edge-case unit tests for TaskSectionParser::parse()

## Intent

`task_sections.rs` (105 LOC) contains the parser that reads gate stage records from task markdown files. It has no direct unit tests. The roundtrip tests in `section_factory.rs` cover the happy path but don't test edge cases where the parser encounters non-gate content, missing fields, or mixed sections.

## Scope

File to modify:
- `crates/maenifold-gate/src/task_sections.rs` — add `#[cfg(test)]` module

## Test Plan

### Tests to add:

1. **`non_gate_section_produces_no_records`** — Lines like `## Acceptance Criteria\n\n1. valid login` should produce 0 records

2. **`missing_required_field_returns_error`** — A section with `- Stage ID: swe` and `- Record Kind: outcome` but missing `- Agent:` should return an error

3. **`multiple_sections_parse_independently`** — Two consecutive gate sections (each with full fields) produce 2 records

4. **`unknown_fields_are_silently_ignored`** — A section with standard gate fields plus `- Custom: value` should parse successfully, ignoring the extra field

5. **`mixed_gate_and_non_gate_sections`** — Lines containing `## Acceptance Criteria` (non-gate) followed by `## SWE` (gate section with fields) produces exactly 1 record

## Acceptance Criteria

1. `cargo build --release -p maenifold-gate` succeeds
2. `cargo test -p maenifold-gate` passes (all existing + new tests)
3. All 5 new tests pass
4. No production code changes
5. Only `task_sections.rs` is modified
