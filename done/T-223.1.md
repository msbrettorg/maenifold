# T-223.1 - Agents provider/model picker does not scroll

## Problem

On the Agents tab, the provider/model selection menu does not scroll when the option list exceeds the visible popover height. Lower provider or model entries become unreachable, so the user cannot inspect or select the full list from the UI.

## Evidence

- User screenshot report from this session: `Screenshot 2026-04-25 at 11.12.41 AM.png`.
- `docs/UAT-PLAN.md:884-887` - agent dropdown must open, allow selection, close on escape, and support arrow-key navigation.
- `docs/UAT-PLAN.md:1142-1152` - dropdowns must render above siblings and overflowing lists/cards must scroll instead of clipping.
- Prior selector/model surface work: `done/T-176.4a-chat-input-core-model-selector.md`.

## Acceptance Criteria

- [ ] Provider/model menus scroll when the rendered option list exceeds available height.
- [ ] The last visible option in the full provider/model list is reachable by mouse wheel, trackpad, and keyboard navigation.
- [ ] Opening the menu does not clip or trap options behind adjacent UI.
- [ ] Existing selection behavior still works after the scroll fix.
- [ ] `cd apps/desktop && npx vue-tsc --noEmit` succeeds.
