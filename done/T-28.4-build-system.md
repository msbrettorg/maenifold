# T-28.4: Wire Build System

**Requirement**: FR-39 (Replace chrome-acp with ACP UI)

## Context

The build system currently points at `vendor/chrome-acp/packages/proxy-server/public` for the SPA assets. We need to update all references to point at `vendor/acp-ui/dist`.

## Acceptance Criteria

1. **`crates/maenifold-core/build.rs`** — change vendor path from `../../vendor/chrome-acp/packages/proxy-server/public` to `../../vendor/acp-ui/dist`

2. **`Makefile`** — `web-assets` target becomes:
   ```make
   web-assets:
   	cd vendor/acp-ui && bun install && bun run build
   ```

3. **`make web-assets`** succeeds — produces `vendor/acp-ui/dist/index.html`

4. **`make web-build`** succeeds — produces release binary with embedded SPA

5. **`make`** (default target, if any) still works

6. **No references to `chrome-acp` remain** in Makefile, build.rs, Cargo.toml, or any build-related file
