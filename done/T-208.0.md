# T-208.0 — repo_dogfood tests fail: T-205.7xx tasks use unregistered 'test' pipeline

## Problem

All 4 `repo_dogfood` integration tests fail because `done/T-205.7xx` task files use `**Pipeline**: test`, which is not a registered builtin gate pipeline.

### Failure Chain

1. `repo_dogfood` tests copy all `todo/` and `done/` task files to a temp directory
2. `gate sync --root <temp> --rebuild` runs on the temp dir
3. For T-205.7xx tasks, `GateDefinitionCatalog::resolve(root, "test")` is called
4. `test` is not in `RESERVED_BUILTIN_NAMES` (`gate_catalog.rs` line 10)
5. Falls to `load_builtin_inner("test")` which tries to read `<gates_dir>/test.json`
6. File doesn't exist → `io error: No such file or directory (os error 2)`
7. Gate reports the task as errored, and the test assertion (`sync --rebuild` exits 0) fails

### Failing Tests

- `sync_rebuild_succeeds_for_shipped_repo_tasks`
- `status_loads_every_shipped_repo_task`
- `status_respects_frontmatter_done_state_for_repo_tasks`
- `status_uses_canonical_frontmatter_id_for_repo_task`

## Acceptance Criteria

1. All 4 `repo_dogfood` tests pass: `cargo test -p maenifold-gate --test repo_dogfood`
2. T-205.7xx task files either use a valid builtin pipeline name OR the `test` pipeline is registered as a builtin
3. No regression in other gate tests (142 unit tests + other integration tests)

## Implementation (Option A: register `test` as builtin)

The `test` pipeline is a real single-stage pipeline used for Sprint 205 UAT bug fixes: pending → done.

### Changes Required

**1. Create `crates/maenifold-gate/assets/test.json`:**
```json
{
  "schemaVersion": 1,
  "id": "test",
  "name": "Test",
  "initial": "pending",
  "states": {
    "pending": {
      "on": {
        "pass": "done"
      }
    },
    "done": {
      "terminal": true
    }
  }
}
```

**2. `crates/maenifold-gate/src/gate_catalog.rs`:**
- Line 10: Add `"test"` to `RESERVED_BUILTIN_NAMES` array
- After line 18: Add `const TEST_JSON: &str = include_str!("../assets/test.json");`
- After line 120 (in `builtin_asset_text` match): Add `"test" => Ok(TEST_JSON),`

### File Scope
- `crates/maenifold-gate/assets/test.json` (new)
- `crates/maenifold-gate/src/gate_catalog.rs` (3 edits)
