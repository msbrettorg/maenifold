# T-210.3 — Message Handler

## Description

Process Teams message notifications from the Trouter client:

1. Extract message content (strip HTML)
2. Match against configured keywords (case-insensitive, word boundary)
3. Filter by sender (allow-list or deny-list)
4. Apply cooldown (rate-limit matching to prevent notification storms)
5. On match → emit event for ACP session dispatch (T-210.6)

## Key Files

- Create: `crates/maenifold-core/src/teams/handler.rs`

## Acceptance Criteria

- Keyword matching with word boundaries
- Sender filtering
- Configurable cooldown period
- Clear match/no-match event emission
- `cargo build --release -p maenifold-core` succeeds
