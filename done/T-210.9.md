# T-210.9 — MSAL Auth for Teams

## Description

Implement Azure AD authentication for the Trouter client:

1. Device code flow (user visits URL + enters code)
2. Token stored in OS keychain/credential store
3. Automatic token refresh
4. Token revocation on sign-out
5. Status exposed via teams://status resource

- Token stored securely

- Expired token triggers re-auth prompt
- `cargo build --release -p maenifold-core` succeeds
