# T-67.13 — FLIP Animation Composable

**Requirement**: FR-35
**Phase**: 3

## Context
No FLIP animation utilities exist in the codebase. Need a composable that captures a source element's rect, then animates an overlay from that position to a target position.

## Acceptance Criteria
1. New composable `src/composables/useFlipAnimation.ts` created
2. API: `useFlipAnimation()` returns `{ captureSource(el: HTMLElement): DOMRect, animateToTarget(overlayEl: HTMLElement, sourceRect: DOMRect, targetRect: DOMRect, duration?: number): Promise<void> }`
3. Animation uses `transform: translate() scale()` with `cubic-bezier(0.4, 0, 0.2, 1)` easing
4. Default duration: 350ms
5. Uses `requestAnimationFrame` for FLIP inversion, CSS transitions for playback
6. Returns a Promise that resolves when animation completes (via `transitionend` listener)
7. `npx vue-tsc --noEmit` passes
8. Composable stays under 80 LOC

## Files
