# T-28.2: Strip Tauri from ACP UI SPA

**Requirement**: FR-39 (Replace chrome-acp with ACP UI)

## Context

ACP UI (formulahendry/acp-ui) is a Vue 3 + Vite SPA wrapped in a Tauri desktop shell. We need to extract the pure web SPA by removing all Tauri dependencies and replacing them with browser-native equivalents.

The SPA lives at `vendor/acp-ui/`. The Tauri coupling is contained in exactly 4 files:

| File | Tauri Usage | Replacement |
|------|-------------|-------------|
| `src/lib/tauri.ts` | `invoke()` for spawn/send/kill/config, `listen()` for events | New `src/lib/relay.ts` — WebSocket adapter |
| `src/lib/acp-bridge.ts` | `@tauri-apps/plugin-fs` (readTextFile/writeTextFile) | Remove fs calls or use fetch |
| `src/App.vue` | `@tauri-apps/plugin-dialog` (folder picker), `@tauri-apps/plugin-store` (prefs) | Text input + localStorage |
| `src/stores/session.ts` | `@tauri-apps/plugin-store` (sessions), `getVersion()` | localStorage |

All 13 Vue components in `src/components/` are Tauri-free.

## Acceptance Criteria

1. **`src/lib/relay.ts` created** — replaces `tauri.ts` with a WebSocket adapter that:
   - Connects to `ws://${location.host}/ws/acp?agent=${selectedAgent}`
   - Exposes `getConfig()` that fetches `GET /api/agents` and returns agent list
   - Exposes `sendToAgent(agentId, message)` that sends JSON-RPC over WebSocket
   - Exposes `onAgentMessage(callback)` that receives JSON-RPC from WebSocket
   - Exposes `killAgent(agentId)` that closes the WebSocket
   - Exposes `spawnAgent(name)` that opens the WebSocket connection
   - Event listeners: `onAgentMessage`, `onAgentClosed`, `onAgentStderr`, `onConfigChanged`

2. **`src/lib/tauri.ts` deleted**

3. **`src/lib/acp-bridge.ts` updated** — no `@tauri-apps/plugin-fs` imports. Any file read/write calls removed or replaced with fetch to server endpoints.

4. **`src/App.vue` updated**:
   - No `@tauri-apps/plugin-dialog` — folder picker replaced with a text `<input>` bound to `workingDirectory`
   - No `@tauri-apps/plugin-store` — preferences stored in `localStorage`

5. **`src/stores/session.ts` updated**:
   - No `@tauri-apps/plugin-store` — sessions stored in `localStorage`
   - No `@tauri-apps/api/app` — version hardcoded or fetched from server

6. **`package.json` updated** — all `@tauri-apps/*` deps removed from dependencies and devDependencies

7. **`src-tauri/` directory deleted** (entire Tauri Rust backend)

8. **`vite.config.ts` updated** — Tauri Vite plugin removed, `base: '/'` set

9. **`bun install && bun run build` succeeds** — produces `dist/index.html` + `dist/assets/`

10. **Zero `@tauri-apps` imports remain anywhere** in `src/`

## SWE Remediation

### What I changed

- `vendor/acp-ui/src/lib/relay.ts`
  - Added a browser-native relay adapter that fetches agents from `GET /api/agents`, opens `ws://${location.host}/ws/acp?agent=...` connections, sends arbitrary JSON payloads over WebSocket, and exposes `onAgentMessage`, `onAgentClosed`, `onAgentStderr`, and `onConfigChanged` listeners.
- `vendor/acp-ui/src/lib/tauri.ts`
  - Deleted the Tauri IPC wrapper.
- `vendor/acp-ui/src/lib/acp-bridge.ts`
  - Switched transport imports from `tauri.ts` to `relay.ts`.
  - Removed `@tauri-apps/plugin-fs` usage.
  - Kept ACP client file APIs as explicit unsupported browser errors so the bridge no longer performs local filesystem access.
- `vendor/acp-ui/src/App.vue`
  - Replaced the Tauri folder picker with a plain text working-directory input.
  - Replaced preference persistence with `localStorage`.
- `vendor/acp-ui/src/stores/session.ts`
  - Replaced Tauri store persistence with `localStorage` session storage.
  - Removed Tauri app version lookup and hardcoded the app version to `0.1.10`.
  - Stopped advertising browser file-system capabilities during ACP initialize.
- `vendor/acp-ui/src/stores/config.ts`
  - Switched config loading and hot-reload wiring to the new relay adapter.
- `vendor/acp-ui/src/lib/types.ts`
  - Updated agent/config types to support the web relay’s `/api/agents` response and generic WebSocket messages.
- `vendor/acp-ui/src/lib/telemetry.ts`
  - Replaced Tauri machine ID lookup with a browser-local `localStorage` machine ID via `relay.ts`.
- `vendor/acp-ui/src/components/SettingsView.vue`
  - Simplified settings to a read-only server-provided agent list so the SPA no longer depends on Tauri-only config mutation APIs.
- `vendor/acp-ui/src/components/AgentSelector.vue`
  - Updated empty-state copy to reference the relay endpoint instead of a local config file.
- `vendor/acp-ui/package.json`
  - Removed all `@tauri-apps/*` dependencies and the Tauri script.
- `vendor/acp-ui/vite.config.ts`
  - Simplified Vite config and set `base: '/'`.
- `vendor/acp-ui/src-tauri/`
  - Deleted the Tauri backend directory.

- The web build now treats agent configuration as backend-owned/read-only because the provided HTTP surface only exposes `GET /api/agents`.
- `bun install` generated `vendor/acp-ui/bun.lock` and retained the existing `package-lock.json` file in the vendor repo.
