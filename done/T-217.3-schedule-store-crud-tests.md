## Scope

## Tests to Add

1. **Create + read round-trip** — create a ScheduledTask, read it back, fields match
2. **Duplicate create** — creating same ID twice returns error
3. **Update existing** — update fields, read back, verify changes persisted
4. **Delete existing** — create, delete, read returns not-found
5. **Delete nonexistent** — returns error, not panic
6. **List with mixed valid/invalid** — create 2 valid tasks + write a malformed JSON file, `list()` returns 2 valid and skips malformed
7. **Invalid schedule ID** — IDs with path traversal (`../foo`) or special chars rejected
8. **Exists check** — returns true after create, false after delete
