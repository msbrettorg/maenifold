# T-214.12 — Add session node to pipeline

## Problem

Users need a way to add session-backed prompt nodes to a pipeline from the pipeline composer.

## Solution

Add "Add session node" to the pipeline canvas context menu (right-click):

1. Opens a session picker (mini version of SessionBrowserPanel)
2. User selects agent + session
3. Creates a prompt node pre-filled with `sessionRef: { agent, sessionId }`
4. Node placed at cursor position
5. Drag-and-drop deferred to later phase

## Key Files

- Pipeline canvas context menu component
- Session picker dialog/popover

## Acceptance Criteria

- Context menu shows "Add session node" option
- Session picker lists available sessions
- Selected session creates properly configured prompt node
- Node appears on canvas with session visual treatment
- TypeScript clean
