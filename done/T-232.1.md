## Summary

Add `EasterEggsSettings` and `WallpaperSettings` config structs to support the wallpaper slideshow feature. Follow the `gateway_settings.rs` extraction pattern — new file, not additions to `settings.rs` (already at 288 LOC).

## Implementation

### 1. Create `crates/maenifold-core/src/acp/config/easter_eggs.rs`

New file with these structs:

```rust
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Default)]
#[serde(rename_all = "camelCase")]
pub struct EasterEggsSettings {
    #[serde(default)]
    pub wallpaper: WallpaperSettings,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "camelCase")]
pub struct WallpaperSettings {
    #[serde(default)]
    pub enabled: bool,
    #[serde(default = "default_mode")]
    pub mode: String,
    #[serde(default = "default_prompt")]
    pub prompt: String,
    #[serde(default)]
    pub azure: WallpaperAzureSettings,
    #[serde(default = "default_size")]
    pub size: String,
    #[serde(default = "default_quality")]
    pub quality: String,
    #[serde(default)]
    pub continuity: bool,
    #[serde(default = "default_input_fidelity")]
    pub input_fidelity: String,
    #[serde(default = "default_max_retries")]
    pub max_retries: u32,
    #[serde(default = "default_community_count")]
    pub community_count: u32,
    #[serde(default = "default_rotate_minutes")]
    pub rotate_minutes: u32,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "camelCase")]
pub struct WallpaperAzureSettings {
    #[serde(default = "default_endpoint_env_var")]
    pub endpoint_env_var: String,
    #[serde(default = "default_api_key_env_var")]
    pub api_key_env_var: String,
    #[serde(default = "default_image_model")]
    pub image_model: String,
    #[serde(default = "default_small_model")]
    pub small_model: String,
    #[serde(default = "default_reasoning_model")]
    pub reasoning_model: String,
}
```

Include `Default` impls and default functions matching the T-227.1 spec defaults:
- `mode`: `"endophasia"`
- `prompt`: `"Generate an image of what's top of mind."`
- `size`: `"1536x1024"`
- `quality`: `"low"`
- `input_fidelity`: `"medium"`
- `max_retries`: `3`
- `community_count`: `10`
- `rotate_minutes`: `5`
- Azure env vars: `"AZURE_OPENAI_ENDPOINT"`, `"AZURE_OPENAI_API_KEY"`
- Azure models: `"gpt-image-2"`, `"gpt-5.4-mini"`, `"gpt-5.4"`

### 2. Wire into `settings.rs`

Add to `settings.rs`:
- `use super::easter_eggs::EasterEggsSettings;` (import)
- `#[serde(default)] pub easter_eggs: EasterEggsSettings,` field on `MaenifoldSettings`
- `easter_eggs: EasterEggsSettings::default(),` in `Default` impl

### 3. Wire into parent module `config.rs`

**IMPORTANT:** There is no `mod.rs`. The parent module is `crates/maenifold-core/src/acp/config.rs`, which uses explicit `#[path]` attributes due to its own mounting. Follow the `gateway_settings` pattern exactly:

```rust
#[path = "config/easter_eggs.rs"]
mod easter_eggs;
pub use easter_eggs::*;
```

Add these alongside the existing `gateway_settings` declarations.

### 4. Update test fixture in `tests.rs`

`crates/maenifold-core/src/acp/config/tests.rs` contains `expected_settings()` which builds a full `MaenifoldSettings` struct literal. Add `easter_eggs: EasterEggsSettings::default(),` to that fixture so `cargo test -p maenifold-core` continues to compile.

### 5. Add TypeScript types

Add the corresponding TypeScript interface to `apps/desktop/src/lib/types.ts` so the frontend can type-safely access the new config section:

```typescript
export interface EasterEggsSettings {
  wallpaper: WallpaperSettings;
}

export interface WallpaperSettings {
  enabled: boolean;
  mode: string;
  prompt: string;
  azure: WallpaperAzureSettings;
  size: string;
  quality: string;
  continuity: boolean;
  inputFidelity: string;
  maxRetries: number;
  communityCount: number;
  rotateMinutes: number;
}

export interface WallpaperAzureSettings {
  endpointEnvVar: string;
  apiKeyEnvVar: string;
  imageModel: string;
  smallModel: string;
  reasoningModel: string;
}
```

Add `easterEggs?: EasterEggsSettings;` to the existing `MaenifoldSettings` interface.
