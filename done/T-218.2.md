# T-218.2 — Gate Tab Resizable Splitter

## Problem

The Gate tab has a fixed layout split between the task table (left) and task detail pane (right). Two issues:

1. **No resize handle** — the user cannot adjust the split ratio between the table and detail. The table columns ("Progress" especially) are truncated with ellipsis, while the detail pane has ample horizontal space.
2. **Text overflow in table** — the Progress column renders section headings ("Part a rust integration tes...", "Architecture duo reviewe...") that truncate without any way to see the full text.

## Solution

Add a draggable horizontal splitter between the task table and detail pane. Both sides resize when the user drags the splitter. Persist the split ratio to localStorage so it survives navigation.

## Acceptance Criteria

- [ ] Draggable vertical divider between table and detail pane
- [ ] Both panes resize proportionally when divider is dragged
- [ ] Split ratio persisted across tab switches and app restarts
- [ ] Minimum width enforced on both panes (e.g., 300px table, 400px detail)
- [ ] Cursor changes to `col-resize` on hover over the divider
- [ ] Detail pane text wraps within its container — no horizontal overflow
- [ ] Verified via CDP in packaged Electron app
