Keep the desktop Gate detail flow complete while routing through native `maenifold.gate` [[MCP]] tools. ## Acceptance Criteria

- Selecting a task still displays parsed task body content from `gate_TaskBody`.
- Selecting a task still displays gate history from `gate_History`.
- Metadata, stages, progress, task table selection, and history states still render.
- Errors distinguish main maenifold connection failures from `maenifold.gate` command failures.
- Components do not reference standalone [[gate-service]] configuration.

## Verification Commands

- `cd apps/desktop && npm run build`
- `cd apps/desktop && npm run test -- Gate`
- `cd apps/desktop && npm run test -- gate-task-body`

## UI Verification Requirement

Use the packaged Electron app and `agent-browser`. Click Gate tab, choose/confirm a root, refresh, select a todo task, confirm body renders, confirm history renders, select a done task if available, and capture screenshots under `outputs/screenshots/sprint-237/`.

## Non-Goals

- Do not redesign Gate visuals.
- Do not remove or hide body/history sections to simplify the migration.
- Do not add `gate_Cancel`.
