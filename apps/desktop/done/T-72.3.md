# T-72.3 — App view-switch fade transitions

**Pipeline**: mdd
**Pipeline Digest**: b826a880e632e457a4be2a8cbfabf45b8434090f1df1416e349cb1f9700565df
**Requirement**: UX-POLISH-72 — View switches should fade smoothly instead of snapping
**Component**: `src/App.vue`, `src/assets/app-panels.css`

## Context

The main content area in App.vue uses a `v-if`/`v-else-if` chain to switch between ChatView, WorkflowAuthoringPage, PipelineView, GateView, and the welcome screen. Currently these snap instantly, which feels jarring.

## Acceptance Criteria

1. The v-if/v-else-if chain in App.vue main content is wrapped with `<Transition name="view-fade" mode="out-in">`.
2. CSS classes `.view-fade-enter-active`, `.view-fade-leave-active` use `transition: opacity 200ms var(--easing-standard)`.
3. `.view-fade-enter-from`, `.view-fade-leave-to` set `opacity: 0`.
4. Vue `<Transition>` requires a single child — each branch in the v-if chain must be the direct child, or use a wrapper `<div>` with a unique `key`.
5. The transition does NOT cause layout shift — exiting view fades out, entering view fades in.
6. Animation is disabled by the global `prefers-reduced-motion` policy (T-72.1).
7. `npx vue-tsc --noEmit` passes.

## Dependencies

- T-72.1 (reduced-motion policy must exist first)
- Must complete before T-72.6 (both touch App.vue / app-panels.css)
