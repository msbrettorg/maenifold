# T-42.5: Tool Call Content

**Requirement**: FR-42.5  
**Priority**: P1  
**Files**: `vendor/acp-ui/src/lib/types.ts`, `vendor/acp-ui/src/stores/session.ts`

## Acceptance Criteria

1. Add `content` field to `ToolCallInfo` type in `types.ts`:
   ```ts
   export interface ToolCallInfo {
     toolCallId: string;
     title: string;
     kind: string;
     status: 'pending' | 'in_progress' | 'completed' | 'failed' | 'cancelled';
     locations?: { path: string; line?: number }[];
     content?: Array<{ type: string; [key: string]: unknown }>;
   }
   ```
   Note: `line` added to locations, `cancelled` added to status, `content` is new.

2. In the `tool_call` case of `handleSessionUpdate` (~L170), store `update.content` if present:
   ```ts
   content: update.content ?? undefined,
   ```
   In both the message-level entry and the global `toolCalls` map entry.

3. In the `tool_call_update` case (~L195), accumulate content and update locations:
   ```ts
   if (update.content?.length) {
     existing.content = [...(existing.content ?? []), ...update.content];
   }
   if (update.locations) {
     existing.locations = update.locations;
   }
   ```
   Also propagate into matching entries in `messages.value[].toolCalls[]`.
