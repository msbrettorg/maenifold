# T-218.13 — Blue-Team Acceptance Evidence Matrix

## Problem

Blue-team notes frequently record build/test success without mapping evidence to each acceptance criterion. A task can move to done while its user-facing acceptance criteria remain unverified.

## Acceptance Criteria

- [ ] Define required blue-team note format: commands run, test/build result, acceptance criterion checklist, artifact links, and explicit unverified items
- [ ] Add a lint/audit pass over recent done tasks identifying nonconforming blue-team notes
- [ ] Reject future blue-team passes that only say "build passes", "verified clean", or "red-team confirmed" for tasks with multiple acceptance criteria
- [ ] Apply the audit specifically to T-05.66, T-05.70, T-05.85, T-204.4, T-214.12, and T-214.13
- [ ] Document how blue-team records blocked or partially verified acceptance criteria without passing the stage
