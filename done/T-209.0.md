## Problem

RALPH (ralph.sh) runs a single PM agent that manually dispatches SWE/red-team/blue-team agents, manages worktrees, and sequences gate stages. The PM is a sequential bottleneck: it holds context for N parallel tasks in one LLM brain, which costs tokens and turn latency. The maenifold pipeline engine already does parallel scheduling, retries, failure cascading, crash recovery, and conditional routing — but it's only been used for research/thinking workflows, not gate delivery.

## Solution

`pipeline-meta.sh` — a new execution loop that uses the pipeline engine itself to execute gate tasks as DAGs. Each gate task becomes a pipeline with prompt nodes (SWE, red-team, blue-team), tool nodes (gate pass/fail), and conditional edges (red-team PASS → blue-team, FAIL → remediate). The meta layer optimizes pipeline templates based on measured outcomes.

## Architecture (duo-reviewed by opus-4.7 + gpt-5.4)

### Division of labor

| Concern | Owner |
|---------|-------|
| Task selection, worktree create/cleanup, git merge | Shell (`pipeline-meta.sh`) |
| SWE/red/blue dispatch, retries, conditional routing | Pipeline engine |
| Gate stage transitions (pass/fail) | Tool nodes inside the pipeline |
| Template optimization | Meta-agent (outer loop) |

### Pipeline template (SDD example)

```
setup → swe → red_team →(PASS)→ blue_team → gate_pass → cleanup
                        →(FAIL)→ remediate → red_team_reaudit →(PASS)→ blue_team → gate_pass → cleanup
                                                               →(FAIL, cycle 2)→ ... → gate_fail → cleanup
```

Key constraints (verified against code by gpt-5.4):
- `cwd`, `agent`, `toolName` are NOT runtime-interpolated — shell must render before submission
- Conditional edges use dot-path `verdict` (not `$.verdict`)
- Remediation bounded at 2 cycles (DAGs must be acyclic)
- `shell-mcp` needs `--allow` dirs configured for worktree tool nodes

### Score function for meta layer

```
effectiveness = 100 × (
  0.35 × delivery_score +
  0.25 × first_pass_score +
  0.15 × remediation_score +
  0.15 × time_score +
  0.10 × cost_score
)
```
