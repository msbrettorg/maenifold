# T-56.4 — Update Gate CLI References in Agent Docs

**Requirement**: FR-42 (Configurable Pipeline Engine)
**Component**: `assets/integrations/copilot/plugin-product-team/agents/product-manager.agent.md`, `assets/integrations/skills/gate/SKILL.md`

## Context

The `gate` CLI was overhauled in FR-42 (Sprint 55). The old `gate advance --stage <stage> --verdict <verdict>` command was replaced with three purpose-specific commands: `gate pass`, `gate reject`, and `gate append`. The PM agent doc and TDD skill still reference the old `advance` subcommand.

No dependencies — this is a documentation-only task that can run in parallel with T-56.1.

## Current Gate CLI

```
gate pass [--db <DB>] [--root <ROOT>] [--pipeline <PATH>] [--notes <NOTES>] <ID>
gate reject [--db <DB>] [--root <ROOT>] [--pipeline <PATH>] [--notes <NOTES>] <ID>
gate append [--db <DB>] [--root <ROOT>] --notes <NOTES> --agent <ROLE> <ID>
gate status [--db <DB>] [--root <ROOT>] [--json] [ID]
gate sync [--db <DB>] [--rebuild] <ROOT>
```

Key changes from old `advance`:
- `gate advance T-1.1.md --stage swe --notes "..."` → `gate append T-1.1 --agent swe --notes "..."`
- `gate advance T-1.1.md --stage red --verdict PASS --notes "..."` → `gate pass T-1.1 --notes "..."`
- `gate advance T-1.1.md --stage red --verdict REJECT --notes "..."` → `gate reject T-1.1 --notes "..."`
- `gate advance T-1.1.md --stage blue --verdict PASS --notes "..."` → `gate pass T-1.1 --notes "..."`
- `gate advance T-1.1.md --stage blue --verdict FAIL --notes "..."` → `gate reject T-1.1 --notes "..."`
- IDs are now bare task IDs (e.g., `T-1.1`), NOT filenames
- `--stage` and `--verdict` flags are gone — the command itself is the action
