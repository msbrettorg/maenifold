# T-238.48 — P0 Audit hand-rolled Teams Rust against agency-cowork reference implementation

**Pipeline**: gsd

## Problem

The Teams integration in `crates/maenifold-core/src/teams/` (3,616 LOC across 20 files) was greenfield-written in Rust without referencing the proven, battle-tested agency-cowork Python implementation at `/Users/brett/src/agency-cowork/skills/teams/scripts/monitor/`.

The agency-cowork monitor is the canonical reference for Teams Trouter protocol integration. It documents exact protocol details (Socket.IO frame formats, registrar endpoints, auth flow, heartbeat cadence, reconnection backoff) that were reverse-engineered from HAR traces and debugged in production. The Rust agents ignored this reference and invented their own approach.

This violates the constitution's "We Do Not Write Code" and "Research before building" tenets. Hand-rolling what a reference implementation provides is a P0 escalation.
