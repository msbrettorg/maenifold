# T-63.27 — Console.log Cleanup

**Requirement**: NFR-5
**Test Cases**: TC-31
**Repo**: pipeline-ui
**Component**: src/composables/acp-bridge.ts, src/**/*.ts, src/**/*.vue

## Context

`acp-bridge.ts` logs every MCP request at `console.log` level. Other files may have debug logging left in production code.

## Acceptance Criteria

1. Remove or gate `console.log` in `acp-bridge.ts` — either delete the log statements or wrap them in `if (import.meta.env.DEV)` guard
2. Search ALL `.ts` and `.vue` files for `console.log` — remove any that are debug/development leftovers
3. Keep `console.error` and `console.warn` for genuine error/warning paths
4. ZERO `console.log` calls in production code paths (exceptions: behind `DEV` guard only)
5. Typecheck passes: `npx vue-tsc --noEmit`

## Swe Notes

PASS. DEV-gated all src console.log calls in .ts/.vue sweep, preserved console.warn/error paths, verified no unguarded production console.log, and vue-tsc --noEmit passes.
