# T-226.2 — Backend MCP stdio/discovery → rmcp

## Problem

Custom MCP stdio client code in `mcp_discovery/stdio.rs` and `mcp/stdio_session.rs` (~577 LOC) overlaps with rmcp's `TokioChildProcess` + `ServiceExt` (already used in `external_mcp_transport.rs`).

## Key Files

- `crates/maenifold-core/src/api/mcp_discovery/stdio.rs` — compare against rmcp, replace or reduce
- `crates/maenifold-core/src/mcp/stdio_session.rs` — compare against rmcp GatewaySession trait
- `crates/maenifold-core/src/mcp/external_mcp_transport.rs` — reference implementation using rmcp

## Acceptance Criteria

- [ ] Custom MCP stdio code replaced with rmcp where possible
- [ ] Preserved behavior: stderr tail capture, startup timeout, per-call timeout, version compat
- [ ] File reduced to <100 LOC adapter or deleted
- [ ] `cargo build --release -p maenifold-core` succeeds
- [ ] Existing gateway integration tests pass
