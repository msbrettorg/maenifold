# T-44.4: App.vue Layout Refactor

**Requirement**: FR-44.4  
**Priority**: P0  
**Component**: `vendor/acp-ui/src/App.vue`

## Context

App.vue currently renders one ChatView when `isConnected` is true, or a welcome screen when not. We need to add the TabStrip and support rendering the active tab's chat while keeping the sidebar as an always-available agent launcher.

## Acceptance Criteria

### 1. Import and Wire TabStrip

- Import `TabStrip` from `./components/TabStrip.vue`
- Place it between the sidebar and the main content area (above ChatView)
- Feed it `sessionStore.tabList` and `sessionStore.activeTabId`
- Handle `@select` → `sessionStore.setActiveTab(tabId)`
- Handle `@close` → `sessionStore.closeTab(tabId)`

### 2. Main Content Area Changes

Replace the current conditional rendering:

**Before:**
```vue
<ChatView v-if="isConnected" />
<div v-else class="welcome-screen">...</div>
```

**After:**
```vue
<TabStrip 
  v-if="sessionStore.tabList.length > 0"
  :tabs="sessionStore.tabList" 
  :active-tab-id="sessionStore.activeTabId"
  @select="handleTabSelect"
  @close="handleTabClose"
/>
<ChatView v-if="sessionStore.activeTab?.isConnected" />
<div v-else-if="sessionStore.tabList.length === 0" class="welcome-screen">...</div>
<div v-else-if="sessionStore.activeTab?.isConnecting" class="connecting-screen">
  <StartupProgress ... />
</div>
```

### 3. Sidebar Changes

The sidebar currently toggles between "New Session" button and "Disconnect" button based on `isConnected`. Change this:

- **Remove** the single disconnect button from the sidebar
- **Keep** the "New Session" button always visible (it opens a NEW tab, doesn't replace)
- The agent selector and cwd picker remain always available
- Each new session opens in a new tab

Modify `handleNewSession()` to NOT check `isConnected` — user can always create new sessions.

### 4. Session Resume

`handleResumeSession()` should call `sessionStore.resumeSession(session)` which now creates a new tab (handled in T-44.2).

### 5. Tab Event Handlers

Add:
```typescript
function handleTabSelect(tabId: string) {
  sessionStore.setActiveTab(tabId);
}

function handleTabClose(tabId: string) {
  sessionStore.closeTab(tabId);
}
```

### 6. StartupProgress

Move StartupProgress rendering into the main content area (it shows when the active tab is connecting), not in the sidebar.

### 7. Permission/Auth Dialogs

Keep them at root level but they now read from `sessionStore.pendingPermission` which already reads from the active tab (handled by T-44.2's computed props).

## Constraints

- Only modify `vendor/acp-ui/src/App.vue`
- Do NOT modify session store, ChatView, or other components
- Keep the welcome screen (GeodesicsBackground) for when no tabs are open
- Keep settings, traffic monitor, and other global UI unchanged
