# T-70.5 — Workflow Step Timeline Component

**Requirement**: Workflow Authoring — Stitch Screen 1 (Center Panel)
**Component**: `src/components/WorkflowStepTimeline.vue`
**Depends**: T-70.2
**Design Reference**: `.stitch/designs/workflow-authoring-main-1.png`

## Context

The Stitch design center panel shows a vertical step timeline. Each step is a card with step number in a circle, connected by dashed vertical lines. Cards show step name, 2-line description preview, brain icon for sequential thinking, and drag handle. Header shows workflow name + action buttons.

## Skills Required

SWE agent MUST load these skills: `pinia`, `maenifold-workflow-authoring`.

## Acceptance Criteria

1. New file `src/components/WorkflowStepTimeline.vue` (< 250 LOC)
2. Header bar: workflow emoji + name in Space Grotesk (`--font-headline`), action buttons right-aligned: "Save" (filled, `--bg-primary`), "Run" (ghost), "Export" (ghost)
3. Metadata line: step count + "Sequential Thinking" status + last-edited time in `--text-muted`, `--font-mono`
4. Vertical step list, each step card (`--surface-container` background, 4px radius):
   - Left: step number in circle (01, 02...) with dashed vertical connector between cards
   - Step name in Inter semibold
   - 2-line description preview in `--text-secondary`, overflow ellipsis
   - Brain icon in `--color-node-thinking` (#d0bcff) if `requiresSequentialThinking`
   - Drag handle (⠿) on left edge
5. Selected step card: elevated to `--bg-surface` with subtle left accent
6. Click on step card emits `select-step` event with step index
7. After last step: "+ Add Step" ghost button with dashed border
8. Reads from `useWorkflowLibraryStore().currentDefinition`
9. Uses only design tokens — NO hardcoded colors
10. `npx vue-tsc --noEmit` passes
