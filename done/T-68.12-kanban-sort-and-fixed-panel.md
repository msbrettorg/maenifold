# T-68.12 — Kanban Sort & Fixed Detail Panel

**Requirement**: FR-68

## Summary

Two UX improvements to the gate kanban board (`crates/maenifold-gate/src/board/index.html`):

1. **Sort by ID** — Add a sort toggle to the toolbar that sorts task cards within each column by their task ID (e.g., T-28.2 before T-68.9). Default sort order should be ascending by ID. The sort should be alphanumeric-aware (T-2.1 before T-10.1).
2. **Fixed detail panel** — The detail side panel (`#detail-panel`) must remain fixed/sticky in the viewport when the kanban columns scroll. Currently it scrolls away with the board content.

- [ ] Sort is natural/alphanumeric (T-2.x before T-10.x)
- [ ] Detail panel stays fixed in viewport when scrolling horizontally or vertically
- [ ] Detail panel scrolls its own content independently if it overflows
- [ ] No regressions: double-click detail, close button, sprint groups all still work
- [ ] File stays under 300 LOC equivalent (HTML file is exempt from strict LOC but keep it reasonable)
