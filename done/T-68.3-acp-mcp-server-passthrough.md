# T-68.3: Pass MCP Server Configuration to ACP Agents

## Requirement
FR-50 — Agents launched via ACP must be able to connect to maenifold's MCP server.

## Problem
`NewSessionRequest::new(cwd)` defaults `mcp_servers: vec![]`. Agents spawned by `native.rs` have no way to connect to maenifold's own MCP endpoint or any external MCP tools unless configured via environment variables in the agent's command.

## Acceptance Criteria
1. `SessionOpts` must include `mcp_servers: Option<Vec<McpServerConfig>>`
2. When maenifold is running in `--http` mode, automatically include its own MCP endpoint in `mcp_servers`
3. `agents.json` entries should support an optional `mcp_servers` array per agent
4. `NewSessionRequest` must pass configured MCP servers to the agent
5. Agents should be able to call maenifold tools (WriteMemory, SearchMemories, etc.) through the MCP connection

## Files to modify
- `crates/maenifold-core/src/acp/native.rs` — pass mcp_servers in NewSessionRequest
- `crates/maenifold-core/src/acp_config.rs` — add mcp_servers to AgentEntry
- `crates/maenifold-core/src/workflow/agent_session.rs` — forward mcp_servers from config

## Reference
- `agent-client-protocol` types: `NewSessionRequest`, `McpServerConfig`
- `~/maenifold/agents.json` schema

## Tests
- All existing tests must pass
- Verify with smoke test that agent can call maenifold MCP tools
