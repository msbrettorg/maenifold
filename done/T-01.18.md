# T-01.18 — maenifold-core: no-unwrap violations

## Objective

Remove all 36 `.unwrap()` calls in non-test code across `crates/maenifold-core/`.

## Approach

Replace each `.unwrap()` with either:
- `?` (when the function returns `Result`)
- `.expect("descriptive context")` (when unwrap is safe but needs documentation)
- Proper error handling with `map_err` or `ok_or_else`

Mutex `.unwrap()` calls should use `.unwrap_or_else(|e| e.into_inner())` for poison recovery.

## Note

This is a large batch (36 violations across 10 files). May need to be split into 2 iteration batches by file group. Suggested split: acp_relay.rs (12) + lease.rs (7) as batch 1, remainder as batch 2.

## Acceptance Criteria

1. Zero `no-unwrap` violations in `make audit-crates` output for maenifold-core
2. `cargo build --release -p maenifold-core` succeeds
3. `cargo test -p maenifold-core` — no regressions
4. No silent error swallowing — every replaced unwrap has appropriate error context
