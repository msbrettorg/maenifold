## Context

Dual-model ACP upgrade research concluded that moving from `@agentclientprotocol/sdk` `0.13.1` to `0.18.0` is worthwhile and mostly additive, but the repo needs a targeted compatibility pass to adopt the relevant new surface safely.

Verified repo-specific work:

1. `AuthMethod` consumers currently assume a flat shape and need normalization or narrowing for the newer auth variants.
2. `normalizeConfigOptions()` only accepts `type === 'select'`, so boolean config options would be dropped.
3. `useMessageHandler` does not handle `usage_update`.
4. The app advertises `clientCapabilities.terminal = true` but does not implement inbound `terminal/*` methods.
5. `session/close` and `additionalDirectories` are newly relevant follow-on capabilities.

## Acceptance Criteria

1. `package.json` and lockfile are updated to `@agentclientprotocol/sdk` `0.18.0`.
2. `AuthMethod` handling is compatible with the newer SDK type surface without unsafe casts.
3. Boolean session config options are preserved and usable in the UI.
4. `usage_update` notifications are handled instead of being dropped.
5. Terminal capability drift is resolved by either implementing inbound `terminal/*` methods or no longer advertising terminal support.
6. If the agent advertises `sessionCapabilities.close`, the client uses `session/close` during teardown.
7. `additionalDirectories` is either implemented for session lifecycle flows or explicitly deferred in task notes with rationale.
8. `npx vue-tsc --noEmit` passes.
9. `npm run tauri build` produces a working `.app` bundle.
