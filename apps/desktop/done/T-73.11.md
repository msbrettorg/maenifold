## Description
Wire the Export button in WorkflowStepTimeline.vue header. Opens a save-file dialog (Tauri plugin-dialog) with default filename matching the workflow ID. Serializes the current definition (or draft if dirty — with confirmation) to the chosen location. Uses rawJson for lossless export if available, falls back to typed definition.
