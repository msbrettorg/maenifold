# T-63.24 — Empty States + Loading Skeletons

**Requirement**: FR-2
**Test Cases**: TC-3
**Repo**: pipeline-ui
**Component**: src/components/PipelineComposer.vue, src/components/PipelineView.vue

## Context

Blank canvas shows nothing — no hint to add nodes. Loading a pipeline shows no feedback. Failed loads show nothing.

## Acceptance Criteria

1. **Composer empty state**: When canvas has zero nodes, show centered hint: "Add your first node" with an arrow or icon pointing to the Add Node button. Use `var(--text-muted)` color.
2. **Loading state**: When `store.loading` is true, show a skeleton placeholder (pulsing rectangles) in the canvas area and runner panel. Use CSS animation: `@keyframes skeleton-pulse` with `var(--bg-surface)` → `var(--bg-panel)` alternation.
3. **Error state**: When pipeline load fails (after T-63.2 error handling), show centered error message with "Retry" button (`.btn-primary`)
4. **Sidebar empty state**: When no pipelines exist, show "No pipelines yet" hint
5. All states use design token colors and typography
6. Typecheck passes: `npx vue-tsc --noEmit`

## Swe Notes

PASS. Added composer empty-state hint, global loading skeleton pulse and centered retryable load-error state in PipelineView, and surfaced store.loading for UI state orchestration. Verified with npx vue-tsc --noEmit.
