# T-42.9: File System Compliance

**Requirement**: FR-42.9  
**Priority**: P0/P1  
**Files**: `vendor/acp-ui/src/lib/acp-bridge.ts`

## Acceptance Criteria

1. **Absolute path validation**: In both `readTextFile` and `writeTextFile` methods, validate that `params.path` is an absolute path before executing. On Unix: starts with `/`. On Windows: matches `^[A-Za-z]:[\\\/]`. If invalid, throw a JSON-RPC error:
   ```ts
   if (!params.path.startsWith('/') && !/^[A-Za-z]:[\\\/]/.test(params.path)) {
     throw Object.assign(new Error('Path must be absolute'), { code: -32602 });
   }
   ```

2. **Create parent directories**: In `writeTextFile`, before calling `tauriWriteTextFile`, create parent directories:
   ```ts
   import { mkdir } from '@tauri-apps/plugin-fs';
   import { dirname } from '@tauri-apps/api/path';
   
   const dir = await dirname(params.path);
   await mkdir(dir, { recursive: true });
   ```

3. **Return `null` on success**: Change `writeTextFile` to `return null;` instead of `return {};`.

## Spec References

- https://agentclientprotocol.com/protocol/file-system
- Audit findings: Finding 3 (wrong return), Finding 4 (no path validation), Finding 5 (no mkdir)

## SWE Remediation

- **What changed**
  - `vendor/acp-ui/src/lib/acp-bridge.ts`
    - Added absolute-path validation to `writeTextFile` and `readTextFile` using the required Unix/Windows checks.
    - Added parent-directory creation in `writeTextFile` via `dirname()` + recursive `mkdir()`.
    - Changed `writeTextFile` to return runtime `null` on success.
    - Preserved thrown JSON-RPC error codes in `handleRequest` so the new `-32602` validation error is not collapsed to `-32603`.

- **Test results**

    - `src/stores/session.ts`: `agentInfo` / location typing issues
    - `src/lib/acp-bridge.ts`: existing `params.toolCall.locations` typing mismatch

- **Notes**
  - I did not run `bun run build` or the full test suite, per instruction.
  - `WriteTextFileResponse` from the installed ACP SDK is still typed as an object, so the implementation returns runtime `null` using a narrow cast to satisfy the spec without widening scope into vendored SDK types.
