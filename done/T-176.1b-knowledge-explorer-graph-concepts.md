## Scope

1. Implement graph view mode in Knowledge Explorer by reusing the existing Cytoscape graph stack (`GraphView.vue`, `GraphViewCanvas.vue`, `useForceGraph.ts`). Do not introduce a second graph library.
2. Add concept browser list with concept names and edge counts.
3. Concept click-through behavior:
   - click concept -> run `buildcontext`
   - navigate/open concept anchor note in content pane/store
4. Add related concepts panel for active note by calling `findsimilarconcepts`.
5. Share and extend the `useKnowledgeStore` created in T-176.1a (no duplicate store implementations).
6. Ensure graph rendering and interactions are responsive in Fluent 2 dark surfaces.

## Acceptance Criteria

1. Graph renders at least 100 nodes without visible interaction lag.
2. Concept browser shows concepts with edge counts and supports click-through.
3. Clicking a concept opens its anchor note in the explorer.
4. Related concepts panel calls `findsimilarconcepts` for the active note and displays results.
