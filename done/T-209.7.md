## Description

End-to-end validation of the pipeline-driven delivery system on real gate tasks from the T-02.x UI cleanup backlog.

### Test plan

1. Select 5 tasks spanning different pipelines:
   - 2x lightweight (T-02.10, T-02.11 — raw buttons, border-radius)
   - 2x sdd (T-02.6, T-02.15 — arbitrary values, dead code)
   - 1x tdd if available

2. Run pipeline-meta.sh inner loop with these 5 tasks
3. Verify:
   - All worktrees created and cleaned up
   - Gate transitions happened correctly
   - Builds pass in worktrees
   - Successful tasks merged to main
   - Failed tasks preserved for inspection
   - Metrics recorded accurately

4. Compare against equivalent RALPH execution:
   - Wall-clock time
   - Token cost (approximate)
   - First-pass rate
   - Quality of SWE output

## Acceptance Criteria

- At least 3 of 5 tasks complete successfully through the pipeline
- No worktree leaks (all cleaned up or explicitly preserved)
- Gate state consistent with pipeline outcomes
- Metrics summary generated
- Comparison notes written to ralph/pipeline-meta/validation-report.md
