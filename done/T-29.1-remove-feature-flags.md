# T-29.1: Remove Cargo Feature Flags

**Requirement**: FR-36 (Remove Cargo Feature Flags)

## Context

The codebase currently uses two feature flags: `http` and `web`. All features ship in every binary — the flags add build matrix complexity, conditional compilation bugs, and "forgot `--features`" friction for zero benefit.

### Current feature flag structure:

**`crates/maenifold-core/Cargo.toml`:**
```toml
[features]
http = ["rmcp/transport-streamable-http-server", "dep:axum", "dep:tower-http", "dep:tokio-util"]
web = ["http", "dep:rust-embed", "dep:mime_guess"]
```

**`crates/maenifold-cli/Cargo.toml`:**
```toml
[features]
web = ["maenifold-core/web"]

[dependencies]
maenifold-core = { path = "../maenifold-core", features = ["http"] }
```

**`Makefile`:**
```make
web-build: web-assets
	cargo build --release -p maenifold-cli --features web
```

### cfg gates to remove (10 occurrences):

- `crates/maenifold-core/src/lib.rs:4` — `#[cfg(feature = "web")]`
- `crates/maenifold-core/src/lib.rs:6` — `#[cfg(feature = "web")]`
- `crates/maenifold-core/src/mcp/mod.rs:3` — `#[cfg(feature = "http")]`
- `crates/maenifold-core/src/mcp/mod.rs:7` — `#[cfg(feature = "web")]`
- `crates/maenifold-core/src/cli.rs:47` — `#[cfg(feature = "http")]`
- `crates/maenifold-core/src/cli.rs:69` — `#[cfg(feature = "web")]`
- `crates/maenifold-core/src/cli.rs:127` — `#[cfg(feature = "http")]`
- `crates/maenifold-core/src/cli.rs:158` — `#[cfg(feature = "web")]`
- `crates/maenifold-core/tests/main.rs:108` — `#[cfg(feature = "http")]`
- `crates/maenifold-core/tests/http_transport_tests.rs:2` — `#![cfg(feature = "http")]`

## Acceptance Criteria

1. **`crates/maenifold-core/Cargo.toml`**: `[features]` section removed entirely. All optional deps (`axum`, `tower-http`, `tokio-util`, `rust-embed`, `mime_guess`) become unconditional. `rmcp` gains `transport-streamable-http-server` feature unconditionally.

2. **`crates/maenifold-cli/Cargo.toml`**: `[features]` section removed. `maenifold-core` dep has no `features = [...]` attribute.

3. **All `#[cfg(feature = "...")]` gates removed** from every `.rs` file in `crates/`. The gated code becomes unconditional.

4. **`Makefile`**: `--features web` removed from cargo build command. Just `cargo build --release -p maenifold-cli`.

5. **`cargo build --release -p maenifold-cli`** succeeds (no `--features` needed).

6. **`cargo test -p maenifold-core`** passes (all tests, including previously feature-gated ones).

7. **`cargo test -p maenifold-cli`** passes.

8. **Zero occurrences** of `cfg(feature` in `crates/` directory.

## Verdicts

- P0: All acceptance criteria must pass
- REJECT if any `cfg(feature` remains in `crates/`
- REJECT if `cargo build` requires `--features`
