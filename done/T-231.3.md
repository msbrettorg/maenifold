## Summary

Running `cargo test -p maenifold-core` produces 5-6 consistent test failures. Tests pass individually but fail in the full suite due to shared global state contamination.

## Failing tests and root causes

### Group 1: Config global state contamination (3 tests)

Tests create temp dirs and override `Config::current()`, but concurrent tests stomp the global state.

```
workflow::pipeline::executor_nodes::tests_runtime::run_tool_node_preserves_local_tool_registry_path_for_maenifold_namespace
workflow::pipeline::executor_nodes::tests_runtime::run_tool_node_preserves_local_tool_registry_path_for_non_namespaced_tools
workflow::pipeline::executor_nodes::tests_runtime::run_tool_node_rejects_external_tool_not_in_explicit_allowlist
```

Error: `"Agent setup failed: agents config '.../maenifold.json' not found"` — another test changed Config::current() between setup and execution.

**Fix:** Add `#[serial]` attribute (from `serial_test` crate, already a dependency).

File: `crates/maenifold-core/src/workflow/pipeline/executor_nodes_tests_runtime.rs`

### Group 2: Async timing race (1 test)

```
mcp::resources::throttle::tests::boundary_signal_does_not_cancel_prior_trailing_dispatch
```

Error: `assertion failed: throttle.take_trailing_dispatch().await` — the trailing dispatch may not have registered yet when the assertion runs.

**Fix:** Add `#[serial]` and/or add a small yield/sleep between signal and assertion.

File: `crates/maenifold-core/src/mcp/resources/throttle.rs`

### Group 3: Schema test (1 test)

```
mcp::schema::graph_params_tests::visualize_schema_exposes_format_enum_for_tools_list
```

Error: `"format enum"` — panics on schema validation. Needs investigation. May be a Config-dependent test that fails when another test changes the global config.

File: `crates/maenifold-core/src/mcp/schema/graph_params_tests.rs`

### Group 4: Intermittent (1 test — sometimes passes)

```
mcp::gateway_intent_tests::read_safe_single_high_confidence_auto_executes
```

Sometimes passes in full suite, always passes individually. Same Config contamination pattern.

File: `crates/maenifold-core/src/mcp/gateway_intent_tests.rs`
