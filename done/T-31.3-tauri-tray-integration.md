# T-31.3: Tauri Tray Icon with Window Show/Hide

**Requirement**: FR-41 (Native Desktop App via Tauri)

## Objective

Add system tray functionality to the Tauri app using Tauri's native tray APIs. Implement window show/hide behavior: close button hides to tray, tray click shows window, dock icon visible only when window is visible.

## Acceptance Criteria

1. Tray icon appears in macOS menu bar when `maenifold --app` runs
2. Tray menu has: "Open Window", "Open at Login", "Help", separator, "Quit"
3. Clicking "Open Window" shows the main Tauri window and adds app to dock
4. Closing the window (red X) hides it and removes from dock (ActivationPolicy::Accessory)
5. Clicking tray icon itself shows the window (same as "Open Window")
6. "Open at Login" toggles LaunchAgent plist (reuse logic from current `tray.rs` helpers: `launch_agent_path()`, `write_launch_agent()`, `remove_launch_agent()`)
7. "Help" opens GitHub issues in default browser
8. "Quit" terminates the app
9. `cargo build -p maenifold-app` succeeds

## Files to Examine

- `crates/maenifold-core/src/tray.rs` — LaunchAgent helpers to reuse
- Tauri tray API: `tauri::tray::TrayIconBuilder`, `tauri::tray::TrayIconEvent`
- Tauri activation policy: `app.set_activation_policy()`
