# T-72.8 — Scoped scrollbar theming

**Pipeline**: mdd
**Pipeline Digest**: b826a880e632e457a4be2a8cbfabf45b8434090f1df1416e349cb1f9700565df
**Requirement**: UX-POLISH-72 — Default scrollbars break dark theme immersion
**Component**: `src/assets/shared-components.css`

## Context

Default system scrollbars on a dark-themed app are visually jarring. Custom thin scrollbar styling makes the interface feel cohesive. Tauri's WKWebView (macOS) and WebView2 (Windows) both support WebKit scrollbar pseudo-elements.

## Acceptance Criteria

1. Scrollbar styles use BOTH standards-track (`scrollbar-color`, `scrollbar-width`) AND WebKit pseudo-elements (`::-webkit-scrollbar`, `::-webkit-scrollbar-track`, `::-webkit-scrollbar-thumb`).
2. Styles are scoped to named containers: `.sidebar-content`, `.messages-container`, `.gate-table-wrap`, `.logs-content`, `.workflow-panel-body` — NOT applied globally via `*`.
3. Vue Flow containers (`.vue-flow__pane`, `.vue-flow__viewport`, `.vue-flow__minimap`) are explicitly EXCLUDED and retain default scrollbar behavior.
4. Scrollbar thumb uses `background: var(--border-default); border-radius: 4px`, hover state uses `background: var(--text-muted)`.
5. Track is transparent. Width is 8px.
6. `npx vue-tsc --noEmit` passes.
