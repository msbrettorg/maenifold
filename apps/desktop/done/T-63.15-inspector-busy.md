# T-63.15 — Inspector Busy States

**Requirement**: FR-6
**Test Cases**: TC-16
**Repo**: pipeline-ui
**Component**: src/components/PipelineInspector.vue

## Context

Inspector action buttons (Restart, Rewind, Complete, Abandon) have no busy state. Double-clicking sends duplicate MCP mutations. No visual feedback during operation.

## Acceptance Criteria

1. Add `busyAction: ref<string | null>(null)` to the inspector component
2. Before each action (restart, rewind, complete, abandon), set `busyAction` to the action name
3. While `busyAction` is set, ALL action buttons are disabled (add `.btn--busy` class or `:disabled`)
4. On action completion (success or error), clear `busyAction`
5. Show visual feedback: the active button gets a loading indicator (e.g., "..." text or opacity pulse via `.btn--busy`)
6. Rapid clicks during busy state are ignored (`:disabled` handles this)
7. Typecheck passes: `npx vue-tsc --noEmit`
