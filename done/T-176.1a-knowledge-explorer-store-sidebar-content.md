## Scope

1. Implement Pinia `useKnowledgeStore` with:
   - `folders` (folder tree structure)
   - `searchResults` (memory search result set)
   - `activeNote` / `activeUri` (currently-open note content and metadata)
   - loading/error/empty state flags for folder load, search, and note load
2. Build Knowledge Explorer sidebar tree view using shadcn-vue `Collapsible` + `ScrollArea`.
3. Build center content viewer pane rendering selected memory markdown.
4. Wire search input to `searchmemories` through existing `useMemoryApi()` composable at `apps/desktop/src/composables/useMemoryApi.ts` (no raw HTTP).
5. Wire note open flow to `readmemory` via the same composable.
6. Implement empty/loading/error states with shadcn `Skeleton` + `Alert`.
7. Keep graph-concept visualization work explicitly out of this split task (covered by T-176.1b).

## Acceptance Criteria

1. Search returns real results from a running maenifold daemon via MCP-backed `searchmemories`.
2. Folder tree reflects actual `memory/` structure.
3. Opening a note loads full content through `readmemory`.
4. Loading, empty, and error states are rendered with shadcn `Skeleton` and `Alert`.
5. Home dashboard remains the default landing route; Knowledge Explorer opens via the dedicated Home tile and tab navigation.
