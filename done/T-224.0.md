# T-224.0 — Epic: CopilotKit AG-UI Standalone POC

## Goal

Build a standalone React + CopilotKit app that connects to our running maenifold daemon via a thin Node.js ACP→AG-UI bridge. Shared nothing with the existing Electron/Vue UI. Proves whether AG-UI is viable as the conversational protocol for maenifold.

## Architecture

```
poc/copilotkit/
├── bridge/          # Node.js Express server (~200 LOC)
│   ├── index.ts     # ACP WebSocket → AG-UI SSE translator
│   └── package.json
├── app/             # Vite + React + CopilotKit chat app
│   ├── src/
│   │   ├── App.tsx
│   │   └── main.tsx
│   ├── package.json
│   └── vite.config.ts
└── README.md        # Setup, run, test instructions
```

## What it validates

1. Can CopilotKit chat stream responses from our ACP agents?
2. Can our MCP tools surface through CopilotKit's tool system?
3. Does the streaming UX feel good out of the box?
4. What's the latency/quality compared to our existing Agents tab?
5. Can we get rich tool result rendering?

## What it does NOT validate

- Vue integration (that's the production build)
- Voice (separate concern)
- App control bus / navigation (separate concern)
- Floating shell UX in Electron (separate concern)

## Subtasks

- T-224.1 — Scaffold POC directory and bridge server
- T-224.2 — Implement ACP→AG-UI event translator
- T-224.3 — Scaffold CopilotKit React app with chat UI
- T-224.4 — Wire bridge to daemon, validate streaming
- T-224.5 — Add tool call rendering and MCP tool discovery

## Success criteria

- User can type a prompt in CopilotKit UI
- Response streams in real-time from maenifold daemon
- Tool calls (search memory, gate status, etc.) are visible and results render
- Multi-turn conversation works
- Side-by-side comparison with existing Agents tab is possible

## Decision gate

After POC completes, the team decides:
- **If UX is compelling** → Port patterns to Vue composables
- **If protocol works but UX is meh** → Build native Vue shell, skip CopilotKit
- **If impedance mismatch** → Stick with pure ACP frontend
