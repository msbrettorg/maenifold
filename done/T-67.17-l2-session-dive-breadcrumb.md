**Requirement**: FR-37
**Phase**: 3

## Context
L2 stretches the overlay to fill the center panel and mounts ChatView bound to the node's sessionId. A breadcrumb shows graph position.

**Stitch Reference**: Screen "Session Dive - Synthesis Agent" in project `projects/1113463130459108073`

## Acceptance Criteria
1. When `zoomStore.isSession`, SemanticZoomOverlay morphs: width→100% center panel, height→100%, border-radius→0
2. New component `src/components/PipelineBreadcrumb.vue`: horizontal strip of node pills showing predecessor → current → successor chain
3. Each breadcrumb pill: node ID in mono font, status emoji, clickable (navigates to that node — exits current L2, enters L1/L2 on target)
4. Current node highlighted with primary accent
5. ChatView mounts inside the overlay, bound to `viewNode.sessionId` from pipeline store
6. If session is active: messages stream live. If completed: read-only history. If pending: empty state "This node hasn't executed yet"
7. Chat input bar disabled with "Watching live session..." text for non-interactive sessions
8. Inspector panel collapses when entering L2 (restore on exit)
9. `npx vue-tsc --noEmit` passes
10. PipelineBreadcrumb under 100 LOC, L2 logic under 50 LOC added to SemanticZoomOverlay
