# T-220.10 - Remove Implicit Ort Native Binary Downloads

## Problem

The workspace enables `ort` features that download/copy native ONNX Runtime binaries during build.

## Evidence

- `Cargo.toml:55` enables `ort` with `download-binaries` and `copy-dylibs`.
- `Cargo.lock:4322-4344` resolves `ort` / `ort-sys` `2.0.0-rc.12`.
- Source: `docs/codebase-audit-2026-04-25.md#p1-9`.
- Parent sequential thinking session: `session-1777125506368-62098`.

## Acceptance Criteria

- [ ] Native ONNX Runtime acquisition is behind an explicit opt-in feature or documented system dependency.
- [ ] Default/release builds do not silently download native binaries.
- [ ] If vendored artifacts remain, their provenance and checksums are documented and verified.
- [ ] Build documentation describes how to provide ONNX Runtime.
- [ ] `cargo build --release -p maenifold-cli` succeeds.
