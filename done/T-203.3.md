# T-203.3 — McpAppFrame.vue: AppBridge host component + sandbox proxy

## Problem

No component exists for rendering MCP Apps in the maenifold desktop UI. Need:
1. A sandbox proxy infrastructure in Electron (separate origin for iframe isolation)
2. A Vue 3 component that wraps the official AppBridge SDK

## Part A: Sandbox proxy infrastructure

Register `mcp-app-sandbox` as a privileged Electron custom protocol in `electron/main.ts`.

```
protocol.registerSchemesAsPrivileged([
  { scheme: 'mcp-app-sandbox', privileges: { standard: true, secure: true, supportFetchAPI: true } }
])
```

Serve a bundled `sandbox-proxy.html` + inline script via `protocol.handle('mcp-app-sandbox', ...)`.
The handler applies CSP from `?csp=<url-encoded-json>` query param as an HTTP `Content-Security-Policy` header.

Reference implementation: `modelcontextprotocol/ext-apps/examples/basic-host/src/sandbox.ts`

The sandbox proxy script:
- Validates `document.referrer` origin
- Creates inner iframe with `sandbox="allow-scripts allow-same-origin allow-forms"`
- Relays postMessage bidirectionally between parent (host) and inner iframe (app)
- Intercepts `ui/notifications/sandbox-resource-ready` to inject HTML via `document.write()`
- Sends `ui/notifications/sandbox-proxy-ready` to parent on load

Exempt `mcp-app-sandbox://` from the existing global CSP `frame-ancestors 'none'` header
in the `onHeadersReceived` handler so the sandbox iframe can embed.

## Part B: McpAppFrame.vue

Create `apps/desktop/src/components/McpAppFrame.vue`:

### Props
- `toolCall: ToolCallInfo` — the complete tool call info (carries `appUi`, `rawOutput`, `rawInput`)
- `serverName: string` — originating MCP server name for tool call proxying

### Derived from props
- `resourceUri` from `toolCall.appUi.resourceUri`
- `csp` from `toolCall.appUi.csp`
- `permissions` from `toolCall.appUi.permissions`
- `toolResult` from `toolCall.rawOutput` (typed as MCP `CallToolResult`)
- `toolInput` from `toolCall.rawInput`

### Behavior
1. On mount: create outer iframe pointing to `mcp-app-sandbox://proxy?csp=<encoded>`
2. Wait for `onsandboxready` from sandbox proxy
3. Call `bridge.sendSandboxResourceReady({ html, sandbox, permissions })` with resource HTML
4. Resource HTML is fetched via MCP `resources/read` on the originating server
5. After `oninitialized`: push `sendToolResult()` with tool call result, and `sendToolInput()` with tool input
6. Proxy `oncalltool` manually: `bridge.oncalltool = (params) => callTool(serverName, params)`
7. Handle `onsizechange`: update iframe container height (clamped to min 100px, max 600px)
8. Handle `onopenlink`: open URL via `window.open(url, '_blank')` (validate http/https only)
9. On unmount: call `bridge.teardownResource({})`, disconnect transport, clean up listeners
10. Use `disposed` guard pattern for all post-await operations

### Design
- DESIGN.md tokens for surface (`bg-secondary`), radius (`rounded-lg`)
- Responsive height from `onsizechange` notifications, clamped
- Loading skeleton while sandbox proxy loads
- Error state with message if resource fetch or sandbox setup fails

### Theme sync
- Read theme from app-wide dark/light mode (e.g., media query or theme store)
- Pass `hostContext.theme` on init and via `sendHostContextChange` on changes
- Pass `platform: 'desktop'`, `displayMode: 'inline'`

## Files

- `apps/desktop/electron/main.ts` (modify — register protocol, sandbox handler, CSP exemption)
- `apps/desktop/src/components/McpAppFrame.vue` (new)

## Acceptance criteria

1. `mcp-app-sandbox://` protocol registered and serves sandbox proxy with CSP headers
2. Component renders a sandboxed iframe from a `ui://` resource via the sandbox proxy
3. Resource HTML is fetched via MCP `resources/read` (not direct HTTP)
4. Bidirectional postMessage works: app can call tools, host pushes results
5. Tool call proxy routes to the correct server (not just default)
6. Iframe tears down cleanly on unmount (no leaked listeners, `disposed` guard)
7. Error state shown if resource fetch fails or sandbox errors
8. Size changes from app update container height (100px-600px clamp)
9. Theme/host context provided on init
10. `npx vue-tsc --noEmit` passes
