# T-178.6b — Frontend safe dependency patches

**Pipeline**: lightweight
**Pipeline Digest**: tbd

## Objective

Update all frontend dependencies that are patch/minor version behind and resolve low-hanging security advisories.

## Updates Required

### Security Fixes (npm audit fix)
- `lodash-es` → latest (2 HIGH: code injection, prototype pollution)
- `dompurify` 3.3.3 → 3.4.0 (MODERATE: HTML injection in ADD_TAGS)

### Minor/Patch Bumps
- `vue` 3.5.27 → 3.5.32
- `typescript` 6.0.2 → 6.0.3
- `mermaid` 11.13.0 → 11.14.0
- `vitest` 4.1.0 → 4.1.4
- `jsdom` 29.0.1 → 29.0.2
- `cytoscape` 3.33.1 → 3.33.2
- `@types/node` 25.1.0 → 25.6.0
- `@microsoft/applicationinsights-web` 3.3.11 → 3.4.1
- `@agentclientprotocol/sdk` 0.18.2 → 0.19.0

## Scope

- `cd apps/desktop`
- Run `npm audit fix` for lodash-es and dompurify
- Update minor/patch versions in `package.json`
- Run `npm install`
- Verify `npx vue-tsc --noEmit` passes
- Verify `npm run build` succeeds

## Acceptance Criteria

1. All listed packages updated in `package.json`
2. `npm audit` shows reduced vulnerability count (Electron/Vite vulns remain — separate tasks)
3. `npx vue-tsc --noEmit` passes
4. `npm run build` succeeds
5. No runtime regressions in import paths or API usage
