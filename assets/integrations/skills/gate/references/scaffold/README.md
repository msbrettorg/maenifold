# Gate Pipeline Scaffold

This scaffold provides the starting structure for a gated pipeline.
The sample files in this scaffold use the default SDD flow (`swe → red → blue → done`), but the directory layout is reusable for any Gate pipeline.

## Setup

1. Copy this scaffold to your project root
2. Write your PRD and spec files (use `T-{sprint}.{seq}-description.md` naming)
3. Place pending specs in `todo/`
4. Run `gate sync --rebuild .` to initialize the cache

## File Structure

```text
project/
├── PRD.md          # Requirements document
├── RTM.md          # Requirements traceability matrix
├── pipeline.db     # Cache (auto-generated by gate sync)
├── todo/           # Pending task specs
│   └── T-1.1-*.md
└── done/           # Completed task specs (moved by the final gate pass)
    └── T-1.2-*.md
```

## Commands

- `gate status --root .` — View pipeline status
- `gate append <FILE> --root . --agent swe` — Record SDD SWE completion
- `gate pass <FILE> --root .` — Advance the current stage
- `gate reject <FILE> --root .` — Return the task to the configured retry state
- `gate sync --rebuild .` — Rebuild pipeline.db from files
