# T-63.17 — Fix canResume Excludes Stuck

**Requirement**: FR-5
**Test Cases**: TC-13
**Repo**: pipeline-ui
**Component**: src/components/PipelineRunner.vue

## Context

`canResume` computed property does not exclude `stuck` from resumable states. A stuck pipeline (with abandoned nodes) shows the Resume button, but resuming it does nothing useful.

## Acceptance Criteria

1. In `PipelineRunner.vue`, find the `canResume` computed
2. Add `stuck` to the exclusion list alongside `completed` and `cancelled`
3. A pipeline with status `stuck` does NOT show the Resume button
4. Verify: `completed`, `cancelled`, and `stuck` all hide Resume; `paused` shows Resume
5. Typecheck passes: `npx vue-tsc --noEmit`


## SWE Remediation

Implemented by gpt-5.4. Modified src/components/PipelineRunner.vue — canResume computed now hides Resume for stuck status alongside completed/cancelled. Commit df65cbb. vue-tsc passes.
