## Objective

Create E2E tests for graft/rewind operations on pipelines that have undergone
real execution, verifying correct state after surgery.

## Test file

`crates/maenifold-core/src/workflow/pipeline/e2e_tests_surgery_live.rs`

## Test cases

1. **Graft onto completed pipeline** — run pipeline to completion, graft new nodes, run again
2. **Graft onto paused pipeline** — run, pause, graft new nodes, resume, verify new nodes execute
3. **Rewind completed node** — run to completion, rewind one node, run again, verify re-executes
4. **Rewind cascades downstream** — a→b→c all completed, rewind b, verify c also reset
5. **Rewind preserves sibling branch** — diamond a→{b,c}→d, rewind b, verify c stays completed
6. **Fork from completed pipeline** — run to completion, fork subgraph, verify independent copy
7. **Full lifecycle: create → run → pause → graft → resume → complete → rewind → run** — comprehensive chain

## Harness

Same as T-71.1. Use tool nodes for deterministic execution.

## Acceptance criteria

- All tests pass without mocks
- Surgery operations verified against real execution state (not seeded frontmatter)
- Tests complete in <30s each
