# T-178.10b — Replace SemanticZoomOverlay hand-rolled modal with shadcn Dialog

**Pipeline**: sdd
**Pipeline Digest**: tbd

## Objective

SemanticZoomOverlay.vue (427 LOC) is a hand-rolled modal system using Teleport + manual backdrop + keyboard handling. Replace with shadcn Dialog/Sheet primitives.

## Current Implementation
- `Teleport to="body"` with manual backdrop div
- Manual click-outside handling
- Manual Escape key handling
- Manual focus trapping
- ~80 LOC of modal infrastructure that shadcn Dialog provides for free

## Fix
- Replace Teleport+backdrop with shadcn `Dialog` or `Sheet` (Sheet if the overlay slides in from the side, Dialog if it's centered)
- Remove manual backdrop click handler — Dialog handles this
- Remove manual keyboard trap — Dialog handles this
- Remove manual close button logic — use DialogClose
- Keep ALL content rendering (node details, failure panel, metadata grid) — only replace the modal shell

## Also Extract (per duo audit)
- `SemanticZoomOverlayFailure.vue` — the failure-pre block + show-more toggle
- Move shared `.zoom-*` tokens into component scoped styles

## Acceptance Criteria
1. SemanticZoomOverlay uses shadcn Dialog or Sheet — no Teleport, no manual backdrop
2. `SemanticZoomOverlay.vue` under 300 LOC after extraction
3. `npx vue-tsc --noEmit` passes
4. `npm run build` succeeds
