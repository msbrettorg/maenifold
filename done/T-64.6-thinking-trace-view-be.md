# T-64.6 — Thinking trace reader + view integration (BE)

**Requirement**: FR-23

## Acceptance Criteria

- New helper function to read thinking session content from session markdown files
- For SequentialThinking nodes with completed/active status: view response includes `thinking_trace` array
- Each trace element contains: `thought_number` (u32), `text` (String), `is_revision` (bool), `revises_thought` (Option<u32>)
- Session files located via `session_id` from NodeState
- When session file is missing or corrupt: `thinking_trace` is null (not an error — errors are information at the tool level, not the view level)
- For in-progress sessions: return partial trace (thoughts completed so far)
- All existing pipeline tests pass
- `cargo test -p maenifold-core -- pipeline` green

## Design Guidance

**No public read API exists for thinking sessions.** The sequential thinking tool writes markdown session files with structured content. This spec must create a reader that parses the session markdown to extract individual thoughts.

Examine the thinking session file format in `session_io.rs` and the sequential thinking tool's write path to understand the markdown structure before implementing the reader.
