# T-44.6: SessionList + Sidebar Refactor

**Requirement**: FR-44.6  
**Priority**: P1  
**Component**: `vendor/acp-ui/src/components/SessionList.vue`

## Context

SessionList currently emits a `resume` event that App.vue handles by replacing the singleton session. Now that resume creates a new tab, we need to handle the case where a session is already open in a tab.

## Acceptance Criteria

### 1. Duplicate Tab Prevention

When the user clicks to resume a session that's already open in a tab:
- Do NOT create a new tab
- Instead, switch to the existing tab (`setActiveTab`)

Add logic: before emitting `resume`, check `sessionStore.tabList` for a tab with a matching `sessionId`. If found, emit a new `focus` event instead.

### 2. SessionList Visual Updates

Show which sessions are currently open in tabs:
- Sessions that have an active tab should show a subtle indicator (e.g., a dot, "open" badge, or different styling)
- Import `useSessionStore` in SessionList to read `tabList`

### 3. Events

Update emits:

```typescript
defineEmits<{
  (e: 'resume', session: SavedSession): void;
  (e: 'focus', tabId: string): void;
  (e: 'delete', sessionId: string): void;
}>();
```

### 4. Delete Safety

When deleting a session that's currently open in a tab:
- Show a confirmation or warning that the tab will be closed
- Close the tab first, then delete the session

## Constraints

- Primary changes in `vendor/acp-ui/src/components/SessionList.vue`
- May need minor handler additions in `App.vue` for the new `focus` event
- Do NOT modify the session store
- Do NOT modify ChatView or TabStrip

## SWE Remediation

- What I changed:
  - `vendor/acp-ui/src/components/SessionList.vue`: added duplicate-tab prevention, emitted the new `focus` event for already-open sessions, showed an open/opening indicator for sessions with active tabs, and closed any open tab before deleting its saved session.
  - `vendor/acp-ui/src/App.vue`: added the new `focus` handler so SessionList can switch to an existing tab instead of resuming the same session into a duplicate tab.
- Test results:
  - PASS — `cd vendor/acp-ui && npx vue-tsc --noEmit`
- Notes:
  - SessionList now checks the store’s open tabs before resuming so clicking an already-open saved session focuses the existing tab.
  - Deleting an open saved session now warns the user that its tab will close first, then closes that tab before removing the saved session.
