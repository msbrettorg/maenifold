# T-176.5 — Unified navigation — tab bar, icon rail, and keyboard shortcuts

## Intent

**P1 design system violation.** AppTabBar and AppSidebar have zero shadcn-vue imports. SessionList has zero. These are the navigation spine of the entire app — every user sees them on every screen — and they're fully bespoke. This task eliminates that and makes navigation feel cohesive with the new homepage and all other views.

## Reference

- `apps/desktop/src/components/AppTabBar.vue` — current tab bar
- `apps/desktop/src/components/AppSidebar.vue` — current sidebar
- `apps/desktop/DESIGN.md`

## Scope

**Directive: DELETE bespoke markup and CSS. REPLACE with existing shadcn-vue components. The goal is less code, not more. Every bespoke `<style>` block, hardcoded hex color, hardcoded `border:` declaration, and hand-rolled `<button>`/`<input>`/`<select>` is a deletion target. Use the 21 shadcn-vue components already installed in the project. Use Tailwind utility classes referencing CSS custom properties from DESIGN.md. If a shadcn-vue component covers 80% of the need, use it and adjust via props/slots — do not hand-roll a replacement.**


### Tab bar (top or left rail)

- Tabs: Home, Agents, Pipelines, Gate, Knowledge, Workflows, Settings
- Icons: Lucide icon set (Home, MessageSquare, GitBranch, ShieldCheck, Brain, Workflow, Settings)
- Active indicator: 3px bottom border in `brand` (`#0078D4`) (top bar) or left accent (rail)
- Inactive: `text-muted-foreground`, hover shifts icon to `text-foreground`
- Typography: Segoe UI Variable 400 0.6875rem labels below icons

### Icon rail mode

- On viewports < 900px or when sidebar is collapsed, tab bar becomes a vertical icon rail (48px wide)
- Icons only, tooltips on hover
- Same active indicator (left accent bar)

### Keyboard shortcuts

- `Cmd+1` through `Cmd+7` switch tabs
- `Cmd+K` opens CommandPalette (already exists)
- `Cmd+N` new session from anywhere
- `Cmd+/` toggles sidebar
- Shortcuts shown in tooltip for each tab

### Sidebar integration

- When in Agents tab, sidebar shows session list (existing behavior)
- When in other tabs, sidebar collapses to icon rail or hides
- Smooth transition between states

## Files touched

- `src/components/AppTabBar.vue` (restyle + icon rail mode)
- `src/components/AppSidebar.vue` (responsive collapse)
- `src/composables/useAppShell.ts` (keyboard shortcut registration)
- `src/App.vue` (layout adjustments for rail mode)

## Acceptance criteria

1. Tab bar renders with Lucide icons and Fluent 2 dark styling
2. Active tab has `brand` (`#0078D4`) indicator
3. Icon rail mode activates on narrow viewport or toggle
4. Cmd+1–7 switches tabs
5. Cmd+N creates new session from any view
6. Tooltips show shortcut hints
7. Smooth transitions between sidebar visible/collapsed/rail states
8. No layout jumps when switching between tab bar modes
9. Knowledge Explorer is the first item in the icon rail and has a global keyboard shortcut that opens it directly
