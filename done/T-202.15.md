# T-202.15 — Prompt template & doc rendering fallbacks for terminal MCP clients

## Problem

The Copilot CLI environment (and likely other terminal-based MCP/ACP clients) does **not** render the following markdown extensions:

- **Images** — neither remote URLs nor local repo paths render. `![alt](path.png)` shows nothing.
- **Mermaid diagrams** — fenced ` ```mermaid ` blocks render as raw source, not diagrams.
- **LaTeX math** — both inline `$...$` and block `$$...$$` render as raw source.

Verified against this Copilot CLI session 2026-04-20.

This affects any agent output, prompt template, workflow asset, or doc that assumes a rich markdown renderer. Agents emitting Mermaid state diagrams or LaTeX equations to explain their reasoning will produce noise instead of signal in terminal clients.

## What does render reliably

- All standard markdown (headings, lists, tables, blockquotes, links, code blocks with syntax highlighting, task lists, footnotes)
- ASCII / unicode box-drawing diagrams
- Emoji and unicode symbols (Σ ∫ ∞ α β ✅ ❌ 🟢 🔴)
- Inline HTML: `<kbd>`, `<details>`/`<summary>`, `<u>`
- Horizontal rules

## Fix

1. Audit existing prompt templates and shipped assets for renderer-dependent content:
   - `crates/maenifold-gate/assets/*.json` (process descriptions)
   - `assets/workflows/*.json` (workflow step prompts and descriptions)
   - `~/.copilot/skills/gate/references/*.md` (prompt templates)
   - `docs/` (any agent-facing docs)
2. Replace renderer-dependent content with portable equivalents:
   - **Mermaid → ASCII box-drawing** for state machines and flowcharts
   - **LaTeX → unicode** (Σ, √, ≤, ∈) or plain text (`e^(i*pi) + 1 = 0`)
   - **Images → text descriptions + filesystem path references** so the user can open the file directly
3. Add a one-line guidance note to the agent constitution / `AGENTS.md` documenting the rendering-fallback rule for terminal clients.

## Acceptance criteria

1. Grep finds zero `mermaid` fenced blocks in shipped prompt templates and workflow assets (or each occurrence has an ASCII fallback adjacent).
2. Grep finds zero `$$` math blocks in the same surfaces (or each has a unicode/text fallback).
3. Image references in agent-facing docs either describe the image inline or include a "open `<path>` in a graphical viewer" instruction.
4. `AGENTS.md` (or equivalent) documents the rendering-fallback rule.

## Notes

- Rich-renderer clients (the maenifold desktop app, GitHub web UI, browser-based copilot) WILL render mermaid/math/images correctly. The rule is "lowest common denominator" — emit content that works everywhere, not content that breaks in terminal.
- Consider whether MCP responses should ever embed images at all, given the broader portability problem.
