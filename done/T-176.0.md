# T-176.0 — Homepage tile launcher — replace ChatWelcomeScreen

## Intent

The current ChatWelcomeScreen is 3 static chips and a button. Agency-cowork's homepage has rich action tiles with icons, colors, prompt builders, and a central text input. Maenifold's homepage should be the launchpad into all four modes — agent conversations, pipelines, gates, and workflows — with the same prompt-first UX pattern, adapted for maenifold's richer feature set.

## Reference

- `agency-cowork/ui/src/App.jsx:4746-4765` — canonical homepage tile style (emoji icons + tile anatomy + border treatment)
- `agency-cowork/ui/src/App.jsx:4762` — emoji icon rendering in category tiles
- `apps/desktop/src/components/ChatWelcomeScreen.vue` — current bare implementation
- `apps/desktop/DESIGN.md` — Fluent 2 dark design system

## Scope

**Directive: DELETE bespoke markup and CSS. REPLACE with existing shadcn-vue components. The goal is less code, not more. Every bespoke `<style>` block, hardcoded hex color, hardcoded `border:` declaration, and hand-rolled `<button>`/`<input>`/`<select>` is a deletion target. Use the 21 shadcn-vue components already installed in the project. Use Tailwind utility classes referencing CSS custom properties from DESIGN.md. If a shadcn-vue component covers 80% of the need, use it and adjust via props/slots — do not hand-roll a replacement.**


Replace `ChatWelcomeScreen.vue` with a new `HomeDashboard.vue` component:

### Tile grid (2×3 or responsive auto-fit)

| Tile | Icon | Accent | Action |
|------|------|--------|--------|
| New conversation | 💬 (emoji) | `brand` (`#0078D4`) | Opens agent selector → new session |
| Run pipeline | 🔀 (emoji) | `success` (`#0E9C57`) | Opens PipelineView or template gallery |
| Gate dashboard | 🛡️ (emoji) | `warning` (`#E8910A`) | Opens GateView |
| Start workflow | 🧠 (emoji) | `thinking` (`#B4891C`) | Opens workflow browser |
| Explore knowledge | 🔍 (emoji) | `brand` (`#0078D4`) | Opens Knowledge Explorer (T-176.1a) |
| Recent sessions | 🕘 (emoji) | `textSecondary` (`#A0AAB2`) | Shows recent session list, click to resume |

### Central prompt bar

- Full-width text input below tiles, styled per Fluent 2 dark inputs (`bgSidebar` `#282828`, `borderSubtle` `#383838`, `brand` focus ring `#0078D4`)
- Agent selector dropdown to the left of the input
- CWD indicator pill
- Enter launches a new agent session with the typed prompt
- Placeholder: "Ask anything, or pick a tile above..."

### Design requirements

- Cards use `bgSurface` (`#333333`)
- Borders per `apps/desktop/DESIGN.md` §5 — `border-subtle` for structural separators, `border-card` for tile/card edges.
- Hover: shift to `bgSurfaceHover` (`#3A3A3A`) + drop shadow per Fluent 2 elevation scale at 8% opacity
- 4px left accent bar per tile color
- Status beads: show daemon connection status (emerald), active pipeline count, pending gate tasks
- Typography: Segoe UI Variable 500 for tile labels, Segoe UI Variable 400 for descriptions
- All shadcn-vue primitives: Card, Button, Input, Tooltip

### Wiring

- `useAppShell` composable gains a `showHome` boolean (true when no session active and not in any sub-view)
- `App.vue` routes to `HomeDashboard` as the default view instead of `ChatWelcomeScreen`
- Each tile click sets the appropriate `show*` flag or initiates a session

## Files touched

- `src/App.vue` (swap import, add routing)

3. Prompt bar creates a new agent session with typed text
4. Agent selector and CWD indicator functional
5. Status beads show live daemon/gate state
6. Design matches Fluent 2 dark tokens exactly — borders and separators follow `apps/desktop/DESIGN.md` §5 (`border-subtle` and `border-card`), with correct surfaces and typography
7. Keyboard accessible: Tab navigates tiles, Enter activates
8. Knowledge Explorer is a first-class home tile and opens the Knowledge Explorer surface owned by T-176.1a (Home dashboard remains the default landing route).
