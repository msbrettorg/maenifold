# T-238.51 — P0 Add prompt injection scanning before Teams dispatch

**Pipeline**: sdd

## Problem

External messages from Teams are dispatched to agents without any injection scanning. The agency-cowork reference scans all prompts for injection patterns and blocks external (non-self-chat) messages with high-severity findings. This is a security gap — any Teams user who messages the monitored chat can inject arbitrary agent instructions.

## Reference

- agency-cowork: `/Users/brett/src/agency-cowork/skills/teams/scripts/monitor/message_handler.py` L997-1034 `scan_for_injections()`
- agency-cowork: `/Users/brett/src/agency-cowork/scripts/prompt_guard.py` (536 LOC — the real implementation with `_PATTERNS` table)
- NOTE: `/Users/brett/src/agency-cowork/skills/teams/scripts/prompt_guard.py` is an 18-line stub that always returns clean — do NOT use it
- Rust target: `crates/maenifold-core/src/teams/handler.rs`

## Required changes

1. Port injection pattern scanning from agency-cowork `prompt_guard.py`
2. Add scanning step in `handler.rs` between keyword match and dispatch
3. Block external messages (non-self-chat) that contain injection patterns
4. Log blocked messages with the triggering pattern
5. Allow self-chat messages through without scanning (user trusts themselves)

## Acceptance Criteria

- [ ] External messages are scanned for injection patterns before dispatch
- [ ] Messages with injection findings are blocked with a log entry
- [ ] Self-chat messages bypass scanning
- [ ] Pattern library covers: system prompt override, role assumption, instruction injection
