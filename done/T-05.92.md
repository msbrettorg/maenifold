## Problem

Every push to GitHub reports:
```
GitHub found 14 vulnerabilities on msbrettorg/maenifold-rs's default branch
(10 high, 2 moderate, 2 low)
```

## Fix

1. Check Dependabot alerts: `gh api repos/msbrettorg/maenifold-rs/dependabot/alerts --jq '.[] | {package: .security_advisory.summary, severity: .security_vulnerability.severity, ecosystem: .dependency.package.ecosystem}'`
2. For npm vulnerabilities: `cd apps/desktop && npm audit fix`
3. For cargo vulnerabilities: `cargo audit` and update affected crates in Cargo.toml
4. For unfixable vulns: document why in this task and assess actual risk

## Acceptance Criteria

1. `npm audit` reports 0 high/critical vulnerabilities
2. `cargo audit` reports 0 high/critical vulnerabilities
3. Dependabot alert count reduced (ideally to 0)
4. Any remaining vulns have documented justification
