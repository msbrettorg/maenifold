# T-63.1 — Fix --bg-panel + Dark Mode Tokens

**Requirement**: FR-3
**Test Cases**: TC-6
**Repo**: pipeline-ui
**Component**: src/App.vue, src/components/PipelineRunner.vue

## Context

`--bg-panel` is referenced by components but NEVER DEFINED in `:root`. Result: textarea backgrounds are transparent in dark mode. Several other surface/error tokens also missing.

## Acceptance Criteria

1. After T-63.0 lands, verify `--bg-panel` is defined in `:root` (it will be from the design tokens spec)
2. Ensure `PipelineRunner.vue` textarea uses `var(--bg-input)` or `var(--bg-panel)` — no hardcoded colors
3. Ensure `PipelineInspector.vue` input/select elements use `var(--bg-input)` — no hardcoded colors
4. Audit ALL components for hardcoded background colors and replace with design token variables
5. Verify dark mode: every surface token has a dark override in the `@media (prefers-color-scheme: dark)` block
6. Typecheck passes: `npx vue-tsc --noEmit`

## SWE Remediation

PASS. Verified --bg-panel and dark-mode surface overrides in App.vue; moved PipelineInspector inputs to --bg-input; confirmed PipelineRunner textarea uses tokenized background; replaced remaining hardcoded component background colors with design tokens/color-mix token blends across chat, palettes, dialogs, cards, badges, and workflow views; vue-tsc passes.
