# T-63.7 — Fix compute_pipeline_status Abandoned

**Requirement**: FR-9
**Test Cases**: TC-21
**Repo**: maenifold-rs
**Component**: crates/maenifold-core/src/workflow/pipeline/engine.rs

## Context

`compute_pipeline_status` does not account for `abandoned` nodes. A pipeline where all nodes are terminal but some are abandoned shows as "active" in the view response instead of a terminal state.

## Acceptance Criteria

1. In `compute_pipeline_status` (engine.rs), add logic: if all nodes are in terminal state AND any node is `abandoned`, pipeline status = `"stuck"`
2. Define terminal states explicitly: `completed`, `abandoned`, `stuck`
3. If ALL nodes are `completed` (none abandoned/stuck), pipeline status = `"completed"`
4. If any node is `abandoned` or `stuck` AND no node is `active`/`ready`/`pending`, pipeline status = `"stuck"`
5. View response reflects the corrected status
6. ALL existing pipeline tests pass: `cargo test -p maenifold-core -- pipeline`
7. Add a test: create pipeline with 2 nodes, complete one, abandon the other → status = `"stuck"`
