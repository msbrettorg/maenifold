## Problem

Selecting a note on the Knowledge tab shows the title and memory:// URI but the content area is blank — just a thin gray bar where the rendered markdown should be. No text, no headings, no content at all.

## Requirements

The note content must render as proper markdown with:
- Headings (h1-h6) with correct hierarchy and sizing
- Body text in `text-text-primary` — readable, not blue, not faint
- Code blocks with syntax highlighting and `font-mono` in `bg-surface-container`
- Mermaid diagrams rendered (not raw source)
- Tables with proper borders and padding
- Links styled but not blue-on-gray — use `text-brand` with underline on hover
- WikiLinks `[[concept]]` rendered as clickable internal links
- Text size minimum `text-sm` (12px) — never smaller
- Proper line spacing and paragraph margins

## Contrast rules

- Body text: `text-text-primary` on `bg-surface` or `bg-bg-app`
- Secondary text: `text-text-secondary` — captions, metadata only
- NEVER blue text on gray background
- NEVER faint/tertiary text for body content

## Files

- `apps/desktop/src/components/KnowledgeNoteRenderer.vue` — rebuilt in sprint 05, likely broken
- `apps/desktop/src/components/KnowledgeContent.vue` — container
- Check markdown-it configuration and prose styling

## Acceptance Criteria

1. Note content renders as formatted markdown
2. All text readable against dark background
3. Mermaid diagrams render (not raw source)
4. Code blocks have syntax highlighting
5. Tables render with visible borders
6. Verified in packaged Electron app via CDP

## Root cause found

`@tailwindcss/typography` plugin is NOT installed. The `prose prose-sm dark:prose-invert` classes in KnowledgeNoteRenderer.vue do nothing. Markdown renders as unstyled HTML — invisible on dark background.

The component code is actually correct — it uses `useMarkdownIt` + `useMermaid` + DOMPurify. Just needs the Tailwind plugin.

## Fix

```bash
cd apps/desktop && npm install @tailwindcss/typography
```

Then add to tailwind config if needed. The `prose dark:prose-invert` classes will style all markdown output automatically.

Same fix needed in ChatMessageItem.vue and ChatContentBlocks.vue if they use prose classes.
