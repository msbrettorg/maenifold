# T-63.25 — Sidebar Delete Without Navigation

**Requirement**: FR-5
**Test Cases**: TC-13
**Repo**: pipeline-ui
**Component**: src/components/PipelineSidebar.vue, src/stores/pipeline.ts

## Context

Deleting a non-current pipeline in the sidebar first loads it (causing a visible flash/navigation), then deletes it. Should delete by session ID without loading.

## Acceptance Criteria

1. Add `deletePipelineById(sessionId: string)` to the Pinia store that calls the MCP delete operation directly without first loading the pipeline
2. `PipelineSidebar.vue` delete button calls `deletePipelineById` instead of loading then deleting
3. If the deleted pipeline is the currently loaded one, clear the canvas/runner state
4. If the deleted pipeline is NOT the currently loaded one, current view is unaffected
5. After delete, refresh the sidebar pipeline list
6. Typecheck passes: `npx vue-tsc --noEmit`

## Swe Notes

PASS. Added store-level deletePipelineById, updated sidebar delete to avoid load/navigation, preserved current view for non-current deletes, cleared state only when deleting the active pipeline, and passed vue-tsc.
