# T-48.4 — Composable: `useMemoryApi`

**Requirement:** FR-48
**Component:** `vendor/acp-ui/src/composables/`

## Summary

Vue composable that provides typed fetch wrappers for the `/api/memory/*` REST endpoints.

## Acceptance Criteria

1. Create `vendor/acp-ui/src/composables/useMemoryApi.ts`
2. Exports `useMemoryApi()` returning:
   - `readMemory(uri: string): Promise<MemoryFile>` — calls `/api/memory/read?uri=...`
   - `searchMemories(query: string, opts?): Promise<SearchResult>` — calls `/api/memory/search`
   - `recentActivity(opts?): Promise<RecentResult>` — calls `/api/memory/recent`
3. Response types defined or imported from `workflow-types.ts`
4. Uses `fetch()` with relative URLs (same-origin)
5. Error handling: throws on non-200 responses with server error message
6. No Pinia dependency — pure fetch wrapper
