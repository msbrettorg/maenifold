## Revised Scope (post-discovery)

**Original scope**: Full vue-flow replacement. **Revised**: CSS→Tailwind migration only.

The PipelineComposer subsystem is 2,721 LOC across 14 components. Full vue-flow replacement exceeds the 600 LOC/task limit and carries significant functional risk. The T-03.0 epic goal is "zero style blocks" — CSS migration achieves this with lower risk.

13 pipeline components have `<style>` blocks. Batch into 2-3 SWE dispatches by file group:
- Batch 1: PipelineComposer.vue, PipelineComposerToolbar.vue, PipelineComposerContextMenu.vue, PipelineComposerContextMenuDesign.vue
- Batch 2: PipelineNodeCard.vue, PipelineNodeCardPorts.vue, PipelineNodeCardStatus.vue, PipelineFlowEdge.vue
- Batch 3: PipelineView.vue, PipelineActionBar.vue, PipelineFlyout.vue, PipelineIconRail.vue, PipelineRunner.vue, PipelineSidebar.vue

## Acceptance Criteria
- Zero `<style>` blocks in all 13 pipeline components (excluding audit-ok exemptions for `:deep()` or complex selectors)
- `npx vue-tsc --noEmit && npm run build` passes
