# T-205.707 — Fix: Knowledge notes cannot be selected via click

**Pipeline**: test
**Pipeline Digest**: 16842feaee5604e196f8d0c4ddc8a6566bd538a1ad2d739bc956a9e49f123128

## Bug

On the Knowledge tab (Notes view), clicking a file in the folder tree does not select it. The content pane stays on "Select a note." The click event is not registering on the tree item buttons.

User confirmed the same behavior with real mouse — the note cannot be selected by clicking.

**Severity: P1** — Knowledge Notes viewer is non-functional. Users cannot read any note content.

## Reproduction

1. Navigate to Knowledge tab
2. Expand any folder (e.g., architecture)
3. Click any file button in the tree
4. Content pane remains on "Select a note" empty state

## Found During

UAT T-205.376 interactive CDP testing. User confirmed via mouse.

## Acceptance

- Clicking a file in the tree selects it and displays its content in the viewer pane
