# T-224.1 — Scaffold POC Directory + Bridge Server

## Problem

We need a standalone POC that connects CopilotKit to our maenifold daemon. The first piece is a thin Node.js bridge that translates ACP WebSocket events into AG-UI SSE events that CopilotKit can consume.

## Scope

Create `poc/copilotkit/bridge/` with:

1. **`package.json`** with deps: `express`, `cors`, `ws`, `@ag-ui/core`, `@ag-ui/encoder`, `uuid`, `typescript`, `tsx`
2. **`index.ts`** — Express server on port 4000 that:
   - Accepts POST requests from CopilotKit's `RunAgent` endpoint
   - Opens/reuses ACP WebSocket connections to `ws://127.0.0.1:<PORT>/ws/acp?agent=<agent>`
   - Sends `initialize` → `session/new` → `session/prompt` sequence
   - Translates streaming ACP `session/update` events → AG-UI SSE events
   - Returns SSE stream with `text/event-stream` content type
3. **`README.md`** with setup and run instructions

## ACP→AG-UI Event Translation

```
ACP session/update          →  AG-UI SSE Event
─────────────────────────────────────────────
(on connect + prompt)       →  RUN_STARTED
AgentMessageChunk (first)   →  TEXT_MESSAGE_START
AgentMessageChunk (next)    →  TEXT_MESSAGE_CONTENT
ToolCall                    →  TOOL_CALL_START + TOOL_CALL_ARGS
ToolCallUpdate (completed)  →  TOOL_CALL_END
stopReason: endTurn         →  TEXT_MESSAGE_END + RUN_FINISHED
stopReason: toolUse         →  (keep run open, more events coming)
Error / disconnect          →  RUN_ERROR
```

## Key implementation details

- Bridge maintains a session pool keyed by CopilotKit `threadId`
- LRU evict stale sessions after 30 minutes
- The daemon port is read from `MAENIFOLD_PORT` env var (default: the daemon's configured port)
- Agent name defaults to `copilot` but is configurable via `MAENIFOLD_AGENT` env var
- CORS allows localhost:3000 (the React app)

## Acceptance Criteria

- [ ] `cd poc/copilotkit/bridge && npm install && npx tsx index.ts` starts the bridge on port 4000
- [ ] POST to `http://localhost:4000/` with a RunAgent-shaped body returns SSE stream
- [ ] SSE stream contains properly formatted AG-UI events
- [ ] Bridge connects to running maenifold daemon via ACP WebSocket
- [ ] Multiple requests reuse the same ACP session (keyed by threadId)
- [ ] Errors return RUN_ERROR events, not crashes
