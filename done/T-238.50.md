# T-238.50 — P0 Add token refresh loop to Teams supervisor

**Pipeline**: sdd

## Problem

The token is passed once at startup and never refreshed. When it expires, the Trouter connection dies silently. The agency-cowork reference runs a background token refresh loop that also re-registers with Trouter after each refresh.

## Reference

- agency-cowork: `/Users/brett/src/agency-cowork/skills/teams/scripts/monitor/service.py` L719-760 `_token_refresh_loop()`
- agency-cowork: `/Users/brett/src/agency-cowork/skills/teams/scripts/api/auth.py` L78-181 `TokenManager`
- Rust target: `crates/maenifold-core/src/teams/supervisor.rs` and `token_provider.rs`

## Required changes

1. Add `refresh_due()` and `seconds_until_refresh()` to token provider (port from Python `TokenManager`)
2. Add a background task in supervisor that:
   - Sleeps until token refresh is due (compute from token expiry minus buffer)
   - Acquires a fresh token via `acquire_token(force_refresh=true)`
   - Updates the Trouter client token
   - Re-registers with Trouter registrar
   - Updates chatsvc token for reply functionality
3. Log refresh events

## Acceptance Criteria

- [ ] Token refreshes proactively before expiry
- [ ] Trouter re-registers after token refresh
- [ ] Refresh failure logs error, retries with backoff
- [ ] `cargo build --release -p maenifold-cli` passes
- [ ] All files under 300 LOC
