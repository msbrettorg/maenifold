## Problem

Workflows tab opens to a wasteland (screenshot in gate notes):

1. **No default selection.** Center pane shows the empty-state "Select a workflow" placeholder even though dozens of workflows are in the left rail. Every visit forces a manual click before any content appears.
2. **Dead empty column.** There's a wide blank band between the workflow list (left rail) and the detail pane. Looks like a missing or zero-content middle column. The list rail is also visually cramped — workflow titles truncate (`Constitutional Agent Architectur…`, `Conjectures & Refutations (Multi-…`).

## Fix

- On `WorkflowsView` mount: if no workflow is selected AND the list has items, default the selection to the first item in the currently-visible (filtered) list. Re-evaluate when the category filter or search changes — if the active selection is filtered out, fall back to the first remaining item.
- Collapse the dead column. Two-pane layout: list rail (320–360px) on the left, detail panel (fluid) on the right. Either widen the list rail enough that titles fit, or ellipsize gracefully with a `title` tooltip on hover so the full name is still reachable.

## Files

- `apps/desktop/src/components/WorkflowsView.vue` (and the layout container that owns the pane sizes)
- Workflow selection store / composable if selection state lives outside the view

- [ ] Opening the Workflows tab from a fresh session immediately shows the first workflow's detail (steps + description), not the empty-state placeholder
- [ ] Switching category tabs (`All`, `Reasoning`, `Scientific`, `Multi-agent`, ...) auto-re-selects the first item in that category if the current selection is no longer visible
