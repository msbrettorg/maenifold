# T-238.52 — P0 Add chatsvc region probing and 200-echo detection for Teams reply

**Pipeline**: sdd

## Problem

`reply.rs` sends replies to a hardcoded chatsvc region. Non-AMER users get silent reply failures because the message is sent to the wrong regional endpoint. The agency-cowork reference probes for the correct region on startup and detects 200-echo responses (wrong region indicator) with automatic region correction.

## Reference

- agency-cowork: `/Users/brett/src/agency-cowork/skills/teams/scripts/monitor/message_handler.py` L151-228 `probe_chatsvc_region()`
- agency-cowork: `/Users/brett/src/agency-cowork/skills/teams/scripts/monitor/message_handler.py` L639-720 (200-echo detection + region auto-correction)
- Rust target: `crates/maenifold-core/src/teams/reply.rs`

## Required changes

1. Port `probe_chatsvc_region()` — probe multiple regional endpoints to find the one that returns the user's conversations
2. Add 200-echo detection — when chatsvc returns 200 with a `messages` array (echo), extract correct region from `conversationLink` and retry
3. Store discovered region for subsequent replies
4. Add region probing on supervisor startup
