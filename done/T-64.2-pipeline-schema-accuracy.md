# T-64.2 Pipeline Schema Accuracy

**Requirement**: FR-44 (Pipeline composer node types)
**Priority**: High
**Files**: `crates/maenifold-core/src/mcp/schema/workflow_tools.rs`

## Problem

The pipeline tool's MCP JSON schema in `workflow_tools.rs` has three inaccuracies:

1. **Description** (line 161): Says "composed of workflow nodes" — should reflect all 4 node types.
2. **Missing `prompt` property**: The handler accepts an optional `prompt` string when `run=true` (handler.rs line 170), but the schema does not advertise this parameter.
3. **Graft node schema too narrow** (lines 236-254): Graft node items require `["id", "workflowId"]` and only expose `id`, `workflowId`, `acpClient`. This makes it impossible to graft Prompt, SequentialThinking, or Tool nodes at the schema level.

## Acceptance Criteria

1. **Description**: Change to `"Creates and manages pipeline sessions composed of DAG nodes."`.
2. **Add `prompt` property**: Add a string property after `run`:
   ```rust
   ("prompt", string_property("Ambient prompt for autonomous pipeline execution")),
   ```
3. **Graft node schema**: Relax the graft node items to accept any valid node shape. Remove `"required": ["id", "workflowId"]` and `"additionalProperties": false` from graft node items, replacing with a more permissive schema that requires only `"id"`:
   ```json
   {
     "type": "object",
     "properties": {
       "id": { "type": "string", "description": "New node identifier" },
       "workflowId": { "type": "string", "description": "Workflow definition to run" },
       "acpClient": { "type": "string", "description": "Optional ACP client" },
       "prompt": { "type": "string", "description": "Prompt text for prompt nodes" },
       "agent": { "type": "string", "description": "ACP agent for prompt/thinking nodes" },
       "toolMode": { "type": "string", "description": "Tool mode for prompt nodes" },
       "topic": { "type": "string", "description": "Topic for sequential thinking nodes" },
       "totalThoughts": { "type": "integer", "description": "Thought count for thinking nodes" },
       "analysisType": { "type": "string", "description": "Analysis type for thinking nodes" },
       "toolName": { "type": "string", "description": "MCP tool name for tool nodes" },
       "toolArgs": { "type": "object", "description": "Tool arguments for tool nodes" }
     },
     "required": ["id"]
   }
   ```
4. **Existing test** `pipeline_schema_includes_all_new_operation_fields_with_expected_types` SHALL continue to pass.
5. **No other schema changes** — only the three fixes above.
