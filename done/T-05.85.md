## Problem

The Gate task table text is barely readable against the dark background. Task ID, Task title, and Process columns all use low-contrast text colors. The table headers are also too faint.

## Fix

Use design tokens from DESIGN.md — no custom colors:

- Table headers: `text-text-primary` + `font-medium` (currently too faint)
- Task ID column: `text-text-secondary` (mono) — this is OK as-is
- Task title column: `text-text-primary` — currently too dark/faint, needs primary
- Process column: `text-text-secondary` — OK
- Progress column badges: already using Badge — check contrast
- Row hover: `bg-surface-high` 
- Selected row: `bg-brand/10` with `text-text-primary`

## Files

- `apps/desktop/src/components/GateTaskTable.vue`

## Rules

- ZERO custom colors, ZERO var(--), ZERO hand-rolled anything
- Compare against DESIGN.md §4 (color roles) for correct token usage
