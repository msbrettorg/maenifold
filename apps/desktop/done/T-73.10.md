## Description
Wire the import button in WorkflowBrowser.vue. Opens a file dialog (Tauri plugin-dialog) to select a .json file. Parses and validates the JSON. Loads into draftDefinition for review before saving. Handles ID collision (warns if workflow with same ID already exists). Validation errors shown inline. Uses the draft model from T-73.3.
