## Problem

`make audit-crates` fails because 3 files in `maenifold-gate` exceed the 300 LOC limit:

- `src/mcp/dispatch.rs` — 308 lines (8 over)
- `src/ui_window.rs` — 313 lines (13 over)
- `src/task_status.rs` — 302 lines (2 over)

## Fix

Split each file to bring all under 300 LOC. Strategies per file:

1. **dispatch.rs (308):** Extract helper functions or a logical subsection into a new sibling module (e.g., `dispatch_helpers.rs`).
2. **ui_window.rs (313):** Extract tray menu construction or event handling into a sibling module.
3. **task_status.rs (302):** Only 2 lines over — tighten whitespace, remove unnecessary blank lines, or extract a small helper. Do NOT add `// audit-ok`.

## Acceptance Criteria

1. All 3 files are under 300 LOC (measured by `wc -l`)
2. `cargo build --release -p maenifold-gate` succeeds
3. `make audit-crates` passes for these 3 files
4. No behavioral changes — pure structural refactor
5. No `// audit-ok` exemptions added
