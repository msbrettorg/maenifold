# T-210.7 — Teams Tab

## Description

Add a Teams tab to the desktop app's AppTabBar. The tab:

1. Shows Teams-originated sessions using existing SessionList
2. Renders conversations using existing ChatView/ChatMessageList/ChatContentBlocks
3. Shows connection status badge (connected/disconnected/error)
4. Settings section for keyword/scope/identity using shadcn form components

## KISS Constraint

ZERO custom components. Reuse existing chat infrastructure. The Teams tab is a filtered view of sessions tagged as Teams-originated.

## Key Files

- Create: `apps/desktop/src/components/teams/TeamsTab.vue`
- Modify: `AppTabBar.vue` to add Teams tab

## Acceptance Criteria

- Tab appears in AppTabBar with Teams icon
- Sessions filtered to Teams-originated only
- Chat rendering identical to Agents tab
- Connection status visible
- TypeScript clean
- Follows DESIGN.md tokens
