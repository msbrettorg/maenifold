## Problem

T-205.714 added column resize handles to GateTaskTable.vue. When GateTaskTable was deleted and rebuilt from scratch in T-05.70, the column resize feature was lost. There are no resize handles in the current implementation.

## Evidence

CDP verification on 2026-04-24: `document.querySelector('[data-column-resize-handle]')` and `document.querySelector('.resize-handle')` both return null. No resize-related code exists in GateTaskTable.vue.

## Fix

Add column resize handles to the gate task table. Consider using TanStack Table's built-in column resizing API or a custom drag handle approach.

## Acceptance criteria

1. Gate task table column headers have visible drag handles
2. Dragging a handle resizes the column
3. Column widths persist across tab switches (nice to have, not required)
