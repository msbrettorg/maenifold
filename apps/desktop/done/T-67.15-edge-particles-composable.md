# T-67.15 — Edge Particles Composable

**Requirement**: FR-38
**Phase**: 3

## Context
Edge particles make reasoning propagation visible. Tiny dots travel along SVG edge paths. Must be imperative SVG manipulation (not reactive Vue templates) for 60fps.

## Acceptance Criteria
1. New composable `src/composables/useEdgeParticles.ts` created
2. API: `useEdgeParticles()` returns `{ startParticles(edgeIds: string[]): void, stopParticles(): void, stopAll(): void }`
3. Particles: 3px SVG circles, source node accent color at 70% opacity
4. Speed: ~120px/sec along SVG path via `getPointAtLength()`
5. Spawn rate: 1 particle per 400ms per active edge
6. Single `requestAnimationFrame` loop manages all particles
7. Particle cleanup on component unmount (via `onUnmounted`)
8. Particles only show on edges from/to active or recently-completed nodes
9. `npx vue-tsc --noEmit` passes
10. Composable stays under 150 LOC
