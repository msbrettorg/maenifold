### 3) Replacement rule

Every replaced literal must become a token-driven Tailwind utility (`bg-app`, `bg-sidebar`, `bg-surface`, `text-primary`, `text-secondary`, `text-tertiary`, `text-disabled`, `border-subtle`, `border-card`, etc.).

Raw `var(--token)` usage inside component files is allowed only where Tailwind does not expose the required token utility.

### 4) Escalation rule

Any hex literal not present in the mapping table is out of scope for executor judgment and must be escalated to PM before replacement.

## Acceptance Criteria

1. `rg "#[0-9a-fA-F]{3,8}\\b" apps/desktop/src/ --glob '!components/ui/**' --glob '!assets/tailwind.css'` returns 0 matches.

3. Visual baseline diffs (T-176.LINT) show <1% pixel drift on home, gate, knowledge, chat, and pipeline surfaces.
