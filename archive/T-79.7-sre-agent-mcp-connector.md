# T-79.7: Register Maenifold as SRE Agent MCP Connector

## Requirement
FR-SRE-2 — Azure SRE Agent must be able to call maenifold tools (memory, knowledge graph, pipelines) via MCP.

## Problem
Azure SRE Agent supports MCP connectors natively. Maenifold already exposes an MCP HTTP endpoint. This is a configuration-only task — no code changes — but needs a connector YAML template and documentation.

## Acceptance Criteria
1. Connector template file created at `docs/sre-config/connectors/maenifold.yaml`:
   ```yaml
   api_version: azuresre.ai/v1
   kind: DataConnector
   spec:
     name: maenifold
     dataConnectorType: MCP
     dataSource: ##maenifoldEndpoint##
     identity: system
   ```
2. Documentation covers both setup paths:
   - **Portal**: Builder → Connectors → Add MCP Server → Streamable-HTTP → maenifold URL
   - **srectl**: `srectl apply-yaml --file connectors/maenifold.yaml` (with parameter substitution)
3. Documentation lists which maenifold MCP tools SRE Agent gains access to:
   - `SearchMemories`, `ReadMemory`, `WriteMemory`, `BuildContext`
   - `SequentialThinking`, `Workflow`, `Pipeline`
   - `FindSimilarConcepts`, `Visualize`
4. Documentation includes network requirements (maenifold HTTP endpoint must be reachable from Azure)
5. Documentation includes optional YAML for assigning maenifold tools to a subagent:
   ```yaml
   mcp_tools:
     - maenifold/*
   ```
