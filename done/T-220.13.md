# T-220.13 - Preserve Home Quick Prompt on Send Failure

## Problem

The home quick prompt clears user input and navigates before the backend/session send is confirmed.

## Evidence

- `apps/desktop/src/components/HomeDashboard.vue:61-68` emits prompt, switches tabs, and clears input immediately.
- `apps/desktop/src/App.vue:80-98` tries to preserve input when `sendPrompt` returns false, but the event path does not return the result to `HomeDashboard`.
- Source: `docs/codebase-audit-2026-04-25.md#p1-12`.
- Parent sequential thinking session: `session-1777125506368-62098`.

## Acceptance Criteria

- [ ] Home prompt submission is modeled as an async callback or result-bearing action.
- [ ] Input is cleared only after confirmed send or session creation.
- [ ] On send/session failure, the input remains visible and an inline error is shown.
- [ ] Navigation to chat happens only after confirmed success or preserves recoverable state on failure.
- [ ] `cd apps/desktop && npx vue-tsc --noEmit` succeeds.
