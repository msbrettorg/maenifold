# T-57.3 — Submachine Integration

## Context

The bash `run_workflow()` checks each workflow step for `requiresSequentialThinking: true`. When found, it:
1. Extracts `metadata.toolHints.SequentialThinking.estimated_thoughts`
2. Seeds a new SequentialThinking session with `parentWorkflowId` linking to the workflow
3. Registers it as a submachine via the Workflow tool (`submachineSessionId`)
4. Runs `run_think()` to completion
5. Then continues with the normal agent call for that step

This composability is a key differentiator — thinking happens *within* workflow steps, not as a separate process.

## Requirements

Modify `run_workflow()` in `runner.rs` to add submachine support:

### Before each agent call in the step loop:

1. **Check step metadata**: Parse the workflow step response for `requiresSequentialThinking` flag. The workflow handler returns step metadata as JSON — extract the boolean flag and estimated thoughts count.

2. **If thinking required**:
   a. Call `run_think(context, agent, topic, ThinkOptions { total_thoughts: estimated, parent_workflow_id: Some(workflow_session_id) })`.
   b. Register the thinking session as a submachine: call `workflow::workflow()` with `{sessionId: workflow_session_id, submachineSessionId: think_session_id}`.
   c. Wait for `run_think()` to complete.
   d. Then proceed to the agent prompt for the step (thinking gives context, agent does the work).

3. **If thinking NOT required**: Skip directly to agent prompt (current behavior).

## Test Strategy

1. Step with `requiresSequentialThinking: true`: verify `run_think()` is called before agent prompt
2. Step without the flag: verify `run_think()` is NOT called
3. Submachine registration: verify Workflow tool called with `submachineSessionId`
4. Parent workflow linkage: verify `ThinkOptions.parent_workflow_id` is set

## Acceptance Criteria

- [ ] Steps with `requiresSequentialThinking` trigger a thinking submachine before the agent prompt
- [ ] Thinking session linked to workflow via `parentWorkflowId` and `submachineSessionId`
- [ ] Steps without the flag skip thinking entirely
- [ ] All existing `run_workflow()` tests still pass
- [ ] Under 60 LOC delta on runner.rs
