# T-202.6 — Register sdd-c and tdd-c confession processes as gate built-ins

## Intent

The `sdd-c.json` and `tdd-c.json` process definition files already exist in `crates/maenifold-gate/assets/`. They need to be registered in the gate catalog so they ship as built-in processes alongside sdd, tdd, gsd, lightweight, mdd, slc.

## Scope

**Modified files:**
- `crates/maenifold-gate/src/gate_catalog.rs`

## Changes required

1. **Line 10**: Add `"sdd-c"` and `"tdd-c"` to `RESERVED_BUILTIN_NAMES`
2. **After line 16**: Add `const SDD_C_JSON: &str = include_str!("../assets/sdd-c.json");` and `const TDD_C_JSON: &str = include_str!("../assets/tdd-c.json");`
3. **Lines 111-116** (`builtin_asset_text` match): Add `"sdd-c" => Ok(SDD_C_JSON),` and `"tdd-c" => Ok(TDD_C_JSON),`
4. **Test `all_builtin_assets_parse_and_validate`** (~line 257): Add `("sdd-c", SDD_C_JSON),` and `("tdd-c", TDD_C_JSON),` to the test matrix
5. **Test imports** (~line 127): Add `SDD_C_JSON, TDD_C_JSON` to the import list

## Acceptance criteria

1. `cargo build --release -p maenifold-gate` succeeds
2. `cargo test -p maenifold-gate` passes (including the new built-in parse/validate test entries)
3. `gate status --root .` works on a project using `pipeline: sdd-c`
