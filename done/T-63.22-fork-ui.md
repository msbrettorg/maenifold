## Context

Fork creates a new pipeline session derived from a specific node's point in the DAG. The operation exists in the store (after T-63.20) but has no UI trigger.

## Acceptance Criteria

1. Add "Fork from here" action button in `PipelineInspector.vue` node actions area (visible in server mode when a node is selected)

5. Button uses `.btn-ghost` or `.btn-primary` class from design system
6. Button has busy state (disable during fork operation)
7. Typecheck passes: `npx vue-tsc --noEmit`
