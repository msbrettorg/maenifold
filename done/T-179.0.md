## Problem

1. **Home/Agents overlap:** When Agents tab is active but no session is connected, main content falls through to `v-else` → HomeDashboard. Agent sidebar + Home tiles = mixed concerns.
2. **Settings is a modal dialog:** SettingsView uses `position: fixed; inset: 0; z-index: 1000` overlay. The `@close` emit isn't wired in App.vue so the ✕ button does nothing. Can't navigate back.
3. **Redundant settings icon:** AppSidebar has ⚙ button that duplicates the Settings tab in the nav bar.

## Acceptance Criteria

1. Home tab shows HomeDashboard. Agents tab shows sidebar + agents empty state (not connected) or ChatView (connected). No fallback HomeDashboard on other tabs.
2. Settings tab renders inline as a full page filling the content area — not a modal overlay.
3. No ⚙ settings button in the agents sidebar.
4. `cd apps/desktop && npx vue-tsc --noEmit` passes.

## Files

- `apps/desktop/src/App.vue`
- `apps/desktop/src/components/SettingsView.vue`
- `apps/desktop/src/components/AppSidebar.vue`

## Spec

### App.vue
- Replace `v-else` HomeDashboard fallback (line ~142) with explicit `v-else-if="activeTab === 'agents'"` showing a centered empty state: "Select an agent and start a new session"
- Remove `@open-settings="activeTab = 'settings'"` from AppSidebar usage
- Remove `'open-settings'` from sidebar emit handling

### SettingsView.vue
- Remove `.settings-overlay` fixed positioning, backdrop-filter, backdrop blur, z-index
- Make component fill parent container (flex col, h-full)
- Remove close button and `emit('close')`
- Remove `onKeydown` Escape handler and focus trap
- Remove `overlayRef` and all refs to it
- Keep internal nav + content layout intact

### AppSidebar.vue
- Remove ⚙ button (lines 63-67)
- Remove `'open-settings': []` from emits
