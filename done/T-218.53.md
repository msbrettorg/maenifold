# T-218.53 — Desktop Design Token Drift Audit Inventory

## Problem

Multiple desktop surfaces may use hardcoded Tailwind palette classes, hex literals, or component-local color hacks instead of the semantic design tokens defined in `apps/desktop/DESIGN.md`. Prior duo review found only 2 Vue files with hardcoded palette classes (10 matches total), suggesting the actual drift is smaller than originally feared — but a systematic audit is needed to confirm.

## Parent

Decomposed from T-218.41 (Audit and remediate desktop contrast and design-token drift). T-218.41 was too broad (308 components). This task performs the audit only; remediation tasks will be created based on findings.

## Research Stage (GSD: research → plan → execute → verify)

### Research
1. Run `npm run lint:design` and `npm run audit:components` — capture current pass/fail state
2. Grep all `.vue` files for hardcoded Tailwind palette classes: `bg-blue-*`, `text-blue-*`, `border-blue-*`, `bg-gray-*`, `text-gray-*`, etc.
3. Grep for hex color literals (`#[0-9a-fA-F]{3,8}`)
4. Grep for `style=` inline styles with color values
5. Cross-reference findings against `apps/desktop/DESIGN.md` semantic token list
6. Categorize: contrast violation, token drift, or both

### Plan
Produce an audit inventory at `outputs/audits/T-218.53-token-drift-inventory.md` with one row per finding:
- UI surface, file path, component name
- Current class/token usage
- Violated DESIGN.md rule
- Proposed replacement token
- Severity (high = contrast failure, medium = wrong token, low = cosmetic)

### Execute
Write the inventory document.

### Verify
Confirm inventory completeness: every hardcoded palette class, hex literal, and component-local color hack in reachable `.vue` files is catalogued.

## Acceptance Criteria

- [ ] Audit inventory produced at `outputs/audits/T-218.53-token-drift-inventory.md`
- [ ] All hardcoded Tailwind palette classes in `.vue` files catalogued
- [ ] All hex color literals in `.vue` files catalogued
- [ ] Each finding categorized with severity and proposed fix
- [ ] Summary statistics: total findings, by severity, by view
- [ ] Based on findings, create specific remediation gate tasks (or document that no remediation is needed)
