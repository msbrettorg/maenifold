## ✨ Features

- Updated TypeScript and Vue LSP server configurations: added `rootUri: "apps/desktop"`, specified initialization options for TypeScript/Vue, expanded `fileExtensions` for more file types, and set `requestTimeoutMs` for Vue server to support large projects
- Added a comprehensive "LSP Reference" section describing LSP server configs, monorepo layouts, operational caveats, and agent guidance; clarifies that LSP is preferred (not strictly mandatory) with detailed instructions on usage and limitations
- Added `unicode-normalization 0.1.25` to the dependency tree for use in the Rust backend
- Added `unicode-normalization = "0.1"` to dependencies for possible Unicode handling in the core crate
- Changed native tool invocation logic: if the JSON output envelope has `{"success": false, ...}`, the result is now surfaced as an MCP error (`CallToolResult::error`) instead of success, enabling client-side error routing
- Added `envelope_indicates_failure(text: &str) -> bool` to detect error envelopes in tool output
- Added tests for domain-failure envelope detection in the new helper
- Added tests related to failure and success JSON envelopes for sequential thinking completions with and without conclusions, and improved error reporting for unknown fields and session starting requirements
- Added `suggest_known_field(key: &str) -> Option<&'static str>` helper to provide actionable suggestions for unknown SequentialThinking payload fields in `crates/maenifold-core/src/thinking/validation.rs`
- Added explicit verification step to check for `maenifold.gate` domain registration via `GatewayIndex` on the MCP daemon after rebuild, and print a warning if missing
