# T-214.4 — MCP schema extension

## Problem

The Pipeline MCP tool schema needs to expose `sessionRef` on prompt nodes so clients can submit pipelines with session-backed nodes.

## Solution

Add `sessionRef` to `PipelinePromptNodeSchema` in the MCP schema definitions. The field should be optional with the same shape as `SessionRef`:
```json
{
  "sessionRef": {
    "type": "object",
    "properties": {
      "agent": { "type": "string" },
      "sessionId": { "type": "string" }
    },
    "required": ["agent", "sessionId"]
  }
}
```

Also add validation: `sessionRef.agent` must match the node's `agent` field.

## Key Files

- `crates/maenifold-core/src/mcp/schema/pipeline_node_types.rs` — `PipelinePromptNodeSchema`

## Acceptance Criteria

- `sessionRef` appears in the Pipeline MCP tool's input schema for prompt nodes
- Validation rejects mismatched `sessionRef.agent` vs node `agent`
- `cargo build --release -p maenifold-core` succeeds
