# T-200.11 — Split client.rs (417 LOC → 2 files under 300)

## Intent

`crates/maenifold-jockey/src/acp/client.rs` is 417 production LOC — 1.39x the 300 LOC hard limit. Extract terminal handling into a separate module.

## Scope

Files to modify:
- `crates/maenifold-jockey/src/acp/client.rs` — trim to ~270 LOC (remove terminal impl, delegate to client_terminal)
- `crates/maenifold-jockey/src/acp/client_terminal.rs` — new, ~150 LOC (terminal infrastructure + impl functions)
- `crates/maenifold-jockey/src/acp/mod.rs` — add `mod client_terminal;`

## Extraction Plan

### client_terminal.rs (new, ~150 LOC)
- `TerminalHandle` struct (lines 20-24)
- `TERMINAL_HANDLES` static + `terminal_handles()` (lines 26-29)
- `shutdown_terminals()` (lines 31-51) — change visibility to `pub(crate)`
- Free functions implementing terminal logic (extracted from trait methods):
  - `create_terminal(args)` → from lines 300-328
  - `terminal_output(args)` → from lines 330-374
  - `wait_for_terminal_exit(args)` → from lines 376-392
  - `kill_terminal(args)` → from lines 394-404
  - `release_terminal(args)` → from lines 406-416

### client.rs (keep, ~270 LOC)
- `cap_raw()` (lines 8-18)
- `JockeyUiClient` struct (lines 53-56)
- `impl acp::Client for JockeyUiClient` with:
  - `request_permission` — stays (lines 60-117)
  - `session_notification` — stays (lines 118-258)
  - `read_text_file` — stays (lines 259-286)
  - `write_text_file` — stays (lines 287-298)
  - terminal trait methods — delegate to `client_terminal::*`

### Visibility
- `shutdown_terminals` in client_terminal.rs: `pub(crate)` (called from handlers.rs via `super::client::shutdown_terminals`)
- Terminal impl functions: `pub(crate)` (called from client.rs trait impl)
- client.rs import: `use super::client_terminal;`
- mod.rs: The existing `use super::client::shutdown_terminals` path in worker/handlers.rs still works because the function is re-exported or accessible

## Acceptance Criteria
1. `cargo build --release -p maenifold-jockey` succeeds
2. `cargo test -p maenifold-jockey` passes (all existing tests)
3. Both files are under 300 production LOC
4. No behavioral changes — pure code move
5. `shutdown_terminals()` remains accessible from `super::client::shutdown_terminals` in handlers.rs
