# T-220.11 - Sanitize Mermaid SVG Output

## Problem

Mermaid SVG output is injected into the DOM without the DOMPurify sanitizer used by the Markdown renderer.

## Evidence

- `apps/desktop/src/composables/useMermaid.ts:83-90` uses `outerHTML` and `insertAdjacentHTML` for Mermaid output/error paths.
- `docs/dependency-simplification-audit.md:39-67` recommends using existing DOMPurify.
- Source: `docs/codebase-audit-2026-04-25.md#p1-10`.
- Parent sequential thinking session: `session-1777125506368-62098`.

## Acceptance Criteria

- [ ] Mermaid SVG output is sanitized with DOMPurify using an SVG-appropriate profile or tight allowlist.
- [ ] Mermaid error rendering uses DOM construction and `textContent`, not raw HTML insertion.
- [ ] Sanitization happens after Mermaid render and before DOM insertion.
- [ ] Tests or targeted verification cover malicious diagram content.
- [ ] `cd apps/desktop && npx vue-tsc --noEmit` succeeds.
