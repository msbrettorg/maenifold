# T-200.13 — Split cold_start.rs (343 LOC → 2 files under 300)

## Intent

`crates/maenifold-jockey/src/acp/session/cold_start.rs` is 343 production LOC — 1.14x the 300 LOC hard limit. Extract model/config extraction helpers into a separate module.

## Scope

Files to modify:
- `crates/maenifold-jockey/src/acp/session/cold_start.rs` — trim to ~270 LOC (remove helper functions)
- `crates/maenifold-jockey/src/acp/session/cold_start_helpers.rs` — new, ~75 LOC (constants, capability builder, model/mode extraction)
- `crates/maenifold-jockey/src/acp/session/mod.rs` — add `mod cold_start_helpers;`

## Extraction Plan

### cold_start_helpers.rs (new, ~75 LOC)

Move from cold_start.rs:
- `INIT_TIMEOUT` constant (line 18)
- `SESSION_TIMEOUT` constant (line 19)
- `LIVE_CONNECTION_SEQ` static (line 20)
- `default_client_capabilities()` function (lines 22-28)
- `collect_models_from_select_options()` function (lines 30-49)
- `extract_models_from_config_options()` function (lines 51-75)
- `extract_mode_ids()` function (lines 77-91)

### cold_start.rs (keep, ~270 LOC)

Retain only `cold_start()` function with imports from cold_start_helpers.

Note: `default_client_capabilities` is also imported by `execute.rs` as `super::cold_start::default_client_capabilities`. After the move, re-export it from cold_start.rs or update execute.rs to import from cold_start_helpers.

## Acceptance Criteria
1. `cargo build --release -p maenifold-jockey` succeeds
2. `cargo test -p maenifold-jockey` passes (all existing tests)
3. Both files are under 300 production LOC
4. No behavioral changes — pure code move
