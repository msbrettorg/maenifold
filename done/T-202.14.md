# T-202.14 — Bug: Gate page task title column too narrow

## Problem

The Gate page task table has a very narrow "Task" column that causes long task titles to wrap into many lines, making the table nearly unreadable. Each row becomes extremely tall.

Evidence: `outputs/screenshots/sprint-202/11-gate.png` — T-202.9 title wraps across 7+ lines in a column roughly 120px wide, while the Task detail panel on the right is mostly empty space.

## Fix

Rebalance column widths. The Task ID and Process columns can be narrower. The Task title column should get the majority of horizontal space. Consider:
- Using `table-layout: fixed` with explicit column width percentages
- Making Task ID ~80px, Process ~80px, Progress ~80px, Task title gets remaining space
- Or use a responsive approach where the detail panel collapses on narrow viewports

## Acceptance criteria

1. Task titles in the Gate table are readable without excessive wrapping
2. Column widths are balanced — narrow columns for ID/Process/Progress, wide column for title
3. CDP screenshot shows readable task list
