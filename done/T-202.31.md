# T-202.31 — Embeddings page shows flat-layout model as "Not installed"

## Problem

On Settings > Embeddings, `all-MiniLM-L6-v2` shows "Not installed" even though it exists on disk at `~/maenifold/assets/models/all-MiniLM-L6-v2.onnx` (flat layout). The `is_model_installed()` function only checks subdir layout (`{id}/model.onnx`), so flat-layout models are invisible to the UI.

## Observed

CDP test 2026-04-20: Embeddings tab shows "Not installed" + "Download" button for a model that is physically present and was previously loaded by the daemon.

## Expected

Models installed in flat layout should show as "Installed" (not "Active" — only the configured active model gets that badge). The Download button should not appear for models already on disk.

## Acceptance Criteria

1. `is_model_installed()` checks both subdir AND flat layout
2. Flat-layout models show "Installed" status, not "Not installed"
3. No "Download" button shown for models already on disk
