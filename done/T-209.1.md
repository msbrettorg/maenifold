## Description

The pipeline score function needs per-node timing and token data. Current `NodeState` (in `types_node.rs`) lacks `startedAt`, `completedAt`, `inputTokens`, `outputTokens`, `costUsd`, and `model`.

## Changes

1. Add fields to `NodeState` struct in `crates/maenifold-core/src/workflow/pipeline/types_node.rs`:
   - `started_at: Option<chrono::DateTime<Utc>>`
   - `completed_at: Option<chrono::DateTime<Utc>>`
   - `input_tokens: Option<u64>`
   - `output_tokens: Option<u64>`
   - `model: Option<String>`

2. Populate `started_at` when node transitions to `Active` in `executor_apply.rs`
3. Populate `completed_at` when node transitions to `Completed`/`Failed`/`Abandoned`
4. Populate token fields from ACP session response if available
5. Expose in `Pipeline view` output

## Acceptance Criteria

- `NodeState` serializes/deserializes with new optional fields (backwards compatible)
- Timing fields populated for prompt and thinking nodes
- `Pipeline view` includes timing data
- `cargo build --release -p maenifold-core` passes
- Existing pipeline tests pass
