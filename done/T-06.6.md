# T-06.6 — Packaged Electron verification must attach to the real app page

## Problem

Mandatory visual verification for desktop regressions is currently blocked by the verification path itself.

During packaged-Electron verification for the Knowledge screen layout fix, the app launched and exposed a real CDP page target for:

- `file:///.../maenifold.app/Contents/Resources/app.asar/dist/index.html`

But `agent-browser connect`, `agent-browser --cdp 9334`, and direct page-websocket attempts all resolved to:

- `about:blank`
- no interactive elements

That means the required packaged-app verification loop cannot currently prove or disprove UI behavior, even when the packaged app and CDP port are live. This is a trust problem, not a tooling inconvenience.

## Evidence

- Packaged build succeeded in this session:
  - `cd apps/desktop && npm run build`
  - `cd apps/desktop && npm run package`
- Captured launch log: `/tmp/maenifold-9334.log`
- Raw CDP targets from `curl http://127.0.0.1:9334/json/list` included:
  - page title `maenifold`
  - page URL `file:///Users/brett/src/ma-collective/maenifold-rs/apps/desktop/out/maenifold-darwin-arm64/maenifold.app/Contents/Resources/app.asar/dist/index.html`
- `agent-browser` verification attempts in this session still returned:
  - URL `about:blank`
  - empty page / no interactive elements

## Acceptance Criteria

- [ ] Launching the packaged Electron app with `--remote-debugging-port=<port>` produces a verifiable `agent-browser` session against the actual app page, not `about:blank`.
- [ ] `agent-browser connect <port>` or an approved documented equivalent can target the real packaged-app page reliably.
- [ ] `agent-browser snapshot -i` on the packaged app returns real interactive elements from the app shell.
- [ ] The verification path works without requiring screenshots alone or manual trust in agent self-report.
- [ ] The fix is demonstrated against the packaged Electron app, not only the dev server.
- [ ] The verification notes include the exact launch/connect workflow that future agents should use.
