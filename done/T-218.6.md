# T-218.6 — Teams Tab Status Regression Verification

## Problem

The Teams tab blank-page fix was closed without validating the original packaged Electron symptom or console failure. Prior review also identified a status parsing risk: plain text `disconnected` can be misread as connected if the UI uses substring matching.

## Affected Completed Tasks

- T-210.7 — Teams tab component
- T-210.10 — Teams tab unread badge
- T-218.4 — Teams tab renders blank page

## Acceptance Criteria

- [ ] In packaged Electron via CDP, navigate to the Teams tab from a cold start
- [ ] Confirm visible `Teams Monitor` header, status badge, and empty state/action controls
- [ ] Confirm no Vue/reactivity console errors during tab activation, tab switching away/back, and refresh
- [ ] Verify JSON `{"status":"disconnected"}` renders disconnected
- [ ] Verify JSON `{"connected":false}` renders disconnected
- [ ] Verify plain text `disconnected` does not render as connected
- [ ] Verify MCP/resource error payloads render explicit error state, not connected
- [ ] Verify unread badge appears only when unread count is greater than zero and clears on Teams tab activation
