## Description
Wire the "+ ADD NEW STEP" button in WorkflowStepTimeline.vue. Inserts a new step into draftDefinition.steps with a generated stable kebab-case ID (e.g., "step-{timestamp}"), default name "New Step", empty description. New step appears at the end of the timeline. Step is auto-selected in the inspector for immediate editing.
