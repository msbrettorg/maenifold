# T-175.5 — Cross-cutting: adopt Paper/Ink palette + DM Sans across SPA shell

**Pipeline**: sdd
**State**: pending

## Context

The dashboards (`memory/Dashboards/gate-pipeline.html`, `mind.html`) use a coherent Paper/Ink design system: warm off-white `--bg`, sage/blue/amber/terracotta/plum accents, DM Sans display + Fira Code mono. The SPA shell still uses the legacy Tailwind defaults (`bg-[#201f1f]`, `text-[#707070]`, generic Inter/system stack). Switching tabs feels like switching apps.

Goal: make the SPA shell visually quote the dashboards so the four tabs (Agents/Pipelines/Gates/Workflows/Graph) feel like one product. Avoid touching every component — restyle the shell + tokens; let component CSS inherit.

Repo: `/Users/brett/src/ma-collective/maenifold-rs`

## Scope

**Files:**
- `apps/desktop/src/assets/main.css` — root CSS variables (`--background`, `--foreground`, `--text-*`, `--font-*`, accent colors)
- `apps/desktop/src/App.vue` — `<style>` block (transitions only currently — leave intact, just ensure tokens flow)
- `apps/desktop/src/components/AppTabBar.vue` — `<style scoped>` (currently hardcoded `#131313`, `#e5e2e1`)
- `apps/desktop/src/components/AppSidebar.vue` — replace hardcoded `#201f1f`, `#707070`, `#4d8eff` with tokens
- `apps/desktop/index.html` — add Google Fonts link for DM Sans + Fira Code

**Out of scope:** ChatView body styling (tickets T-132.4 owns), PipelineView/WorkflowAuthoringPage internal CSS (separate ticket if needed), `@vue-flow/core` theme overrides, dashboards in `memory/Dashboards/`, dark/light mode logic (must continue to work via existing `prefers-color-scheme`).

## Acceptance Criteria

- Root `--background`, `--surface`, `--text`, `--text-dim`, `--border`, `--sage`, `--blue`, `--amber`, `--terracotta`, `--plum` tokens exist and match the dashboards.
- `--font-display` uses `'DM Sans', system-ui, sans-serif`; `--font-mono` uses `'Fira Code', 'Cascadia Code', Consolas, monospace`.
- `AppTabBar` and `AppSidebar` reference tokens — no raw hex left in either component.
- Light + dark mode both render coherently — verify by toggling system theme.
- Tab-bar active underline + tab hover state read at parity with the dashboard nav style.
- No regression: every existing tab still loads, no contrast failures, no broken layouts.
- Build passes: `cd apps/desktop && pnpm build`.
