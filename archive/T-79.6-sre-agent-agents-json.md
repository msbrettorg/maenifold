# T-79.6: agents.json Configuration and Pipeline Integration Test

## Requirement
FR-SRE-1 — Azure SRE Agent must be usable as a pipeline prompt node.

## Problem
Once the binary exists, it needs to be registered in `~/maenifold/agents.json` so maenifold's `AgentPool` can spawn it. The runtime config no longer lives in the repo, now includes a top-level `mcpServers` array plus per-agent `mcpServers`, and agent entries point at native binaries rather than npm shims. An integration test must verify the full path: pipeline node → agent pool → agent binary → SRE Agent → response.

## Acceptance Criteria
1. Documentation added to `docs/` explaining SRE Agent setup:
   - Prerequisites: .NET 9, SRE Agent available, `az login`, and any required local binaries installed
   - `~/maenifold/agents.json` location and update workflow
   - Current baseline agent set in `~/maenifold/agents.json`: `Codex`, `Copilot`, `OpenCode`, `Goose`, `claude-code`
   - Current config shape example showing top-level `mcpServers` and per-agent `mcpServers`:
      ```json
      {
        "mcpServers": [
          {
            "name": "maenifold",
            "command": "/absolute/path/to/maenifold",
            "args": ["mcp", "stdio"],
            "env": {}
          }
        ],
        "agents": {
          "AzureSRE": {
            "command": "/absolute/path/to/maenifold-sre-agent",
            "args": [],
            "env": {
              "SRE_AGENT_ENDPOINT": "https://example"
            },
            "mcpServers": ["maenifold"]
          }
        }
      }
      ```
   - Agent entries use native binary paths, not npm shim commands
   - Required env vars: `SRE_AGENT_ENDPOINT`; document any additional supported env vars if implemented
   - Example pipeline YAML using `agent: AzureSRE`
2. Example pipeline definition that uses SRE Agent as a node:
    ```yaml
    - id: investigate
      type: prompt
      agent: AzureSRE
      prompt: "Check the health of resource group prod-web"
    ```
3. Integration test (can be `#[ignore]` for CI, requires live SRE Agent):
   - Loads config compatible with `~/maenifold/agents.json`
   - Spawns the configured native agent binary
   - Sends ACP initialize + new_session + prompt
   - Verifies a response is returned
   - Sends close_session + shutdown
4. All existing tests pass
