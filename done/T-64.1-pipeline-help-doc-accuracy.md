# T-64.1 Pipeline Help Doc Accuracy

**Requirement**: FR-44 (Pipeline composer node types)
**Priority**: High
**Files**: `assets/usage/tools/pipeline.md`

## Problem

The pipeline tool help doc (`assets/usage/tools/pipeline.md`) has not been updated to reflect the v2 node type additions. It only shows Workflow node examples and omits the `prompt` parameter for `run`.

## Acceptance Criteria

1. **Description**: The opening line SHALL say "Creates and manages pipeline sessions composed of DAG nodes." (not "workflow nodes").
2. **Parameters section**: SHALL document the `prompt` parameter: `- \`prompt\` (string, optional): Ambient prompt passed to all agent-dispatched nodes during autonomous execution.`
3. **Node type examples**: The "Definition shape" section SHALL show examples for all 4 node types:
   - Workflow: `{ "id": "...", "workflowId": "...", "acpClient": "..." }`
   - Prompt: `{ "id": "...", "prompt": "...", "agent": "...", "toolMode": "disabled" }`
   - SequentialThinking: `{ "id": "...", "topic": "...", "agent": "...", "totalThoughts": 5 }`
   - Tool: `{ "id": "...", "toolName": "...", "toolArgs": {} }`
4. **Lifecycle section**: The `run` entry SHALL mention the optional `prompt` parameter.
5. **No existing content removed** — only additions and the description wording change.

## Verification

- File renders as valid Markdown.
- All 4 node types shown in definition shape.
- `prompt` parameter documented in both Parameters and Lifecycle sections.
