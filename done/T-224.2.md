# T-224.2 — Scaffold CopilotKit React App

## Problem

We need a minimal React app using CopilotKit that connects to our bridge server and provides a fully agentic chat UI — CopilotKit's prebuilt components handle streaming, tool calls, and conversation state.

## Scope

Create `poc/copilotkit/app/` with:

1. **Vite + React + TypeScript** scaffold
2. **CopilotKit integration**:
   - `@copilotkit/react-core` for the runtime
   - `@copilotkit/react-ui` for prebuilt chat components
3. **App.tsx** with `CopilotKit` provider pointing at bridge URL (`http://localhost:4000`)
4. **A chat surface** — use `<CopilotSidebar>` or `<CopilotChat>` for the main interaction
5. **Dark theme** matching maenifold's aesthetic (Obsidian Engine-inspired)
6. **Vite proxy** to avoid CORS issues: `/api → localhost:4000`

## Key implementation details

- CopilotKit's `runtimeUrl` points to the bridge server
- No tool registrations on the React side — all tools are server-side (ACP agent selects them)
- The app is purely a consumer of the AG-UI event stream
- Conversation history is managed by CopilotKit's built-in state

## Acceptance Criteria

- [ ] `cd poc/copilotkit/app && npm install && npm run dev` starts the app on localhost:3000
- [ ] CopilotKit chat UI renders with an input field and message area
- [ ] Dark theme applied (dark background, light text, accent colors)
- [ ] Chat input accepts text and submits to bridge
- [ ] README documents setup and run instructions
