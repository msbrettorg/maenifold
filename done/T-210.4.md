# T-210.4 — TeamsMonitor MCP Tools

## Description

MCP tool for controlling the Teams monitor:

- `enable` — start the Trouter connection + message handler
- `disable` — stop monitoring, close WebSocket
- `status` — return connection state, last message time, match count
- `configure` — set keywords, sender filter, cooldown, agent to dispatch

Config stored in `maenifold.json` settings.
