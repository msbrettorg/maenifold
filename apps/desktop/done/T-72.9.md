**Pipeline**: mdd

**Component**: `src/components/PipelineNodeCard.vue`, `src/assets/app-sidebar.css`

## Context

Pipeline nodes currently show BOTH a status emoji (⏳🔄✅⚠️🚫) AND a color-coded `.status-dot`. The emoji is redundant and clutters the node card. The sidebar `<h1>` ("maenifold") is plain text with no brand treatment.

## Acceptance Criteria

1. Remove the `statusEmoji` computed property and `<span class="status-emoji">` element from `PipelineNodeCard.vue`.
2. Remove the `.status-emoji` CSS rule.
3. The color-coded `.status-dot` remains as the sole status indicator — it is sufficient.
4. In `app-sidebar.css`, `.sidebar-header h1` gets `font-family: var(--font-headline); letter-spacing: 0.06em`.
5. Net result is code DELETION — fewer lines, cleaner nodes.
6. `npx vue-tsc --noEmit` passes.
