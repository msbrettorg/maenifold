# T-65.1 — Session Store Decomposition

**Requirement**: NFR-6
**Test Cases**: TC-83, TC-84
**Repo**: pipeline-ui
**Component**: src/stores/session.ts

## Context

session.ts is 369 LOC — over the 300 LOC guideline. It contains ~25 computed properties that simply project fields from `activeSession`, plus async actions for mode/model/config changes. The computed projections are mechanical and can be extracted.

## Acceptance Criteria

1. Extract all computed property projections (currentSession through startupElapsed — approximately 20 computeds) into a new file `src/stores/session-getters.ts` that exports a function taking the reactive session state and returning the computed refs
2. The session store (`session.ts`) imports and spreads the getters, maintaining the identical public API — all existing consumers continue to work without changes
3. `session.ts` is ≤ 300 LOC after extraction
4. `session-getters.ts` is ≤ 300 LOC
5. All existing tests pass: `npx vitest run` (if applicable) and `npx vue-tsc --noEmit`
6. No changes to any component that imports from the session store
