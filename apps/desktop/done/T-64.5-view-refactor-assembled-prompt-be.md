**Requirement**: FR-20

## Acceptance Criteria

- `add_pipeline_node_view_fields` signature refactored to `(&mut Value, &PipelineNode, &NodeState, &ToolContext)`
- ToolContext threaded through `pipeline_nodes_json` → `add_pipeline_node_view_fields`
- For completed/active Prompt, Workflow, and SequentialThinking nodes: view response includes `assembled_prompt` field
- Assembled prompt reconstructed from: predecessor context + ambient prompt + node instruction
- Predecessor context sourced from `predecessor_context_content()` using incoming edges + completed upstream node outputs
- When predecessor context is unavailable (node pending, no upstream): `assembled_prompt` is null
- All existing pipeline tests pass
- `cargo test -p maenifold-core -- pipeline` green

## Design Guidance

The assembled prompt is the cognitive pipeline's primary output artifact — it IS how reasoning context flows into agent nodes. This must be reconstructable from existing state, not stored redundantly.
