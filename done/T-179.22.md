# T-179.22 — Home hero redesign (cowork pattern)

## Intent

The Home tab is cluttered with a 3x2 tile grid, status header, and embedded recent sessions. The north-star reference (agency-cowork) uses a **centered hero layout**: logo → headline → compact category row → config chips → input bar. We need to match that pattern exactly.

## Reference (agency-cowork App.jsx:4731-5110)

The cowork hero has these layers, all centered vertically and horizontally:
1. **Brand icon** — CopilotLogo, 100px, mb-20
2. **Headline** — "What can I help you with?" (26px, fw600, textPrimary, centered)
3. **Category tiles** — 5-across grid of compact cards (bgElevated, border-card, r8, min-h 72px) each with: icon (22px) + label (11px fw600) + description (9px textTertiary)
4. **Config chips** — horizontal flex row of pill tags (folder, model, mode) with subtle borders
5. **Input bar** — full-width textarea in a surfaced container with mic + send buttons
6. **Disclaimer** — tiny muted footer text

## Scope

**File:** `apps/desktop/src/components/HomeDashboard.vue` (full rewrite of template)

## Categories (replacing tiles)

| Key | Label | Description | Lucide Icon | Accent |
|-----|-------|------------|-------------|--------|
| agents | Agents | Start or resume sessions | MessageSquare | brand |
| pipelines | Pipelines | Run multi-step workflows | GitBranch | success |
| gate | Gate | Track tasks & delivery | Shield | warning |
| workflows | Workflows | Browse & author | Brain | thinking |
| knowledge | Knowledge | Explore the graph | Search | brand |

## What to remove

- The entire `HomeTile` interface and `tiles` array
- The status header with "maenifold" h1 and daemon/gate pills (move to config chips)
- The Recent sessions embedded Card (users go to Agents tab for sessions)
- The current composer at bottom (replace with centered hero input)

## What to keep (refactored)

- `useDaemonStore()` for connection status (shown as chip)
- `useGateRegistryStore()` for pending count (shown as chip)
- Category click handlers that call `emit('select-tab', cat.tab)` to navigate

## Acceptance Criteria

1. Home shows centered hero layout: brand icon → headline → 5 category tiles → status chips → input bar
2. Category tiles are compact (min-h 72px), single row, 5 columns, with lucide icons
3. No emoji anywhere
4. Status info shown as subtle chips, not a header
5. Input bar is prominent, centered, max-w 800px
6. Clicking a category navigates to that tab
7. Vast breathing room — content vertically centered in available space
8. `npx vue-tsc --noEmit` passes
