# T-67.11 — Glassmorphism CSS System

**Requirement**: FR-31
**Phase**: 2

## Context
Zero backdrop-filter infrastructure exists. Need glassmorphism system for semantic zoom overlays and expanded nodes.

## Acceptance Criteria
1. New utility classes added to `src/styles/glass.css` (new) or `src/styles/shared-components.css`:
   - `.glass-surface`: `background: rgba(53, 53, 52, 0.6); backdrop-filter: blur(24px); -webkit-backdrop-filter: blur(24px);`
   - `.glass-surface-light`: Same at 80% opacity with 12px blur
   - `.ghost-border`: `border: 1px solid rgba(66, 71, 84, 0.15);`
2. New tokens added to `src/styles/design-tokens.css`: `--glass-bg: rgba(53, 53, 52, 0.6)`, `--glass-blur: 24px`, `--ghost-border-color: rgba(66, 71, 84, 0.15)`
3. CSS imported in main entry point
4. `npx vue-tsc --noEmit` passes

## Files
- `src/styles/glass.css` (new) or `src/styles/shared-components.css` (existing)
- `src/styles/design-tokens.css` (existing)

## Dependencies
- T-67.2 (surface tokens must be in place before defining glass surfaces)
