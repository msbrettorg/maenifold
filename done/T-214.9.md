# T-214.9 — Session Browser panel

## Problem

Users need a way to browse live sessions across connected ACP agents. This panel shows sessions grouped by agent with status and capability information.

## Solution

Create `apps/desktop/src/components/sessions/SessionBrowserPanel.vue`:

- Sections grouped by agent (accordion or collapsible groups)
- Each session shows: session ID (truncated), status, created date
- Capability badge: "Resumable" if `supports_load_session` is true
- Empty state per agent: "No sessions" or "Agent not connected"
- Error state: toast/inline error when fetch fails
- Refresh button per agent and global refresh
- Uses `useSessionBrowserStore()` from T-214.8
