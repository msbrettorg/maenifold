## The missing module

The discarded commits added `crates/maenifold-core/src/registry_gateway.rs` containing static `ToolDescriptor` entries for:

- `GatewayIndex`, `GatewayExecute`, `GatewayBatch`, `GatewayIntent`, `DiscoverMcpTools`
- `gate_Status`, `gate_Sync`, `gate_Append`, `gate_Pass`, `gate_Fail`, `gate_History`, `gate_TaskBody`

Each descriptor's `invoke` is a thin wrapper that calls `mcp::invoke(context, "<ToolName>", payload)`. The wrappers are defined via a `gateway_tool!` macro.

`crates/maenifold-core/src/registry.rs` was modified to chain `registry_gateway::descriptors()` into the `all_descriptors()` iterator.
