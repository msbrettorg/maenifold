# T-202.8 — Bug: gate parser treats H2 headings inside fenced code blocks as stage records

## Problem

`task_section_parser.rs` splits task markdown on `## ` headings without respecting fenced code blocks (triple backtick regions). If a task spec contains an H2 heading inside a code example, the parser treats it as a real stage record and fails with "gate section is missing Stage ID."

## Reproduction

A task file containing:

    ```markdown
    ## Cancelled
    - Record Kind: cancel
    ```

...will cause `gate sync` to fail because the parser sees `## Cancelled` as a stage heading.

## Expected behavior

H2 headings inside fenced code blocks (``` ... ```) should be ignored by the section parser.

## Acceptance criteria

1. Task files with H2 headings inside fenced code blocks parse without error
2. Task files with H2 headings outside code blocks still parse correctly as stage records
3. Existing tests pass
4. New test: fenced code block containing `## SomeHeading` does not produce a parsed section
5. `cargo build --release -p maenifold-gate` succeeds
6. `cargo test -p maenifold-gate` passes

## File

`crates/maenifold-gate/src/task_section_parser.rs`
