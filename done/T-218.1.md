# T-218.1 — Knowledge Note Content Text Overflow

## Problem

In the Knowledge tab, when viewing a note (e.g. "The Bridge — Converged Intelligence Panel Vision"), the body text paragraphs overflow the right edge of the content area and are clipped without wrapping. Long descriptive lines run off-screen — the user cannot read the full text without horizontal scrolling.

The ASCII art / code-block sections render correctly within their bordered container, but the prose paragraphs below ("Top: The Latent Question", "Stratum 1: The Now Line", etc.) extend past the viewport boundary.

## Evidence

Screenshot: `Screenshot 2026-04-24 at 8.58.04 PM.png` — visible text truncation on paragraphs under "Stratum 2: The Thread" and "Top: The Latent Question".

## Expected Behavior

Note body text wraps within the content panel. No horizontal overflow. Long lines break at the container boundary.

## Likely Cause

Missing `overflow-wrap: break-word`, `word-wrap: break-word`, or `max-width` constraint on the note content container in the Knowledge/Notes view component.

## Acceptance Criteria

- [ ] Note prose text wraps within the content area — no horizontal overflow
- [ ] Code blocks / ASCII art still render with horizontal scroll if needed (preserve `pre` behavior)
- [ ] Verified via CDP in packaged Electron app
