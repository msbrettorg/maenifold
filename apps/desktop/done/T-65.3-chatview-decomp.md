# T-65.3 — ChatView Decomposition

**Requirement**: NFR-6
**Test Cases**: TC-87, TC-88
**Repo**: pipeline-ui
**Component**: src/components/ChatView.vue

## Context

ChatView.vue is 1766 LOC — nearly 6x the 300 LOC guideline. It is the largest file in the codebase. It handles message rendering, input composition, tool call display, thinking trace display, permission handling, and streaming state. This needs decomposition into focused sub-components.

## Acceptance Criteria

1. ChatView.vue is decomposed into sub-components, each ≤ 300 LOC. Suggested decomposition (agent may adjust):
   - `ChatMessageList.vue` — scrollable message list with auto-scroll
   - `ChatMessageItem.vue` — individual message rendering (user vs assistant styling)
   - `ChatInputBar.vue` — input textarea, send button, mode/model selectors
   - `ChatToolCallList.vue` — tool call result rendering within messages
   - `ChatStreamingIndicator.vue` — streaming/thinking state display
   - `ChatView.vue` — composition root (imports sub-components, wires store)
2. The parent `ChatView.vue` remains the public entry point — no changes to any file that imports `ChatView.vue`
3. All sub-components are ≤ 300 LOC
4. `ChatView.vue` itself is ≤ 300 LOC
5. `npx vue-tsc --noEmit` passes
6. All existing tests pass
7. No behavioral changes — same user experience before and after
