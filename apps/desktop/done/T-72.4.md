# T-72.4 — Dialog backdrop blur

**Pipeline**: mdd
**Pipeline Digest**: b826a880e632e457a4be2a8cbfabf45b8434090f1df1416e349cb1f9700565df
**Requirement**: UX-POLISH-72 — Modal overlays should feel premium with glass-morphism depth
**Component**: `src/components/PermissionDialog.vue`, `src/components/AuthMethodDialog.vue`, `src/components/SettingsView.vue`

## Context

Modal overlays currently use a flat semi-transparent `--bg-overlay` background. Adding `backdrop-filter: blur()` creates a modern glass-morphism effect that reads as premium desktop app quality.

Cross-platform concern: Tauri uses WebView2 on Windows and WKWebView on macOS. `backdrop-filter` is widely supported but should use an `@supports` guard.

## Acceptance Criteria

1. All three overlay components add `backdrop-filter: blur(8px); -webkit-backdrop-filter: blur(8px)` to their overlay container.
2. The blur is wrapped in `@supports (backdrop-filter: blur(1px))` to gracefully degrade on unsupported renderers.
3. Inside the `@supports` block, overlay background opacity is reduced from `rgba(0,0,0,0.6)` to `rgba(0,0,0,0.4)` to avoid double-dimming when blur is active.
4. SettingsView overlay (if it uses one) follows the same pattern.
5. `npx vue-tsc --noEmit` passes.
