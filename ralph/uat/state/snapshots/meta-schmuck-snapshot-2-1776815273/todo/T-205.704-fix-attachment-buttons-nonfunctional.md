# T-205.704 — Fix: Image, Audio, and File attachment buttons non-functional on Agents tab

**Pipeline**: test
**Pipeline Digest**: 16842feaee5604e196f8d0c4ddc8a6566bd538a1ad2d739bc956a9e49f123128

## Bug

On the Agents tab chat interface, the Image, Audio, and File (@) attachment buttons do not work at all. User-reported during UAT session — confirmed by accessibility tree showing Image and Audio as `[disabled]`.

From CDP snapshot:
```
- button "Image" [disabled, ref=e60]
- button "Audio" [disabled, ref=e61]
- button "@ File" [ref=e59]
```

Image and Audio are permanently disabled with no apparent way to enable them. The "@ File" button exists but its functionality is unconfirmed.

**Severity: P1** — Core chat functionality. Users cannot attach files, images, or audio to agent conversations.

## Found During

UAT sprint 205, user-reported during interactive CDP testing. Corroborated by accessibility tree snapshot from T-205.22 session creation.

## Acceptance

- Image button opens a file picker filtered to image types, or provides clear feedback on why it's unavailable
- Audio button opens a file picker filtered to audio types, or provides clear feedback on why it's unavailable
- File button opens a file picker or context menu for file selection
- If buttons are conditionally disabled (e.g., agent doesn't support attachments), show a tooltip or visual indicator explaining why
- All three buttons functional for agents that support attachments
