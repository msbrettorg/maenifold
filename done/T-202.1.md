# T-202.1 — Fix reka-ui Select test migration drift

## Intent

17 pre-existing tests fail across 12 files because tests look for `<select>` HTML elements but reka-ui's Select component renders as `<button role="combobox">`. This is migration drift from the CSS migration commit (50750f25f), predating Sprint 201.

- `ToolPaletteFields.test.ts`
- `ToolNodeFields.test.ts`
