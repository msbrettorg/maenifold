# T-202.11 — P0: Home page shows hardcoded placeholder data

## Problem

`MindDashboard.vue` line 20: `const hasMcpResources = false` — permanently hardcoded to false. The entire home screen shows fake numbers:

- Concepts: 1,420 (hardcoded)
- Memories: 386 (hardcoded)
- Edges: 9,210 (hardcoded)
- Communities: hardcoded list with fake member counts

This is what every user sees after completing onboarding. The first impression of the product is fake data. Sprint 178 shipped this as a TODO stub and it was never connected to real data.

## Verified ground truth

- `apps/desktop/src/components/MindDashboard.vue` line 20-30: hardcoded stats
- Line 22: `// TODO(T-178.0): replace placeholder refs with useMcpResources-backed reads`
- The TODO references `graph://stats`, `graph://corpus/snapshot`, `graph://corpus/communities` as MCP resources
- The maenifold MCP server exposes `MemoryStatus` tool which returns real corpus stats
- The HTTP API has `/api/graph/communities`, `/api/graph/nodes`, `/api/graph/edges`

## Fix

Connect the dashboard to real data via the existing API endpoints or MCP resources. Remove the hardcoded placeholder entirely. If no data exists yet (fresh install), show an empty state — not fake numbers.

## Acceptance criteria

1. Home page shows REAL corpus stats from the daemon (or empty state if no data)
2. No hardcoded numbers in the component
3. `hasMcpResources` removed or always true when daemon is connected
4. Communities loaded from real graph data
5. Loading state while fetching
6. Error state if daemon unreachable
