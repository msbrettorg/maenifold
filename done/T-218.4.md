# T-218.1 — Teams Tab Blank Page

## Bug Description

The Teams tab in the desktop app renders a completely blank page when clicked. The tab's navigation entry appears and selects correctly, but the TeamsTab.vue component's content area is empty.

## Evidence

- CDP verification (2026-04-24): Teams tab selected, accessibility tree shows only nav + notification region — no content elements
- DOM inspection: The container exists (`v-if` passed, `display: flex`) but has 0 children — innerHTML is `<!---->` (Vue empty render)
- Console error: `TypeError: Cannot read properties of null (reading 'effect')` — Vue reactivity error
- Settings tab works fine for comparison
- Screenshot: `outputs/screenshots/cdp-210.11/teams-tab-initial.png`

## Root Cause Hypothesis

The TeamsTab.vue component's `onMounted` hook calls `useMcpResources().subscribeResource('teams://status', ...)`. If this composable or the subscription fails with a reactivity error, the entire component render crashes silently.

The `Cannot read properties of null (reading 'effect')` error suggests a Vue computed/watch is accessing a ref that was already disposed — possibly a race condition between component mount and MCP resource subscription teardown.
