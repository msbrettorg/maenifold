# T-211.3 — Natural Language Cron Parser

## Description

Parse natural language time expressions into standard 5-field cron:

- "every weekday at 9am" → `0 9 * * 1-5`
- "every Monday at 3pm" → `0 15 * * 1`
- "every hour" → `0 * * * *`
- "daily at midnight" → `0 0 * * *`

Use the `croner` crate for validation and human-readable descriptions (per T-211.1 research — croner has `describe()`, `find_next_occurrence()`, and is already a transitive dependency). The NL parsing can be a lookup table of common patterns.

## Acceptance Criteria

- Common patterns parsed correctly
- Invalid expressions rejected with clear error
- Raw cron expressions accepted as passthrough
- `cargo build --release -p maenifold-core` succeeds
