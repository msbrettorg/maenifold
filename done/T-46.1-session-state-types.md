# T-46.1: Session State Types

**Requirement**: FR-46
**Priority**: P0
**Files**: `vendor/acp-ui/src/lib/types.ts`

## Acceptance Criteria

1. Add a `SessionState` interface to `types.ts` containing all per-session state:
   - `sessionId: string` — unique key for this live session slot
   - `agentName: string`
   - `cwd: string`
   - `session: SavedSession | null`
   - `isConnected: boolean`
   - `isConnecting: boolean`
   - `isLoading: boolean`
   - `error: string | null`
   - `messages: ChatMessage[]`
   - `toolCalls: Map<string, ToolCallInfo>`
   - `pendingPermissions: PermissionRequest[]`
   - `pendingAuthMethods: any[]`
   - `pendingAuthAgentName: string`
   - `agentInfo: { name: string; title?: string; version?: string } | null`
   - `agentPromptCapabilities: PromptCapabilities | null`
   - `supportsSessionList: boolean`
   - `availableModes: SessionMode[]`
   - `currentModeId: string`
   - `availableModels: ModelInfo[]`
   - `currentModelId: string`
   - `availableCommands: AvailableCommand[]`
   - `configOptions: SessionConfigOption[]`
   - `hasConfigOptions: boolean`
   - `currentPlan: PlanEntry[]`
   - `startupPhase: string`
   - `startupLogs: string[]`
   - `startupElapsed: number`

2. Add a `createEmptySessionState(sessionId: string, agentName: string, cwd: string): SessionState` factory function.

3. Add a `generateSessionId(): string` function that returns `session-${Date.now()}-${Math.random().toString(36).slice(2, 6)}`.

4. Do NOT modify any other files. Types only.
