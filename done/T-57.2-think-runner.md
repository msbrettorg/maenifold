# T-57.2 — Think Runner

## Context

The bash script `maenifold-acp` has a `run_think()` function that drives SequentialThinking sessions via acpx. It seeds a thinking session, then loops: prompt the agent for each thought, feed the response back to the SequentialThinking MCP tool, repeat until the agent says "DONE" or the thought count exceeds the limit.

No Rust equivalent exists. The existing `sequential_thinking()` handler manages session state; we need a runner that orchestrates agent calls around it.

## Requirements

Add to `crates/maenifold-core/src/workflow/runner.rs`:

### `pub async fn run_think(context, agent, topic, opts) -> Result<ThinkResult>`

1. **Seed thinking session**: Call `sequential_thinking()` handler with `{thoughtNumber: 0, totalThoughts: 5, nextThoughtNeeded: true, response: "[[{topic-slug}]]"}`. Extract `sessionId`.

2. **Create acpx session**: Call `AcpxDriver::create_session(&format!("think-{session_id}"))`.

3. **Thought loop** (`n = 1..`):
   a. Call `AcpxDriver::prompt(&acpx_session, &format!("Thought {n}/~{total} on: {topic}. Include [[WikiLinks]]. Say DONE when complete."))`.
   b. Ensure response contains `[[...]]` WikiLinks — append `[[step]]` if none found (matches bash `tag()` behavior).
   c. **Terminal condition**: if response starts with `DONE` (case-insensitive) OR `n >= total + 3`:
      - Call `sequential_thinking()` with `{nextThoughtNeeded: false, conclusion: response.text}`.
      - Break.
   d. Otherwise: call `sequential_thinking()` with `{nextThoughtNeeded: true, response: response.text, thoughtNumber: n}`.

4. **Return** `ThinkResult { session_id, conclusion, thoughts_completed }`.

### `pub struct ThinkResult`

```rust
pub struct ThinkResult {
    pub session_id: String,
    pub conclusion: Option<String>,
    pub thoughts_completed: u32,
}
```

### `pub struct ThinkOptions`

```rust
pub struct ThinkOptions {
    pub total_thoughts: u32,        // default: 5
    pub parent_workflow_id: Option<String>,  // for submachine linking
}
```

### Integration points

- Call `sessions::sequential_thinking()` handler directly.
- Call `AcpxDriver::create_session()`, `prompt()`.
- WikiLink tagging: simple regex check for `\[\[.*?\]\]`.

## Test Strategy

1. Happy path: agent completes in 3 thoughts with "DONE" prefix
2. Overflow protection: agent never says DONE, loop terminates at total + 3
3. WikiLink injection: response without `[[...]]` gets `[[step]]` appended
4. Session ID format: `think-{session_id}` for acpx session
