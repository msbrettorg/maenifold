# T-68.6: Enable Additional ACP Feature Flags

## Requirement
FR-50 — Enable useful unstable ACP features for richer agent interaction.

## Problem
We only enable 2 of 11 available feature flags: `unstable_session_close` and `unstable_session_model`. Several others would provide immediate value:
- `unstable_session_usage` — token usage tracking per prompt (cost visibility)
- `unstable_message_id` — message correlation across turns
- `unstable_session_fork` — fork sessions for branching experiments

## Acceptance Criteria
1. Enable `unstable_session_usage` feature flag in workspace Cargo.toml
2. Capture `UsageUpdate` in `HeadlessClient::session_notification`
3. Include `usage` from `PromptResponse` in `AcpxResponse`
4. Add `AcpxResponse.usage: Option<Usage>` field (tokens_in, tokens_out, cost)
5. Pipeline node completion output should include token usage when available
6. Evaluate `unstable_session_fork` and `unstable_message_id` — enable if beneficial, document if deferred
