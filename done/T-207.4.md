# T-207.4 — Extend MaenifoldHandler for gateway delegation

## Requirement

Modify `MaenifoldHandler` to delegate `tools/call` for gateway tools and include gateway tools in `tools/list`.

## Shared State

`StdioPool` and `ToolRoutingRegistry` must be `Arc`-wrapped and injected into `MaenifoldHandler` from the factory closure in `mcp/http.rs`. They are constructed once in `serve_http_listener_with_shutdown`, NOT per handler.

### Changes to `mcp/http.rs`

```rust
// In serve_http_listener_with_shutdown:
let pool = Arc::new(StdioPool::start(gateway_servers).await?);
let registry = Arc::new(ToolRoutingRegistry::build(&native_tools, &pool)?);

// In service() factory closure:
let pool_clone = Arc::clone(&pool);
let reg_clone = Arc::clone(&registry);
StreamableHttpService::new(
    move || {
        let mut handler = MaenifoldHandler::new(TransportKind::Http)?;
        handler.set_gateway(Arc::clone(&pool_clone), Arc::clone(&reg_clone));
        Ok(handler)
    },
    ...
)
```

### Changes to `call_tool` in `MaenifoldHandler`

Current flow:
1. Look up tool in native `ToolRegistry` → execute → return

New flow:
1. Look up tool in native `ToolRegistry` → if found, execute → return
2. If not found: check `ToolRoutingRegistry::lookup(tool_name)`
3. If `Some(server_name)`: call `StdioPool::call_tool(server_name, tool_name, arguments)`
4. Map the result:
   - `Ok(CallToolResult)` → return as-is (includes `isError: true` tool errors)
   - `Err(McpJsonRpcError { code, message, data })` → return as JSON-RPC error with same code (preserves protocol semantics per Server/Tools § Error Handling)
   - `Err(ConnectionError)` → return JSON-RPC error `-32603` (Internal error) with descriptive message including server name and stderr tail
5. If lookup returns `None`: return existing "tool not found" JSON-RPC error `-32601`

### Changes to `list_tools` in `MaenifoldHandler`

Current: returns native tools only.
New: returns native tools + `ToolRoutingRegistry::gateway_tools()`.

Gateway tools retain their original `name` and `inputSchema` unmodified.

## Key Files

- Modify: `crates/maenifold-core/src/mcp/mod.rs` (MaenifoldHandler struct + ServerHandler impl)
- Modify: `crates/maenifold-core/src/mcp/http.rs` (service factory + serve_http_listener_with_shutdown)
