# T-155.4 — Design system for desktop app

## Problem

There is no design system. Every component defines its own font sizes, colors, spacing, and occasionally its own font family. The result is visually inconsistent — different text sizes in the same view, no unified type scale, no central place to change the look and feel. This is systemic, not a per-component bug.

## What to build

### 1. Design tokens file — `apps/desktop/src/assets/design-tokens.css`

A single CSS file imported at the root that defines ALL visual tokens:

**Typography scale** (one font family, one scale):
- `--font-family: 'Inter', system-ui, -apple-system, sans-serif`
- `--text-2xs: 0.625rem` (10px)
- `--text-xs: 0.6875rem` (11px)
- `--text-sm: 0.75rem` (12px)
- `--text-base: 0.8125rem` (13px) — smaller default
- `--text-md: 0.875rem` (14px)
- `--text-lg: 1rem` (16px)
- `--text-xl: 1.125rem` (18px)
- `--text-2xl: 1.25rem` (20px)
- `--font-weight-normal: 400`
- `--font-weight-medium: 500`
- `--font-weight-semibold: 600`
- `--line-height-tight: 1.25`
- `--line-height-normal: 1.5`

**Spacing scale** (consistent gaps):
- `--space-1` through `--space-12` (4px increments)

**Color tokens** (already partially exist — consolidate):
- Existing `--bg-*`, `--text-*`, `--border-*` variables centralized

**Root application of tokens:**
```css
:root {
  font-family: var(--font-family);
  font-size: var(--text-base);
  line-height: var(--line-height-normal);
}
```

### 2. Font size preference — Settings → Preferences

A slider or 3-option selector (Compact / Default / Comfortable) that adjusts the root `font-size`:
- Compact: `--text-base: 0.75rem` (12px)
- Default: `--text-base: 0.8125rem` (13px)
- Comfortable: `--text-base: 0.875rem` (14px)

Persisted in local preferences store. Applied by setting a CSS class on `<html>` or adjusting the CSS variable directly.

### 3. Component migration

Every component that uses hardcoded `font-size` values must switch to the design token variables. This is the bulk of the work.

## Approach

1. Create the tokens file first
2. Import it in `main.ts` or `App.vue`
3. Audit every `<style>` block for hardcoded `font-size`, `font-family`, `font-weight`
4. Replace with token references
5. Add the preference control
6. Visual verification across all views

## Acceptance Criteria

1. One `design-tokens.css` file defines all typography, spacing, and color tokens
2. Every component uses token variables — zero hardcoded font-size/font-family values
3. Default base font is 13px (smaller than current)
4. Font size preference in Settings persists across app restart
5. All views visually consistent — same text sizes at same hierarchy levels
6. `cd apps/desktop && npx vue-tsc --noEmit` passes
7. Visual verification required across: Agents tab, Pipeline designer, Chat view, Settings, Edge mapping editor
