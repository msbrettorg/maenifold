Provide blue-team style evidence that a fresh [[Copilot-CLI]] session exposes [[maenifold]] and [[gate]] [[MCP]] tools after the bootstrap documentation/config path is followed. This continues parent [[sequential-thinking]] session `session-1777236650835-22077`.

## Acceptance Criteria

- Evidence distinguishes config presence, daemon reachability, Copilot server listing, and actual in-session tool exposure.
- `copilot mcp list` shows both `maenifold` and `gate`, or the task records exactly why that cannot be proven in-repo.
- A fresh Copilot CLI session exposes maenifold graph/reasoning tools and gate status/mutation tools, or the task records the blocking external limitation.
- Direct filesystem reads and CLI calls are not accepted as proof of MCP exposure.

## Verification

- Probe maenifold MCP endpoint on `8080` using the correct MCP protocol request.
- Probe gate MCP endpoint on `8081` using the correct MCP protocol request.
- Capture fresh-session Copilot MCP/tool visibility evidence.

- Do not create fake tool shims.
