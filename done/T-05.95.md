## Problem

Two different markdown renderers with different styling:

1. **KnowledgeNoteRenderer.vue** — uses `useMarkdownIt` (with Shiki + WikiLinks + mermaid) + `prose` classes. Correct approach but `@tailwindcss/typography` not installed so prose does nothing.

2. **GateTaskDetail.vue** — uses `marked` (different library!) with 40+ hand-rolled `[&_*]` Tailwind selectors to style HTML elements. No Shiki, no mermaid, no WikiLinks.

Both should look identical and use the design system.

## Fix

1. `npm install @tailwindcss/typography` — enables prose classes
2. Replace `marked` in GateTaskDetail with `useMarkdownIt` (same as KnowledgeNoteRenderer)
3. Both components use `<article class="prose prose-sm max-w-none dark:prose-invert">` with v-html
4. Remove the 40+ hand-rolled `[&_*]` selectors from GateTaskDetail
5. If prose defaults need overrides for our dark theme, add them to `tailwind.css` global layer (allowed per DESIGN.md)
6. Both render mermaid diagrams, syntax-highlighted code blocks, and WikiLinks

## Shared component

Consider extracting a shared `<MarkdownRenderer :content="..." />` wrapper that both GateTaskDetail and KnowledgeNoteRenderer use — it's the same code:
- `getMarkdownIt()` → `md.render(source)` → `DOMPurify.sanitize(html)` → `renderMermaidBlocks(container)`
- `<article class="prose prose-sm max-w-none dark:prose-invert" v-html="rendered" />`

KnowledgeNoteRenderer already IS this. GateTaskDetail should just use it.

## Files

- `apps/desktop/package.json` — add `@tailwindcss/typography`
- `apps/desktop/src/components/GateTaskDetail.vue` — replace `marked` + hand-rolled styles with `KnowledgeNoteRenderer`
- `apps/desktop/src/components/KnowledgeNoteRenderer.vue` — no changes needed (already correct)

## Acceptance Criteria

1. Gate task detail body renders with same styling as knowledge notes
2. Both have syntax highlighting (Shiki), mermaid rendering, WikiLinks
3. Prose typography matches dark theme — headings, body, code, tables all readable
4. No hand-rolled `[&_*]` element selectors
5. `npm run build` passes
6. Verified in packaged Electron app
