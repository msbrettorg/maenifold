# T-67.1 — Font Infrastructure

**Requirement**: FR-29
**Phase**: 1

## Context
Pipeline UI uses system font stacks. Kinetic Lumina requires Space Grotesk (headlines), Inter (body), JetBrains Mono (code). Fonts must be bundled as Tauri assets for offline desktop use.

## Acceptance Criteria
1. Font files for Space Grotesk (400, 500, 700), Inter (400, 500, 600), JetBrains Mono (400, 500) are added to `src/assets/fonts/`
2. `@font-face` declarations added to a new `src/styles/fonts.css` file
3. `fonts.css` imported in `main.ts` or `index.html`
4. `--font-headline: 'Space Grotesk', sans-serif` token added to `src/styles/design-tokens.css`
5. `--font-sans` updated to `'Inter', -apple-system, ...` (Inter first, system fallback)
6. `--font-mono` updated to `'JetBrains Mono', 'SF Mono', ...` (JetBrains first, system fallback)
7. 2 hardcoded font-family overrides fixed: `PipelineNodeCard.vue:240`, `WorkflowTreeView.vue:58`
8. `npx vue-tsc --noEmit` passes
