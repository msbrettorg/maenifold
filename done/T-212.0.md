# T-212.0 — Epic: ralph-console — live monitoring for RALPH loop

## Vision

Live terminal visibility into what RALPH is doing while it runs. The user opens a second pane and watches agents work — token usage, tool calls, gate progress, traces.

## Discovery: otel-tui already exists

`ymtdzzz/otel-tui` (976 stars, Go, `brew install ymtdzzz/tap/otel-tui`) is a terminal OpenTelemetry viewer that supports `--from-json-file` mode — it reads our OTEL JSONL file exporter output directly and displays traces, metrics, and logs in a full TUI.

**This eliminates the need for a custom ratatui binary for OTEL visualization.**

## What we actually need

A thin wrapper script (`ralph-watch.sh`) that:
1. Tails the OTEL file with `otel-tui --from-json-file`
2. Optionally splits a tmux pane showing gate status + log tail alongside

## Data sources (already flowing)

- **OTEL JSONL** (`ralph/state/otel/iter-N.jsonl`) — token usage, tool calls, model, cost, duration
- **Log file** (`ralph/state/logs/iter-N.log`) — raw copilot output
- **Session markdown** (`ralph/state/sessions/iter-N.md`) — full session dump post-completion
- **Metrics JSONL** (`ralph/state/metrics.jsonl`) — per-iteration summary from ralph-meta.sh

## Sub-tasks

- T-212.1: `ralph-watch.sh` wrapper — launches otel-tui + log tail in split view
- T-212.2: Wire `COPILOT_OTEL_FILE_EXPORTER_PATH` into ralph.sh (currently only in ralph-meta.sh)
- T-212.3: Document the monitoring workflow in ralph/README.md

## Acceptance criteria

1. `otel-tui --from-json-file ralph/state/otel/current.jsonl` shows live traces during a ralph.sh run
2. `ralph-watch.sh` provides a single-command monitoring experience
3. Gate progress visible alongside OTEL data
