# T-202.13 — Bug: Settings sidebar description text truncated

## Problem

The Settings left sidebar truncates description text. "Configure maenifold runtime behavior and tuning…" is visibly cut off. The sidebar width is too narrow for the description text, and there's no wrapping or ellipsis handling.

Evidence: `outputs/screenshots/sprint-202/02-settings-overview.png` — Maenifold description reads "Configure maenifold runtime behavior and tunin…"

## Fix

- Widen the sidebar to accommodate descriptions

Per DESIGN.md, description text should be legible and not clipped mid-word.

## Acceptance criteria

1. All settings sidebar descriptions are fully visible or properly truncated with ellipsis
2. No mid-word clipping
