# T-241.5 — Fix pre-existing Teams monitor config test failures

**Pipeline**: tdd

## Problem

Two tests have been failing since Wave 1 and were accepted as "pre-existing" across every blue-team audit:

- `tools::teams_monitor::tests::status_action_returns_current_config_state` — expects `monitoredConversations: []` but gets `["48:notes"]`, expects `chatsvcRegion: "amer"` but gets `""`

## Root cause
