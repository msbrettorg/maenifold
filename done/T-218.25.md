# T-218.25 — Durable Pipeline Retry Budget

## Problem

Pipeline retry budget is per-process lifetime, not per-pipeline lifetime. A crash can reset retry counters and exceed declared retry policy for non-idempotent ACP prompts or external MCP calls.

## Acceptance Criteria

- [ ] Persist retry attempt count before each retry attempt, not only after final outcome
- [ ] Rehydrate retry state on pipeline resume
- [ ] Preserve backoff schedule across restarts
- [ ] Crash/restart simulation cannot exceed `retryMaxAttempts`
- [ ] `retry_after` survives restart and is honored
- [ ] Tests cover prompt node retry, external MCP tool retry, and process restart/reload
- [ ] Documentation clarifies whether `max_attempts` includes the initial attempt or only retries
