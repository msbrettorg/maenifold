# T-72.7 — Chat input focus glow

**Pipeline**: mdd
**Pipeline Digest**: b826a880e632e457a4be2a8cbfabf45b8434090f1df1416e349cb1f9700565df
**Requirement**: UX-POLISH-72 — Chat textarea should feel premium when focused
**Component**: `src/components/ChatInputBar.vue`

## Context

The chat textarea currently just changes border-color on focus. Adding a subtle box-shadow glow creates a more polished, premium feel that makes the active input state unmistakable.

## Acceptance Criteria

1. `textarea:focus` in ChatInputBar.vue adds `box-shadow: 0 0 0 3px color-mix(in srgb, var(--border-focus) 20%, transparent)`.
2. The box-shadow transitions smoothly via `transition: box-shadow var(--transition-fast), border-color var(--transition-fast)`.
3. The existing `outline: none` on focus is retained — the box-shadow replaces the outline as the focus indicator. Do NOT stack both outline and box-shadow.
4. `npx vue-tsc --noEmit` passes.
