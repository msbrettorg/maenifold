# T-238.46 - P0 Agents tab session reconnect is broken

**Pipeline**: sdd

## Goal

Fix the Agents tab so reconnecting to existing agent sessions works reliably in the packaged Electron app.

## Problem

The user reported that reconnecting to sessions from the Agents tab is broken.

This is a P0 UI/runtime bug because reconnect is core session lifecycle behavior. A user must be able to leave and return to an existing session without losing access to the active agent conversation or controls.

## Required behavior

- Existing sessions are visible from the Agents tab.
- Selecting an existing session reconnects to that session instead of creating an unrelated new session or leaving the UI inert.
- Reconnected sessions render the expected conversation/session state.
- Reconnected sessions keep working for prompt/send/stop or equivalent controls exposed by the Agents tab.
- Error states are explicit and actionable when reconnect fails.
- No fake, stubbed, placeholder, or screenshot-only verification is acceptable.

## File Scope

Likely desktop scope:

- `apps/desktop/src/**/agents/**/*.vue`
- `apps/desktop/src/**/agents/**/*.ts`
- session/ACP composables used by the Agents tab
- Electron/ACP bridge code only if reconnect requires it

Do not modify unrelated Teams Monitor code in this task.

- [ ] Agents tab exposes existing sessions and reconnect affordance.
- [ ] Reconnect calls the real session load/reconnect path.
- [ ] Reconnected session state is visible in the Agents tab.
