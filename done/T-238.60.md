# T-238.60 — P2 Add prompt queue with per-conversation contention handling

**Pipeline**: sdd

## Problem

No prompt queuing. If multiple messages arrive for the same conversation while a dispatch is in-flight, they are either lost or create contention. Agency-cowork queues prompts per-conversation with startup grace periods and session reuse.

## Reference

- agency-cowork: `/Users/brett/src/agency-cowork/skills/teams/scripts/monitor/prompt_queue.py` (637 LOC)
- Rust target: new file `crates/maenifold-core/src/teams/prompt_queue.rs`

## Required changes

1. Port `PromptQueue` — per-conversation FIFO queues
2. Contention detection with `startup_grace_until`
3. Session reuse across prompts in the same conversation
4. Idle timeout cleanup for stale queues

## Acceptance Criteria

- [ ] Prompts queued per-conversation
