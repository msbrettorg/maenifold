## Description
When no step is selected, the inspector shows workflow metadata. Make these fields editable on the draftDefinition: name, emoji, description, triggers (comma-separated text input), sequentialThinkingEnabled (toggle), multiAgent (toggle). Workflow ID is read-only for existing workflows. This is required before "Create new workflow" makes sense.
