# T-238.64 — P1 Add outbound credential scanning before Teams replies

**Pipeline**: sdd

## Problem

Agent output is sent directly to Teams without scanning for secrets. An agent could leak API keys, tokens, passwords, or other credentials into a Teams chat. Agency-cowork scans outbound messages for credential patterns and blocks sends that contain them.

## Reference

- agency-cowork: `/Users/brett/src/agency-cowork/skills/teams/scripts/rich/send_message.py` L258-276 `scan_for_credentials()`
- agency-cowork: `/Users/brett/src/agency-cowork/skills/teams/scripts/rich/credential_scanner.py`
- Rust target: `crates/maenifold-core/src/teams/reply.rs`

## Required changes

1. Port credential pattern library from `credential_scanner.py`
2. Scan agent output before `send_reply()` — block if credentials detected
3. Log blocked sends with redacted pattern match
4. Reply to chat with "Response blocked — potential credential leak detected" instead of the agent output

## Acceptance Criteria

- [ ] Outbound messages scanned for credential patterns before delivery
- [ ] Messages containing credentials blocked with warning reply
- [ ] Pattern library covers: API keys, bearer tokens, connection strings, passwords, AWS keys
- [ ] `cargo build --release -p maenifold-cli` passes
