# T-175.4 — Agents: polish chat shell (startup, permissions, traffic monitor)

**Pipeline**: sdd
**State**: pending

## Context

The Agents tab is `ChatView` plus the auxiliary surfaces that surround it: startup phase logs, permission dialog, traffic monitor. All function but read raw — utilitarian dev tooling rather than a polished operator surface.

1. **Startup phase** (`AppSidebar` startup detail panel) shows a vertical log dump while the ACP agent boots. No phase indicator, no failure-state visual.
2. **PermissionDialog** is a flat modal listing tool-call permission requests with accept/deny buttons. Multiple stacked requests (`pendingPermissionCount > 1`) are not summarised on the trigger.
3. **TrafficMonitor** is a raw frame log — useful for protocol debugging but visually dense; no filtering by direction (`→ agent` / `← agent`) or by frame type.

Repo: `/Users/brett/src/ma-collective/maenifold-rs`

## Scope

**Files:**
- `apps/desktop/src/components/ChatWelcomeScreen.vue` — empty/disconnected state
- `apps/desktop/src/components/AppSidebar.vue` — startup details disclosure (lines around `startup-logs` binding ~67-70)
- `apps/desktop/src/components/PermissionDialog.vue` — stack indicator + visual hierarchy
- `apps/desktop/src/components/TrafficMonitor.vue` — direction/type filters, color coding

**Out of scope:** `useAppSession.ts` logic, ACP relay (`/api/acp/session`), session create/resume flow, agent registry, startup phase emit logic, the Agents dashboard rewrite (cancelled).

## Acceptance Criteria

- Startup details panel shows a phase pill (`spawning`, `initializing`, `ready`, `error`) plus the existing log tail. Phase pill colors: blue/amber/sage/terracotta from Paper/Ink palette.
- `PermissionDialog`: when `pendingPermissionCount > 1`, header shows `Permission 1 of N — <toolName>` and an explicit `N pending` chip.
- `TrafficMonitor` gains:
  - direction toggle (All / Outbound / Inbound)
  - method/notification filter (text input)
  - color band on each row by direction
- `ChatWelcomeScreen` (no-agent / not-connected state) lays out the agent picker + cwd picker with breathing room and a clear primary CTA.
- No regression on chat streaming, permission accept/deny, traffic capture, session connect/cancel.
- Build passes: `cd apps/desktop && pnpm build`.
