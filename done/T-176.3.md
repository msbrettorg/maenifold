# T-176.3 — Pipeline view — migrate bespoke chrome to shadcn-vue primitives

## Intent

**P1 design system violation.** We have Fluent 2 dark. We have shadcn-vue, Reka UI, and Lucide installed. Yet every toolbar button, sidebar panel, action bar, context menu, and node card in the pipeline view is hand-rolled markup with zero shadcn-vue usage. Bespoke UI when a design system exists is a bug, not a style preference. Every bespoke component is unmaintainable drift that makes the app feel inconsistent.

## Current state (verified 2026-04-18)

- `PipelineComposerToolbar.vue` — 0 shadcn imports, bespoke buttons
- `PipelineSidebar.vue` — 0 shadcn imports, bespoke panel
- `PipelineActionBar.vue` — 0 shadcn imports, bespoke buttons
- `PipelineNodeCard.vue` — 0 shadcn imports, bespoke card markup
- `PipelineComposerContextMenu*.vue` — bespoke context menus
- `TemplateGallery*.vue` — bespoke dialog/card/filter

Vue Flow, ELK.js, Background, Controls, MiniMap all present and working. Don't touch any of these — they're fine.

## Scope

**Directive: DELETE bespoke markup and CSS. REPLACE with existing shadcn-vue components. The goal is less code, not more. Every bespoke `<style>` block, hardcoded hex color, hardcoded `border:` declaration, and hand-rolled `<button>`/`<input>`/`<select>` is a deletion target. Use the 21 shadcn-vue components already installed in the project. Use Tailwind utility classes referencing CSS custom properties from DESIGN.md. If a shadcn-vue component covers 80% of the need, use it and adjust via props/slots — do not hand-roll a replacement.**


### Node cards → Fluent 2 dark cards

- Body: `bgSurface` (`#333333`) with borders per `apps/desktop/DESIGN.md` §5 (`border-subtle` / `border-card`)
- Ghost border on hover (`rgba(66, 71, 83, 0.15)`)
- 4px left accent bar by type (`brand` `#0078D4` = prompt, `thinking` `#B4891C` = thinking, `success` `#0E9C57` = tool, `warning` `#E8910A` = workflow)
- Active: drop shadow per Fluent 2 elevation scale `rgba(77, 142, 255, 0.1)` 20px blur
- Status: 6px bead not banner
- Typography: Segoe UI Variable for node ID, Segoe UI Variable for body

### Toolbar → shadcn-vue Button + Select

- Replace bespoke buttons with `<Button variant="ghost">` / `<Button variant="secondary">`
- Pipeline selector → `<Select>` with `<SelectTrigger>` / `<SelectContent>`
- Run/stop → `<Button variant="default">` with Lucide Play/Square icons
- Layout toggle → `<Button variant="ghost">` with Lucide LayoutGrid icon

### Sidebar → shadcn-vue Card grid

- Node palette items → `<Card>` matching homepage tile pattern
- Category headers → sentence case, Segoe UI Variable 400 0.6875rem
- Section separators follow `apps/desktop/DESIGN.md` §5 using `border-subtle` for structure and `border-card` for card edges

### Context menus → shadcn-vue ContextMenu

- Swap internals of `PipelineComposerContextMenu.vue` and `PipelineComposerContextMenuDesign.vue`
- Same menu items, shadcn `<ContextMenu>` / `<ContextMenuItem>` wrappers

### Template gallery → shadcn-vue Dialog + Card

- `TemplateGallery.vue` → render inside `<Dialog>` / `<DialogContent>`
- Each template → `<Card>` with accent bar, title, description
- Search → `<Input>` with Fluent 2 dark focus style
