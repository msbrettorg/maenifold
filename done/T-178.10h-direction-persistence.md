# T-178.10h — Pipeline direction persistence

**Pipeline**: lightweight
**Pipeline Digest**: tbd

## Objective

Layout direction (LR/TB) resets to default when switching away from the pipeline tab and back. The user's direction choice should persist.

## Fix
Store the direction preference in localStorage keyed by pipeline ID, or in the pipeline Pinia store. On pipeline load, restore the saved direction.

## Acceptance Criteria
1. Switch to TB layout → navigate to Home → navigate back to Pipelines → direction is still TB
2. Direction persists per pipeline (different pipelines can have different directions)
3. `npx vue-tsc --noEmit` passes
4. `npm run build` succeeds
