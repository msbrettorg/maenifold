# T-179.25 — Pipeline intent hero + empty states

## Intent

Pipeline and Workflow tabs have too much empty black void when no session is active. Make the intent input the hero element (like cowork's "Ask me anything") and add proper empty states.

## Cowork empty state pattern
```
flex flex-col items-center justify-center (centered in available space)
icon: size-8 text-text-tertiary opacity-40 :stroke-width="1"
heading: text-base font-medium text-text-secondary mt-3
subtext: text-sm text-text-tertiary mt-1
```

## Cowork input bar pattern
```
max-w-[800px] w-full rounded-xl border border-border-card bg-bg-elevated px-4 py-3 shadow-[var(--shadow-8)]
```

## Scope — 3 files

### 1. `apps/desktop/src/components/TemplateGallery.vue`
The template gallery is shown when no pipeline is loaded. Currently it has a small "What would you like to do?" heading and tiny template cards floating in space.

Changes:
- Center the entire gallery content vertically: wrap in `flex flex-1 flex-col items-center justify-center`
- Make the intent form the hero: apply cowork input bar pattern (max-w-[800px], rounded-xl, bg-bg-elevated, shadow-8)
- Below the intent input, add "or choose a template" as a subtle section label: `text-[11px] font-semibold uppercase tracking-wider text-text-tertiary mt-6 mb-3`
- Make the template grid wider (max-w-[800px]) to reduce empty space

### 2. `apps/desktop/src/components/TemplateGalleryIntentForm.vue`
- Style the intent input container as the hero input bar: `rounded-xl border border-border-card bg-bg-elevated px-4 py-3 shadow-[var(--shadow-8)]`
- Make the heading "What would you like to do?" larger and centered: `text-lg font-semibold text-text-primary text-center mb-4`
- Input should be transparent bg, full-width, with placeholder styling

### 3. `apps/desktop/src/components/WorkflowAuthoringPage.vue`
When no workflow is selected, the timeline and inspector panels are empty. The WorkflowBrowser already shows the list on the left.

Changes:
- When `!isWorkflowSelected`, show a centered empty state in the timeline area using the EmptyState component (already exists at `@/components/EmptyState.vue`)
- Props: `icon="Brain"`, `title="Select a workflow"`, `description="Choose a workflow from the browser to view its steps and details."`
- The empty state should fill the timeline+inspector area

## Acceptance Criteria
1. Pipeline template gallery is vertically centered with hero-sized intent input
2. Template cards section has a subtle label divider
3. Workflow page shows EmptyState when no workflow selected
4. No empty black voids
5. `npx vue-tsc --noEmit` passes
