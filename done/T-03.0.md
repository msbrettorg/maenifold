## Problem

90 components have `<style>` blocks. Custom controls reimpliment what shadcn-vue and ecosystem packages provide. The design system has token gaps that force hand-rolling. DESIGN.md now mandates ZERO `<style>` blocks, ZERO hand-rolled components, ZERO exceptions.

## Policy (DESIGN.md §10, updated 2026-04-23)

- No `<style>` blocks in any .vue file (except ui/)
- No companion .css files
- No inline styles except dynamic bindings with `<!-- audit-ok: dynamic-binding -->`
- If Tailwind can't express it, fix the tokens — never work around them
- Source components from shadcn-vue, Reka UI, lucide-vue-next, or ecosystem packages
- Never hand-roll a component

## Execution order

1. **T-03.1** — Token infrastructure (P0 blocker, everything depends on this)
2. **T-03.13** — Electron security (P0, independent)
3. **T-03.2–T-03.8** — Component replacements (parallel after T-03.1)

5. **T-03.11–T-03.15** — Quality fixes (contrast, dead code, leaks, errors)
6. **T-03.16** — Final sweep: strip all remaining `<style>` blocks
