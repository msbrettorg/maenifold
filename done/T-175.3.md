# T-175.3 — Workflows: tighten authoring layout (timeline density + inspector hierarchy)

**Pipeline**: sdd
**State**: pending

## Context

`WorkflowAuthoringPage` is the 3-pane workflow authoring UI (`WorkflowBrowser | WorkflowStepTimeline | WorkflowStepInspector`) with resizable panels. Two readability issues:

1. **Step timeline reads dense.** `WorkflowStepTimeline.vue` lists every step with full body inline. Long workflows (e.g. `agentic-slc` ~12 steps with paragraph descriptions) become a wall of text. There is no fold/zoom; selected-step indication is subtle.
2. **Inspector lacks hierarchy.** `WorkflowStepInspector.vue` shows step prompt, sequential thinking config, allowed tools, etc. as a flat scroll. No section headers / dividers, hard to scan.

Repo: `/Users/brett/src/ma-collective/maenifold-rs`

## Scope

**Files:**
- `apps/desktop/src/components/WorkflowStepTimeline.vue` — step card density, selected-state visual, optional collapse-to-title
- `apps/desktop/src/components/WorkflowStepInspector.vue` — section structure (Prompt / Tools / Thinking / Meta), spacing
- `apps/desktop/src/components/WorkflowAuthoringPage.vue` only if a layout change is required to support the above

**Out of scope:** workflow JSON schema, draft save flow, `useWorkflowLibraryStore`, browser pane sorting/filtering (separate ticket if needed), step reordering DnD.

## Acceptance Criteria

- Step in `WorkflowStepTimeline` defaults to collapsed (title + first 1–2 lines of prompt), expands on click; selected step has a high-contrast left border (Paper/Ink sage `--sage`) and elevated card background.
- A `Collapse all / Expand all` control sits in the timeline header.
- `WorkflowStepInspector` is structured into named sections: `Prompt`, `Tools & permissions`, `Sequential thinking`, `Meta` (id, label, etc.). Each section has a header label and `--border-light` divider.
- Empty inspector state ("Select a step") uses the Paper/Ink dim-text style; matches dashboards.
- No regression on draft save, panel resize, or step add/remove.
- Build passes: `cd apps/desktop && pnpm build`.
