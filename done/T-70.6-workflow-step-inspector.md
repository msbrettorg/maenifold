# T-70.6 — Workflow Step Inspector Component

**Requirement**: Workflow Authoring — Stitch Screen 1 (Right Panel)
**Component**: `src/components/WorkflowStepInspector.vue`
**Depends**: T-70.1, T-70.2
**Design Reference**: `.stitch/designs/workflow-authoring-main-1.png`

## Context

The Stitch design right panel (300px, #1c1b1b) shows a property inspector for the selected step. It includes form fields for step name, description, reasoning effort, sequential thinking toggle, tool hints as chips, stop conditions, and escape hatches.

## Skills Required

SWE agent MUST load these skills: `pinia`, `maenifold-workflow-authoring`.

## Acceptance Criteria

1. New file `src/components/WorkflowStepInspector.vue` (< 250 LOC)
2. Panel header: "Step Properties" in Space Grotesk (`--font-headline`)
3. Shows selected step name as subheader
4. When no step selected: shows workflow-level metadata (id, name, emoji, triggers list, sequentialThinkingEnabled toggle, multiAgent toggle)
5. When step selected, form fields:
   - "Step Name" text input on `--bg-input`
   - "Description" multiline textarea (4 lines)
   - "Reasoning Effort" segmented control: Low / Medium / High — selected segment uses `--color-status-active` (#F59E0B) highlight
   - "Sequential Thinking" toggle switch — ON state uses `--color-node-thinking` (#d0bcff)
   - "Tool Hints" section: chips for each tool hint key (e.g. "SearchMemories", "BuildContext") on `--bg-surface`, with + button
   - "Stop Conditions" list with delete (×) buttons per item
   - "Escape Hatches" similar list
6. All inputs use `--bg-input` backgrounds
7. All labels use `--text-muted` color, `--text-xs` size
8. Read-only for now (Phase 1 is viewer, not editor) — inputs display values but don't save
9. Uses only design tokens — NO hardcoded colors
10. `npx vue-tsc --noEmit` passes
