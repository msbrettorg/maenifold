# T-238.61 — P2 Add per-conversation ACP session reuse for Teams dispatch

**Pipeline**: sdd

## Problem

Each dispatch creates a new ACP session. Agency-cowork maintains persistent session IDs per conversation for multi-turn context. The Rust dispatch passes `resume_session_id: None` always. Self-chat conversations especially need session continuity.

## Reference

- agency-cowork: `/Users/brett/src/agency-cowork/skills/teams/scripts/monitor/message_handler.py` L1419 (`persistent_session_id` for self-chat)
- agency-cowork: `/Users/brett/src/agency-cowork/skills/teams/scripts/monitor/prompt_queue.py` (session reuse across prompts)
- Rust target: `crates/maenifold-core/src/teams/supervisor.rs`, `dispatch.rs`

## Required changes

1. Store active `session_id` per `conversation_id` in a bounded map
2. Pass `resume_session_id` for follow-up dispatches in the same conversation
3. Self-chat always reuses session for multi-turn context
4. Idle session cleanup after configurable timeout
5. Use existing ACP `Prewarm`/`Execute`/`resume_session_id` primitives — do NOT port Python PTY bridge

## Acceptance Criteria

- [ ] Follow-up prompts in same conversation reuse ACP session
- [ ] Self-chat session persistence across dispatches
- [ ] Stale sessions cleaned up after idle timeout
- [ ] `cargo build --release -p maenifold-cli` passes
