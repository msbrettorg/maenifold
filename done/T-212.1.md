# T-212.1 — ralph-watch.sh

## Description

Create `ralph/ralph-watch.sh` that launches a monitoring view for RALPH:

1. Launches `otel-tui --from-json-file` pointing at the current iteration's OTEL JSONL
2. If tmux is available, creates a split with gate status + log tail
3. Falls back to just otel-tui if tmux is not available

## Acceptance Criteria

- Script is executable with proper shebang
- `otel-tui` must be installed (`brew install ymtdzzz/tap/otel-tui`)
- Points at the correct OTEL file path
- tmux split is optional (works without tmux)
