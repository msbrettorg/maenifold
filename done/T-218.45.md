# T-218.45 — Teams Keyring Credential Store

## Problem

Teams auth tokens are in-memory only. App restart loses authentication, requiring re-authentication every time. Tokens must be persisted securely in OS credential storage.

## Decomposed from T-218.30

This is sub-task 1 of 3 from T-218.30 (Teams auth lifecycle). No dependencies on other sub-tasks.

## Implementation

- Add `keyring = "3"` to `crates/maenifold-core/Cargo.toml`
- Create `crates/maenifold-core/src/teams/credential_store.rs`
- Service name: `"maenifold-teams"`
- Account key: `"{client_id}:{tenant_id}"` (deterministic, unique per config)
- Store: `access_token`, `refresh_token`, `expires_at` as JSON blob
- Retrieve: returns `Option<TokenInfo>` (from existing `teams/auth.rs`)
- Delete: clears all stored credentials for the account
- Error handling: keyring failures return `MaenifoldError`, never panic

## Acceptance Criteria

- [ ] `keyring = "3"` added to maenifold-core Cargo.toml
