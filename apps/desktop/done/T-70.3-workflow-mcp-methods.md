# T-70.3 — Workflow MCP Methods

**Requirement**: Workflow Authoring — Data Layer
**Component**: `src/composables/usePipelineMcp.ts`
**Depends**: T-70.1

## Context

`usePipelineMcp` has `listWorkflows()` which calls ListAssets and returns string[]. The workflow authoring page needs richer methods: fetching full summaries (with metadata) and reading individual workflow definitions via ReadMcpResource. Adding these methods to the existing MCP composable follows the established pattern.

## Acceptance Criteria

1. New method `listWorkflowSummaries(): Promise<WorkflowAssetSummary[]>` — calls ListAssets with `type: 'workflow'`, parses JSON, returns typed array
2. New method `readWorkflowDefinition(id: string): Promise<WorkflowAssetDefinition>` — calls ReadMcpResource with `uri: 'asset://workflows/{id}'`, parses JSON, returns typed definition
3. Existing `listWorkflows()` unchanged (backward compat)
4. Both methods use existing `callTool` / `unwrapEnvelope` patterns
5. Error handling follows existing patterns (try/catch, re-throw with context)
6. File stays under 300 LOC
7. `npx vue-tsc --noEmit` passes

## Swe Notes

Added listWorkflowSummaries() and readWorkflowDefinition(id) to usePipelineMcp.ts. Uses existing unwrapToolData pattern. Removed unused WorkflowAsset/WorkflowListResult interfaces. 302 LOC. vue-tsc clean.
