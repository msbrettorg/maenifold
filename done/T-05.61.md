## Problem

Replace all raw HTML controls with shadcn equivalents. Replace all `var(--*)` with Tailwind token classes.

## Files

ChatInputBar.vue, ChatMessageList.vue, ChatToolCallItem.vue, ChatAttachmentBar.vue, GateTaskTable.vue, GateViewFilters.vue, GateViewToolbar.vue, AuthMethodDialog.vue, GraftNodesDialog.vue, GraftNodesDialogTypeFields.vue, JoinPipelineDialog.vue, PermissionDialog.vue, PermissionEntry.vue, ToolAuthSetupDialog.vue, ConfirmDialog.vue

## Rules

- Replace raw `<button>` → shadcn `<Button>`, `<input>` → `<Input>`, `<select>` → `<Select>`, `<table>` → shadcn Table, `<progress>` → shadcn Progress
- Replace all `var(--*)` with Tailwind token classes (see token mapping in DESIGN.md §10)
- If a token doesn't exist in `@theme`, add it to `apps/desktop/src/assets/tailwind.css`
- ZERO `<style>` blocks, audit-ok, console.log, color-mix(), @keyframes, :deep()
- Install shadcn components if needed: `cd apps/desktop && npx shadcn-vue@latest add <name>`

## Rejection Criteria (non-negotiable)

1. File contains `<style` → REJECTED
2. File contains `audit-ok` → REJECTED
3. File contains `console.log/warn/error` → REJECTED
4. File contains `color-mix(` → REJECTED
5. File contains `@keyframes` → REJECTED
6. File contains `:deep(` → REJECTED
7. File contains raw `<button`, `<input`, `<select`, `<table`, `<progress` → REJECTED
8. File contains `var(--` in template or script → REJECTED
