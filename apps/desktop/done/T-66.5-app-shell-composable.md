# T-66.5 — App Shell Composable Extraction

## Objective
Extract reactive state and event handlers from App.vue's `<script setup>` into a `useAppShell()` composable, bringing App.vue under 300 LOC.

## Scope
- **Source**: `src/App.vue` `<script setup>` block (~183 LOC)
- **Target**: `src/composables/useAppShell.ts` (~100 LOC)
- **Extract**:
  - Local reactive state (`selectedAgent`, `showSidebar`, `showSettings`, `showWorkflows`, `showPipeline`, `showTraffic`, panel width refs, etc.)
  - Computed properties
  - Event handlers (`handleAgentSelect`, `handleNewSession`, `handleResumeSession`, `handleDeleteSession`, panel toggle handlers, etc.)
  - `onMounted` initialization logic (prefsStore async load, default agent selection)
- **Keep in App.vue**:
  - Store imports and instantiation
  - Template bindings (using destructured composable return values)
  - Style imports

## Dependencies
- T-66.3 must be committed first (modifies same file)

## Acceptance Criteria
- [ ] `src/composables/useAppShell.ts` created with all extracted logic
- [ ] App.vue `<script setup>` reduced to ~80 LOC (imports + store setup + composable call + template helpers)
- [ ] App.vue total LOC ~275 (under 300 ✅)
- [ ] `npx vue-tsc --noEmit` passes
- [ ] `npx vitest run` passes
- [ ] All UI interactions work: sidebar toggle, session management, panel open/close, settings, agent selection

## Constraints
- useAppShell must accept store instances as parameters (not import them internally) for testability
- Return type must be fully typed — no `any` escapes
- Do NOT change any behavior or event signatures
