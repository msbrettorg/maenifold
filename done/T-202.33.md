# T-202.33 — Knowledge search returns "No notes matched" for queries that should match

## Problem

On the Knowledge tab, searching for "embedding model" returns "No notes matched this query" despite multiple notes about embedding models existing in the corpus (at least 3 in architecture/ folder).

## Observed

CDP test 2026-04-20: Typed "embedding model" in Knowledge search box, clicked Search. "Search results" section appeared with "No notes matched this query." The previously selected note continued to display in the content panel.

## Expected

Search should return notes matching "embedding model" — at minimum `embedding-model-management-duo-design-review-with-p0-blockers.md` and `embedding-model-catalog-research-2026-mtebgrounded-recommendations.md`.

## Hypothesis

Either the search is not connected to the daemon's search endpoint, or the search is using a different index than the maenifold MCP SearchMemories tool.

## Acceptance Criteria

1. Knowledge search returns relevant notes for "embedding model"
2. Search results are clickable and load the note content
