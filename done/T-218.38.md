# T-218.38 — Vec0 Rust-Side Load Verification

## Problem

The Electron onboarding wizard verifies downloaded vec0 with Node, but Rust core loads vec0 through a separate path and process. Electron success does not prove the Rust daemon can load vec0 or that vector tables/search will work.

## Acceptance Criteria

- [ ] After Electron download, call a Rust-side verification endpoint/tool using the same `rusqlite` load path as sync/search
- [ ] Verification reports extension path used by Rust, load success/failure, and table creation probe success/failure
- [ ] On successful vec0 install, prompt or trigger sync/index rebuild where appropriate
- [ ] EmbeddingModels status distinguishes model installed, vec0 installed, Rust vec0 loadable, vector tables ready, and embeddings populated
- [ ] Packaged verification covers a clean machine with no pre-existing vec0
