## Context

The three sub-components (Browser, StepTimeline, StepInspector) need assembly into a single page component that replaces the current workflow tab content. The page uses CSS Grid for the three-panel layout. The existing WorkflowTreeView components remain available for execution monitoring but the default view becomes the authoring page.
