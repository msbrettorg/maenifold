### Notes

- The setup file mocks at two layers: (1) all `@tauri-apps/*` npm packages and (2) the local `src/lib/tauri.ts` wrapper. This ensures any source file that transitively depends on Tauri IPC can be loaded in jsdom without errors.
- `ToolKind` from `@agentclientprotocol/sdk` is an enum-like union (`"read" | "edit" | ...`); the tool_call test uses `kind: 'read'` (not `'file'`, which is not in the SDK type).
- The tsconfig.json does not define path aliases; the `src`/`@` aliases in `vitest.config.ts` are additive for test convenience and do not conflict with existing resolution.
