# T-210.2 — Trouter WebSocket Client

## Description

Implement a long-lived Trouter WebSocket client in Rust using tokio-tungstenite. The client:

1. Connects to the Trouter service endpoint
2. Authenticates with Bearer JWT (from MSAL token)
3. Registers for Teams message notifications
4. Receives push notifications via WebSocket frames
5. Parses notification payloads into typed structs
6. Handles reconnection (heartbeat, exponential backoff, token refresh)
7. Runs as a tokio task managed by the maenifold runtime

## Key Files

- Create: `crates/maenifold-core/src/teams/trouter.rs` (or appropriate module)

## Acceptance Criteria

- Connects to Trouter and receives notifications
- Automatic reconnection on disconnect
- Token refresh when JWT expires
- Clean shutdown via CancellationToken
- `cargo build --release -p maenifold-core` succeeds
