# T-218.22 — Gateway Facade Local Parameter Validation

## Problem

The consolidated gateway facade hides upstream schemas until learn mode, but command execution forwards malformed `parameters` to upstream servers and relies on upstream validation. Callers get opaque upstream errors instead of actionable local validation failures.

## Implementation Constraints

- **Validator dependency**: Add `jsonschema` crate (MIT, Draft 7 compatible) to `maenifold-core/Cargo.toml`. Do NOT hand-roll a validator.
- **Health surface**: Extend `StdioServerHealth` in `stdio_pool_health.rs` with `tool_schema_hashes: Vec<(String, String)>` where each entry is `(tool_name, sha256_hex)`. SHA-256 of canonical JSON serialization of the upstream tool `inputSchema`.
- **Drift = across restarts only**: On gateway startup, compute and store schema hashes in `StdioServerHealth`. A changed hash between gateway starts is observable in health output. No in-process cache invalidation or staleness detection is in scope.

## Acceptance Criteria

- [ ] Validate facade `parameters` locally against cached upstream JSON Schema when available
- [ ] Invalid parameters for a known command return MCP JSON-RPC `-32602 invalid_params` with a message naming the failing field via JSON Pointer path (e.g., `/accountId`)
- [ ] Valid parameters dispatch unchanged to upstream
- [ ] Schemas that are empty, lack `type: object`, fail validator compilation, or are otherwise unsupported skip local validation and dispatch upstream unchanged
- [ ] `StdioServerHealth` includes per-upstream-tool schema hash (SHA-256 of canonical JSON)
- [ ] Integration test starts a fake server, records schema hashes, restarts with changed schema, and verifies new hashes differ
- [ ] `tools/list` consolidated facade count does not regress (existing `gateway_consolidation_counts_tests` still pass)

## Files Likely Touched

- `crates/maenifold-core/src/mcp/gateway_dispatch.rs` — validation hook before `CallTool`
- `crates/maenifold-core/src/mcp/gateway_consolidation.rs` — compute + store schema hash on `ConsolidatedServerTool`
- `crates/maenifold-core/src/mcp/gateway_handler.rs` — map validation error to `-32602`
- `crates/maenifold-core/src/mcp/stdio_pool_health.rs` — extend health struct
- New `crates/maenifold-core/src/mcp/gateway_schema_validation.rs` (~150 LOC: validate + hash helpers)
- `crates/maenifold-core/Cargo.toml` — add `jsonschema` dep
- Test files: `gateway_dispatch_tests.rs`, `gateway_integration_tests.rs`
