# T-79.5: SRE Agent Shim Main Entrypoint

## Requirement
FR-SRE-1 — Azure SRE Agent must be usable as a pipeline prompt node.

## Problem
The shim binary needs a main function that wires config → srectl client → agent trait → ACP stdio transport. When maenifold spawns the binary, it must immediately start the ACP JSON-RPC loop on stdin/stdout.

## Acceptance Criteria
1. `main.rs` performs this sequence:
   - Load `SreAgentConfig` from env vars
   - Initialize `SrectlClient` with endpoint (runs `srectl init`)
   - Construct `SreAgent` with config + client + session store
   - Start `AgentSideConnection::new(stdin, stdout, agent)` and run until EOF
2. On config error: print diagnostic to stderr and exit with code 1
3. On srectl init failure: print diagnostic to stderr and exit with code 1
4. Tracing subscriber configured to write to stderr (stdout is reserved for ACP JSON-RPC)
5. Binary name: `maenifold-sre-agent`
6. `cargo build -p maenifold-sre-agent` produces working binary
7. `cargo test --workspace` passes

## Files to modify
- `crates/maenifold-sre-agent/src/main.rs`

## Reference
- `agent-client-protocol` crate: `AgentSideConnection` for stdio transport
- `crates/maenifold-core/src/acp/native/mod.rs` — `spawn_agent()` shows the client side (this is the mirror)
