# T-43.3: PipelineSidebar Component

**Requirement**: FR-43.3
**RTM**: RTM-194
**Priority**: P0 — Sidebar is required for the pipeline view shell

## Context

The pipeline-ui application at `/Users/brett/src/ma-collective/pipeline-ui/` needs a left-panel sidebar component that lists all pipeline sessions from the server and provides create/load/delete actions.

The Pinia store at `src/stores/pipeline.ts` exposes: `pipelines` (array of `PipelineListItem`), `currentPipelineId`, `connected`, `refreshList()`, `loadPipeline(id)`, `newPipeline()`, `deletePipeline()`. The `PipelineListItem` type is in `src/lib/pipeline-types.ts`: `{ pipelineId, status, nodeCount, completedCount }`.

Reference `src/components/SessionList.vue` for the existing sidebar list pattern and style conventions.

## Scope

Create `src/components/PipelineSidebar.vue` in the pipeline-ui project.

## Acceptance Criteria

1. **On mount**: If `store.connected` is truthy, calls `store.refreshList()` to hydrate the pipeline list.
2. **Header**: Shows title "Pipelines" and a "+ New" button that calls `store.newPipeline()`.
3. **Pipeline list**: Renders `store.pipelines` as clickable items. Each item shows:
   - Status icon (emoji): active=🔄, paused=⏸, completed=✅, cancelled=⏹, stuck=🚫, default=⏳
   - Pipeline ID (truncated with ellipsis)
   - Status text (colored): active=#2196f3, paused=#ff9800, completed=#4caf50, cancelled=#9e9e9e, stuck=#f44336
   - Progress: `{completedCount}/{nodeCount} nodes`
4. **Selection**: Clicking an item calls `store.loadPipeline(pipelineId)`. The active pipeline (`store.currentPipelineId`) gets a highlighted style (left border accent + background).
5. **Delete**: Each item has a delete button (×) that appears on hover. Click stops propagation, shows `confirm()` dialog, then deletes. If deleting the current pipeline, calls `store.deletePipeline()`. If deleting a different pipeline, loads it first, then deletes. Refreshes list after.
6. **Empty state**: When `pipelines.length === 0`, shows "No pipelines yet" centered text.
7. **Styling**: 240px width, full height, right border. Uses project CSS variables. Matches `SessionList.vue` visual density. Scoped styles. Under 300 lines.
8. **Build**: `npm run build` passes with zero errors.
