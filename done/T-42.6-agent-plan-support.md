# T-42.6: Agent Plan Support

**Requirement**: FR-42.6  
**Priority**: P1  
**Files**: `vendor/acp-ui/src/lib/types.ts`, `vendor/acp-ui/src/stores/session.ts`, `vendor/acp-ui/src/components/PlanView.vue`, `vendor/acp-ui/src/components/ChatView.vue`

## Acceptance Criteria

1. Add `PlanEntry` type to `types.ts`:
   ```ts
   export interface PlanEntry {
     content: string;
     priority: 'high' | 'medium' | 'low';
     status: 'pending' | 'in_progress' | 'completed';
     _meta?: Record<string, unknown> | null;
   }
   ```

2. Add reactive state in `session.ts`:
   ```ts
   const currentPlan = ref<PlanEntry[] | null>(null);
   ```
   Clear in `disconnect()` and at session start.

3. Add `case 'plan':` in `handleSessionUpdate`:
   ```ts
   case 'plan':
     if ('entries' in update && Array.isArray(update.entries)) {
       currentPlan.value = update.entries.map((e: any) => ({
         content: e.content,
         priority: e.priority ?? 'medium',
         status: e.status ?? 'pending',
         _meta: e._meta ?? null,
       }));
     }
     break;
   ```

4. Export `currentPlan` from the store.

5. Create `PlanView.vue` component that renders plan entries:
   - Status icons: `pending` → ○, `in_progress` → spinner/◐, `completed` → ✓
   - Priority badges: `high` → red, `medium` → yellow, `low` → grey
   - Content as text
   - Collapsible panel that appears when `currentPlan` is non-null

6. Mount `<PlanView />` in `ChatView.vue`, shown conditionally when `currentPlan !== null`.
