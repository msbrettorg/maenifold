## Summary

Implement the zeitgeist wallpaper mode: after Louvain community detection, generate one image per top community (by size). Each community's anchor concept and members become the image prompt. The slideshow cycles through all generated community images.

## Implementation

### 1. Create `crates/maenifold-core/src/wallpaper/zeitgeist.rs`

**Function (mirrors endophasia pattern — takes `&Config` only):**

```rust
pub async fn generate_zeitgeist_wallpapers(config: &Config) -> anyhow::Result<Vec<PathBuf>>
```

Steps:
1. Read wallpaper settings: `let wallpaper = &config.settings.easter_eggs.wallpaper;`
2. Open DB connection: `let conn = crate::db::open_connection(&config.database_path)?;`
3. Query communities via re-exported path: `let graph = crate::api::graph::get_communities(&conn)?;`
4. If `graph.nodes.is_empty()`, return `Ok(vec![])` (no communities = no images, not an error)
5. Sort `graph.nodes` by `node.size` descending, take top `wallpaper.community_count as usize`
6. Create `ImageClient::from_config(wallpaper)?` once (reuse across all communities)
7. For each community node:
   a. Get community concepts: `let concepts = crate::api::graph::get_community_concepts(&conn, node.id)?;`
   b. Format prompt: `**[[{node.anchor}]]** [[{member1}]] [[{member2}]] ...` (concept names from `concepts.nodes`)
   c. Prepend `wallpaper.prompt` + `\n\n`
   d. Call `client.generate(&prompt, &wallpaper.size, &wallpaper.quality).await?`
   e. Save via `cache::save_image(&cache::cache_dir(&config.memory_path), "zeitgeist", &node.anchor, &data)?`
   f. Sleep 15 seconds between API calls (proactive pacing, in addition to ImageClient's 429 retry)
8. Return all saved paths

### 2. Integrate into `wallpaper/service.rs`

Add zeitgeist branch to the existing mode match (must return `Duration` like endophasia):
```rust
"zeitgeist" => match zeitgeist::generate_zeitgeist_wallpapers(&cfg).await {
    Ok(_paths) => {
        let mut state = service_state().write();
        state.last_generated = Some(Utc::now());
        state.error = None;
        Duration::from_secs(u64::from(wallpaper.rotate_minutes) * 60)
    }
    Err(error) => {
        let message = error.to_string();
        tracing::warn!(error = %message, "zeitgeist wallpaper generation failed");
        service_state().write().error = Some(message);
        Duration::from_secs(60)
    }
},
```

**Regeneration semantics:** The service regenerates ALL community images every `rotate_minutes` cycle. This is intentional — communities evolve over time and the images should reflect the current graph state. The frontend (WallpaperBackground.vue) handles cycling/slideshow — it already reads the `images` array from `WallpaperStatus` and rotates through them on its own timer.

**No `currentIndex` in backend.** The frontend manages its own cycling position. `WallpaperStatus` returns the full image list; the frontend picks which one to display.

### 3. WallpaperStatus — no changes needed

`WallpaperStatus` already returns `images: cache::list_images(...)` filtered by `&wallpaper.mode` from config. Zeitgeist images (`zeitgeist_*.png`) will automatically appear when mode is set to "zeitgeist". No `currentIndex` needed — frontend manages cycling.
