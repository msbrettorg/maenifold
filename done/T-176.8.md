# T-176.8 — Chat message rendering — design system pass on 11 bespoke components

## Intent

**P1 design system violation.** The entire chat rendering pipeline — 11 components — has zero shadcn-vue imports. Message bubbles, tool call cards, thought sections, content blocks, attachment bar, the input bar (covered separately in T-176.4a/T-176.4b), and the message list are all hand-rolled. This is the primary view users interact with. It must feel native.

## Scope

**Directive: DELETE bespoke markup and CSS. REPLACE with existing shadcn-vue components. The goal is less code, not more. Every bespoke `<style>` block, hardcoded hex color, hardcoded `border:` declaration, and hand-rolled `<button>`/`<input>`/`<select>` is a deletion target. Use the 21 shadcn-vue components already installed in the project. Use Tailwind utility classes referencing CSS custom properties from DESIGN.md. If a shadcn-vue component covers 80% of the need, use it and adjust via props/slots — do not hand-roll a replacement.**


- `ChatMessageItem.vue` → Fluent 2 dark surface cards with borders per `apps/desktop/DESIGN.md` §5 (`border-subtle` / `border-card`) and gap separation between messages
- `ChatMessageList.vue` → `<ScrollArea>` wrapper, proper scroll anchoring
- `ChatContentBlocks.vue` → typed content blocks using shadcn Card/Badge for code, text, image
- `ChatToolCallItem.vue` / `ChatToolCallList.vue` / `ChatToolCallDetails.vue` → collapsible tool call cards using `<Collapsible>` or `<Sheet>`, status beads, Lucide icons for tool types
- `ChatThoughtSection.vue` → thinking indicator using `thinking` (`#B4891C`) accent, `<Badge>` for thought count
- `ChatAttachmentBar.vue` → `<Badge>` pills for attachments, remove button
- `ChatView.vue` → layout shell using Fluent 2 dark surfaces

(`ChatInputBar.vue` is T-176.4a/T-176.4b, `ChatWelcomeScreen.vue` is T-176.0)

## Files touched

9 Chat*.vue files (excluding ChatInputBar and ChatWelcomeScreen).

## Acceptance criteria

1. All message rendering uses shadcn-vue primitives
2. Tool calls render as collapsible cards with status beads
3. Scroll area properly anchors to bottom on new messages
4. Thought sections use `thinking` (`#B4891C`) accent
5. Fluent 2 dark surfaces with borders/separators implemented per `apps/desktop/DESIGN.md` §5 (`border-subtle` / `border-card`)
6. No visual regressions in message content (markdown, code blocks, images)
