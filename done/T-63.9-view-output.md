**Requirement**: FR-10

## Context

2. View response also includes runtime state per node: `status`, `output`, `attempts`
3. The JSON structure uses camelCase field names matching the wire format
4. ALL existing pipeline tests pass: `cargo test -p maenifold-core -- pipeline`
5. Add a test: create pipeline with PromptNode, view it → response includes `prompt` and `agent` fields
