# T-201.4 — Wizard agent configuration step

## Intent

Create the `OnboardingStepAgent.vue` component for the wizard's agent configuration step. Lets the user name their first agent, select a runtime, and add it to the config store.

## Parent Epic

T-179.34 — First-run onboarding wizard

**Modified files:**

- `apps/desktop/src/stores/config.ts` — add `addAgent()` method if not already present

## Architecture

### Agent form

- **Agent name** text input (default: "Copilot"), validated non-empty
- **Runtime** radio card selection:
  - GitHub Copilot CLI — `[popular]` badge, "Free with GitHub Copilot subscription"
  - Claude (Anthropic) — "Requires API key"
  - OpenAI GPT — "Requires API key"

Radio cards use `wizard-option-card` styling: `bg-bg-surface border-subtle`, selected state: `border-brand bg-brand/5`.

### addAgent in config store

If `config.ts` doesn't have `addAgent`, add it:

```typescript
async function addAgent(name: string, agent: AgentConfig): Promise<void> {
  const response = await fetch(`${DAEMON_BASE_URL}/api/config`, {
    method: 'PUT',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      ...config.value,
      agents: { ...config.value.agents, [name]: agent },
    }),
  });
  if (!response.ok) {
    throw new Error(`Failed to add agent: HTTP ${response.status}`);
  }
  await loadConfig();
}
```

### Validation

- Agent name must be non-empty and not duplicate an existing agent name
- Runtime must be selected
- "Add agent →" button disabled until both valid

### On success

After successful `addAgent`, call `advance()` to move to the model step.

### Error handling

Show error text below the form if `addAgent` fails. No silent recovery — display the error message from the API response.

## Acceptance Criteria

1. Agent name input with default value "Copilot"
2. Three runtime radio cards with correct labels and descriptions
3. Selected radio card shows brand border highlighting
4. "Add agent →" disabled when name empty or no runtime selected
5. Duplicate agent name shows validation error
6. `addAgent` calls daemon API and reloads config on success
7. API errors displayed as error text below form
8. Advances to next step on success
9. "← Back" navigates to Daemon step
10. All design tokens from DESIGN.md — zero hardcoded colors
11. `npx vue-tsc --noEmit` passes
