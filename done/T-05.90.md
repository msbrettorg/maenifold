## Problem

The onboarding wizard gets stuck on the "Download embedding model" step. Neither the "Next →" nor "Download later →" buttons advance to the Finish step. The model list loads correctly (8 models shown, BGE Small active), but clicking either button does nothing visible.

Additionally, there is no download progress indicator — if a model IS downloading, the user sees no feedback and assumes the app is hung.

## Root cause (from earlier investigation)

`OnboardingStepModel.vue` calls `advance()` via inject from `OnboardingWizard.vue`. The advance function increments `step.value`. The buttons' click handlers (`onDownload`, `onSkip`) both call `advance?.()` but the step doesn't change. Likely a Vue reactivity issue with the inject/provide chain or the Stepper component's v-model fighting the step ref.

## Fix

1. Debug why `advance()` doesn't increment the step — add a progress indicator (shadcn Progress) during model download so the user knows it's working
2. Add a download progress bar using the existing EmbeddingModels MCP tool (it may support progress events)
3. If no progress events available, show an indeterminate Progress with "Downloading..." text
4. Ensure "Download later →" always advances immediately (it should skip download entirely)
