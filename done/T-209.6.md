## Description

Add the meta-optimization layer to pipeline-meta.sh. After inner iterations execute, a meta-agent analyzes pipeline telemetry and proposes one template change per iteration.

### Optimizable knobs

1. Per-node model assignment
2. Per-node maxTurns
3. Per-node timeout
4. Retry policies (retryMaxAttempts, backoff)
5. Conditional edge thresholds
6. Node prompts
7. adopt roles/colors
8. allowedTools per node
9. maxConcurrency
10. Node decomposition (split swe into draft+refine)

### Meta-agent contract

- Input: metrics summary + current templates + previous verdict
- Output: one mutated template file + `meta-verdict.json`
- Keep/discard: new_score ≥ baseline + threshold AND failed_task_rate ≤ baseline

### Process

```
for meta_iteration in 1..MAX:
  snapshot templates
  run N inner iterations (pipeline-meta.sh inner loop)
  compute score
  dispatch meta-agent to analyze + propose one change
  if meta-agent writes kept:true AND score improved:
    accept
  else:
    restore snapshot
```

## Acceptance Criteria

- Meta-agent reads pipeline telemetry and proposes template changes
- One change per iteration, one template per iteration
- Keep/discard enforced by shell via score comparison
- Verdict file written per iteration
- Immutable file hashing prevents meta-agent from editing the shell
