## Intent

Clicking any workflow in the Workflows tab shows an error card: "Tool hint 'Bash' reason is required." with a Retry button instead of displaying the workflow definition/steps. This is a user-facing P1 bug — the workflow browser is non-functional for its primary use case (browsing workflow definitions).

## Evidence

Screenshot: `/tmp/ui-wf-slc-detail.png` — clicking "Agentic SLC (Simple, Lovable, Complete)" produces the error instead of showing the 11 steps.

## Root Cause (to investigate)

The workflow viewer likely calls a maenifold MCP tool (e.g., `Workflow` or `ReadMcpResource`) on click, and the tool call is missing a required parameter (`reason` for a Bash-type tool hint). The UI should either:
1. Fix the tool call to include the required parameter, OR
2. Display the workflow definition from the asset JSON without executing a tool call
