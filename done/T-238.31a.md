# T-238.31a — Remove idempotencyKey from GatewayExecute/GatewayBatch schemas

## Problem

`idempotencyKey` is accepted in GatewayExecute and GatewayBatch schemas but never used for deduplication. No result cache exists. Callers are misled into thinking retries are safe.

## Fix

Remove `idempotencyKey` from `GatewayExecuteParams`, `BatchItemParams`, and any extraction/passthrough code. Re-add when idempotency infrastructure exists.

## Files

- `crates/maenifold-core/src/mcp/schema/gateway_tools.rs`
- `crates/maenifold-core/src/mcp/gateway_handler.rs`
- `crates/maenifold-core/src/mcp/gateway_batch.rs`

## Verification

- `cargo build --release -p maenifold-core`
- `cargo test -p maenifold-core -- gateway`
