### font-family tokenization (7 instances)

Replace hard-coded font stacks with CSS variables:
- `'JetBrains Mono', 'Cascadia Code', ...` → `var(--font-code)` (only in genuine code contexts)
- `'Segoe UI Variable', ...` → `var(--font-body)`
- UI chrome using `var(--font-code)` / `var(--font-mono)` → `var(--font-body)` (mono is for code, not badges/meta strips)

Files: KnowledgeNoteRenderer.vue, WorkflowBrowserList.vue, SettingsPreferences.vue, SettingsConnectionDaemon.vue

## Acceptance Criteria

1. Zero `text-transform` declarations in any `.vue` file
2. Zero hard-coded `font-family` declarations — all use CSS variables
3. `var(--font-code)` / `var(--font-mono)` used ONLY in code/payload contexts, not UI chrome
4. `npx vue-tsc --noEmit` passes
5. `npm run build` succeeds
