## Description
Add a remove/delete button to each step in the timeline or inspector. Shows confirmation dialog before removing. Splices the step from draftDefinition.steps. If the removed step was selected, clears the selection. Warns if other steps reference the removed step's ID in metadata text.

## Acceptance Criteria
- [ ] Remove button visible on each step (icon or text)
- [ ] Confirmation dialog before removal
- [ ] Step removed from draftDefinition.steps on confirm
- [ ] Timeline re-renders with correct numbering
- [ ] Selection cleared if removed step was selected
- [ ] isDirty becomes true after removing a step
- [ ] Warning shown if other steps reference the removed step ID
- [ ] vue-tsc --noEmit passes
