# T-204.2 — IPC: voice:check + voice:launch

## Requirement

Add two IPC handlers to `apps/desktop/electron/main.ts` and expose them via `apps/desktop/electron/preload.ts`:

### voice:check
- `findHandyPath()`: `which handy` → fallback to known paths per platform
  - macOS: `/Applications/Handy.app/Contents/MacOS/Handy`
  - Windows: `LOCALAPPDATA/Programs/Handy/Handy.exe`, `LOCALAPPDATA/Handy/handy.exe`, `PROGRAMFILES/Handy/Handy.exe`
  - Linux: `/usr/bin/handy`, `/usr/local/bin/handy`
- `isHandyRunning()`: `pgrep -x Handy || pgrep -x handy` (macOS/Linux), `tasklist /FI "IMAGENAME eq handy.exe"` (Windows)
- Returns `{ installed: boolean, path: string|null, running: boolean, enabled: boolean }`
- Reads `enabled` from localStorage preference (default: true)

### voice:launch
- If not installed: return `{ ok: false, error: "Install via: brew install --cask handy" }`
- If already running on macOS: `open -a Handy` to foreground
- If already running on Windows: `shell.openPath(exePath)`
- Otherwise: `spawn(exePath, [], { detached: true, stdio: 'ignore' })` + `child.unref()`
- Returns `{ ok: boolean, error?: string, pid?: number, alreadyRunning?: boolean }`

### preload.ts
- `voiceCheck: () => ipcRenderer.invoke('voice:check')`
- `voiceLaunch: () => ipcRenderer.invoke('voice:launch')`

## Acceptance criteria

1. `voice:check` correctly detects installed/running Handy on macOS
2. `voice:launch` launches or foregrounds Handy
3. No arbitrary user-supplied paths — only well-known locations
4. Preload exposes both methods on `window.electronAPI`
