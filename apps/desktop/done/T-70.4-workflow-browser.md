# T-70.4 — Workflow Browser Component

**Requirement**: Workflow Authoring — Stitch Screen 1 (Left Panel)
**Component**: `src/components/WorkflowBrowser.vue`
**Depends**: T-70.2
**Design Reference**: `.stitch/designs/workflow-authoring-main-1.png`

## Context

The Stitch design shows a left sidebar panel (250px, #1c1b1b) with search input, filter chips, and a scrollable list of workflow items. Each item shows emoji, name, step count badge, and multi-agent indicator. Selected item has elevated background with accent bar.

## Skills Required

SWE agent MUST load these skills: `pinia`, `maenifold-workflow-authoring`.

## Acceptance Criteria

1. New file `src/components/WorkflowBrowser.vue` (< 200 LOC)
2. Search input at top using design token `--bg-input` (#0e0e0e) background
3. Horizontal filter chip row below search: "All", "Reasoning", "Scientific", "Multi-Agent", "DevOps", "Memory" — scrollable overflow
4. Selected chip uses `--bg-surface` (#2a2a2a) background
5. Scrollable workflow list binding to `useWorkflowLibraryStore().filteredWorkflows`
6. Each list item shows:
   - Emoji from workflow data (not hardcoded)
   - Workflow name in Inter medium
   - Step count badge in `--text-muted` (derived from fetched definition or shown as "—" if not loaded)
   - Purple pill badge if `multiAgent === true`
7. Selected item: `--bg-surface` background with 4px left border in `--color-node-workflow`
8. Click emits selection to store via `workflowLibraryStore.selectWorkflow(id)`
9. Bottom toolbar: "+ New" ghost button (dashed border), "Import" icon button
10. Uses only design tokens from `design-tokens.css` — NO hardcoded colors
11. `npx vue-tsc --noEmit` passes
