## Description

Implement the scoring system for pipeline execution quality.

### Metrics per task (written by pipeline-meta.sh)

```json
{
  "task_id": "T-02.10",
  "session_id": "sdd-T-02.10-1776965xxx",
  "template": "sdd-v1",
  "status": "completed",
  "first_pass": true,
  "remediation_cycles": 0,
  "wall_clock_seconds": 342,
  "node_timings": { "swe": 180, "red_team": 60, "blue_team": 45 },
  "approx_tokens": { "input": 45000, "output": 8000 }
}
```

### Composite score (per iteration)

```
effectiveness = 100 × (
  0.35 × delivery_score +
  0.25 × first_pass_score +
  0.15 × remediation_score +
  0.15 × time_score +
  0.10 × cost_score
)
```

### Implementation

- `ralph/pipeline-meta/score.sh` — reads metrics dir, computes composite score
- Outputs `ralph/pipeline-meta/metrics/{iteration}/summary.json`
- Baseline from first iteration stored in `ralph/pipeline-meta/baseline.json`

## Acceptance Criteria

- Score computed from real pipeline execution metrics
- Baseline established on first run
- Delta reported between iterations
- Summary JSON written per iteration
