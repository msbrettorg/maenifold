# T-156.7 — Prevent agents from reformatting unrelated files

## Problem

During T-156.2, the SWE agent reformatted `maenifold-jockey/src/db/global_mcp.rs` (whitespace-only changes) despite only being scoped to maenifold-core. The PM caught and reverted it before commit, but the agent shouldn't have touched it at all.

## Root Cause

Agent likely ran rustfmt or an equivalent across the whole workspace rather than the targeted file.

## Fix

Add to AGENTS.md: "SWE agents must not run workspace-wide formatters. If formatting is needed, format only the files you created or modified."

## Acceptance Criteria

1. Rule added to AGENTS.md
2. No code changes needed
