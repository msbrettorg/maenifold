## Objective

Create E2E tests that execute real pipelines with tool nodes through the full
`pipeline()` → `supervisor_run()` → `execute_pipeline()` → `run_tool_node()` path.
Tool nodes execute locally via `ToolRegistry::global().try_invoke()` — no ACP agent needed.

## Test file

`crates/maenifold-core/src/workflow/pipeline/e2e_tests_tool_chain.rs`

## Test cases

1. **Single tool node completes** — create pipeline with one `MemoryStatus` tool node, run, wait, verify node status=completed
2. **Two tool nodes in chain** — a→b with success edge, verify dependency ordering (a completes before b starts)
3. **Parallel tool nodes** — two independent tool nodes, verify both complete
4. **Tool node with args** — tool node with `toolArgs`, verify args passed through
5. **Tool node failure → abandoned** — tool node calling unknown tool, verify node abandoned
6. **Three-node diamond** — a→{b,c}→d, verify d waits for both b and c
7. **Max concurrency respected** — 3 parallel roots with maxConcurrency=1, verify sequential execution
