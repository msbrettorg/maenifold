# T-67.18 — Keyboard Navigation & Status Animations

**Requirement**: FR-34
**Phase**: 3

## Context
Keyboard shortcuts for zoom navigation and CSS animations for node status transitions.

## Acceptance Criteria
1. Document-level `keydown` listener (via composable or in overlay component):
   - `Escape`: calls `zoomStore.back()` — L2→L1 or L1→L0
   - `Escape` twice rapidly from L2: goes directly to L0
   - `Cmd+[` / `Cmd+]`: lateral navigation to predecessor/successor node (only in L1/L2)
2. New CSS animations in PipelineNodeCard or a `src/styles/node-animations.css`:
   - `.node-ready-pulse`: gentle scale oscillation (1.0→1.02→1.0, 2s infinite)
   - `.node-active-glow`: animated border glow using accent color
   - `.node-completion-ripple`: `@keyframes` radial pulse (600ms, accent color 20%→0% opacity, max radius 40px beyond card)
3. Status animations applied reactively based on node status from pipeline store
4. Animations respect `prefers-reduced-motion` media query
5. `npx vue-tsc --noEmit` passes

## Files
- `src/styles/node-animations.css` (new)
- `src/components/SemanticZoomOverlay.vue` (keyboard handler)
- `src/components/PipelineNodeCard.vue` (apply animation classes)

## Dependencies
- T-67.12 (zoom store required for keyboard navigation actions)
- T-67.10 (node card must exist before animation classes can be applied)
