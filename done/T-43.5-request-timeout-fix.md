# T-43.5: Request Timeout Fix

**Requirement**: FR-42 audit findings — Transports  
**Priority**: P2  
**Files**: `vendor/acp-ui/src/lib/acp-bridge.ts`

## Acceptance Criteria

1. The current `sendRequest` method in `acp-bridge.ts` applies a blanket 60-second timeout to ALL outgoing requests (~L221-228). This is incompatible with long-lived methods like `terminal/wait_for_exit` which may block for minutes.

2. Add per-method timeout support:
   ```ts
   private getTimeoutForMethod(method: string): number {
     switch (method) {
       case 'terminal/wait_for_exit':
         return 30 * 60 * 1000; // 30 minutes
       case 'terminal/create':
         return 5 * 60 * 1000; // 5 minutes
       case 'session/load':
         return 5 * 60 * 1000; // 5 minutes (large session replay)
       default:
         return 60 * 1000; // 60 seconds
     }
   }
   ```

3. Use `this.getTimeoutForMethod(method)` instead of the hardcoded `60000` in the `setTimeout` call.
