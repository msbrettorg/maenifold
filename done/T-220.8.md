# T-220.8 - Verify HuggingFace Model Downloads and Catalog

## Problem

Embedding model downloads and external model catalog overrides are trusted without immutable revisions, hashes, or signatures.

## Evidence

- `crates/maenifold-core/src/tools/embedding_download.rs:76-168` downloads and moves model/tokenizer files without hash verification.
- `crates/maenifold-core/src/tools/embedding_models.rs:54-66` prefers an external `{assets_path}/models/catalog.json`.
- `crates/maenifold-core/assets/models/catalog.json:67-91` includes large remote models and a noncommercial model entry.
- Source: `docs/codebase-audit-2026-04-25.md#p1-7`.
- Parent sequential thinking session: `session-1777125506368-62098`.

## Acceptance Criteria

- [ ] Model catalog entries include immutable revision identifiers and per-file hashes.
- [ ] Every downloaded model/tokenizer file is verified before finalization.
- [ ] External catalog overrides require explicit trust and report provenance.
- [ ] Non-MIT/Apache model licenses require explicit opt-in before download/use.
- [ ] `cargo build --release -p maenifold-cli` succeeds.
