# T-239.0b - Cargo gate fallback blocked by maenifold-core compile errors

**Pipeline**: lightweight

## Problem

After the gate MCP surface and installed CLI were unavailable, the PM used the repository fallback:

```text

cargo run -q -p maenifold-gate -- status --root . --json
```
