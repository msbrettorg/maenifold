# T-63.12 — Frontend: Tool Node Type

**Requirement**: FR-4
**Test Cases**: TC-8, TC-9, TC-10
**Repo**: pipeline-ui
**Component**: src/lib/pipeline-types.ts, src/stores/pipeline.ts, src/components/AddNodeForm.vue, src/components/PipelineNodeCard.vue, src/components/PipelineInspector.vue

## Context

Backend will have a Tool node type (T-63.11). Frontend needs to support it across all surfaces: types, store, form, node card, and inspector.

## Acceptance Criteria

1. **pipeline-types.ts**: Add `ToolNode` to the discriminated union:
   ```ts
   interface ToolNode { type: 'tool'; id: string; toolName: string; toolArgs?: Record<string, unknown>; agent: string; }
   ```
   Update `PipelineNode = WorkflowNode | PromptNode | SequentialThinkingNode | ToolNode`
   Add `isToolNode()` type guard
   Update `createNode()` to handle `'tool'` type
   Update `nodeLabel()`: returns `toolName` for tool nodes
2. **pipeline.ts (store)**: `addNode()` handles `'tool'` type. `normalizeNode()` handles tool nodes from server.
3. **AddNodeForm.vue**: Add "Tool" to type dropdown. Show fields: Tool Name (text input, required), Tool Args (JSON textarea, optional), Agent (text input, required).
4. **PipelineNodeCard.vue**: Tool accent color `var(--color-node-tool)` (#00897b teal). Icon: 🔧. Show `toolName` as metadata.
5. **PipelineInspector.vue**: Design mode: edit toolName, toolArgs (JSON), agent. Server mode: display toolName, toolArgs, output.
6. Typecheck passes: `npx vue-tsc --noEmit`

## Swe Notes

PASS. Added ToolNode to pipeline types and store normalization/addNode handling; added Tool node form fields; updated node card accent/icon/metadata; added inspector editing and server display for toolName, toolArgs, and output; vue-tsc passes.
