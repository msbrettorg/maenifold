# T-238.26 — Consolidate config mutation tools into maenifold.config gateway domain

## Problem

9 config mutation tools are exposed flat in `tools/list`, inflating the MCP surface from the target 6 control-plane tools to 15. This undermines the gateway consolidation design which aims for a tiny `tools/list` with everything else routed through `GatewayIndex` → `GatewayExecute`.

Current flat tools that should be routed:

- `ReloadConfig`
- `UpdateSettings`
- `AddAgent`
- `UpdateAgent`
- `DeleteAgent`
- `AddMcpServer`
- `UpdateMcpServer`
- `DeleteMcpServer`
- `DiscoverMcpTools`

## Expected behavior

- `tools/list` exposes exactly 6 tools: `GetHelp`, `ReadMcpResource`, `GatewayIndex`, `GatewayExecute`, `GatewayBatch`, `GatewayIntent` (when intent resolver enabled; 5 without).
- All 9 config mutation tools are accessible via `GatewayExecute` under domain `maenifold.config`.
- `GatewayIndex` for `maenifold.config` lists all 9 commands with schemas.
- Safety classification: all 9 are `mutate`.

## Evidence

- `tools/list` returns 15 tools after GatewayIntent enablement.
- The gateway catalog domain test `gateway_active_surface_has_exact_tool_count_by_intent_mode` expects only GetHelp, ReadMcpResource, and gateway tools — but the test does not count config mutation tools because they are handler-intercepted.
- Prior learning (T-229.2): handler-intercepted tools added to `TOOL_DOMAINS` get advertised by GatewayIndex but fail through GatewayExecute because `invoke_native()` lacks `ConfigMutationState`. The solution must handle execution correctly, not just catalog advertisement.

## Acceptance criteria

- [ ] `tools/list` returns exactly 5 tools (6 with intent resolver enabled).
- [ ] `GatewayIndex` lists `maenifold.config` domain with all 9 config commands.
- [ ] `GatewayExecute` with `domain: "maenifold.config"` executes all 9 commands.
- [ ] Config mutation state is available to the gateway dispatch path.
- [ ] Existing config mutation behavior does not regress.

## Verification

- `tools/list` count assertion.
- `GatewayIndex` for `maenifold.config` lists 9 commands.
- `GatewayExecute` with each of the 9 commands succeeds.
- `cargo test -p maenifold-core -- gateway_catalog_domain`
- `cargo test -p maenifold-core -- gateway_dispatch`
- `cargo build --release -p maenifold-core`
