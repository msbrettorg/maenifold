# T-46.3: Sidebar Multi-Session Awareness

**Requirement**: FR-46
**Priority**: P0
**Files**: `vendor/acp-ui/src/components/SessionList.vue`, `vendor/acp-ui/src/App.vue`

## Context

After T-46.2, the store supports multiple simultaneous connections. The sidebar needs to reflect this — show which sessions are connected, switch active session on click (not resume), and handle the × button correctly.

## Acceptance Criteria

1. In `SessionList.vue`, update session status detection:
   - A session is "connected" if it exists in `sessionStore.sessions` Map with `isConnected === true` (check by matching `sessionId` against live session entries)
   - A session is "connecting" if it exists with `isConnecting === true`
   - Show green "connected" badge and amber "connecting" badge as before

2. When clicking a session that's already connected:
   - Do NOT call `resumeSession` — call `sessionStore.setActiveSession(sessionId)` to switch the view
   - Only call `resumeSession` for sessions that are NOT currently connected

3. × button behavior remains:
   - Connected → `sessionStore.closeSession(sessionId)` (disconnects and removes)
   - Connecting → cancel connection
   - Not connected → confirm and delete

4. In `App.vue`:
   - `handleResumeSession` should check if the session is already in the sessions Map before calling resumeSession
   - If already connected, call `setActiveSession` instead

5. Update `ChatView` rendering key to use `activeSessionId` so it re-renders when switching sessions:
   - `<ChatView v-if="isConnected" :key="sessionStore.activeSessionId" />`
