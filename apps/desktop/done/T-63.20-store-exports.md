# T-63.20 — Export Fork/Join/Dispatch from Store

**Requirement**: FR-5
**Test Cases**: TC-13, TC-14
**Repo**: pipeline-ui
**Component**: src/stores/pipeline.ts, src/composables/usePipelineMcp.ts

## Context

`usePipelineMcp.ts` has `forkPipeline`, `joinPipeline`, `dispatchPipeline` implemented but the Pinia store does not export wrapper actions. Components can't access these operations through the standard store interface.

## Acceptance Criteria

1. Add `forkPipeline(sessionId: string, fromNodeId: string, newSessionId?: string)` action to the Pinia store
2. Add `joinPipeline(sessionId: string, sourceSessionId: string, edges: PipelineEdge[])` action to the store
3. Add `dispatchPipeline(sessionId: string)` action to the store
4. Fix `forkPipeline` in `usePipelineMcp.ts`: include `newSessionId` parameter (currently missing from MCP call args)
5. All 3 new actions follow the same error handling pattern as existing store actions (catch → set errorMessage after T-63.2)
6. Typecheck passes: `npx vue-tsc --noEmit`

## SWE Remediation

PASS. Added Pinia store actions for fork/join/dispatch using withError, refreshed store state after operations, and fixed MCP fork args to pass optional newSessionId.
