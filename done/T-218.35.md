# T-218.35 — Scheduled ACP Permission Model

## Problem

Scheduled task prompts are user-configurable and run unattended, but scheduler execution uses automatic permissions. This differs from the safer Teams dispatch model and can allow stale or maliciously edited prompts to execute tools without a contemporaneous approval decision.

## Acceptance Criteria

- [ ] Define scheduler permission model explicitly: auto-grant off by default, per-schedule allowlist, or signed/trusted schedule policy
- [ ] UI displays whether a schedule runs with automatic permissions
- [ ] Existing schedules migrate to the safest behavior
- [ ] A schedule that attempts a sensitive tool call does not silently auto-grant unless explicitly configured
- [ ] Permission denial/error path is visible in schedule logs and UI
- [ ] Tests cover default, explicit allowlist, and denied sensitive tool scenarios
