# T-220.3 - Contain Pipeline Cwd and Config Loading

## Problem

Pipeline node `cwd` values can canonicalize outside the configured maenifold root, and agent configuration can then be loaded from the escaped directory.

## Evidence

- `crates/maenifold-core/src/workflow/pipeline/executor_nodes_cwd.rs:6-24` accepts absolute and traversal cwd values without root containment.
- `crates/maenifold-core/src/workflow/agent_session.rs:259-267` loads `AgentsConfig` from `cwd`.
- `crates/maenifold-core/src/acp/config/loader.rs:27-42` silently returns default config for missing or unparsable config.
- Source: `docs/codebase-audit-2026-04-25.md#p1-2`.
- Parent sequential thinking session: `session-1777125506368-62098`.

## Acceptance Criteria

- [ ] Pipeline cwd canonicalization rejects paths outside `context.config.maenifold_root` unless an explicitly named unsafe mode is configured.
- [ ] Execution-sensitive agent configuration is loaded from the trusted root, not an arbitrary node cwd.
- [ ] Missing or unparsable execution config fails with an explicit error instead of silently defaulting.
- [ ] Tests cover absolute escape, relative traversal escape, valid contained cwd, and invalid config handling.
- [ ] `cargo build --release -p maenifold-cli` succeeds.
