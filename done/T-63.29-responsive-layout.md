# T-63.29 — Responsive Layout Below 900px

**Requirement**: NFR-3
**Test Cases**: TC-29
**Repo**: pipeline-ui
**Component**: src/App.vue, src/components/PipelineView.vue

## Context

Layout is fixed three-column (sidebar + canvas + inspector). Below 900px viewport width, it overflows or becomes unusable.

## Acceptance Criteria

1. Add CSS breakpoint `@media (max-width: 900px)` in App.vue or PipelineView.vue
2. Below 900px:
   - Sidebar collapses to an overlay/drawer (toggle button to show/hide)
   - Canvas takes full width
   - Inspector becomes a bottom sheet or overlay (shown when a node is selected)
3. Above 900px: layout remains three-column as today
4. Touch/click targets remain usable at tablet size
5. No horizontal overflow at 900px viewport width
6. Typecheck passes: `npx vue-tsc --noEmit`

## Swe Notes

PASS. Added @media (max-width: 900px) responsive behavior in PipelineView: sidebar collapses to overlay drawer with toggle, composer/canvas remains full width, inspector becomes mobile bottom-sheet overlay with toggle + close controls, touch targets enlarged, and no horizontal overflow in narrow viewport. Verified npx vue-tsc --noEmit passes.
