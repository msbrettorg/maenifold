# T-201.2 — Wizard shell + Welcome step + App.vue gate

## Intent

Create the `OnboardingWizard.vue` component shell with sidebar step indicator, crossfade transitions, and the Welcome step content. Integrate into `App.vue` with a first-run gate that shows the wizard or the main app.

## Parent Epic

T-179.34 — First-run onboarding wizard

## Scope

**New files:**
- `apps/desktop/src/components/OnboardingWizard.vue` — shell layout + Welcome content
- `apps/desktop/src/components/OnboardingStepWelcome.vue` — Welcome step (static content + "Get started" button)

**Modified files:**
- `apps/desktop/src/App.vue` — add `v-if="isFirstRun"` gate wrapping wizard vs main content

## Architecture

### Shell layout

Left sidebar (240px) with step indicator dots + right main content area (max-width 640px):

- Sidebar: `w-60 bg-bg-sidebar` with 52px top padding for macOS traffic lights
- Step dots: 20px circles, states: complete (bg-success), current (bg-brand + ring), pending (bg-bg-surface)
- Step labels below dots, clickable only for visited steps (≤ highWaterStep)
- Main area: `flex-1 bg-bg-app overflow-y-auto p-10`, content centered in `max-w-[640px] mx-auto`

### Step switching

Use Vue `<Transition>` with 0.35s fade + translateY for crossfade:

```vue
<Transition name="wizard-step" mode="out-in">
  <component :is="activeStepComponent" :key="currentStepId" />
</Transition>
```

The shell imports all step components and switches via `computed` based on `currentStepId` from `useOnboarding()`.

### Welcome step (OnboardingStepWelcome.vue)

Static content:
- Sparkles icon
- "Welcome to maenifold" heading
- Brief description
- 3 setup items listed (daemon, agent, model)
- "Get started →" brand button → calls `advance()`

### App.vue integration

```vue
<OnboardingWizard v-if="isFirstRun" @complete="onOnboardingComplete" />
<div v-else class="relative box-border flex h-screen flex-col overflow-hidden">
  <!-- existing app content -->
</div>
```

`onOnboardingComplete` calls `markComplete()` from useOnboarding.

### Design tokens

All from DESIGN.md — zero hardcoded colors:
- `--bg-app`, `--bg-sidebar`, `--bg-elevated`, `--bg-surface`
- `--text-primary`, `--text-secondary`, `--text-tertiary`
- `--brand`, `--success`
- `--border-card`, `--border-subtle`
- `--r12` for card radius, `--shadow-16` for card shadow

## Acceptance Criteria

1. Wizard renders when `isFirstRun` is true
2. Main app renders when `isFirstRun` is false
3. Sidebar shows 5 step dots with correct states (complete/current/pending)
4. Clicking a visited step dot navigates to that step
5. Clicking a future step dot does nothing
6. Welcome step shows heading, description, setup preview, and "Get started" button
7. "Get started" advances to step 1 (Daemon)
8. Step transitions use 0.35s crossfade animation
9. All design tokens from DESIGN.md — zero hardcoded colors
10. `npx vue-tsc --noEmit` passes
