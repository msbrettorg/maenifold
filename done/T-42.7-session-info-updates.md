# T-42.7: Session Info Updates

**Requirement**: FR-42.7  
**Priority**: P1  
**Files**: `vendor/acp-ui/src/stores/session.ts`

## Acceptance Criteria

1. Add `case 'session_info_update':` in `handleSessionUpdate`:
   ```ts
   case 'session_info_update':
     if (currentSession.value) {
       if ('title' in update && update.title !== undefined) {
         currentSession.value.title = update.title ?? '';
         // Persist to saved sessions
         const saved = savedSessions.value.find(s => s.sessionId === currentSession.value?.sessionId);
         if (saved) {
           saved.title = currentSession.value.title;
           persistSessions();
         }
       }
       if ('updatedAt' in update && update.updatedAt !== undefined) {
         currentSession.value.lastUpdated = update.updatedAt ? new Date(update.updatedAt).getTime() : Date.now();
       }
     }
     break;
   ```

2. Remove the client-side title hack in `sendPrompt` (~L697-700):
   ```ts
   // DELETE THIS:
   if (messages.value.length === 2 && currentSession.value) {
     currentSession.value.title = text.slice(0, 50) + (text.length > 50 ? '...' : '');
   ```
   Instead, keep the session title as whatever the agent sends via `session_info_update`. If no title is ever sent, the default (empty or session ID) remains.
