# T-178.P0a — Folder picker broken in iframe and visually broken everywhere

## Priority: P0

## Symptom
When running in cowork iframe: Browse button opens "Enter Working Directory" dialog but Cancel and Use Path buttons do not respond. In Electron: dialog renders but buttons may be invisible due to stale design tokens.

## Root Cause (duo-confirmed, 2026-04-19)

Three independent issues in `composables/folder-picker.ts`:

### 1. Stale Tailwind tokens (affects all contexts)
Lines 19-32 use old Obsidian/shadcn-default tokens: `bg-card`, `bg-muted`, `bg-primary`, `text-foreground`, `border-border`, `bg-input`, `focus:ring-ring/20`. The app moved to Fluent 2 tokens. These don't resolve → buttons render with transparent backgrounds → invisible clicks.

### 2. `dialog.showModal()` blocked in iframe
Line 116 calls `dialog.showModal()` which requires `allow-modals` in the iframe sandbox attribute. Without it, `showModal()` throws → caught → falls through to `window.prompt()` which is ALSO blocked → silent failure.

### 3. Raw DOM dialog bypasses Vue event system
The entire dialog is built via `document.createElement` with raw `addEventListener`. This is fragile, untestable, and inconsistent with the shadcn-vue design system used everywhere else.

## Fix Approach
Replace the raw DOM `<dialog>` with a Vue component using shadcn-vue `<Dialog>` primitives:

1. Create `components/FolderPickerDialog.vue` using shadcn `Dialog`/`DialogContent`/`DialogHeader`/`DialogFooter`
2. Use Fluent 2 design tokens (bg-bg-surface, text-text-primary, border-border-subtle)
3. Mount it at the App root level (e.g., alongside PermissionDialog)
4. `pickAbsoluteDirectory()` in `folder-picker.ts` becomes a promise that resolves/rejects via a Pinia store or event bus connecting to the mounted dialog
5. The 3-tier fallback remains: File System Access API → Electron bridge → Vue Dialog (not raw DOM)

### Also fix:
- `SemanticZoomOverlay.vue:212` — replace `window.prompt()` for fork-rename with a shadcn Dialog + Input
- Audit all other `window.prompt()`, `window.confirm()`, `dialog.showModal()` calls in the codebase

## Acceptance Criteria
1. Folder picker works in cowork iframe context — Cancel closes, Use Path applies the path
2. Folder picker works in Electron standalone — all 3 tiers function
3. Buttons are visible with correct Fluent 2 design tokens
4. Path validation provides feedback when `isAbsolutePath` fails (not silent)
5. Fork-rename in SemanticZoomOverlay uses shadcn Dialog, not window.prompt()
6. No `window.prompt()`, `window.confirm()`, or raw `document.createElement('dialog')` remain in the codebase
7. `npx vue-tsc --noEmit` passes
8. All callers of `pickAbsoluteDirectory` still work (AppSidebar, GateViewToolbar)
