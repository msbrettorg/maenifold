# T-211.6 — Schedule Supervisor Script

## Description

Shell script at `~/maenifold/bin/schedule-supervisor.sh`:
1. Acquire lock file (prevent overlap)
2. Execute: `maenifold tool AcpExec '{"agent":"...","prompt":"..."}'`
3. Log output to `~/maenifold/logs/schedules/{id}/`
4. Timeout with SIGTERM → SIGKILL
5. Record result to job config

## Acceptance Criteria

- Lock prevents concurrent runs of same job
- Timeout enforced
- Logs captured
- Exit status recorded in job config
