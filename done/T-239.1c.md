# T-239.1c - Teams token cache path must not silently default to relative directory

**Pipeline**: lightweight

## Problem

The T-239.1 token cache implementation resolves the agency-cowork cache path with `HOME`, then `USERPROFILE`, then silently falls back to `PathBuf::from(".")`. That can write or read `.teams-agent/token-cache.json` relative to the current working directory when no home directory is available.

Silent defaults are forbidden. The proven agency-cowork pattern is `~/.teams-agent/token-cache.json`; if the home directory cannot be resolved, the provider must return an explicit actionable error.
