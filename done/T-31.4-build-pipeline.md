# T-31.4: Build Pipeline for Tauri + Frontend

**Requirement**: FR-41 (Native Desktop App via Tauri)

## Objective

Update the Makefile to build the frontend before the Rust binary, ensuring `vendor/acp-ui/dist/` exists when `cargo build -p maenifold-app` runs Tauri codegen.

## Acceptance Criteria

1. `Makefile` has a `frontend` target that runs `cd vendor/acp-ui && npm install && npm run build`
2. `Makefile` has an `app` target that depends on `frontend` and runs `cargo build --release -p maenifold-cli`
3. `make app` produces a working binary at `target/release/maenifold`
4. `make app` succeeds from a clean state (no pre-existing dist/)
5. The existing `make build` or default target still works for non-Tauri builds
