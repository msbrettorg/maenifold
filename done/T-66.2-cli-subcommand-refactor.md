# T-66.2: CLI Subcommand Refactor

**Requirement**: FR-8.1 (CLI interface)
**Sprint**: 66

## Summary

Replace the mixed flag/subcommand CLI interface with a consistent subcommand-based API. Add `prompt` subcommand for direct ACP agent interaction.

## Current Interface (BEFORE)

```
maenifold --tool <name> --payload '<json>' [--json]
maenifold workflow <id> <agent> <prompt>
maenifold think <agent> <topic>
maenifold --mcp
maenifold --http [--port <PORT>]
```

Mixed style: `--tool` is a flag, `workflow`/`think` are subcommands.

## Target Interface (AFTER)

```
maenifold prompt   <agent> <message>
maenifold think    <agent> <topic>
maenifold workflow <id> <agent> <prompt>
maenifold tool     <name> <payload> [--json]
maenifold --mcp
maenifold --http [--port <PORT>]
```

Subcommands for user actions, flags for server modes only.

## Changes Required

### 1. Production Code (cli.rs + handlers.rs)

**File: `crates/maenifold-core/src/cli.rs`**
- Parse `tool` as a subcommand (like `workflow`/`think`) instead of `--tool` flag
- `tool <name> <payload>` replaces `--tool <name> --payload '<json>'`
- Keep `--json` as an optional flag on the `tool` subcommand
- Update help text to show new syntax
- Maintain backward compat: `--tool` still works but prints deprecation warning to stderr

**File: `crates/maenifold-core/src/cli/handlers.rs`**
- Add `run_prompt_command(args)` (~15 lines):
  - Parse `<agent> <message>` args
  - Call `open_agent_session` + `session.prompt()` + `session.close()`
  - Print response text to stdout
- Add `"prompt"` match arm in `run_script_command`
- Add `"tool"` match arm in `run_script_command` (delegating to existing tool logic)

### 2. Test Files (bulk find-replace)

All CLI integration tests use helper functions that build args with `--tool` and `--payload`. The helpers are in:
- `crates/maenifold-cli/tests/cli_output_support/mod.rs`
- `crates/maenifold-cli/tests/cli_security_support/mod.rs`
- `crates/maenifold-cli/tests/mcp_resource_support/mod.rs`

**Strategy**: Update the helper functions to use `tool <name> <payload>` syntax. All tests that call through the helpers get fixed automatically. Tests that build args directly need individual updates.
