# T-201.3 — Wizard daemon health check step

## Intent

Create the `OnboardingStepDaemon.vue` component for the wizard's daemon connection step. Probes the daemon health endpoint, shows connection status, and blocks advance until the daemon is reachable.

**Modified files:**

## Architecture

### Health probe

```typescript
async function checkDaemonHealth(): Promise<DaemonStatus | null> {
  try {
    const res = await fetch(`${DAEMON_BASE_URL}/health`, {
      signal: AbortSignal.timeout(3000),
    });
    if (!res.ok) return null;
    return await res.json() as DaemonStatus;
  } catch {
    return null;
  }
}
```

Import `DAEMON_BASE_URL` from `lib/daemon-url.ts`.

### States

**Disconnected:**
- Status indicator: red dot + "Disconnected"
- "Expected at: http://localhost:8080"
- Copyable command: `maenifold-cli serve` with clipboard button
- "Check connection" button → re-probe
- "Continue →" button disabled

**Connecting:**
- Status indicator: animated dot + "Checking..."
- Buttons disabled during probe

**Connected:**
- Success box (bg-success/10, border-success)
- "✓ Connected to daemon"
- Version, tool count, agent count from health response
- "Continue →" button enabled → calls `advance()`

### Auto-probe

Probe on mount. If disconnected, re-probe every 5 seconds (poll interval). Clear interval on unmount or when connected.

### Back navigation

"← Back" button calls `goBack()` from useOnboarding.

## Acceptance Criteria

1. Probes daemon health on mount
2. Shows disconnected state with launch command when daemon unreachable
3. Shows connected state with version/tools/agents when daemon reachable
4. "Check connection" button triggers manual re-probe
5. Auto-polls every 5 seconds when disconnected
6. "Continue →" blocked until connected
7. "← Back" navigates to Welcome step
8. Clipboard copy button works for launch command
9. All design tokens from DESIGN.md — zero hardcoded colors
10. `npx vue-tsc --noEmit` passes
