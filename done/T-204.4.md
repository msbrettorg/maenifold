# T-204.4 — VoiceInputButton.vue

## Requirement

Create `apps/desktop/src/components/VoiceInputButton.vue`:

- 32×32 ghost button using shadcn-vue `Button variant="ghost" size="icon"`
- lucide-vue-next `Mic` icon (16px)
- 4px border-radius per DESIGN.md
- 6px status bead (absolutely positioned bottom-right): `#0E9C57` when running, hidden otherwise
- Tooltip (sentence case):
  - Not installed: "Install Handy: brew install --cask handy" (platform-aware)
  - Installed, not running: "Launch Handy to dictate"
  - Running: "Open Handy — use its hotkey to record"
- Click: calls `voiceHandyStore.launch()`
- Hidden when `window.electronAPI?.voiceCheck` is undefined (web mode)
- When installed=false && enabled=true: render at `textDisabled` opacity with install tooltip

## Acceptance criteria

1. Component renders per DESIGN.md spec
2. Status bead accurately reflects Handy running state
3. Click launches or foregrounds Handy
4. Tooltip is platform-aware and sentence case
5. Hidden in web mode
