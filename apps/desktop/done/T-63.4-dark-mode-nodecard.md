# T-63.4 — Dark Mode: NodeCard #fff Fix

**Requirement**: FR-3
**Test Cases**: TC-5
**Repo**: pipeline-ui
**Component**: src/components/PipelineNodeCard.vue

## Context

PipelineNodeCard.vue uses `color-mix(in srgb, {accent} 10%, #fff)` in 5 places for node card backgrounds. `#fff` is hardcoded, breaking dark mode (cards appear as bright white-tinted blocks).

## Acceptance Criteria

1. Find ALL occurrences of `#fff` in PipelineNodeCard.vue (expect 5)
2. Replace each `#fff` with `var(--bg-main)` so `color-mix()` blends the accent against the actual background
3. Verify node cards render with subtle accent tint in both light and dark mode
4. No other hardcoded color values remain in PipelineNodeCard.vue — all should reference CSS custom properties
5. Typecheck passes: `npx vue-tsc --noEmit`

## SWE Remediation

PASS. Replaced hardcoded NodeCard color literals with design tokens, including all #fff color-mix/bg references now using --bg-main, and mapped node/status colors to App.vue CSS custom properties. Verified with npx vue-tsc --noEmit.
