## Objective

Create E2E tests for pipeline lifecycle operations (run/pause/resume/cancel)
using real tool-node execution through the supervisor.

## Test file

`crates/maenifold-core/src/workflow/pipeline/e2e_tests_lifecycle.rs`

## Test cases

1. **Run completes all nodes** — create 3-node chain, run, wait, verify all completed
2. **Cancel abandons running pipeline** — create pipeline, run, cancel immediately, verify abandoned
3. **Pause stops dispatch** — create multi-wave pipeline, run, pause after first wave, verify paused state
4. **Resume after pause completes** — pause a running pipeline, resume, wait for completion
5. **Run twice is rejected** — create, run, attempt second run, verify error
6. **Run on completed pipeline is rejected** — complete a pipeline, try run again, verify error
7. **Pipeline auto-completes** — all nodes complete, verify pipeline status transitions to completed
8. **Failed node abandons but pipeline continues** — always-edge downstream continues after abandoned node

## Harness

Same as T-71.1. Tests use tool nodes for fast, deterministic execution.
Lifecycle tests may need longer `wait_for` timeouts.

## Acceptance criteria

- All tests pass without mocks
- Tests exercise real supervisor_run → executor → tool_node path
- Lifecycle state transitions verified via view
