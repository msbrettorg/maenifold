# T-64.11 — Fork context inheritance (BE)

**Requirement**: FR-26

## Acceptance Criteria

- When forking at node B in A→B→C: forked B' receives A's completed output as predecessor context
- Implementation: copy `state.output` from source pipeline's completed predecessors of the fork point into the forked pipeline's initial state
- Forked root nodes have access to the same reasoning context the original had
- When predecessor has no output (not completed): no context injected (graceful absence)
- Fork without upstream predecessors (forking at a root node): no change in behavior
- All existing pipeline + fork tests pass
- `cargo test -p maenifold-core -- pipeline` green

## Context

Fork is a cognitive operation: "explore an alternative reasoning path from this point." Without predecessor context, the fork starts blind — it doesn't know what upstream reasoning produced. This breaks the cognitive pipeline model.

See: `memory://build/architecture/pipeline-t64-architectural-intent-analysis` Section 8.
