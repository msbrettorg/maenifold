# T-67.14 — Node Double-Click & Dimming

**Requirement**: FR-35
**Phase**: 3

## Context
useComposerCanvas.ts handles node events. Need to add onNodeDoubleClick for L0→L1 transition, and apply per-node dimming styles when zoom level is 'inspect' or 'session'.

## Acceptance Criteria
1. `onNodeDoubleClick` handler added to `useComposerCanvas.ts` — calls `zoomStore.enterInspect(node.id, nodeEl.getBoundingClientRect())`
2. When `zoomStore.isInspecting`, all non-focused nodes get class `'zoom-dimmed'` via `updateNode()`
3. CSS class `.zoom-dimmed` defined: `opacity: 0.4; filter: blur(2px); transition: opacity 300ms var(--easing-standard) 50ms, filter 300ms var(--easing-standard) 50ms;`
4. Edges connected to focused node stay at full opacity; others get 15% opacity
5. `setInteractive(false)` called when entering L1; restored on exit
6. `onNodeDoubleClick` does NOT fire in designMode (only execution mode)
7. `npx vue-tsc --noEmit` passes

- `src/components/PipelineComposer.vue` (existing — add CSS)
