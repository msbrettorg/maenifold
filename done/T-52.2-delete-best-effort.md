# T-52.2 — Delete Best-Effort Cleanup

**Requirement**: FR-40 (Pipeline Active Executor)
**Component**: `crates/maenifold-core/src/workflow/pipeline/handler.rs`, `session_io.rs`

## Context

Red-team finding F-1 on T-51.8: `delete_pipeline` hard-fails if any workflow session file is missing. `derive_pipeline_node_states` returns `Err` on absent files, so a partially-orphaned pipeline becomes permanently un-deletable.

## Acceptance Criteria

1. Delete must be best-effort: skip missing workflow session files, log a warning, continue
2. Always delete the pipeline session file at the end regardless of individual file failures
3. Active-node guard should check frontmatter states directly (not derived states) to avoid the chicken-and-egg problem
4. Return count of successfully deleted files + count of missing/skipped files
5. Add test: delete pipeline with one missing workflow session → succeeds, reports skip

## Scoped Tests

```bash
cargo test -p maenifold-core --lib pipeline_delete -- --nocapture
```
