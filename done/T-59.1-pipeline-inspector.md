# T-43.1: PipelineInspector Component

**Requirement**: FR-43.1
**RTM**: RTM-192
**Priority**: P0 — Inspector is required for the pipeline view shell

## Context

The pipeline-ui application at `/Users/brett/src/ma-collective/pipeline-ui/` needs a right-panel inspector component that shows context-sensitive content based on what's selected and whether the pipeline is in design mode or server mode.

The Pinia store is at `src/stores/pipeline.ts`. The types are at `src/lib/pipeline-types.ts`. Existing components `PipelineComposer.vue` and `PipelineNodeCard.vue` demonstrate the project's CSS conventions (CSS variables from App.vue's `:root`, scoped styles, `-apple-system` font stack).

## Scope

Create `src/components/PipelineInspector.vue` in the pipeline-ui project.

## Acceptance Criteria

1. **Props**: Accepts `selectedNodeId: string | null` and `selectedEdge: { source: string; target: string } | null`.
2. **Design mode, nothing selected**: Shows pipeline settings — editable `maxConcurrency` (number input, min 1, max 32), node count, edge count. Reads from `store.maxConcurrency` and `store.localDefinition`.
3. **Design mode, node selected**: Shows editable fields for `id`, `workflowId` (with `<datalist>` autocomplete from `store.workflows`), and `acpClient` (optional, with placeholder). Mutations update `store.localDefinition.nodes` immutably.
4. **Design mode, edge selected**: Shows edge endpoints (source → target) and a radio toggle for edge type (`success` / `always`). Mutations update `store.localDefinition.edges` immutably.
5. **Server mode, nothing selected**: Shows pipeline overview — `pipelineId`, `status` (colored), progress (`completed.length / nodes.length`), and `running` flag. Reads from `store.currentView`.
6. **Server mode, node selected**: Shows read-only node details (`workflowId`, `status` colored, `sessionId` monospace, `attempts`). Shows action buttons:
   - **Restart** (visible when status is `abandoned` or `stuck`) → calls `store.restartNode(nodeId)`
   - **Rewind** (visible when status is `completed`, `abandoned`, or `stuck`) → calls `store.rewindNodes([nodeId])`
   - **Complete** (visible when status is `active`) → calls `store.updateNodeStatus(nodeId, 'completed', conclusionText)` with a textarea for optional conclusion
   - **Abandon** (visible when status is `active`) → calls `store.updateNodeStatus(nodeId, 'abandoned')`
7. **Fallback**: When nothing applies (no selection, no view), shows "Select a node or edge to inspect".
8. **Status colors**: Use the same palette as PipelineNodeCard — pending:#9e9e9e, ready:#ffc107, active:#2196f3, completed:#4caf50, abandoned:#f44336, stuck:#ff9800.
9. **Styling**: Uses project CSS variables (`--bg-sidebar`, `--border-color`, `--text-primary`, etc.). Scoped styles. No external CSS imports. Component must be under 300 lines.
10. **Build**: `npm run build` passes with zero errors.
