## Problem

During T-235.1 orchestration, the PM attempted to use the GitHub MCP server for local repository file reads and received `404 Not Found` for `msbrettorg/maenifold-rs`. The same session also exposed an operational gap: required maenifold reasoning tools are not available as first-class Copilot CLI MCP tools in this environment, forcing CLI fallback for `SequentialThinking`, `SearchMemories`, `BuildContext`, and `FindSimilarConcepts`.

Those are product/process failures, not "pre-existing" background noise. Errors found during dogfooding must immediately become gate work.

The immediate gap in this task is not the runtime failure itself. The gap is that PM instruction surfaces disagree on what to do when the failure happens. `ralph/prompt.md` already requires tracked fallback, while other PM-facing surfaces still imply agents can switch to CLI without first creating tracked work.
