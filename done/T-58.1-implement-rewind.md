## Implementation Notes

All required primitives exist:
- `reachable_node_ids(&graph, node_index)` — BFS downstream traversal (handler.rs:1006)
- `allocate_node_session_id(context, &node_id)` — fresh session ID (session_io.rs:124)
- `write_workflow_node_session(context, ...)` — write workflow session file (session_io.rs:312)
- `persist_pipeline_state(...)` — atomic frontmatter write (session_io.rs:137)
- `compute_pipeline_status(...)` — derive status from node states
- `build_pipeline_view_result(...)` — return view JSON

Algorithm:
1. Load pipeline definition + node_states from session
2. Guard: reject if `supervisor_is_running(session_id)`
3. Build petgraph from definition
4. For each node_id in request.node_ids: find in graph, compute reachable set, union into to_reset HashSet
5. Validate all requested node_ids exist (error if not found)
6. For each node in to_reset: allocate session ID, write workflow session, update node_states to Pending
7. Persist pipeline state (sessions first, then frontmatter)
8. Return build_pipeline_view_result
