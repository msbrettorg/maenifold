# T-178.P0b — Tab routing broken / blank pane

## Priority: P0

## Symptom
Pipeline tab (and potentially other tabs) appear non-functional in cowork iframe. Navigation clicks seem to do nothing or produce a blank main panel.

## Root Cause (duo-confirmed, 2026-04-19)

There is NO vue-router in the app. Tab navigation is Pinia state via `useAppShellStore.activeTab` with `v-if`/`v-else-if` chain in `App.vue`.

### Primary bug: blank-pane fall-through
In `App.vue` template (lines ~99-150):
- `showHome` (computed in `useAppShell.ts:24-30`) = `activeTab === 'home' && !sessionStore.activeSessionId`
- When `activeTab === 'home'` AND a session IS active → `showHome = false`
- No other `v-else-if` branch matches `home` → `<main>` renders NOTHING → blank pane
- User perceives this as "tab navigation broken"

### Secondary: HomeDashboard silently drops user input
`HomeDashboard.vue:83-89` — the prompt form switches tabs and clears input but the actual prompt text is lost. The `prompt-submit` event is never consumed.

### Tertiary (unconfirmed): iframe-specific tab click issue
Beta architect could NOT reproduce tab click failures in iframe. The blank-pane bug above may be the entire symptom. If a real iframe click issue exists, it may be related to shadcn Tabs `pointer-events` propagation under certain `data-disabled` states.

## Fix Requirements

### 1. Fix blank-pane fall-through
In `App.vue`, add an explicit branch for `activeTab === 'home'` that renders even when a session is active. Options:
- Show HomeDashboard regardless (simplest)
- Show a "Return to session" view
- Redirect to agents tab when session is active

### 2. Fix HomeDashboard prompt loss
Ensure the prompt text from HomeDashboard's form is actually sent to the agent session, not just used to switch tabs.

### 3. Audit tab proxy setters
`app-shell.ts` defines computed proxies where toggling false falls back to different default tabs. This asymmetric behavior is fragile. Document the fallback logic or simplify to a single `setTab(name)` action.

## Acceptance Criteria
1. Clicking any tab from any state always shows content — never a blank `<main>` pane
2. Home tab with an active session shows either the dashboard or redirects visibly (not blank)
3. Typing a prompt in HomeDashboard and pressing Enter actually sends it
4. Tab keyboard navigation (arrow keys per shadcn Tabs pattern) works
5. Tab state persists correctly across pipeline/workflow operations
6. Works in both Electron standalone and cowork iframe
7. `npx vue-tsc --noEmit` passes

## Files to modify
- `apps/desktop/src/App.vue`
- `apps/desktop/src/composables/useAppShell.ts`
- `apps/desktop/src/components/HomeDashboard.vue`
