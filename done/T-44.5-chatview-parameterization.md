# T-44.5: ChatView Parameterization

**Requirement**: FR-44.5  
**Priority**: P0  
**Component**: `vendor/acp-ui/src/components/ChatView.vue`

## Context

ChatView currently reads all state from the singleton session store with no parameterization. Thanks to T-44.2's backward-compatible computed props (which read from the active tab), ChatView already works without changes for the ACTIVE tab. However, we need to ensure it re-renders correctly when the user switches tabs.

## Acceptance Criteria

### 1. Reactivity on Tab Switch

The session store's computed props (`messageList`, `isLoading`, `currentSession`, etc.) are all derived from `activeTab`. When `activeTabId` changes, Vue's reactivity should propagate through the computed chain to ChatView.

**Verify this works**: When the user switches tabs, ChatView should immediately show the new tab's messages, mode, model, plan, etc. If it doesn't, add a `:key="sessionStore.activeTabId"` to the `<ChatView>` in App.vue to force re-mount.

### 2. Scroll Position Preservation

When switching tabs, the chat scroll position should ideally be preserved per-tab. Add a simple mechanism:

- Before switching away from a tab, save the scroll position in the tab's state
- After switching to a tab, restore its saved scroll position
- Add `scrollPosition: number` to TabState in types.ts (this is the ONE addition to types.ts allowed)

If this is too complex, at minimum scroll to the bottom when switching tabs (so the user sees the latest messages).

### 3. Input State Preservation

The chat input field text should be preserved per-tab:

- Add `inputDraft: string` to TabState in types.ts
- When the user types in the input, save to the active tab's `inputDraft`
- When switching tabs, restore the input from the new tab's `inputDraft`

### 4. Auto-scroll Behavior

Auto-scroll to bottom should work per-tab:
- When new messages arrive on the active tab, auto-scroll
- When switching to a tab that has new messages since last viewed, scroll to bottom

## Constraints

- Primary changes in `vendor/acp-ui/src/components/ChatView.vue`
- May add `scrollPosition` and `inputDraft` fields to TabState in `types.ts`
- May add these fields to `createEmptyTabState()` in `types.ts`
- Do NOT modify the session store
- Do NOT modify App.vue
