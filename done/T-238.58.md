# T-238.58 — P2 Add interactive Teams monitor commands

**Pipeline**: sdd

## Problem

No interactive commands. Agency-cowork supports join/leave/list/status/stop/resume/cancel/dispatches commands sent via Teams chat to control the monitor. The Rust monitor has no equivalent.

## Reference

- agency-cowork: `/Users/brett/src/agency-cowork/skills/teams/scripts/monitor/message_handler.py` L890-1240

## Required changes

1. Add command detection in handler.rs — messages starting with `!` or a configurable prefix
2. Port core commands: `!status`, `!stop`, `!resume`, `!cancel`, `!dispatches`, `!list`
3. `!join` and `!leave` are deferred — they require multi-workspace config (T-238.59)
3. Commands execute locally and reply with results to the chat
4. Commands bypass keyword matching and dispatch flow

## Acceptance Criteria

- [ ] Commands detected by prefix before keyword matching
- [ ] `!status` replies with monitor state (connected, uptime, dispatches)
- [ ] `!stop`/`!resume` pause/unpause message processing
- [ ] `!cancel` cancels the active dispatch
- [ ] `!dispatches` lists recent dispatch history
- [ ] `cargo build --release -p maenifold-cli` passes
