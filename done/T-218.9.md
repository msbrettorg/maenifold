# T-218.9 — Unify Chat Markdown Rendering

## Problem

Knowledge and Gate detail were moved toward a shared markdown renderer, but chat still appears to use a legacy markdown rendering path with hand-rolled element selectors. This risks inconsistent headings, tables, code blocks, WikiLinks, and wrapping behavior across surfaces.

## Affected Completed Tasks

- T-05.94 — Knowledge blank content / markdown rendering
- T-05.95 — Unified markdown rendering for Gate detail and Knowledge notes
- T-05.96 — Shiki JS engine
- T-218.1 — Knowledge note horizontal overflow

## Acceptance Criteria

- [ ] Replace the chat legacy markdown `v-html` styling path with the shared markdown renderer, or document why it cannot yet be shared
- [ ] Verify Knowledge, Gate detail, and chat render the same markdown fixture: headings, lists, tables, code blocks, WikiLinks, and long prose
- [ ] In packaged Electron CDP, verify prose wraps inside the viewport on all three surfaces
- [ ] Verify `pre`/ASCII/code blocks preserve horizontal scrolling without expanding page width
- [ ] Verify no Shiki WASM compile errors or markdown-related console errors
- [ ] Verify no hand-rolled markdown element selector block remains outside the shared renderer path unless explicitly justified in the task notes
