# T-67.5 — Border Elimination: CSS Files

**Requirement**: FR-28
**Phase**: 2

## Context
5 CSS files contain ~50 structural border declarations that violate the No-Line Rule. Boundaries must use background color shifts instead.

## Acceptance Criteria
1. All `1px solid` structural borders removed from: `src/styles/design-tokens.css`, `src/styles/shared-components.css`, `src/styles/app-panels.css`, `src/styles/app-sidebar.css`, `src/components/PipelineView.css`
2. Panel/section boundaries replaced with background color token shifts (e.g., sidebar uses `--bg-panel` against canvas `--bg-main`)
3. Form/input borders converted to ghost borders: `1px solid rgba(var(--outline-variant-rgb), 0.15)` or removed
4. Divider patterns replaced with spacing gaps (`var(--space-3)`) or background shifts
5. No visual regression in panel layout readability
6. `npx vue-tsc --noEmit` passes

## Files
- `src/styles/design-tokens.css` (existing)
- `src/styles/shared-components.css` (existing)
- `src/styles/app-panels.css` (existing)
- `src/styles/app-sidebar.css` (existing)
- `src/components/PipelineView.css` (existing)

## Dependencies

- T-67.4 (light mode must be retired before border elimination)
