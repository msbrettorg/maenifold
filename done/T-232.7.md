## Summary

Implement the self-actualization wallpaper mode: for each Louvain community, dispatch an ACP session to a reasoning model with scoped graph tools (BuildContext, ReadMemory, SearchMemories, FindSimilarConcepts). The reasoning model reads the knowledge graph, synthesizes a grounded image prompt, which then goes to the image model.

## Implementation

### 1. Create `crates/maenifold-core/src/wallpaper/self_actualization.rs`

**Function (mirrors zeitgeist pattern — takes `&Config` only):**

```rust
pub async fn generate_self_actualization_wallpapers(
    config: &Config,
) -> anyhow::Result<Vec<PathBuf>>
```

Steps:
1. Read wallpaper settings: `let wallpaper = &config.settings.easter_eggs.wallpaper;`
2. Get top communities (same pattern as zeitgeist — open DB, get_communities, sort by size)
3. For each community:
   a. Format community line: `**[[{anchor}]]** [[{member1}]] ...`
   b. Build ACP dispatch payload following `TeamsDispatchRequest::to_acp_payload()` pattern:
      - `agent`: use `wallpaper.azure.reasoning_model` (or `small_model`)
      - `prompt`: user preface + community line + reasoning instructions
      - `allowedTools`: `["BuildContext", "ReadMemory", "SearchMemories", "FindSimilarConcepts"]`
      - `autoGrantPermissions`: true (read-only tools)
      - `mode`: "prompt"
   c. Dispatch via `AcpExec` tool — call `crate::tools::acp_exec::acp_exec()` with the payload
   d. Extract the generated image prompt from the ACP response
   e. Send that prompt to `ImageClient::generate()` verbatim (no preface, no community data)
   f. Save the image via `cache::save_image(..., "self-actualization", &anchor, &data)`
   g. 15s gap between image API calls
3. Return all saved paths
