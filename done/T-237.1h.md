## Goal

Address architect-discovered hardening gaps in native [[gate]] after the full lifecycle surface exists inside [[maenifold-mcp]].

## Failure Evidence

- Gate execution is synchronous inside async gateway handling, while other native tool execution uses blocking isolation; file walks over large `done/` corpora can stall the HTTP runtime.
- `GatewayBatch` accepts `CommandTarget::Gate` items without validating parameters against the published schema.
- Pipeline filtering currently risks surfacing synthetic error rows instead of excluding non-matching tasks.
- `sync` currently validates/counts task markdown but does not perform the file-authoritative rebuild semantics implied by the command name.
- Native `gate` domain naming can collide with any upstream server named `gate`; the reserved native domain must be protected.
- `rebuild.sh` kills any listener on port `8080` without verifying that the process is maenifold.
- `rebuild.sh` smoke verification checks `/api/config` only and would miss a missing Gate gateway domain regression.
- Desktop `gateGatewayValidated` can remain true after an unknown-domain gateway error unless validation is explicitly reset.

## Acceptance Criteria

- Gate gateway execution cannot block the async MCP/HTTP runtime on task-file walks.
- Gate batch validation rejects malformed or extra parameters consistently with published Gate schemas.
- Pipeline filters exclude non-matching tasks instead of producing fake error rows.
- `gate_Sync` or its accepted replacement performs honest sync/rebuild semantics, or the command is renamed so the contract is truthful.
- Upstream MCP servers cannot silently merge into or override the reserved native Gate domain.
- `rebuild.sh` only kills a process on port `8080` when it is the maenifold process intended to be replaced.
- `rebuild.sh` verifies the native Gate gateway domain in addition to `/api/config`.
- Desktop Gate validation resets on unknown-domain errors and surfaces an actionable error.
- No standalone Gate binary, service, tray, launchd plist, port `8081`, or global install path is reintroduced.
