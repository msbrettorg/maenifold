# T-73.2: Fix Test Failures from Mutex Races

## Requirement
NFR-3 (Test Infrastructure)

## Context
26 integration tests fail when run in parallel due to per-module mutex copies not serializing access to the process-global `Config::override_root()`. After the monolith split (T-73.1), most of these should self-resolve because each binary has its own process space. This task verifies which failures remain and fixes them.
