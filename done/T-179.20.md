## Problem

The `.dark` / `@media (prefers-color-scheme: dark)` CSS custom properties in `tailwind.css` still use the old Obsidian Engine palette values. DESIGN.md specifies Fluent 2 values from agency-cowork. Every token drifts.

This is the ROOT CAUSE of all visual inconsistency — fixing component hex values is pointless if the CSS vars themselves resolve to wrong colors.
