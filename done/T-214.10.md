# T-214.10 — Frontend TS type propagation

## Problem

The frontend TypeScript types, factory functions, schema forms, and view transforms for pipeline nodes need to include `sessionRef`. Without this, the pipeline composer cannot create or display session-backed prompt nodes.

## Solution

Update all frontend type paths:

1. **Node types**: Add `sessionRef?: { agent: string; sessionId: string }` to prompt node TS type
2. **Factory**: Default `sessionRef` to `undefined` in prompt node creation
3. **Schema forms**: Add optional `sessionRef` fields to prompt node form (agent + sessionId inputs)
4. **View transforms**: Pass `sessionRef` through to flow-node data for visual treatment
5. **Validation**: Ensure `sessionRef.agent` matches node `agent` in form validation

## Key Files

- `apps/desktop/src/types/` — pipeline node TS types
- `apps/desktop/src/components/pipeline/` — factory, schema, view transform files

## Acceptance Criteria

- TS types include `sessionRef` as optional field
- Factory creates prompt nodes with `sessionRef: undefined` by default
- Schema form exposes `sessionRef` fields when editing a prompt node
- Validation catches agent mismatch
- TypeScript clean (`npx vue-tsc --noEmit` passes)
