# T-178.6c — Vite 6→8 ecosystem upgrade

**Pipeline**: sdd
**Pipeline Digest**: tbd

## Objective

Upgrade the Vite build toolchain from v6 to v8, including all ecosystem packages that depend on the Vite major version.

## Updates Required

- `vite` 6.4.1 → 8.0.8 (2 HIGH security: path traversal, arbitrary file read)
- `@vitejs/plugin-vue` 5.2.4 → 6.0.6 (requires Vite 8)
- `vue-tsc` 2.2.12 → 3.2.7 (new major, aligns with Vite 8 ecosystem)
- `marked` 17.0.1 → 18.0.2 (major bump — review breaking changes in markdown parsing)

## Scope

- `cd apps/desktop`
- Update all 4 packages in `package.json`
- Run `npm install`
- Fix any breaking changes in `vite.config.ts` or build configuration
- Fix any breaking `vue-tsc` configuration changes
- Review `marked` changelog for breaking API changes; update any call sites
- Verify `npx vue-tsc --noEmit` passes
- Verify `npm run build` succeeds
- Verify `npm run dev` starts without errors

## Risk Assessment

- **Vite 6→8**: May have breaking config changes (check migration guide)
- **vue-tsc 2→3**: May change diagnostic behavior or strictness
- **marked 17→18**: May change rendering output or API surface
- **@vitejs/plugin-vue**: Usually tracks Vite major — low independent risk

## Acceptance Criteria

1. All 4 packages at target versions
2. `npx vue-tsc --noEmit` passes
3. `npm run build` produces working bundle
4. `npm run dev` starts and serves without errors
5. No regressions in markdown rendering (marked)

## Out of Scope

- Electron upgrade (T-178.6d)
- Runtime visual verification (handled by blue-team)
