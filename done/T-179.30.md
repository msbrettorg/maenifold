# T-179.30 — Agents session list cardization

## Intent

Agents tab session list items are flat text rows with hairline dividers. They should be elevated cards matching the cowork pattern. Timestamps should use relative format.

## Scope

File: apps/desktop/src/components/SessionList.vue

## Changes

1. Wrap each session entry in a card: rounded-[6px] border border-border-card bg-bg-elevated p-2.5 transition-all hover:bg-bg-surface-hover
2. Add 6px gap between session cards
3. Convert timestamps from full locale string to relative: "2m ago", "1h ago", "yesterday", "Apr 16"
4. Session title should be text-sm font-medium text-text-primary
5. Session timestamp should be text-xs text-text-tertiary

## Acceptance Criteria
1. Session entries are elevated cards with border-card + hover
2. Timestamps are relative format
3. npx vue-tsc --noEmit passes
