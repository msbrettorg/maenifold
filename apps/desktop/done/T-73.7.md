## Description
Implement workflow save. This task explicitly requires a new Tauri command in `src-tauri/src/` because the webview cannot write to the filesystem directly. Add a Tauri command `save_workflow_asset` that accepts workflow JSON and a target file path, writes JSON to `~/maenifold/assets/workflows/`, performs the write atomically (write temp file, then rename), and returns success/error to the frontend. Store tracks rawJson (Record<string, unknown>) alongside typed draftDefinition for lossless round-tripping — edited fields are merged back into rawJson before serialization to preserve unknown fields. Packaged workflows use fork-on-edit (save as new ID to avoid UpdateAssets clobbering). User-created workflows overwrite in place. Lightweight validation on save (non-empty name, at least one step, valid kebab-case ID). File: `src-tauri/src/` for Rust command, `src/stores/workflow-library.ts` for store action.

## Acceptance Criteria
- [ ] New Tauri command in `src-tauri/src/` is used for filesystem writes because the webview cannot write directly to disk
- [ ] Tauri command `save_workflow_asset(path, json)` accepts workflow JSON and target path
- [ ] Command writes atomically by writing a temp file and renaming into place
- [ ] Command returns success/error to the frontend
- [ ] Store carries rawJson alongside draftDefinition

- [ ] Packaged workflows prompt "Save as Copy" with new ID
