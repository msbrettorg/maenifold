# T-73.1: Split Integration Test Monolith

## Requirement
NFR-3 (Test Infrastructure)

## Context
`crates/maenifold-core/tests/main.rs` consolidates 161 test modules (862 tests) into a single binary. Tests serialize behind `GLOBAL_CONFIG_TEST_MUTEX` because `Config::override_root()` mutates process-global state. This causes:
- 500+ second full suite runtime (target: <120s)
- Can't run domain-targeted tests without compiling everything
- 26 test failures from per-module mutex copies not actually serializing
- Unrelated test domains (assets, community) block pipeline development

## Acceptance Criteria
- [ ] main.rs deleted; replaced by ~15 domain-grouped test binaries
- [ ] Each binary defines its own `GLOBAL_CONFIG_TEST_MUTEX`
- [ ] Every mod from main.rs appears in exactly one domain binary
- [ ] `cargo test -p maenifold-core --no-run` compiles all binaries without error
- [ ] Targeted tests work: `cargo test --test workflow_tests -- workflow_lifecycle`
- [ ] No test logic modified — structural refactor only
- [ ] `#[ctor]` guard_full_suite_run removed (unnecessary with split binaries)
