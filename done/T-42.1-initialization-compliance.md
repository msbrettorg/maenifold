# T-42.1: Initialization Compliance

**Requirement**: FR-42.1  
**Priority**: P0  
**Files**: `vendor/acp-ui/src/stores/session.ts`

## Acceptance Criteria

1. After both `initialize` calls (in `createSession` ~L339 and `resumeSession` ~L530), check `initResponse.protocolVersion !== PROTOCOL_VERSION`. If mismatch, disconnect and throw a clear error message.

2. Store `initResponse.agentInfo` in a new reactive ref:
   ```ts
   const agentInfo = ref<{ name: string; title?: string; version?: string } | null>(null);
   ```

3. Store `initResponse.agentCapabilities.promptCapabilities` in a new reactive ref:
   ```ts
   const agentPromptCapabilities = ref<{ image?: boolean; audio?: boolean; embeddedContext?: boolean }>({});
   ```

4. Extract a shared `performInitialization()` async function that both `createSession` and `resumeSession` call. This function handles: initialize call, version check, agentInfo storage, promptCapabilities storage, authMethods extraction.

5. Export `agentInfo` and `agentPromptCapabilities` from the store's return object.

6. Clear both refs in `disconnect()`.

## Spec References

- https://agentclientprotocol.com/protocol/initialization
- Audit findings: REQ-3 (version check MUST), REQ-7 (promptCapabilities), REQ-9 (agentInfo), REQ-10 (duplication)

## SWE Remediation

- **What changed**
  - `vendor/acp-ui/src/stores/session.ts`
    - Added shared `performInitialization()` to centralize ACP initialization for both `createSession()` and `resumeSession()`.
    - Added mandatory `protocolVersion` compliance check; on mismatch the client disconnects and throws a clear error.
    - Added reactive `agentInfo` and `agentPromptCapabilities` refs and populated them from the initialization response.
    - Exported `agentInfo` and `agentPromptCapabilities` from the store return object.
    - Cleared both refs in `disconnect()`.

- **Test results**
  - Not run (per instruction).
  - Command not run: `cd vendor/acp-ui && bun run build`
  - Command not run: full test suite

- **Notes**
  - `performInitialization()` resets the stored agent metadata before each initialize attempt so stale values are not retained across reconnections.
