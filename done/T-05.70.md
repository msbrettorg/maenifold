## Problem

GateTaskTable.vue is a hand-rolled table using @tanstack/vue-table with manual column defs, sort indicators, row selection, and custom styling. This IS a custom component. shadcn-vue provides a Data Table recipe that handles all of this.

## Solution

Replace GateTaskTable.vue with the shadcn-vue Data Table pattern:
- https://www.shadcn-vue.com/docs/components/data-table
- Install if needed: `npx shadcn-vue@latest add table`
- Use the DataTable pattern with proper column definitions
- Built-in sorting, selection, column sizing
- Proper row hover/selection states via shadcn styling

## Column layout

| Column | Width | Content |
|---|---|---|
| Task ID | 100px fixed | `task.taskId` mono font |
| Task | flex | `task.title` with truncate + hover tooltip |
| Process | 80px fixed | `task.pipeline` label |
| Progress | 200px fixed | GateTaskProgress badges, flex-wrap |

## Rules

- ZERO `<style>` blocks
- ZERO hand-rolled sort indicators — use shadcn DataTable sorting
- ZERO custom row selection classes — use shadcn DataTable row selection
- ALL styling via Tailwind
- The table MUST fill available width and look correct at default window size

## Acceptance Criteria

- Uses shadcn-vue Data Table pattern, not hand-wired TanStack
- Columns properly sized — no clipping
- Sort works via column header clicks
- Row selection highlights correctly
- Task titles visible (not taskIds)
- Verified in packaged Electron app via CDP
