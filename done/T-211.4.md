# T-211.4 — launchd Plist Manager

## Description

Write and manage launchd plists for scheduled tasks:

- Write plist to `~/Library/LaunchAgents/com.ma-collective.schedule.{id}.plist`
- Load/unload via `launchctl`
- Plist calls supervisor script with job ID argument
- CalendarInterval from cron expression

## Acceptance Criteria

- Plist files generated correctly
- launchctl load/unload works
- Schedule triggers supervisor script at correct times
- `cargo build --release -p maenifold-core` succeeds
