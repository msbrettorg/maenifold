# T-214.13 — End-to-end validation

## Problem

Session-as-Node must work end-to-end: list sessions → add session node → run pipeline → verify output + preserved session.

## Validation Steps

1. Start maenifold with at least one ACP agent configured
2. Create a session with that agent (via normal prompt)
3. Open Session Browser panel — verify session appears
4. Open pipeline composer — right-click → "Add session node"
5. Select the session from step 2
6. Add edges and configure the pipeline
7. Run the pipeline
8. Verify: the prompt was sent to the EXISTING session (not a new one)
9. Verify: the session is still alive after pipeline completes

## Acceptance Criteria

- Full flow works from UI to backend and back
- Session context preserved (agent responds with awareness of prior conversation)
- Error handling works when agent doesn't support session loading
- Error handling works when session no longer exists
