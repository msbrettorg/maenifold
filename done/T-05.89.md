## Problem

Typing `/` in the chat input on the Agents tab shows a command menu, but it only renders a single item ("Clear chat messages") instead of the full list of available slash commands. The commands do work when typed directly, but the autocomplete/picker menu is broken.

## Screenshot

The menu appears as a small box with just "Clear chat messages" — should show all available commands from the agent's slash command list.

## Files to investigate

- `apps/desktop/src/components/ChatInputBar.vue` — input handling, slash detection
- `apps/desktop/src/components/CommandPalette.vue` — command list rendering
- Check if the command list is being filtered incorrectly or if only one command is registered

## Acceptance Criteria

1. Typing `/` shows all available slash commands in a dropdown/popover
2. Commands are filterable by typing after `/`
3. Selecting a command inserts it into the input
4. Verified in packaged Electron app via CDP
