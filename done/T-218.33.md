# T-218.33 — Scheduler Generated Command Mismatch

## Problem

launchd/systemd writers generate commands like `maenifold schedule run <task_id>`, but the CLI does not expose that subcommand. Schedules can be created and appear active while the OS scheduler executes a nonexistent command.

## Acceptance Criteria

- [ ] Choose and implement one design: add `maenifold schedule run <id>` or change generated units to call an existing supported command safely
- [ ] Generated launchd/systemd units use the implemented command
- [ ] Running the generated command manually updates `last_run` and writes logs
- [ ] Packaged app uses the installed CLI/helper binary path, not an Electron helper path that lacks CLI args
- [ ] Generated launchd/systemd files are inspected in a packaged install
- [ ] A real scheduled task fires and updates `last_run` without the desktop window open
