# T-218.12 — Gate Epic Child-Closure Audit

## Problem

Epic/container tasks can be closed or cancelled while child tasks are pending, in remediation, skipped, or only partially verified. This makes "epic complete" unreliable as a release signal.

## Evidence

Process audit found prior epic/container records that claimed completion while child work was still in flight or decisive validation was partial.

## Acceptance Criteria

- [ ] Add a gate audit command or repository script that scans `todo/` and `done/` frontmatter for `parent`, `depends_on`, and task ID prefixes
- [ ] Report any epic/container in `done/` whose child tasks are still in `todo/`
- [ ] Report any epic/container whose close note claims completion while child notes contain "blocked", "partial", "deferred", "skipped", "in flight", or "backlog"
- [ ] Run the audit against the current repository and produce a zero/known-exceptions report
- [ ] Document explicit exception rules for cancelled/superseded epics
