# T-63.19 — Typography: 13 Sizes → 5-Step Scale

**Requirement**: NFR-4
**Test Cases**: TC-30
**Repo**: pipeline-ui
**Component**: src/App.vue, src/components/*.vue

## Context

13 distinct font sizes across components (10px, 11px, 12px, 13px, 14px, 15px, 16px, 0.75rem, 0.8rem, 0.85rem, 0.875rem, 0.9rem, 1rem). No consistent scale. Mixed px and rem units.

## Acceptance Criteria

1. T-63.0 defines the 5-step type scale in `:root`. This spec MIGRATES all components.
2. Map existing sizes to the scale:
   - 10px, 11px, 0.75rem → `var(--text-xs)`
   - 12px, 13px, 0.8rem, 0.85rem, 0.875rem → `var(--text-sm)`
   - 14px, 15px, 0.9rem, 1rem → `var(--text-base)`
   - 16px → `var(--text-lg)`
   - Any headings → `var(--text-xl)`
3. Replace ALL hardcoded `font-size` values in ALL `.vue` component `<style>` blocks with token references
4. Use `var(--font-mono)` for any monospace code/output text (replace individual `monospace`, `'Fira Code'`, etc.)
5. ZERO hardcoded `font-size` values remain in any component
6. Typecheck passes: `npx vue-tsc --noEmit`

## Swe Notes

PASS. Migrated all Vue component style-block font-size declarations to the 5-step typography tokens, replaced hardcoded monospace stacks with var(--font-mono), updated pipeline/App typography first and completed the remaining component migration, and fixed pipeline composer/card typing so vue-tsc passes.
