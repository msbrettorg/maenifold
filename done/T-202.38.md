# T-202.38 — App crashes during CDP tab navigation

## Problem

The packaged Electron app (`maenifold.app`) frequently crashes when navigating between tabs via CDP (agent-browser). The crash manifests as "Target page, context or browser has been closed" — the entire Electron process dies.

## Observed

CDP test 2026-04-20: App launches and initial snapshot works. Clicking tabs works 2-3 times, then the app process terminates. Happens most reliably when clicking Knowledge tab. Had to relaunch app 5+ times during testing session.

## Impact

- Blocks CDP interactive verification (the new mandatory protocol)
- Makes automated UI testing unreliable
- May also crash during normal user interaction (not just CDP)

## Acceptance Criteria

1. App survives full CDP tab navigation cycle (all 7 tabs + settings sub-tabs) without crashing
2. `agent-browser connect 9222 && agent-browser click` sequence stable for 20+ interactions
