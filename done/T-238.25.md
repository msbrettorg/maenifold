# T-238.25 - Replace Workflow tab layout using the Knowledge workspace pattern

## Problem

The Workflow tab shows the same unacceptable split-pane blank-space/gutter failure visible in the user screenshot. The user directed that Knowledge be fixed first, then Workflow be fixed carefully using the Knowledge replacement pattern.

## Dependency

This task must not start implementation until T-238.24 ships and the Obsidian-style Knowledge workspace pattern has been verified in the real packaged Electron app.

## Spec (discovery-grounded)

### Root cause

`WorkflowAuthoringPage.vue` uses `v-if="isWorkflowSelected && isInspectorVisible"` on the right panel (inspector) and its ResizableHandle. When no step is selected, the entire right panel is removed from the DOM, the center panel stretches to 80%, and the layout has an awkward gutter/dead-space effect. Knowledge workspace uses the `collapsible` prop instead — the panel stays in the DOM and can be collapsed/expanded by the user.

### Architecture: mirror KnowledgeWorkspace.vue layout

The fix restructures `WorkflowAuthoringPage.vue` (rename to `WorkflowWorkspace.vue`) to match KnowledgeWorkspace.vue's always-mounted collapsible panel layout:

```
+------------------+-----------------------------+-------------------+
| WorkflowBrowser  | WorkflowStepTimeline        | WorkflowStep-     |
|   (20%, min 15%) |   OR EmptyState             | Inspector         |
|                  |   (50%, min 30%)            | (already shows    |
|                  |                             | metadata when no  |
|                  |                             | step selected)    |
|                  |                             | (30%, min 15%,    |
|                  |                             |  collapsible)     |
+------------------+-----------------------------+-------------------+
```

### Files to modify

| File | Change |
|------|--------|
| `WorkflowAuthoringPage.vue` | Rename to `WorkflowWorkspace.vue`. Remove `isInspectorVisible` from the `v-if` on inspector panel/handle. Keep `v-if="isWorkflowSelected"` on the inspector. Add `collapsible` prop to inspector ResizablePanel. Fix default-size to constant 50 (remove dynamic 50/80 ternary). Change auto-save-id to `"workflow-workspace"`. |
| `App.vue` | Update import: `WorkflowAuthoringPage` → `WorkflowWorkspace`. Update the workflow tab wrapper from `overflow-auto p-4` to `overflow-hidden` (matching Knowledge workspace wrapper pattern at line 171). |

### Files NOT to modify

- WorkflowStepInspector.vue — already shows WorkflowMetadataForm when no step selected (line 248 v-else branch). No changes needed.
- WorkflowBrowser.vue — keep as-is
- WorkflowStepTimeline.vue — keep as-is
- Pinia stores — no changes
- KnowledgeWorkspace.vue — no regression
- lib/provenance.ts — ProvenanceBreadcrumbs deferred (workflow lineage model not yet defined; separate future task)

### Duo review feedback incorporated

1. **ProvenanceBreadcrumbs deferred** — `ProvenanceKind` does not include `workflow` and `WorkflowDefinition` has no lineage fields. Adding breadcrumbs requires extending the provenance type system. Deferred to a future task.
2. **WorkflowStepInspector already handles metadata fallback** — The v-else branch at line 237-248 already renders `WorkflowMetadataForm`. The only change needed is in the parent: stop hiding the inspector entirely.
3. **Keep v-if="isWorkflowSelected"** on inspector panel — When no workflow is selected, the inspector should remain hidden (no useful content to show). Only remove `isInspectorVisible` from the condition.
4. **App.vue wrapper** — Current workflow wrapper uses `overflow-auto p-4` (line 183-186) while Knowledge uses `overflow-hidden` (line 171-173). Must match to avoid scroll/padding conflicts.
5. **auto-save-id** — Change to `"workflow-workspace"` to invalidate stale persisted panel state from old layout.

### Requirements

1. Inspector panel condition changes from `v-if="isWorkflowSelected && isInspectorVisible"` to `v-if="isWorkflowSelected"` with `collapsible` prop.
2. ResizableHandle for inspector is present whenever a workflow is selected (not conditional on step selection).
3. Panel default-sizes are constant: browser 20%, content 50%, inspector 30%.
4. Auto-save-id changes to `"workflow-workspace"`.
5. App.vue wrapper changes from `overflow-auto p-4` to `overflow-hidden`.
6. All existing workflow actions preserved: select workflow, select step, edit step, save draft, discard.
7. Each touched file stays under 300 LOC.
8. `isInspectorVisible` computed can be removed (dead code after this change).
9. No multi-tab model, no provenance breadcrumbs, no store changes.
