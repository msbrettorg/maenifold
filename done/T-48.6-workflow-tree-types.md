# T-48.6 — TypeScript Types for Workflow Execution Tree

**Requirement:** FR-48
**Component:** `vendor/acp-ui/src/lib/`

## Summary

Define TypeScript types that model the workflow execution tree structure — workflows containing steps, sequential thinking submachines, and child workflow references.

## Acceptance Criteria

1. Create `vendor/acp-ui/src/lib/workflow-types.ts` with these types:

2. `WorkflowSession` — parsed from a workflow memory file:
   - `sessionId: string` (e.g., "workflow-1773720937011")
   - `uri: string` (memory:// URI)
   - `workflowId: string` (e.g., "workflow-dispatch")
   - `workflowName: string`
   - `started: string` (ISO timestamp)
   - `status: 'active' | 'completed' | 'abandoned'`
   - `steps: WorkflowStep[]`
   - `childWorkflowUri?: string` (URI of dispatched child workflow queue)

3. `WorkflowStep`:
   - `stepNumber: number`
   - `totalSteps: number`
   - `id: string` (step id from workflow JSON)
   - `name: string`
   - `status: 'pending' | 'active' | 'completed'`
   - `response?: string` (step response text)
   - `respondedAt?: string` (ISO timestamp)
   - `submachineSessionId?: string` (sequential thinking session ID)
   - `requiresSequentialThinking: boolean`

4. `ThinkingSession` — parsed from a sequential thinking memory file:
   - `sessionId: string`
   - `uri: string`
   - `thoughts: Thought[]`
   - `conclusion?: string`
   - `status: 'active' | 'completed' | 'abandoned'`

5. `Thought`:
   - `number: number`
   - `totalThoughts: number`
   - `agent: string` (e.g., "agent")
   - `content: string` (markdown with [[WikiLinks]])
   - `timestamp: string`

6. `WorkflowTreeNode` — union type for the tree:
   - `type: 'workflow' | 'thinking'`
   - `data: WorkflowSession | ThinkingSession`
   - `children: WorkflowTreeNode[]`

7. All types exported. File typechecks clean.
