## Problem

When the desktop app calls MCP tools like `GetConfig` and `ListMemories` directly, they fail with:

```
MCP error -32602: Tool 'GetConfig' is routed under domain 'maenifold.system'. Use GatewayExecute with the appropriate domain.
```

Same error for `ListMemories` under `maenifold.memory` domain.

## Evidence

Discovered during T-231.7 interactive CDP verification (2026-04-26). Screenshots in `outputs/screenshots/baseline/05-knowledge.png` and `09-settings-easter-eggs.png`.

The Knowledge tab shows the error when trying to list notes. The Settings Easter Eggs tab shows the error in a notification when loading config.

## Root Cause

Frontend components call `callTool('GetConfig', {})` and `callTool('ListMemories', {})` directly instead of routing through `GatewayExecute`. These tools are gateway-domain-routed and must be called via the gateway dispatch path.
