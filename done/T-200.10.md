# T-200.10 — Gate code hygiene and section format roundtrip tests

## Intent

Fix 3 mechanical code hygiene issues in maenifold-gate and add missing roundtrip tests for the section factory ↔ section parser format contract.

## Scope

Files to modify:
- `crates/maenifold-gate/src/mcp/schema.rs` — fix test name
- `crates/maenifold-gate/src/task_metadata.rs` — remove duplicate deserializer
- `crates/maenifold-gate/src/section_factory.rs` — remove unnecessary clippy allow, add roundtrip tests

## Changes

### 1. Fix test name mismatch (schema.rs)

Rename `mcp_tool_list_exposes_exactly_six_gate_tools` → `mcp_tool_list_exposes_exactly_seven_gate_tools`. The test verifies 7 tools but the name says "six" — stale since `task_body` was added.

### 2. Remove duplicate deserializer (task_metadata.rs)

`deserialize_optional_session_id` is byte-for-byte identical to `deserialize_optional_string`. Delete the duplicate and change the `session_id` field's `#[serde(deserialize_with)]` to use `deserialize_optional_string`.

### 3. Remove unnecessary clippy allow (section_factory.rs)

`#[allow(clippy::too_many_arguments)]` on `build()` which takes 6 parameters — clippy's default limit is 7, so the allow is unnecessary.

### 4. Add section format roundtrip tests (section_factory.rs)

Add `#[cfg(test)]` module with:
- `outcome_section_roundtrips_all_fields` — build an outcome section, parse it, verify stage/record_kind/outcome/agent/model/notes all survive
- `outcome_section_without_model_roundtrips` — same but without optional model
- `append_section_roundtrips_all_fields` — build an append section, parse it, verify fields and that outcome is None

## Acceptance Criteria

1. `cargo build --release -p maenifold-gate` succeeds
2. `cargo test -p maenifold-gate` passes (all existing + new tests)
3. No behavioral changes to production code
4. All 3 new roundtrip tests pass
5. `deserialize_optional_session_id` function is deleted
6. Clippy allow is removed
7. Test name accurately says "seven"
