# T-72.2 — Pipeline node pulse animation

**Pipeline**: mdd
**Pipeline Digest**: b826a880e632e457a4be2a8cbfabf45b8434090f1df1416e349cb1f9700565df
**Requirement**: UX-POLISH-72 — Active nodes should visually "breathe" to signal execution
**Component**: `src/components/PipelineNodeCard.vue`

## Context

The DAG canvas is the hero view of pipeline-ui. Active pipeline nodes currently get a static `box-shadow` via `.pipeline-node.is-active`. A pulsing glow animation makes running pipelines feel alive and provides clear state legibility.

## Acceptance Criteria

1. `.pipeline-node.is-active` has a CSS `@keyframes node-pulse` animation that cycles `box-shadow` intensity using `color-mix(in srgb, var(--node-accent) 15%, transparent)` → `30%` over 2s, infinite.
2. Uses `will-change: box-shadow` for GPU acceleration.
3. Animation does NOT use `transform` or `scale` — only `box-shadow`. Vue Flow manages node positioning and transforms must not interfere.
4. Animation is disabled by the global `prefers-reduced-motion` policy (T-72.1).
5. The existing static `box-shadow` on `.is-active` is replaced, not stacked.
6. `npx vue-tsc --noEmit` passes.

## Dependencies

- T-72.1 (reduced-motion policy must exist first)
- Must complete before T-72.9 (both touch PipelineNodeCard.vue)
