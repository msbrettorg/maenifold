# T-220.6 - Make Telemetry Explicit Opt-In

## Problem

Telemetry defaults to enabled and sends a stable machine identifier before explicit consent.

## Evidence

- `apps/desktop/src/composables/useAppSession.ts:118-120` defaults missing `telemetryEnabled` to `true`.
- `apps/desktop/src/lib/telemetry.ts:9` embeds the Application Insights connection string.
- `apps/desktop/src/lib/telemetry.ts:24-57` fetches `/api/machine-id`, sets authenticated user context, and tracks launch.
- `crates/maenifold-core/src/api/routes_config.rs:123-127` returns `machine_uid::get()`.
- Source: `docs/codebase-audit-2026-04-25.md#p1-5`.
- Parent sequential thinking session: `session-1777125506368-62098`.

## Acceptance Criteria

- [ ] Missing telemetry preference is treated as disabled until explicit opt-in.
- [ ] Machine ID is not fetched or sent unless telemetry is explicitly enabled.
- [ ] Disabling telemetry clears authenticated user context and prevents later launch events.
- [ ] UI communicates telemetry state and consent clearly.
- [ ] `cd apps/desktop && npx vue-tsc --noEmit` succeeds.
