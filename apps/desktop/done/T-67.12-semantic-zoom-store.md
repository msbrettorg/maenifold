# T-67.12 — Semantic Zoom Pinia Store

**Requirement**: FR-34
**Phase**: 3

## Context
The zoom state machine needs to be accessed across PipelineComposer, overlay component, useComposerCanvas, PipelineView, and keyboard handler. A Pinia store is the correct architecture (consistent with existing stores: usePipelineStore, useSessionStore, useConfigStore).

## Acceptance Criteria
1. New store `src/stores/semantic-zoom.ts` created with `defineStore('semanticZoom', () => {...})`
2. State: `level: Ref<'graph' | 'inspect' | 'session'>`, `focusedNodeId: Ref<string | null>`, `focusedSessionId: Ref<string | null>`, `sourceRect: Ref<DOMRect | null>`
3. Actions: `enterInspect(nodeId: string, rect: DOMRect)`, `enterSession(sessionId: string)`, `back()`, `reset()`
4. Computed: `isInspecting`, `isSession`, `isGraph`
5. Transition guards: L0→L1 requires valid nodeId, L1→L2 requires sessionId, reverse always allowed
6. Store exported from `src/stores/index.ts` (or equivalent barrel)
7. `npx vue-tsc --noEmit` passes
8. Store stays under 80 LOC
