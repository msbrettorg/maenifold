# T-63.21 — Graft UI: Add Nodes to Running Pipeline

**Requirement**: FR-5
**Test Cases**: TC-13
**Repo**: pipeline-ui
**Component**: src/components/PipelineView.vue, src/components/PipelineComposer.vue

## Context

`graftNodes` exists in the store but no component calls it. Users cannot add nodes to a running pipeline through the UI.

## Acceptance Criteria

1. Add a "Graft Nodes" button in `PipelineView.vue` (runner panel area), visible only when a pipeline is loaded
2. Button opens a dialog/modal with a mini-composer: node type selector, fields, edge connections to existing nodes
3. Dialog shows existing node IDs as potential edge targets
4. On submit, calls `store.graftNodes(sessionId, newNodes, newEdges)`
5. After successful graft, refreshes the pipeline view (re-runs `loadPipeline`)
6. Button uses `.btn-primary` class from design system
7. Dialog inputs use `.field-input` / `.field-select` classes
8. Typecheck passes: `npx vue-tsc --noEmit`

## Swe Notes

PASS. Added a runner-panel Graft Nodes action, extracted a modal mini-composer for grafting one node with upstream/downstream edge selectors against existing node IDs, and refresh the loaded pipeline after store.graftNodes succeeds. Also aligned optional createNode input ids so vue-tsc passes.
