# T-204.9 — Delete embedding model button does not work (flat layout)

**Pipeline**: sdd
**Pipeline Digest**: pending

## Problem

Clicking the "Delete" button on an installed flat-layout embedding model (e.g. all-MiniLM-L6-v2) in the Settings > Embeddings UI silently fails. The confirmation dialog appears, user clicks Delete, but:
- Model file remains on disk (`all-MiniLM-L6-v2.onnx` still in `~/maenifold/assets/models/`)
- Model remains listed in the UI
- No error is shown to the user

Backend returns: `Error: Model directory not found: .../models/all-MiniLM-L6-v2`
The model is stored as a bare `.onnx` file (flat layout), not as a subdirectory. The delete handler only handles subdirectory layout.

## Acceptance Criteria

1. Delete works for both flat-layout and subdir-layout models
2. Flat layout: remove the `.onnx` file (handle shared tokenizer files)
3. UI shows error toast if delete fails
4. UI removes the model from the list on success

## Evidence

- **UI CDP test**: Clicked Delete → dialog confirmed → model stayed on disk and in UI. Screenshots: `del-02` through `del-05`
- Backend error: `Model directory not found` (flat layout has no directory)
- UI swallows the error silently — no toast, no feedback
