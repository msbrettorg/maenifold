## Problem

The Image and Audio attachment buttons in the Agents tab chat input never open the native file picker. Clicking them does nothing (or throws a silent TypeError).

## Root Cause

`ChatAttachmentBar.vue` uses shadcn `<Input>` components for the hidden file inputs:

```vue
<Input ref="imageInputRef" class="hidden" type="file" ... />
```

The refs are typed as `HTMLInputElement`, but Vue 3 `<script setup>` template refs on components resolve to the **component proxy**, not the underlying DOM element. The shadcn `Input.vue` does not `defineExpose()` a `click` method, so `target?.click()` in `triggerPicker()` fails silently — the browser file picker never opens.

## Fix

Replace the two shadcn `<Input>` file-picker elements (lines 132–146) with native `<input>` elements. These inputs are `class="hidden"` — shadcn styling adds zero value, and native `<input>` gives a real `HTMLInputElement` ref where `.click()` works.
