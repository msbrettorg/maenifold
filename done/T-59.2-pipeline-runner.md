# T-43.2: PipelineRunner Component

**Requirement**: FR-43.2
**RTM**: RTM-193
**Priority**: P0 — Runner is required for the pipeline view shell

## Context

The pipeline-ui application at `/Users/brett/src/ma-collective/pipeline-ui/` needs a bottom panel runner component with pipeline lifecycle controls, an event log, and a mermaid diagram tab.

The Pinia store is at `src/stores/pipeline.ts` — it exposes `designMode`, `localDefinition`, `currentView`, `isRunning`, `eventLog`, and all lifecycle actions (`createPipeline`, `runPipeline`, `pausePipeline`, `resumePipeline`, `cancelPipeline`, `deletePipeline`). The `LogEntry` type is in `src/lib/pipeline-types.ts`: `{ nodeId, from, to, timestamp }`.

The project already has `mermaid` installed as a dependency (check package.json). The existing `src/composables/useMermaid.ts` composable may be reusable for rendering — check before reimplementing.

## Scope

Create `src/components/PipelineRunner.vue` in the pipeline-ui project.

## Acceptance Criteria

1. **Control bar**: A row of buttons for lifecycle actions. Button visibility is derived from store state:
   - **Create** → visible when `store.designMode && localDefinition.nodes.length > 0`
   - **Run** → visible when `!designMode && !isRunning && currentView && ready.length > 0`
   - **Pause** → visible when `!designMode && isRunning`
   - **Resume** → visible when `!designMode && !isRunning && currentView && status not in [completed, cancelled]`
   - **Cancel** → visible when `!designMode && (isRunning || status === 'paused')`
   - **Delete** → visible when `!designMode && currentPipelineId`
   - Delete must confirm before acting (`confirm()` dialog).
2. **Status line**: Shows a summary string:
   - Design mode: `"Design mode — N nodes, M edges"`
   - Server mode: `"● {status} — X/Y completed — Active: {list}"`
   - No pipeline: `"No pipeline loaded"`
3. **Tab bar**: Two tabs — "Event Log" and "Mermaid". Active tab styled with bottom border accent.
4. **Event Log tab**: Renders `store.eventLog` entries as formatted lines: `[HH:MM:SS] {icon} {nodeId}: {from} → {to}`. Icons by target status: active=▶, completed=✅, abandoned=❌, stuck=🚫, ready=🟡, pending=⏳. Auto-scrolls to bottom on new entries.
5. **Mermaid tab**: Renders `store.currentView.mermaid` string. Use dynamic `import('mermaid')` to lazy-load. Initialize with `{ startOnLoad: false, theme: 'neutral' }`. Use `mermaid.render()` to produce SVG. Fallback to raw text display if rendering fails.
6. **Styling**: Top border separates runner from content above. Uses project CSS variables. Control buttons use colored backgrounds matching their semantics (green=create, blue=run/resume, orange=pause, red=cancel, transparent=delete). Scoped styles. Under 300 lines.
7. **Build**: `npm run build` passes with zero errors.
