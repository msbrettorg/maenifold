## UI contract

The panel must show:

- Teams Monitor toggle
- connection/auth state and last error card
- Your Identity card:
  - display name
  - UPN
  - MRI/object ID
  - region if known
  - retry detection action
- Trigger Keyword input
- Listen In select
- Reply Behavior select
- Reply Prefix input
- Dispatch Timeout control
- Dispatch Agent control
- Save action with success/error state

- [ ] Component follows desktop design rules: shadcn-vue controls, Tailwind utilities, no raw HTML controls, no local style block.
