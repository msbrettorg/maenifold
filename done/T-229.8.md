## Summary

Replace `EventSource /api/config/watch` SSE hot-reload with MCP resource subscriptions.

## Scope

- Replace `new EventSource(\`\${DAEMON_BASE_URL}/api/config/watch\`)` in `config.ts` with MCP resource subscriptions to:
  - `config://settings`
  - `config://agents`
  - `config://mcp-servers`
- On `notifications/resources/updated`, call `GetConfig` MCP tool to refresh state
- Remove SSE-specific event handling (`config-changed`, `config-error`, `watch-error`)
