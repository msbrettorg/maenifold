# UAT Learnings

## CDP quirks
- agent-browser `click` does NOT work on some Vue components (sidebar expand button, knowledge tree items). Use `focus @eN` then `press Enter` as workaround.
- Refs (`@e1`, `@e2`, ...) go stale after ANY DOM change (click, navigation, dialog open). Always re-snapshot before acting on refs.
- Export button on Workflows opens raw JSON in a new Electron tab (blob: URL). Use `agent-browser tab t1` to get back to the main app.
- The Electron app has a SingletonLock — only one instance at a time.
- The app's gate MCP server holds the sqlite DB lock intermittently. If `gate pass` or `gate fail` returns "database is locked", wait 5 seconds and retry.

## Navigation
- 7 tabs: Home, Agents, Pipelines, Gate, Knowledge, Workflows, Settings
- Settings has 5 sub-tabs: Agents, MCP servers, Maenifold, Embeddings, Preferences
- Home has 5 navigation cards (Agents, Pipelines, Gate, Workflows, Knowledge) + a text input + send button
- Agents tab has a sidebar (sessions list, agent selector, folder select) and a main chat area

## Known design system violations
- Agents tab heading renders as "AGENTS" (ALL CAPS) — violates sentence case rule
- Duplicate workflows in library: FinOps Strategic Analysis x2, FinOps Data Collection x2, Workflow Runner Test x2

## Known broken features
- Image and Audio attachment buttons permanently disabled in chat (`[disabled]` in a11y tree)
- Knowledge Notes tree: clicking files does not select them (user confirmed with mouse)
- Gate UI shows "unbound" for all tasks despite valid pipeline digests on disk
- Gate UI stage progress section parses markdown headings (## Bug, ## Found During) as pipeline stages
- Workflow search returns unrelated results (searching "six thinking" shows FinOps workflows)
- Workflow category filter doesn't exclude non-matching categories
- Command palette (Cmd+K / Ctrl+K) does not open
- Chat code blocks render as flat monospace — no syntax highlighting, no container, no copy button
- Chat code font is not JetBrains Mono per design system spec
- Pipeline canvas edge lines barely visible against dark background

## CDP-untestable actions
- Drag operations (resize handles, drag-to-reorder)
- Native OS dialogs (folder picker)
- Toast notifications (need app-triggered events)
- Permission dialogs (need live ACP permission requests)
- Auth dialogs (need live ACP auth flows)
- Loading/error states (need network failures or slow responses)
- Hover states (CDP click, not hover)
