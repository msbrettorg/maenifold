# T-211.10 — Overlap Protection

## Description

Prevent scheduled job overlap via lock files at `~/maenifold/schedules/locks/{id}.lock`. When a job is already running and a new trigger fires, skip with a log entry.

## Acceptance Criteria

- Lock acquired before execution
- Concurrent trigger skipped with log message
- Stale lock detection (process no longer running)
