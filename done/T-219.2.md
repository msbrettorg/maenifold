# T-219.2 — Gate Task Table Left Panel Doesn't Resize

## Problem

In the Gate view, the horizontal resize handle between the task table (left) and the task detail panel (right) only affects the right column. Dragging the handle does not cause the left table to resize — columns remain clipped at their original width regardless of available space.

The layout uses `ResizablePanelGroup` from `shadcn-vue` (`GateViewContent.vue`), which should handle both panels. The bug is likely in `GateTaskTable.vue` — the table inside the left panel doesn't respond to its container's width changes.

Suspect: the table has fixed or min-width column sizing that ignores the panel's flex/percentage width, or the table's scroll container doesn't propagate width changes from the resizable panel.

## Evidence

Screenshot: `Screenshot 2026-04-25 at 6.19.56 AM.png` — left table columns ("Task ID", "Task", "Process", "Progr…") are clipped and don't expand when the resize handle is dragged left.

## Files

- `apps/desktop/src/components/GateViewContent.vue` — ResizablePanelGroup layout
- `apps/desktop/src/components/GateTaskTable.vue` — table rendering, likely column width issue
- `apps/desktop/src/composables/useResizeHandle.ts` — hand-rolled resize composable (check if this is involved or dead code)

## Acceptance Criteria

- [ ] Dragging the resize handle causes BOTH left table and right detail panel to resize proportionally
- [ ] Table columns in the left panel reflow to use available width
- [ ] If `useResizeHandle.ts` is not used by any component, delete it
