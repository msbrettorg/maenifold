# T-201.5 — Wizard model selection + done step + completion

## Intent

Create the `OnboardingStepModel.vue` component (embedding model selection with explicit skip) and `OnboardingStepDone.vue` component (summary + celebration + mark-complete). Wires the final completion flow including daemon re-validation.

## Parent Epic

T-179.34 — First-run onboarding wizard

## Scope

**New files:**
- `apps/desktop/src/components/OnboardingStepModel.vue`
- `apps/desktop/src/components/OnboardingStepDone.vue`

**Modified files:**
- `apps/desktop/src/components/OnboardingWizard.vue` — import and register both step components

## Architecture

### Model step (OnboardingStepModel.vue)

**Model list:** Fetch from the existing embedding-models MCP tool (delivered in T-179.32) via the daemon. Show 3 models as radio cards:

- all-MiniLM-L6-v2 — `[default]` badge, 384d · 256 tokens · 22 MB
- bge-small-en-v1.5 — 384d · 512 tokens · 33 MB
- nomic-embed-text-v1.5 — 768d · 8192 tokens · 137 MB

**Dimension warning:** `⚠️ Changing dimensions later requires re-embedding all existing memories.`

**Two advance paths (constitutional: no silent defaults):**

1. **"Download →"** — Initiates model download. Show progress bar if progress events available, otherwise show spinner with "Downloading..." state. On success, advance to Done step.
2. **"Download later →"** — Explicit skip button (secondary style). Advances to Done step without downloading. This is NOT a default — the user must actively choose to skip.

**Error handling:** Download failures show error text with retry button. No silent recovery.

### Done step (OnboardingStepDone.vue)

**Summary panel:**
- ✓ Daemon — Connected to v{version}
- ✓ Agent — {agentName} ({runtime})
- ✓ Model — {modelName} ({dims}d) OR ⚠ Model — Download later (skipped)
- ✓ Memory — ~/maenifold/memory

**Celebration animation (CSS only, no JS dependencies):**
- `wizardGlow`: radial gradient pulse (opacity 0.15 → 0.3)
- `wizardShimmer`: subtle moving highlight
- `wizardPulse`: gentle scale bounce on checkmark icon

**"Start using maenifold" brand button:**
1. Re-probes daemon health (constitutional concern: re-validate daemon is still alive)
2. If daemon still connected: calls `markComplete()`, emits `complete` event
3. If daemon disconnected: shows warning toast, does not complete

**Secondary links:**
- "Open memory folder" — opens filesystem path
- "Read documentation" — opens docs URL

### Back navigation

"← Back" from Model → Agent step. "← Back" from Done → Model step.

## Acceptance Criteria

1. Model step shows 3 embedding models as radio cards
2. Default model pre-selected (all-MiniLM-L6-v2)
3. Dimension warning displayed
4. "Download →" initiates model download with progress indication
5. "Download later →" is a visible, explicit button — not a hidden path
6. Download errors show error text with retry option
7. Done step shows summary of all configured items
8. Done step shows warning indicator for skipped model
9. Celebration animation plays on Done step mount
10. "Start using maenifold" re-probes daemon before completing
11. If daemon died, shows warning — does not dismiss wizard against dead daemon
12. `markComplete()` called on successful completion
13. All design tokens from DESIGN.md — zero hardcoded colors
14. `npx vue-tsc --noEmit` passes
