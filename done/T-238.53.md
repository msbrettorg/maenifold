# T-238.53 — P0 Wire Teams dispatch execution and reply delivery

**Pipeline**: sdd

## Problem

## Required changes

1. Wire `dispatch.rs` `TeamsDispatchRequest` into actual ACP session dispatch with timeout
2. Wire `reply.rs` `send_reply()` to deliver agent response back to Teams chat after dispatch completes
3. Add message chunking for long replies (port from agency-cowork)
4. Add dispatch timeout handling (default from config or 300s)
