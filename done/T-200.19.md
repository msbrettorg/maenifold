# T-200.19 — Validate all built-in pipeline assets parse correctly

## Intent

Add a regression test that validates all 6 built-in pipeline JSON assets (sdd, tdd, gsd, lightweight, mdd, slc) parse and pass validation via `GateDefinition::from_json_text`. These assets are embedded via `include_str!` — if any JSON gets corrupted during editing, this test catches it at compile-time.

## New Tests for gate_catalog.rs

1. `all_builtin_assets_parse_and_validate` — iterate all 6 `include_str!` constants, parse each via `GateDefinition::from_json_text`, assert they all succeed and have a non-empty `initial` state
2. `builtin_asset_text_rejects_unknown_name` — `builtin_asset_text("nonexistent")` → Err(UnknownBuiltinGate)
3. `resolve_for_task_rejects_pipeline_mismatch` — creates TaskMetadata with pipeline "sdd" and calls resolve_for_task with requested "tdd" → Err(PipelineOverrideMismatch)
