# T-202.12 — Bug: Settings sub-tabs don't switch content panel

## Problem

CDP verification shows that clicking Maenifold or Preferences in the Settings left sidebar changes the highlight/selection state but does NOT switch the content panel. The MCP servers content remains visible regardless of which sub-tab is selected.

Evidence: `outputs/screenshots/sprint-202/05-settings-maenifold.png` and `07-settings-preferences.png` both show identical MCP servers list content despite different sidebar selections.

## Expected

Each settings sub-tab (Agents, MCP servers, Maenifold, Models, Preferences) should display its own content panel when selected.

## Acceptance criteria

1. Clicking each settings sub-tab renders its corresponding content panel
2. Maenifold tab shows runtime configuration (debounce, sync, decay, etc.)
3. Preferences tab shows persisted application defaults
4. CDP screenshot of each sub-tab shows distinct content
