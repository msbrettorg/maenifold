# T-72.1 — Global prefers-reduced-motion policy

**Pipeline**: mdd
**Pipeline Digest**: b826a880e632e457a4be2a8cbfabf45b8434090f1df1416e349cb1f9700565df
**Requirement**: UX-POLISH-72 — Accessibility foundation for animation sprint
**Component**: `src/assets/shared-components.css`

## Context

The pipeline-ui codebase already contains animations in `PlanView.vue`, `WorkflowStepProgress.vue`, `ChatMessageList.vue`, and `WorkflowTreeLoadingState.vue` with no `prefers-reduced-motion` coverage. Before adding new animations (T-72.2, T-72.3, T-72.5), a global reduced-motion policy must exist.

Tauri ships on macOS where "Reduce motion" is a system preference. This is an accessibility requirement, not a nice-to-have.

## Acceptance Criteria

1. `shared-components.css` includes a `@media (prefers-reduced-motion: reduce)` block that sets `animation-duration: 0.01ms !important; animation-iteration-count: 1 !important; transition-duration: 0.01ms !important;` on `*`.
2. The block preserves `scroll-behavior: auto` to prevent smooth-scroll override.
3. Existing skeleton-pulse animation in `PipelineView.css` is covered by this global policy.
4. `npx vue-tsc --noEmit` passes.
