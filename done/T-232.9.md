## Summary

Publish an event when Louvain community detection completes, so the wallpaper service can regenerate zeitgeist/self-actualization images on community drift instead of only on a timer.

## Implementation

### 1. Add notification channel

Use the existing `endophasia::channel` pattern (tokio broadcast channel):

Create `crates/maenifold-core/src/community/events.rs`:

```rust
use tokio::sync::broadcast;

pub enum CommunityEvent {
    Recomputed { community_count: usize, nmi: f64 },
}

static SENDER: once_cell::sync::Lazy<broadcast::Sender<CommunityEvent>> =
    once_cell::sync::Lazy::new(|| broadcast::channel(16).0);

pub fn sender() -> &'static broadcast::Sender<CommunityEvent> { &SENDER }
pub fn subscribe() -> broadcast::Receiver<CommunityEvent> { SENDER.subscribe() }
```

### 2. Publish from `detect_and_persist()`

In `community/persist.rs`, after `maybe_warn_on_community_drift()`, publish:

```rust
let _ = events::sender().send(CommunityEvent::Recomputed {
    community_count: count,
    nmi,
});
```

### 3. Subscribe in wallpaper service

In `wallpaper/service.rs`, subscribe to `CommunityEvent::Recomputed`. When received in zeitgeist or self-actualization mode, trigger regeneration (with NMI threshold check — only regenerate if drift is significant).
