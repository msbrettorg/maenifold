# T-202.39 — Download needs progress indicator

## Problem

Clicking Download on the Embeddings page shows "Downloading…" with no progress feedback for 50+ seconds. There is no percentage, no bytes transferred, no progress bar. The user has no way to distinguish "downloading 90MB" from "hung."

## Observed

CDP test 2026-04-20: Clicked Download for all-MiniLM-L6-v2 (90 MB). Button showed "Downloading…" for 50 seconds with zero progress indication. Download succeeded — but the user would have cancelled it thinking it was broken.

## Required

Show download progress — percentage, bytes/total, or a progress bar. The backend `hf-hub` crate supports progress callbacks. Wire them through to the frontend.

## Acceptance Criteria

1. User sees real progress (percentage or bytes) during model download
2. Progress updates at least every 2-3 seconds
3. If download stalls for >30s with no progress, show a warning
