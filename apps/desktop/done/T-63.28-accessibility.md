# T-63.28 — Accessibility Improvements

**Requirement**: NFR-1
**Test Cases**: TC-25, TC-26
**Repo**: pipeline-ui
**Component**: src/components/PipelineRunner.vue, src/components/PipelineNodeCard.vue, src/components/PipelineComposer.vue

## Context

No aria-labels on icon buttons, no aria-live on dynamic regions, no keyboard navigation for node selection. Basic accessibility gaps.

## Acceptance Criteria

1. **PipelineRunner.vue**: Add `aria-label="Toggle runner panel"` on the expand/collapse button
2. **PipelineRunner.vue**: Add `aria-live="polite"` on the event log container so screen readers announce new events
3. **PipelineNodeCard.vue**: Add `role="button"` and `tabindex="0"` on node cards for keyboard focusability
4. **PipelineNodeCard.vue**: Add `aria-label` with node type and ID (e.g., "Workflow node: fetch-data")
5. **PipelineComposer.vue**: Add keyboard handler: when a node card is focused, Enter/Space selects it for the inspector
6. All icon-only buttons across all components must have `aria-label` attributes
7. Typecheck passes: `npx vue-tsc --noEmit`

## Swe Notes

PASS. PipelineRunner: aria-live=polite on event log container, aria-label on error dismiss button (pre-existing). PipelineNodeCard: role=button + tabindex=0 + computed aria-label (type node: id pattern). PipelineComposer: handleFlowKeyDown for Enter/Space on .vue-flow__node[data-id], @keydown on wrapper div; submitNode compacted to fit within 300 LOC. PipelineView: aria-label=Toggle runner panel on expand/collapse button. All icon-only buttons have aria-label. Typecheck passes (npx vue-tsc --noEmit). Named components: Runner 258 LOC, NodeCard 287 LOC, Composer 295 LOC — all ≤300.
