**Requirement**: FR-43.4
**RTM**: RTM-195
**Priority**: P0 — Final integration component for the pipeline UI

## Context

The pipeline-ui application at `/Users/brett/src/ma-collective/pipeline-ui/` has four pipeline components that need to be composed into a unified view and wired into the main application shell.

Existing components (all in `src/components/`):
- `PipelineComposer.vue` — Vue Flow canvas (props: designMode, localDefinition, view; emits: update:localDefinition, nodeSelected, edgeSelected)
- `PipelineNodeCard.vue` — Custom Vue Flow node
- `PipelineInspector.vue` — Right panel (props: selectedNodeId, selectedEdge)
- `PipelineRunner.vue` — Bottom panel (no props, reads from store)
- `PipelineSidebar.vue` — Left panel (no props, reads from store)

The Pinia store is at `src/stores/pipeline.ts`. It needs `connect()` called to establish MCP connection, then `refreshList()` + `refreshWorkflows()` to hydrate.

`App.vue` currently uses `showWorkflows` boolean to toggle `WorkflowTreeView`. The pipeline view should follow the same pattern with a `showPipelines` boolean.

## Scope

1. Create `src/components/PipelineView.vue` in the pipeline-ui project.
2. Modify `src/App.vue` to add the pipeline toggle and render PipelineView.

## Acceptance Criteria

### PipelineView.vue

1. **Layout**: Four-panel layout using CSS grid or flexbox:
   - Left: PipelineSidebar (240px fixed)
   - Center: PipelineComposer (flex: 1)
   - Right: PipelineInspector (280px fixed)
   - Bottom: PipelineRunner (200px fixed, spans center+right)
2. **State wiring**: Manages `selectedNodeId` and `selectedEdge` refs, passes them to Composer (via emits) and Inspector (via props).
3. **Store binding**: Passes `store.designMode`, `store.localDefinition`, and `store.currentView` to PipelineComposer as props. Handles `update:localDefinition` emit to update store.
4. **MCP connection**: On mount, calls `store.connect()`, then `store.refreshList()` and `store.refreshWorkflows()`. Handles connection errors gracefully (shows error banner).
5. **Full height**: Takes 100% of available parent height with `overflow: hidden`.

### App.vue modifications

6. **Toggle state**: Add `showPipelines` ref (default false), matching the `showWorkflows` pattern.
7. **Sidebar button**: Add a "🔀 Pipelines" button in the sidebar's workflow section, with the same styling as the "🌳 Workflows" button. Active state when `showPipelines` is true.
8. **Mutual exclusion**: When `showPipelines` is activated, `showWorkflows` is set to false, and vice versa.
9. **Main content**: Add PipelineView rendering in the main content area. Insert `<PipelineView v-else-if="showPipelines" />` after the WorkflowTreeView condition.
10. **Import**: Add `PipelineView` import at top of App.vue script.
11. **Build**: `npm run build` passes with zero errors.
12. **Under 300 lines**: PipelineView.vue must be under 300 lines. App.vue changes should be minimal (import + ref + button + conditional).
