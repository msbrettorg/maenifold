### Key Findings

1. **launchd (macOS)**
   - Install: `~/Library/LaunchAgents/com.maenifold.schedule.{id}.plist`
   - `StartCalendarInterval` for cron-like scheduling
   - **Critical**: No missed-run catch-up — jobs skipped during sleep are NOT replayed on wake
   - Workaround: Application-level tracking of `last_run_time` vs `expected_fire_time`

2. **systemd (Linux)**
   - Requires timer + service unit pair
   - `Persistent=true` DOES catch up missed runs
   - User services only run when logged in unless lingering enabled

3. **opencode-scheduler Patterns to Adopt**
   - Perl supervisor handles: lock files (no overlap), timeouts (SIGTERM/SIGKILL), JSONL logs
   - Scope isolation via FNV-1a hash of workdir
   - Cron-to-native conversion (5-field to launchd dicts, systemd OnCalendar)
   - Non-interactive mode forced via env var

4. **Rust Crate Recommendation**: `croner`
   - Timezone-aware, extended cron syntax (L, W, #)
   - `find_next_occurrence()` / `find_previous_occurrence()` API
   - Human-readable `describe()` for UI

### Recommended Architecture

macOS-first CLI approach:
```bash
maenifold schedule create --cron "0 9 * * *" --agent Copilot --prompt "..."
maenifold schedule install {id}  # generates & loads launchd plist
```

Plist invokes `maenifold schedule run {id}` which:
1. Acquires lock file (skip if running)
2. Executes ACP session with prompt/pipeline
3. Records run to JSONL history
4. Enforces timeout via SIGTERM/SIGKILL
