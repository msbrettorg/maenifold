# T-205.714 — Fix: Gate task list columns are not resizable

**Pipeline**: test
**Pipeline Digest**: 16842feaee5604e196f8d0c4ddc8a6566bd538a1ad2d739bc956a9e49f123128

## Bug

The Gate tab's task list table has fixed-width columns that cannot be resized by dragging column borders. Task titles and notes are truncated with no way to expand. Users need to resize columns to read long task names or see full pipeline/state values.

## Acceptance

- Column borders are draggable to resize
- Resized widths persist during the session
- Truncated content becomes visible when column is widened
