# T-69.1: ACP Authentication Flow

## Requirement
FR-50 — Native ACP client must support agent authentication.

## Problem
The auth gap is still real in the current ACP client architecture. `AgentHandle` no longer exists, so this work cannot be framed as adding auth state to a handle type. Instead, the gap lives in the active execution paths:

- `crates/maenifold-core/src/acp/native/mod.rs` — `exec_prompt_with_context()` calls `conn.initialize()` and discards the `InitializeResponse`, so `auth_methods` are never captured
- `crates/maenifold-core/src/workflow/agent_session.rs` — `run_session_inner()` follows the same pattern and also drops the `InitializeResponse`

Because neither path captures `auth_methods`, neither path can call `conn.authenticate()`. Any agent that requires authentication (for example, OAuth-backed agents) fails during session setup or prompt execution with no explicit auth handshake or retry path.

## Acceptance Criteria
1. `exec_prompt_with_context()` in `crates/maenifold-core/src/acp/native/mod.rs` must retain the `InitializeResponse` from `conn.initialize()` and capture `auth_methods` instead of discarding the response
2. `run_session_inner()` in `crates/maenifold-core/src/workflow/agent_session.rs` must retain the `InitializeResponse` from `conn.initialize()` and capture `auth_methods` instead of discarding the response
3. There must be no new dependency on `AgentHandle`; authentication handling must live inside the `exec_prompt_with_context()` closure and `run_session_inner()`
4. When `new_session` or prompt/session startup returns an authentication-required failure, the code must use the captured `auth_methods` to call `conn.authenticate()`
5. For headless mode: attempt supported auth methods in order; for `AuthMethod::EnvVar`, read from environment; for terminal-based or interactive methods, surface clear instructions and fail gracefully when interaction is not possible
6. After successful `authenticate()`, retry the failed operation exactly once in each path
7. Authentication state must be scoped to the active connection/session flow so agents that do not require auth continue to work without additional behavior

## Files to modify
- `crates/maenifold-core/src/acp/native/mod.rs` — auth capture and retry logic in `exec_prompt_with_context()`
- `crates/maenifold-core/src/workflow/agent_session.rs` — auth capture and retry logic in `run_session_inner()`
