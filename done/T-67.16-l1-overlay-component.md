# T-67.16 — L1 Overlay Component

**Requirement**: FR-35
**Phase**: 3

## Context
The L1 expanded card is the core of semantic zoom — a glassmorphic overlay that shows node details while preserving spatial DAG context behind it.

**Stitch Reference**: Screen "L1: Node Inspection - Synthesis" in project `projects/1113463130459108073`

## Acceptance Criteria
1. New component `src/components/SemanticZoomOverlay.vue` created
2. Renders via `<Teleport to="body">` when `zoomStore.isInspecting`
3. Uses `useFlipAnimation` for entry/exit transitions
4. Applies `.glass-surface` class for glassmorphism (from T-67.11)
5. Header shows: node ID (mono font), type pill, status indicator, agent name, close (×) button, "Enter Session →" button (only for ACP nodes with sessionId)
6. Body sections (all collapsible): Predecessor Context (sub-blocks per predecessor), Ambient Prompt (collapsed by default), Node Instruction, Output (if completed), Thinking Trace (reuses ThinkingTraceView for seq-thinking nodes)
7. Close (×) or Escape triggers reverse FLIP animation back to node position
8. "Enter Session →" calls `zoomStore.enterSession(sessionId)` — transitions to L2
9. `npx vue-tsc --noEmit` passes
10. Component stays under 250 LOC
