# T-218.36 — Dynamic MCP Resource Subscriptions

## Problem

The MCP server advertises resource subscriptions, and the UI subscribes to resources, but dynamic resource families such as Teams, schedules, gate, workflows, and pipeline/session state do not appear to emit `notifications/resources/updated`.

## Acceptance Criteria

- [ ] Define update emitters for Teams status/config
- [ ] Define update emitters for schedules jobs/logs
- [ ] Define update emitters for gate status/task body/history
- [ ] Define update emitters for workflow/pipeline/session resources
- [ ] If a resource family cannot emit updates, the UI uses polling or the server does not advertise/support subscribe for that URI
- [ ] Add a resource subscription matrix documenting which resources are live
- [ ] CDP/manual verification proves resource updates arrive after state changes without clicking Refresh
