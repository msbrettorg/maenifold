# T-202.18 — Token foundation fixes

## Problem

Duo audit found systemic token gaps that silently break styling across the entire app:

1. `--text-tertiary` referenced ~30 places but **never defined** — resolves to inherited color, not `#6B7280`
2. `--radius-4` used in HomeDashboard but undefined
3. `radius-md` is `6px`, should be `8px` per DESIGN.md
4. Dead font imports (`@fontsource/inter`, `@fontsource/space-grotesk`) in `main.ts` — DESIGN.md mandates Segoe UI Variable only
5. `var(--text-dim)` used in `AppSidebar.vue` resolves to `#6B7280` in dark mode, should use `--text-secondary` (`#A0AAB2`)

## Files

- `apps/desktop/src/assets/tailwind.css` — add `--text-tertiary`, `--radius-4`, fix `radius-md`
- `apps/desktop/src/main.ts` — remove dead font imports
- `apps/desktop/src/components/AppSidebar.vue` — replace `var(--text-dim)` with `text-text-secondary`

## Acceptance criteria

1. `--text-tertiary: #6B7280` defined in `:root`/`.dark` and `@theme` as `--color-text-tertiary`
2. `--radius-4: 4px` defined OR all `rounded-[var(--radius-4)]` replaced with `rounded-[4px]`
3. `--radius-md` = `8px` (DESIGN.md default), not `6px`
4. No `@fontsource/inter` or `@fontsource/space-grotesk` imports in `main.ts`
5. No `var(--text-dim)` in `AppSidebar.vue` — all replaced with design token utilities
6. `cd apps/desktop && npx vue-tsc --noEmit` passes
