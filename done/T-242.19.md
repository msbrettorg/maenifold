## Problem

Most CLI tools honor `{"learn": true}` by short-circuiting and returning the canonical help block instead of executing. Eight tools do not — they run their required-parameter validation **first**, so passing `{"learn": true}` returns a missing-parameter error instead of the documentation:

```bash
$ maenifold tool ExtractConceptsFromFile '{"learn": true}'
Error invoking ExtractConceptsFromFile: Required property 'identifier' is missing from payload.

$ maenifold tool ReadMcpResource '{"learn": true}'
Error invoking ReadMcpResource: Required property 'uri' is missing from payload.
```

Affected tools (verified by exhaustive enumeration):

- `ExtractConceptsFromFile` (requires `identifier`)
- `AnalyzeConceptCorruption` (requires `conceptFamily`)
- `RepairConcepts` (requires `conceptsToReplace`)
- `GetHelp` (requires `toolName`)
- `ReadMcpResource` (requires `uri`)
- `AcpExec` (requires `agent`)
- `ReadTextFile` (requires `path`)
- `Schedule` (requires `action`)

Compare against tools that work correctly: `WriteMemory`, `ReadMemory`, `EditMemory`, `MoveMemory`, `DeleteMemory`, `SearchMemories`, `SequentialThinking`, `Workflow`, `Pipeline`, `BuildContext`, `FindSimilarConcepts`, `Adopt` — all return their help text on `{"learn": true}` without complaining about missing required params.

## Root Cause Hypothesis

The required-parameter validator runs unconditionally before the `learn` short-circuit in these eight tool handlers. The other tools either short-circuit `learn` first or have no required params for `learn` to conflict with.

## Required Behavior

`{"learn": true}` MUST always return help text, regardless of which other parameters are present or absent. The `learn` short-circuit must run before required-parameter validation in every tool handler.

## Acceptance Criteria

- [ ] For every tool exposed by the CLI: `maenifold tool <Name> '{"learn": true}'` returns the canonical help block on stdout and exits 0.
- [ ] Same behavior over MCP: `tools/call` with `{"learn": true}` returns help, never a missing-required-param error.
- [ ] One regression test that iterates every registered tool, calls it with `{"learn": true}`, and asserts the response starts with the help marker.
