## What we DO NOT lift (Maenifold extends, separately)

These are real Maenifold features not in acp-ui. They wrap or extend lifted code, never modify it:

- **Output content rendering.** acp-ui doesn't render `tool_call_update.content[]` blocks. Maenifold uses unified content dispatcher (T-244.51). Hook point: a slot inside `ToolCallCard.vue`.
- **Edit diff blocks** for `kind: edit`. Same hook.
- **Raw payload toggle.** Same hook.
- **Location chips** routing to Knowledge tab on `memory://` (T-244.53). Same hook.
- **Markdown engine.** acp-ui uses `marked`, we picked `markdown-it` (T-244.1). The dispatcher does not depend on the markdown engine — irrelevant to the lift.

5. **Wire to our session store.** If our store names diverged from acp-ui, rename ours.
