# T-214.8 — Session Browser store

## Problem

The desktop app needs a Pinia store to fetch and cache sessions from connected ACP agents. The `useAgentStore()` already manages agent connections; this store manages the sessions those agents expose.

## Solution

Create `apps/desktop/src/stores/session-browser.ts`:

- Fetch sessions via `list_sessions` MCP tool (already works via `sessions.rs`)
- Cache by agent → sessions grouping
- Track loading/error states per agent
- Expose computed getters: `sessionsByAgent`, `allSessions`, `isLoading`
- Action: `refreshSessions(agentName?)` — fetch from one or all agents
- Action: `getSession(agent, sessionId)` — get details for a specific session

Use `storeToRefs()` for reactive destructuring in components.

## Key Files

- Create: `apps/desktop/src/stores/session-browser.ts`
- Reference: `apps/desktop/src/stores/agent.ts` — existing agent store pattern

## Acceptance Criteria

- Store fetches and caches sessions from connected agents
- Loading and error states tracked
- `sessionsByAgent` computed getter returns grouped data
- TypeScript types clean (`npx vue-tsc --noEmit` passes)
