# T-63.8 — Agent Existence Validation at Creation

**Requirement**: FR-11
**Test Cases**: TC-23
**Repo**: maenifold-rs
**Component**: crates/maenifold-core/src/workflow/pipeline/handler.rs

## Context

`validate_workflow_node_definitions` checks that workflow files exist for WorkflowNode but does NOT validate that `agent` names resolve to known ACP clients for Prompt/SequentialThinking nodes. A typo in the agent name silently passes creation and fails at runtime.

## Acceptance Criteria

1. In handler.rs pipeline creation validation, resolve `agent` name against known ACP clients for ALL node types (after T-63.5 unifies the field)
2. If agent does not exist, return a clear error: `"Node '{id}': agent '{name}' not found. Available agents: [list]"`
3. Validation runs at creation time (before pipeline session is persisted)
4. WorkflowNode `agent` is also validated (after T-63.5 makes it required)
5. ALL existing pipeline tests pass: `cargo test -p maenifold-core -- pipeline`
6. Add a test: create pipeline with unknown agent name → returns validation error

## SWE Remediation

PASS. Added pipeline creation-time agent validation in handler.rs using configured agents.json discovery, returning clear unknown-agent errors before persistence. Seeded pipeline test contexts with executable test agents and added a regression test for unknown workflow agent validation. cargo test -p maenifold-core --lib -- pipeline passed.
