## Summary

Replace REST `GET /api/config` and `GET /api/config/path` in the frontend config store with `GetConfig` MCP tool call.

## Scope

- Replace `fetch(\`\${DAEMON_BASE_URL}/api/config\`)` with MCP `tools/call` for `GetConfig`
- Replace `fetch(\`\${DAEMON_BASE_URL}/api/config/path\`)` (path is already in `GetConfig` response)
- Add normalizer to transform MCP response shape (agents as sorted array with `name` field) back to frontend `Record<string, AgentConfig>` format
- MCP `GetConfig` splits `command` into `command` + `args` and redacts sensitive env values — normalizer must handle this

## Acceptance criteria

- [ ] `loadConfig()` calls `GetConfig` MCP tool instead of REST
- [ ] Config path populated from MCP response
- [ ] Agent records correctly normalized from array to Record format
- [ ] Existing UI functionality preserved (settings page loads, agent list shows)
- [ ] `vue-tsc --noEmit` passes
- [ ] No `fetch` calls to `/api/config` or `/api/config/path` remain in config.ts
