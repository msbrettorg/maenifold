## Problem

The Electron console shows 3 `CompileError: WebAssembly.instantiate()` errors at startup when the Knowledge tab renders markdown. These come from `@shikijs/engine-oniguruma` trying to compile WASM despite the CSP including `'wasm-unsafe-eval'`.

The errors don't block rendering (shiki appears to fall back to `@shikijs/engine-javascript`), but they create console noise and suggest a misconfigured engine selection.

## Root cause

`@shikijs/markdown-it@4.0.2` defaults to the oniguruma (WASM) engine. In Electron's sandboxed context, even with correct CSP directives, WASM compilation may fail for engine-specific reasons.

## Fix

Configure shiki to use the JavaScript engine explicitly in `apps/desktop/src/composables/useMarkdownIt.ts`:

```ts
import { createJavaScriptRegExpEngine } from '@shikijs/engine-javascript';

// In the Shiki() call:
md.use(await Shiki({
  themes: { light: 'github-light', dark: 'github-dark' },
  engine: createJavaScriptRegExpEngine(),
}));
```
