## Summary

Add continuity mode as a modifier for endophasia and zeitgeist wallpaper modes. When enabled, each new image evolves from the previous one via the Azure OpenAI `/images/edits` endpoint instead of generating from scratch. The `inputFidelity` setting controls how much visual DNA carries over. Also adds `WallpaperClearCache` MCP tool and a per-label cache lookup helper for zeitgeist per-community continuity.

**Scope:** Modifies endophasia.rs and zeitgeist.rs only. Self-actualization continuity will be added as part of T-232.7 (which creates that module).

### 2. Modify `endophasia.rs` — add continuity branch

```rust
let wallpaper = &config.settings.easter_eggs.wallpaper;
let cache_dir = cache::cache_dir(&config.memory_path);

let data = if wallpaper.continuity {
    if let Some(prev) = cache::latest_image(&cache_dir, "endophasia") {
        let prev_bytes = std::fs::read(&prev)?;
        let edit_prompt = format!("Update this image to reflect the latest state: {}", prompt);
        client.edit(&edit_prompt, &prev_bytes, &wallpaper.size, &wallpaper.quality, &wallpaper.input_fidelity).await?
    } else {
        client.generate(&prompt, &wallpaper.size, &wallpaper.quality).await?
    }
} else {
    client.generate(&prompt, &wallpaper.size, &wallpaper.quality).await?
};
cache::save_image(&cache_dir, "endophasia", "recent", &data)
```

### 3. Modify `zeitgeist.rs` — add per-community continuity

```rust
let data = if wallpaper.continuity {
    if let Some(prev) = cache::latest_image_for(&cache_dir, "zeitgeist", &node.anchor) {
        let prev_bytes = std::fs::read(&prev)?;
        let edit_prompt = format!("Update this image to reflect the latest state: {}", prompt);
        client.edit(&edit_prompt, &prev_bytes, &wallpaper.size, &wallpaper.quality, &wallpaper.input_fidelity).await?
    } else {
        client.generate(&prompt, &wallpaper.size, &wallpaper.quality).await?
    }
} else {
    client.generate(&prompt, &wallpaper.size, &wallpaper.quality).await?
};
cache::save_image(&cache_dir, "zeitgeist", &node.anchor, &data)?;
```

Note: uses `latest_image_for` (per-label) so each community evolves independently.

### 4. Create `WallpaperClearCache` MCP tool

New tool in `crates/maenifold-core/src/tools/wallpaper_clear_cache.rs`:

```rust
pub fn wallpaper_clear_cache(context: &ToolContext, payload: &Value) -> Result<String> {
    let mode = payload.get("mode").and_then(|v| v.as_str());
    let cache_dir = cache::cache_dir(&context.config.memory_path);
    cache::clear_cache(&cache_dir, mode)
        .map_err(|e| crate::error::MaenifoldError::Message(e.to_string()))?;
    Ok(json!({ "cleared": true, "mode": mode }).to_string())
}
```

Register in `registry.rs` as `WallpaperClearCache`. The frontend "Reset wallpaper" button calls this.

### 5. First-generation fallback

The first image in a session always uses `/images/generations` (no previous image). This is handled naturally by `cache::latest_image()` / `latest_image_for()` returning `None`.
