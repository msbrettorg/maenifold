# T-176.2 — Gate view design polish — Fluent 2 dark

## Intent

**P1 design system violation.** GateView has 10 components. Only 3 have even a single shadcn-vue import (GateViewFilters, GateViewToolbar, GateTaskDetail — and those use just 1 import each). GateTaskTable, GateTaskProgress, GateTaskDetailHistory, GateTaskDetailStages, GateTaskDetailMeta, GateViewContent, GateViewStatus — all bespoke. We have Fluent 2 dark. Bespoke when a design system exists is a bug.

## Reference

- `apps/desktop/src/components/GateView.vue`, `GateViewContent.vue`, `GateViewToolbar.vue`, `GateViewFilters.vue`, `GateViewStatus.vue`
- `apps/desktop/src/components/GateTaskTable.vue`, `GateTaskDetail.vue`, `GateTaskProgress.vue`
- `apps/desktop/DESIGN.md` — Fluent 2 dark tokens

## Scope

**Directive: DELETE bespoke markup and CSS. REPLACE with existing shadcn-vue components. The goal is less code, not more. Every bespoke `<style>` block, hardcoded hex color, hardcoded `border:` declaration, and hand-rolled `<button>`/`<input>`/`<select>` is a deletion target. Use the 21 shadcn-vue components already installed in the project. Use Tailwind utility classes referencing CSS custom properties from DESIGN.md. If a shadcn-vue component covers 80% of the need, use it and adjust via props/slots — do not hand-roll a replacement.**


### Task table

- Task rows: `bgSurface` (`#333333`) with structural separators using `border-subtle` per `apps/desktop/DESIGN.md` §5
- Hover: shift to `bgSurfaceHover` (`#3A3A3A`)
- Selected: `bgSurfaceHover` + 4px `brand` (`#0078D4`) left accent
- Pipeline badge: colored pill matching pipeline type
- State badge: 6px status bead (emerald=done, amber=active, muted=pending, red=failed)
- Typography: Segoe UI Variable for task IDs, Segoe UI Variable for titles

### Stage progress indicator

- Replace any text-only stage display with a visual horizontal pipeline
- Each stage as a pill/node, connected by thin lines
- Current stage: filled with stage color + drop shadow per Fluent 2 elevation scale
- Completed stages: filled solid, muted
- Future stages: ghost outline only
- Matches PipelineNodeCard visual language

### Detail panel

- Slides in from right (sheet pattern) or expands inline
- Task markdown body rendered with shared markdown component
- History timeline: vertical, each entry with timestamp, agent badge, outcome pill (pass/fail)
- Stage-specific sections collapsible

### Toolbar

- Filter pills: shadcn-vue Badge components, not custom buttons
- Pipeline selector: shadcn-vue Select
- Search: Fluent 2 dark input style
- Refresh: ghost button with Lucide RefreshCw icon
