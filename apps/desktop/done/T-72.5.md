**Pipeline**: mdd

**Requirement**: UX-POLISH-72 — Connected sessions should visually pulse to signal "alive"
**Component**: `src/components/SessionList.vue`

## Context

The session list shows a green `●` dot for connected sessions, but it's static text. A subtle CSS pulse animation signals liveness and makes the connection state immediately scannable.

## Acceptance Criteria

1. `.connection-badge.connected .connection-dot` has a CSS `@keyframes pulse-dot` animation that cycles opacity from 1 → 0.4 → 1 over 2s, infinite.
2. The `.connecting` variant uses a faster pulse (1s) to distinguish "connecting" from "connected."
3. Animation is disabled by the global `prefers-reduced-motion` policy (T-72.1).
4. `npx vue-tsc --noEmit` passes.
