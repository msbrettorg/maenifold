# T-178.9b — Centralize shadow tokens as CSS variables

**Pipeline**: lightweight
**Pipeline Digest**: tbd

## Objective

The same Fluent shadow values are duplicated across 6+ components as inline rgba. Define them once in `assets/tailwind.css` and reference everywhere.

## Add to `assets/tailwind.css`
```css
--shadow-8: 0 2px 4px rgba(0,0,0,0.14), 0 0 2px rgba(0,0,0,0.12);
--shadow-16: 0 8px 16px rgba(0,0,0,0.28), 0 0 2px rgba(0,0,0,0.12);
--shadow-64: 0 32px 64px rgba(0,0,0,0.32), 0 0 8px rgba(0,0,0,0.16);
```

## Replace in components (use `var(--shadow-N)`)
- `PipelineFlyout.vue:178`
- `ToastContainer.vue:73`
- `DesignNodeConfigModal.vue:81`
- `PipelineActionBar.vue:250`
- `CommandPalette.vue:174,240`
- `WorkflowStepCard.vue:145`
- `PipelineView.css:158,183` (or PipelineView.vue if CSS already inlined by 9a)
- `SemanticZoomOverlay.vue:363`
- `PipelineComposer.vue:288`

## Also: KnowledgeNoteRenderer.vue hex colors
Replace 23 hard-coded hex values (#0078D4, #FFFFFF, #A0AAB2, #333333, #282828, #2D2D2D, #D13438) with CSS variable references from the Fluent token table.
