## Problem

The GateTaskTable on the Gate tab has:
1. Progress column content cut off — badges overflow and get clipped
2. Task title column too narrow — titles truncated with no tooltip
3. No column width control — all columns auto-sized equally
4. No text wrapping on progress badges

## Solution

- Set `table-layout: fixed` with explicit column widths via `<colgroup>`
- Task ID: ~100px fixed. Task name: flex/auto. Process: ~80px. Progress: ~200px
- Progress badges should wrap (flex-wrap) not clip
- Task title shows full text on hover (title attribute)
- Consider using shadcn Resizable for column resize if available, otherwise fixed proportions

## Acceptance Criteria

1. All columns visible without horizontal scroll at default window size
2. Progress badges wrap to multiple lines if needed
3. Task title shows full text on hover
4. Table fills available width proportionally
5. Verified in packaged Electron app via CDP
