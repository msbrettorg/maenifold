# T-220.25 - Remove Manual Tokenizer Fallback

## Problem

The vector tokenizer path hand-builds a WordPiece tokenizer when `tokenizer.json` is absent, duplicating library behavior and adding model-parity risk.

## Evidence

- `crates/maenifold-core/src/vector/tokenizer.rs:24-47`, `98-218` implements a manual WordPiece fallback.
- Source: `docs/codebase-audit-2026-04-25.md#p2-11`.
- Parent sequential thinking session: `session-1777125506368-62098`.

## Acceptance Criteria

- [ ] Curated and downloaded models are required to provide `tokenizer.json`.
- [ ] Runtime tokenizer loading uses `tokenizers::Tokenizer::from_file` or equivalent library path only.
- [ ] Missing tokenizer files produce a clear actionable error.
- [ ] Manual WordPiece fallback code is removed.
- [ ] `cargo build --release -p maenifold-cli` succeeds.
