# T-200.3 — Split mcp/mod.rs dispatch logic

## Intent

`crates/maenifold-gate/src/mcp/mod.rs` is 916 LOC (3x over limit). Extract the tool dispatch function and argument parsing helpers into a new `mcp/dispatch.rs` to get production code under 300 LOC.

## Scope

**Crate:** maenifold-gate

**New file:** `crates/maenifold-gate/src/mcp/dispatch.rs` (~130 lines)
- `call_gate_tool()` — tool name → GateToolService dispatch
- `context_from_value()` — builds GateContext from JSON args
- `to_rmcp_tool()` — converts McpToolDefinition to rmcp Tool
- `optional_path()`
- `required_string()`
- `optional_string()`
- `optional_bool()`

**Modified files:**
- `crates/maenifold-gate/src/mcp/mod.rs` — remove extracted items, add `pub(crate) mod dispatch;` and `use dispatch::*;`

## Acceptance Criteria

2. `cargo test -p maenifold-gate` passes
3. `mcp/dispatch.rs` is under 300 LOC
4. `mcp/mod.rs` production code (excluding `#[cfg(test)]`) is under 300 LOC
