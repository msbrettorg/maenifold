# T-178.8c — Fix shadcn primitive theming (Obsidian→Fluent 2)

**Pipeline**: lightweight
**Pipeline Digest**: tbd

## Objective

The shadcn-vue base primitives (Tooltip, Dialog, AlertDialog, Sheet, Select, Dropdown, ContextMenu, Input, Textarea) ship with Obsidian-era ambient blue glow shadows and hard-coded hex backgrounds that don't match the Fluent 2 dark palette. Fix the primitives — every consumer inherits the fix for free.

## Grounding

Audit: `docs/DESIGN-AUDIT.md` findings #130–136
Design system: `apps/desktop/DESIGN.md` (Fluent 2 dark)

## Scope

Files in `apps/desktop/src/components/ui/` — the shadcn primitive wrappers.

### Shadow fixes
Replace all ambient blue glow `box-shadow` values with Fluent shadow tokens:
- `shadow8`: `0 2px 4px rgba(0,0,0,0.14), 0 0 2px rgba(0,0,0,0.12)`
- `shadow16`: `0 8px 16px rgba(0,0,0,0.28), 0 0 2px rgba(0,0,0,0.12)`
- `shadow64`: `0 32px 64px rgba(0,0,0,0.32), 0 0 8px rgba(0,0,0,0.16)`

### Background fixes
Replace hard-coded hex: `#353534`, `#201f1f`, `#1c1b1b` with `var(--color-bg-surface)`, `var(--color-bg-elevated)`, `var(--color-bg-sidebar)` tokens.

### Border fixes
Replace any `rgba(173,198,255,...)` brand-glow borders with `var(--color-border-subtle)` or `var(--color-border-card)`.

### Glass effect removal (audit #128–129)
- `components/ui/alert-dialog/AlertDialogContent.vue` — remove `backdrop-filter: blur()`
- `components/ui/dialog/DialogScrollContent.vue` — remove `backdrop-filter: blur()`
Replace with solid Fluent surface + appropriate shadow token.

## Acceptance Criteria

1. Zero hard-coded hex/rgba values in `components/ui/*.vue`
2. All shadows use Fluent shadow tokens
3. `npx vue-tsc --noEmit` passes
4. `npm run build` succeeds
