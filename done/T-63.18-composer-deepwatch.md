# T-63.18 — Composer Deep-Watch Optimization

**Requirement**: NFR-2
**Test Cases**: TC-27
**Repo**: pipeline-ui
**Component**: src/components/PipelineComposer.vue

## Context

PipelineComposer deep-watches `localDefinition` and re-syncs the entire canvas on every keystroke in Inspector. Editing a node name triggers full node/edge re-render, causing visible jank.

## Acceptance Criteria

1. Remove the deep watch on `localDefinition` (or the equivalent reactive source that triggers canvas re-sync)
2. Replace with ONE of:
   - **Option A**: Debounced watch (150ms) — canvas updates 150ms after last change
   - **Option B**: Shallow watch with manual dirty tracking — only sync when nodes/edges are added/removed, not when properties change
   - **Option C**: Explicit sync on blur/commit — canvas syncs when user finishes editing (not on every keystroke)
3. Inspector keystrokes in a node's fields do NOT trigger canvas re-render
4. Adding/removing nodes still triggers immediate canvas sync
5. Typecheck passes: `npx vue-tsc --noEmit`

## Swe Notes

PASS. Replaced the deep localDefinition watch in PipelineComposer with a shallow watcher that debounces non-structural definition syncs by 150ms, while node/edge count changes still sync immediately and inspector typing no longer forces canvas re-renders. Verified with npx vue-tsc --noEmit.
