# T-72.0 — Gate detail panel — prevent content from resizing panel

**Pipeline**: mdd
**Requirement**: UX-POLISH-72 — Gate detail panel grows to fit markdown content, pushing table off-screen
**Component**: `src/components/GateTaskDetail.vue`

## Bug

When a gate task is selected, `GateTaskDetail` renders full markdown content. The `.gate-detail` panel has `min-width: 20rem` but no width constraint, so it grows to its intrinsic content size and pushes `.gate-table-wrap` off-screen. The unselected layout is correct — the panel just needs to stay that size when content loads.

## Acceptance Criteria

1. The `.gate-detail` panel keeps its current size when task content loads — it must not grow to fit markdown content.
2. The fix is CSS-only on `.gate-detail` in `GateTaskDetail.vue` — add a fixed flex basis and prevent growth (e.g., `flex: 0 0 20rem` or `width: 20rem; flex-shrink: 0`). The panel already has `overflow: auto` for internal scrolling.
3. The table (`.gate-table-wrap`) remains fully visible when a task is selected.
4. The responsive breakpoint at `@media (max-width: 1100px)` still stacks vertically.
5. `npx vue-tsc --noEmit` passes.
