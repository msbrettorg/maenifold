# T-178.6d — Electron 37→41 major upgrade

**Pipeline**: sdd
**Pipeline Digest**: tbd

## Objective

Upgrade Electron from v37 to v41 to resolve 18 CVEs and bring the runtime current.

## Security Motivation

Electron 37.10.3 has 18 HIGH-severity CVEs including:
- AppleScript injection (macOS)
- IPC spoofing vulnerabilities
- Use-after-free memory bugs
- Registry injection (Windows)

## Updates Required

- `electron` 37.10.3 → 41.2.1
- `@electron-forge/cli` → latest compatible with Electron 41
- `@electron-forge/maker-dmg` → latest compatible
- `@electron-forge/maker-zip` → latest compatible
- `@electron-forge/plugin-auto-unpack-natives` → latest compatible
- `@electron-forge/plugin-vite` → latest compatible with Electron 41 + Vite 8

## Risk Assessment — HIGH

This is the highest-risk upgrade in the sprint:
- 4 major version jump (37→41)
- Electron breaking changes across 38, 39, 40, 41
- Forge plugin compatibility must be verified
- Native module rebuilds may be required
- macOS code signing behavior may change
- CDP remote debugging port behavior may change
- Preload script APIs may have changed

## Scope

- `cd apps/desktop`
- Review Electron breaking changes for v38, v39, v40, v41
- Update `package.json` with all Electron + Forge packages
- Run `npm install`
- Fix any breaking changes in:
  - `forge.config.ts`
  - `main.ts` (main process)
  - `preload.ts`
  - Any `electron` API call sites
- Verify `npx vue-tsc --noEmit` passes
- Verify `npm run build` succeeds
- Verify `npm run package` produces working .app bundle
- Verify app launches with `--remote-debugging-port=9222`

## Acceptance Criteria

1. Electron 41.2.1 + all Forge packages at compatible versions
2. `npm run package` produces working macOS app
3. App launches and displays UI
4. CDP debugging port works
5. MCP transport (localhost:8080) connects successfully
6. No regressions in IPC, preload, or native module behavior

## Dependencies

- T-178.6c (Vite 8) should land first — @electron-forge/plugin-vite needs Vite 8 compat
- T-178.6b (safe patches) should land first for clean baseline

## Out of Scope

- GTK3/tray-icon dependency chain (Rust side, not Electron)
- Visual UI regression testing (separate UAT pass)
