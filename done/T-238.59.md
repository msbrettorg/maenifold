# T-238.59 — P2 Add global and per-workspace Teams config system

**Pipeline**: sdd

## Problem

Rust has a flat single-workspace config embedded in `maenifold.json`. Agency-cowork has a sophisticated `GlobalConfig` + `WorkspaceConfig` layering system that supports multiple workspaces with different keywords, reply prefixes, monitored conversations, and dispatch settings.

## Reference

- agency-cowork: `/Users/brett/src/agency-cowork/skills/teams/scripts/monitor/config.py` (616 LOC)
- `GlobalConfig` L144-161: identity, connection, workspaces map
- `WorkspaceConfig` L102-141: enabled, keyword, reply_prefix, monitored_conversations, dispatch
- `DispatchConfig` L71-86: PTY settings per workspace
- Rust target: `crates/maenifold-core/src/acp/config/teams_monitor.rs` and `tools/teams_monitor.rs`

## Required changes

1. Port `GlobalConfig` / `WorkspaceConfig` / `DispatchConfig` structs
2. Support multiple workspace entries with different keywords
3. Add workspace path normalization
4. Wire multi-workspace routing into supervisor message processing
5. Update MCP config tools to read/write the layered config

## Acceptance Criteria

- [ ] Multiple workspaces configurable with different keywords
- [ ] Per-workspace reply prefix, monitored conversations, dispatch settings
- [ ] Config round-trips through MCP tools
- [ ] `cargo build --release -p maenifold-cli` passes
