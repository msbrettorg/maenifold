## Problem

The gate task table on the Gate tab doesn't scroll. With 53 todo items the table extends past the viewport and content is unreachable. The table container uses `overflow-auto` but it's not constrained to the available height.

## Fix

Wrap GateTaskTable in shadcn `<ScrollArea>` with a height constraint (`h-full` or `max-h-[calc(100vh-...)]`). The table header should stay sticky while the body scrolls.

## Files

- `apps/desktop/src/components/GateTaskTable.vue` — wrap table in ScrollArea
- `apps/desktop/src/components/GateViewContent.vue` — ensure parent passes height constraint

## Acceptance Criteria

1. Table scrolls vertically when content exceeds viewport
2. Table header stays sticky at top during scroll
3. Uses shadcn ScrollArea, not raw overflow-auto
4. Verified in packaged Electron app
