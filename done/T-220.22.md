# T-220.22 - Mask Environment Secret Values

## Problem

Environment-variable values in settings are rendered as plain text, exposing likely tokens or API keys.

## Evidence

- `apps/desktop/src/components/SettingsConnectionKeys.vue:46-64` renders environment values as `type="text"`.
- Source: `docs/codebase-audit-2026-04-25.md#p2-8`.
- Parent sequential thinking session: `session-1777125506368-62098`.

## Acceptance Criteria

- [ ] Environment values whose keys contain `TOKEN`, `KEY`, `SECRET`, or `PASSWORD` are masked by default.
- [ ] Masked values can be explicitly revealed with accessible UI affordance.
- [ ] Revealing one value does not reveal unrelated values.
- [ ] Non-secret values remain readable where appropriate.
- [ ] `cd apps/desktop && npx vue-tsc --noEmit` succeeds.
