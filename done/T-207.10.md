# T-207.10 — Gateway startup wiring

## Problem

`serve_http_listener_with_shutdown()` passes `None` for the gateway parameter to `service()`. The StdioPool and ToolRoutingRegistry are never constructed. The gateway is dead code until this wiring lands.

## Change

In `crates/maenifold-core/src/mcp/http.rs`, `serve_http_listener_with_shutdown()`:

1. Read gateway-enabled servers from config: `config.mcp_servers.iter().filter(|s| s.is_gateway())`
2. Map to `StdioServerConfig` structs
3. If any gateway servers exist: `StdioPool::start(configs).await`
4. Get native tools from existing tool registry
5. Build `ToolRoutingRegistry::build(native_tools, &pool)`
6. Pass `Some((Arc::new(pool), Arc::new(registry)))` to `service()`
7. Shutdown pool on graceful shutdown

## Acceptance criteria

1. Gateway-enabled servers in `maenifold.json` get their tools proxied through `/mcp`
2. Non-gateway servers are unaffected
3. Pool construction errors are logged but don't prevent server startup
4. `cargo build --release -p maenifold-core` passes
