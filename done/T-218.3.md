# T-218.3 — Knowledge Tab Resizable Splitter

## Problem

The Knowledge tab has a fixed-width sidebar (note tree) and content pane. The sidebar width cannot be adjusted, and the note content overflows horizontally (see T-218.1).

## Solution

Add a draggable horizontal splitter between the sidebar and note content pane. Same pattern as T-218.2.

## Acceptance Criteria

- [ ] Draggable vertical divider between note tree sidebar and content pane
- [ ] Both panes resize proportionally when divider is dragged
- [ ] Split ratio persisted across tab switches and app restarts
- [ ] Minimum width enforced on both panes (e.g., 200px sidebar, 400px content)
- [ ] Cursor changes to `col-resize` on hover
- [ ] Note content text wraps within resized container (complements T-218.1)
- [ ] Verified via CDP in packaged Electron app
