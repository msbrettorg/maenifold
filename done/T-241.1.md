# T-241.1 — Onboarding wizard does not advance past step 1

**Pipeline**: sdd

## Problem

The onboarding wizard dialog renders correctly on first launch but clicking "Get started →" does not advance to step 2. The dialog remains on step 1 ("Welcome to maenifold"). Pressing Escape also does not dismiss it.

## Evidence

- CDP snapshot shows the dialog renders with 5 steps (Welcome, Daemon, Agent, Model, Finish)
- Steps 2-5 are disabled
- Clicking "Get started →" (ref e8) does not change the UI state
- Pressing Escape does not dismiss the dialog
- The Gate tab (user's actual destination) is inaccessible behind the modal

## Expected Behavior

- "Get started →" should advance to step 2 (Daemon connection check)
- OR: returning users with an existing config should skip onboarding entirely
- Escape should dismiss the dialog for users who want to skip

## Acceptance Criteria

- [ ] Onboarding wizard advances through all 5 steps when buttons are clicked
- [ ] Existing users with a valid `maenifold.json` skip onboarding
- [ ] Escape or a skip/close button dismisses the dialog

## Escalation

- Escalated: P1 → P0 by user directive 2026-04-27T16:00
- Reason: Blocks every app launch. User has reported it 3 times. This is a release blocker alongside T-241.7 (Teams E2E) and T-241.8 (Easter Eggs E2E).
- Existing users with a valid maenifold.json should SKIP onboarding entirely.
