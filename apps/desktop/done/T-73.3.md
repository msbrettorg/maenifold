## Description
Introduce draft/publish editing model into the workflow library store. Add draftDefinition ref (structuredClone of currentDefinition), isDirty computed, beginEditing(), discardDraft() actions. Make 4 step fields editable in WorkflowStepInspector.vue: name, description, requiresSequentialThinking (toggle), reasoning_effort (3-segment selector). Step ID remains read-only. Unsaved-changes guard on workflow switch. This is the foundation for all editing tasks.
