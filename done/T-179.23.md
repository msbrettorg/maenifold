# T-179.23 — Pipeline & workflow emoji → lucide + shadows

## Intent

Pipeline template cards and workflow node cards use emoji in body content. Replace with lucide-vue-next SVG icons and add shadow-8/border-card elevation to match agency-cowork card pattern.

## Cowork card pattern (mandatory)
```
rounded-[8px] border-[1.5px] border-border-card bg-bg-elevated p-3.5 transition-all hover:bg-bg-surface-hover
shadow-[var(--shadow-8)]
```

## Scope — 6 files

### 1. `apps/desktop/src/lib/pipeline-templates.ts`
- Change `icon` field type from emoji string to a string KEY (e.g., `'flask-conical'`, `'brain'`, `'pen-tool'`, `'globe'`, `'briefcase'`)
- Do NOT import Vue components in this .ts file — use string keys

### 2. `apps/desktop/src/components/TemplateGalleryCard.vue`

- Add to card wrapper: `shadow-[var(--shadow-8)] border-[1.5px] border-border-card`

### 3. `apps/desktop/src/components/WorkflowNodeCard.vue`
