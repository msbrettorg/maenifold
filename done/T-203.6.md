# T-203.6 — E2E validation with official example server

## Objective

Prove the full MCP Apps pipeline works end-to-end in the maenifold desktop app using an official example server from https://github.com/modelcontextprotocol/ext-apps/tree/main/examples.

## Method

1. Clone `modelcontextprotocol/ext-apps`
2. Run one of the simple example servers (e.g., `basic-server-vanillajs` or `basic-server-vue`)
3. Connect maenifold desktop to the example server as an MCP connection
4. Trigger the tool call (via chat or tool palette)
5. Verify:
   - Tool description shows `_meta.ui` metadata
   - Resource is fetched via `ui://` scheme
   - Sandboxed iframe renders inline in chat
   - App receives tool result (initial data displays)
   - App can call tools back (button click triggers round-trip)
   - Iframe tears down on conversation clear

## Acceptance criteria

1. At least one official example server renders and communicates bidirectionally
2. Security sandbox is enforced (app cannot access host DOM)
3. No console errors or Electron security warnings
4. Screenshot/recording of working app inline in chat
