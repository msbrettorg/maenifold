# T-218.37 — Gateway Startup Diagnostics

## Problem

Gateway startup can disable the whole gateway if pool startup, native registry load, consolidation, or routing registry build fails. In packaged use this can look like tools disappeared instead of a targeted server failure.

## Acceptance Criteria

- [ ] Gateway startup degrades per-server where possible instead of all-or-nothing
- [ ] UI/settings expose configured servers, started servers, failed servers, sanitized startup error, stderr tail, and exposed facade count
- [ ] A resource or native tool exposes gateway diagnostics when consolidation disables a server
- [ ] `tools/list` does not silently look healthy when all upstream gateway servers failed
- [ ] Packaged app verification covers one intentionally broken gateway server and one healthy server; healthy server remains available
