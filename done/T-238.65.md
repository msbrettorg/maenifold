# T-238.65 — P1 Add processing receipt message on Teams dispatch

**Pipeline**: sdd

## Problem

When a user sends a trigger message, there is no acknowledgment. ACP sessions can take minutes. Without a receipt, the user has no idea the bot received the message. Agency-cowork immediately replies with a "processing" indicator when `dispatch.send_receipt` is true.

## Reference

- agency-cowork: `/Users/brett/src/agency-cowork/skills/teams/scripts/monitor/message_handler.py` ~L1297 (receipt on dispatch start)
- Rust target: `crates/maenifold-core/src/teams/supervisor.rs`

## Required changes

1. After keyword match and before dispatch, send a receipt reply to the source conversation (e.g., "⏳ Processing...")
2. Make receipt configurable (default: enabled)
3. Receipt uses the same `send_reply()` path as final response

## Acceptance Criteria

- [ ] Receipt message sent immediately on dispatch start
- [ ] Receipt does not include raw prompt/user content (generic "⏳ Processing..." only)
- [ ] Receipt is configurable (on/off)
