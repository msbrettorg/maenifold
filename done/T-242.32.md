# T-242.32 — Restore /api/config/reload route handler

**Pipeline**: tdd

## Problem

`cargo test -p maenifold-core --lib` reports 1 failure on dev:

```
test api::routes::tests::reload_config_route_reports_partial_runtime_reload ... FAILED
```

The test at `crates/maenifold-core/src/api/routes_tests.rs:85` posts to `/api/config/reload` and expects HTTP 200 + a partial-reload report. The current `routes.rs` does not register that route, so the test gets 404.

## Background

> "Restored /api/config/reload route + handler (test routes_tests.rs:85 was failing pre-split; restoration aligns with constitutional no-localhost-auth model)."

The restoration was discarded by the dev reset, so the test fails again.

## Recovery

```
git show 5b88d6f9f -- crates/maenifold-core/src/api/routes.rs crates/maenifold-core/src/api/routes_config.rs
```

Then transplant just the route + handler into current source.
