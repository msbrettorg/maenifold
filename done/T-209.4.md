## Description

Create `pipeline-meta.sh` with the inner loop that:

1. Reads gate backlog (`gate status --root . --json`)
2. Selects ready tasks (lowest sprint number first)
3. For each task:
   a. Parse frontmatter (id, pipeline type, crate, file_scope, acceptance_criteria)
   b. Create git worktree
   c. Render pipeline template (substitute inputs into non-interpolatable fields)
   d. Submit to Pipeline MCP tool (or CLI: `maenifold tool Pipeline '...' --json`)
   e. Execute via `maenifold-pipeline-driver <session-id> "ambient prompt"`
   f. Parse final pipeline state
   g. If completed + all verdicts PASS: merge worktree, gate pass
   h. If failed: preserve worktree, gate fail
   i. Record metrics to `ralph/pipeline-meta/metrics/`
4. Bounded parallel execution via `xargs -P` or background jobs

## Shell patterns to reuse from ralph.sh/meta.sh

- Lockfile (prevent concurrent runs)
- Immutable file hashing
- Snapshot/restore
- Signal trapping (SIGTERM/SIGINT)
- Log file tee

## Acceptance Criteria

- Successfully executes a single gate task end-to-end using the SDD pipeline template
- Worktree created before pipeline, cleaned up after
- Gate transitions happen via pipeline tool nodes
- Metrics recorded per task (wall-clock, pipeline status, first-pass flag)
- Lockfile prevents concurrent runs
