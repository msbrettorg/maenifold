# T-179.21 — Remove breadcrumb slabs

## Intent

ProvenanceBreadcrumbs shows a fat Section Current header slab on Pipelines, Knowledge, Gate, and ThinkingTrace views when no session is loaded. Flagged P0 by both duo reviewers.

## Scope

**File:** apps/desktop/src/components/ProvenanceBreadcrumbs.vue

## Changes

Add a computed hasContent that checks whether there is anything worth showing:

const hasContent = computed(() => {
  return normalizedLinks.value.length > 0 || Boolean(props.currentLabel?.trim()) || Boolean(props.currentId?.trim());
});

Wrap the root div with v-if=hasContent so the component renders nothing when empty.

## Acceptance Criteria

1. When links is empty AND currentLabel is falsy AND currentId is falsy — renders nothing
2. When there IS content — renders normally
3. npx vue-tsc --noEmit passes
