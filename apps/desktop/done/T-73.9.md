## Description
Wire the "+ New Workflow" button in WorkflowBrowser.vue. Creates a blank workflow with a generated slug ID (e.g., "untitled-{timestamp}"), default name "Untitled Workflow", one placeholder step with a generated ID. Loads into draftDefinition for editing. Must save before it persists (uses T-73.7 save infrastructure). Unsaved-changes guard if current workflow is dirty.
