## Problem

The CopilotKit POC bridge (`poc/copilotkit/bridge/index.ts`) has two bugs found during interactive testing:

1. **Prompt extraction** — CopilotKit AG-UI sends user messages under `raw.body.messages` but the bridge only checked `raw.params.messages`. Fixed in this session but needs proper testing.

2. **`agent/connect` method** — CopilotKit sends `agent/connect` handshake requests that the bridge incorrectly routes into the prompt loop with empty text, causing `"prompt must contain at least one text block"` errors from the daemon. Partially fixed — needs to return proper AG-UI connect response.

3. **Info endpoint** — CopilotKit expects `{ version, mode, agents: { copilot: { description, capabilities } } }` from the info endpoint. Bridge was returning `{ name, version }`. Fixed in this session.

4. **CopilotKit version** — UI shows "v1.50 is now live!" nag. `package.json` has `^1.56.0` but `node_modules` may have older resolved version. Run `npm update` in `poc/copilotkit/app/`.

## Current state

The bridge now correctly extracts prompts and the daemon processes them (tool calls stream back, thinking chunks arrive). But the multi-turn conversation and rich rendering haven't been verified end-to-end with screenshots.
