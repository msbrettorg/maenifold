# T-179.26 — Settings cardization

## Intent

Settings sections float in open space. Wrap each in a proper card matching the cowork card pattern.

## Cowork card pattern
```html
<div class="rounded-[8px] border border-border-card bg-bg-elevated p-4">
  <!-- section header as subtle label -->
  <h3 class="mb-3 text-[11px] font-semibold uppercase tracking-wider text-text-tertiary">
    Section Title
  </h3>
  <!-- section content -->
</div>
```

## Scope — 5 files

Each of these files has a `<div class="section-header">` that should become the card header, and the section body should be wrapped in the card container.

### 1. `apps/desktop/src/components/SettingsConnection.vue`
- Wrap the entire section in the card div
- Convert existing `section-header` to the subtle uppercase label
- Ensure daemon status, URL input, and action buttons are inside the card

### 2. `apps/desktop/src/components/SettingsMaenifold.vue`
- Same card wrapper pattern
- Health status grid should be inside the card

### 3. `apps/desktop/src/components/SettingsConnectionAgents.vue`
- Wrap agent list in card
- Agent rows should have subtle hover: `hover:bg-bg-surface-hover rounded-[var(--radius-6)] transition-colors`

### 4. `apps/desktop/src/components/SettingsPreferences.vue`
- Wrap preferences in card

### 5. `apps/desktop/src/components/SettingsMcpServersList.vue`
- Wrap MCP servers list in card

## Common changes for all 5 files
Replace the existing `section-header` scoped CSS with:
```css
.section-header {
  margin-bottom: 0.75rem;
  font-size: 11px;
  font-weight: 600;
  text-transform: uppercase;
  letter-spacing: 0.06em;
  color: var(--text-tertiary);
}
```

Add card wrapper around each component's root content:
```html
<div class="rounded-[8px] border border-border-card bg-bg-elevated p-4">
  ...existing content...
</div>
```

## Acceptance Criteria
1. All 5 settings sections are wrapped in elevated cards with border-card
2. Section headers use subtle uppercase label pattern
3. Content doesn't float in open space
4. Agent rows have hover state
5. `npx vue-tsc --noEmit` passes
