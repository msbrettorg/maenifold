## Scope

## Important Notes
- Vue scoped styles use `[data-v-*]` attribute selectors. When extracting to external CSS files, styles lose scoping. Two approaches:
  1. Keep a `<style scoped>` block that `@import`s the files (Vue supports this)
  2. Use unique class naming to avoid conflicts
- Prefer approach 1 (`@import` inside `<style scoped>`) for minimal risk
- Test that styles don't leak to child components or lose specificity
