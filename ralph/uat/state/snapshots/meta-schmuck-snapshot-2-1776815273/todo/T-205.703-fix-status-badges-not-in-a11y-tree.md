# T-205.703 — Fix: Home page status badges missing from accessibility tree

**Pipeline**: test
**Pipeline Digest**: 16842feaee5604e196f8d0c4ddc8a6566bd538a1ad2d739bc956a9e49f123128

## Bug

The Home page status badges ("Connected" / "Daemon not connected" and "661 pending") are visible in the rendered UI but are completely absent from the accessibility tree. Screen readers and CDP automation tools cannot see or interact with these elements.

## Evidence

- Screenshot T-205.29-connection-banner.png shows "● Connected" and "○ 661 pending" badges
- `agent-browser snapshot -i` returns NO elements matching these badges
- The entire status area between the nav cards and the text input is invisible to assistive technology

## Found During

UAT T-205.29 interactive CDP testing.

## Acceptance

- Status badges exposed as `status` or `region` role in the accessibility tree
- Screen readers can announce connection state and pending count
- agent-browser snapshot can see and interact with these elements
