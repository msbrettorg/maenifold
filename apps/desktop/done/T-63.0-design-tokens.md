# T-63.0 — Design System Tokens + Shared CSS

**Requirement**: FR-1
**Test Cases**: TC-1, TC-2
**Repo**: pipeline-ui
**Component**: src/App.vue

## Context

Sprint T-62 shipped 6 components without a design system. Result: 13 distinct font sizes, 5 button systems, 3 conflicting status color maps, 3 input styles, zero focus rings, mixed px/rem. Every subsequent spec in T-63 depends on these tokens existing.

## Acceptance Criteria

1. Add CSS custom properties to `App.vue` `:root` block:
   - **Node accent colors**: `--color-node-workflow: #2196f3`, `--color-node-prompt: #9c27b0`, `--color-node-thinking: #ff9800`, `--color-node-tool: #00897b`
   - **Status palette**: `--color-status-pending: #9e9e9e`, `--color-status-active: #2196f3`, `--color-status-completed: #4caf50`, `--color-status-abandoned: #f44336`, `--color-status-stuck: #ff9800`, `--color-status-ready: #03a9f4`
   - **Surface colors**: `--bg-main`, `--bg-panel`, `--bg-surface`, `--bg-input`, `--bg-code`, `--bg-error`, `--bg-warning`
   - **Text colors**: `--text-primary`, `--text-secondary`, `--text-muted`, `--text-error`, `--text-code`, `--text-on-accent`
   - **Border colors**: `--border-default`, `--border-focus`, `--border-error`
   - **Spacing scale** (4px base): `--space-1: 4px` through `--space-8: 32px`
   - **Type scale** (5 steps): `--text-xs: 0.75rem`, `--text-sm: 0.875rem`, `--text-base: 1rem`, `--text-lg: 1.125rem`, `--text-xl: 1.25rem`
   - **Radius scale**: `--radius-sm: 4px`, `--radius-md: 6px`, `--radius-lg: 8px`, `--radius-xl: 12px`
   - **Transition**: `--transition-fast: 150ms ease`, `--transition-normal: 250ms ease`
   - **Font stacks**: `--font-sans`, `--font-mono`
2. Add dark mode overrides in `@media (prefers-color-scheme: dark)` for all surface, text, and border colors
3. Add shared component classes in a `<style>` block (NOT scoped):
   - `.btn` base: inline-flex, align-center, gap, padding from space tokens, radius-md, font-sm, transition-fast, cursor-pointer, border none
   - `.btn-primary`, `.btn-success`, `.btn-danger`, `.btn-pause`, `.btn-ghost`, `.btn-outline-danger` variants
   - `.btn:disabled` and `.btn--busy` states (opacity, pointer-events)
   - `.field-input`, `.field-select`, `.field-textarea` bases: bg-input, border-default, radius-md, padding, font-sm, transition-fast
   - `.field-input:focus-visible`, `.field-select:focus-visible`, `.field-textarea:focus-visible`: outline 2px solid var(--border-focus), outline-offset 2px
   - `.status-dot` base (8px circle) + `.status-dot--pending`, `.status-dot--active`, etc. using status palette
   - `.panel` base: bg-panel, border-default, radius-lg, padding space-4
4. Typecheck passes: `npx vue-tsc --noEmit`
