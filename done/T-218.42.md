# T-218.42 — Teams Settings Tab in SettingsView

## Problem

`TeamsSettings.vue` exists under `components/teams/` and is fully implemented (keyword config, sender allow/deny lists, cooldown, dispatch agent selector, enable/disable toggle). However, `SettingsView.vue` does not import or render it — the settings window has no Teams tab. The component is orphaned.

## Solution

Add a `teams` entry to the `sections` array in `SettingsView.vue`, import `TeamsSettings`, and render it inside a `<TabsContent value="teams">` block.

## Key Files

- `apps/desktop/src/components/SettingsView.vue`
- `apps/desktop/src/components/teams/TeamsSettings.vue`

## Acceptance Criteria

- Settings window shows a "Teams" tab with description "Configure Teams monitor keywords, senders, and dispatch."
- Clicking the tab renders the existing `TeamsSettings` component.
- All other settings tabs remain unchanged.
- `npx vue-tsc --noEmit` passes.
