# T-220.15 - Constrain ACP Filesystem Client Paths

## Problem

ACP filesystem client methods accept paths without enforcing absolute-path, containment, or symlink policy, and writes silently create parents.

## Evidence

- `crates/maenifold-jockey/src/acp/client.rs:225-263` reads `args.path` directly and creates parent directories before writes.
- `crates/maenifold-jockey/src/acp/session/cold_start_helpers.rs:10-16` advertises filesystem and terminal capabilities by default.
- Source: `docs/codebase-audit-2026-04-25.md#p2-1`.
- Parent sequential thinking session: `session-1777125506368-62098`.

## Acceptance Criteria

- [ ] ACP filesystem handlers reject non-absolute paths.
- [ ] Filesystem access is contained under the session cwd/workspace root where appropriate.
- [ ] Symlink traversal behavior is explicit and tested.
- [ ] Parent directory creation requires explicit request semantics instead of happening silently.
- [ ] `cargo build --release -p maenifold-cli` succeeds.
